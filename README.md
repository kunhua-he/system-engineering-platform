# 系统级支持库与模块库

独立于任何业务项目的系统级工程底座：包声明、能力契约、加载器、依赖解析、
能力搜索、说明书生成、统一验证。只依赖 Python 标准库。

## 架构

```text
系统级支持库与模块库（本目录，零业务依赖）     ← 当前只开发这一层
    ↓
项目适配层（后建）
    ↓
具体项目代码（最后迁移）
```

## 唯一调用边界

```text
正式代码
  → 模块公开能力或支持库公开能力
  → 支持库中文原子能力
  → 外部适配层/提供者
  → 数据库、服务器、DLL、操作系统、第三方库或外部协议
```

支持库负责原子能力和底层转换，模块负责组合流程，项目适配层负责项目配置、依赖锁和外部资源绑定，正式代码只处理公开结果。数据库联通、服务器健康、DLL 存在性和外部协议检查都必须在适配层完成，不得泄漏到底层实现或正式代码。

## 目录

| 目录 | 职责 |
|------|------|
| 公共契约/ | 包声明、能力契约、基础类型、错误结构、生命周期、版本规则 |
| 支持库/后端/ | 原子支持库：文件系统、文本处理、数据集合、时间日期、数据交换 |
| 支持库/前端/ | 平台无关描述模型：窗口、基础组件、状态、文件选择、资源 |
| 模块库/ | 组合支持库：文件管理、文档读取、简单窗口、_模板 |
| 加载器/ | 包发现、包安装、依赖解析、提供者选择、生命周期管理 |
| 能力搜索器/ | 按能力声明搜索（不扫描业务代码） |
| 说明书生成器/ | 从包声明生成 Markdown 说明书（工程缓存/说明书/） |
| 验证器/ | 统一验证（结构/契约/资产/装配/加载器/示例项目） |
| 测试中心/ | 独立测试环境（标准库 unittest） |
| 示例项目/ | 最小运行样板（装配→搜索→调用→验证全链路） |
| 工程缓存/ | 可删除可重新生成的生成物 |

## 边界铁律

- 支持库只提供原子能力；模块只组合支持库；加载器只负责发现/解析/装载/生命周期。
- 模块只能经支持库公开入口（`__init__.py`）调用，禁止深入实现目录。
- 只允许 Python 标准库；第三方库必须封装在 `支持库/适配层/`。
- 严禁导入、引用、读取任何业务项目代码、数据库、配置与运行数据。
- 外部适配层只能把外部技术转换为公共支持库契约，不得包含业务流程。
- 项目适配层只能绑定项目环境，不得复制支持库和模块实现。

## 运行测试

```bash
cd ~/Documents/Agent/PHP/系统级支持库
python3.14 -m py_compile $(find . -type f -name '*.py' -not -path './工程缓存/*')
python3.14 测试中心/运行测试.py
python3.14 测试中心/运行测试.py --范围 慢速
python3.14 测试中心/运行测试.py --范围 全部
```

> **唯一验收入口是 `python3.14 测试中心/运行测试.py`**。默认执行常规层；
> `--范围 慢速` 执行真实强杀、压力和外部提供者场景；`--范围 全部` 顺序执行
> 两层。零测试、导入失败、失败和跳过门禁均已内置。`python3.14 -m unittest
> discover -s 测试中心 -p '测试_*.py'`
> 因 unittest 的 VALID_MODULE_NAME 只认 ASCII 标识符、中文测试文件名
> 被跳过（实测 NO TESTS RAN），已废弃为主验收命令。
> 测试中心/__init__.py 提供 load_tests 协议加载全部中文测试文件。
