## 危险路径护栏（相对安全底线，防「系统性破坏」）

**为什么有这一层**：《系统哲学》第 9 条 5 项「相对安全，不做绝对安全」（华哥 2026-09-16 裁定）——
底座面向本地私有部署，安全是**相对安全**；全通用的标准是**用户拥有绝对自主权**；
但**底线护栏（防止「系统性破坏」）属于必须项，优先级高于用户自主权**。
第三份外部审计 P0-03 指出：本包 读取文件/写入文件/删除文件 原先只做 `Path(路径)` 转换、
无任何危险路径拦截，可被恶意或误操作覆盖 `~/.zshrc`、`~/.ssh/authorized_keys`、`/etc/hosts`，
属「系统性破坏」范畴 → 本层据此落地。

**它是什么、不是什么**：这是**护栏式**（默认拒绝危险路径、可显式放行），不是**牢笼式**
（不设「工作区根目录」、不限制普通路径）。除危险路径判据外，任何路径照常执行，能力不萎缩。

### 判据全文（命中任意一条即视为危险路径）

一、系统目录（目录本身及其全部子路径）
    `/etc`、`/System`、`/usr`、`/bin`、`/sbin`、`/var/db`、
    `/Library/LaunchDaemons`、`/Library/LaunchAgents`、`/dev`、`/boot`，
    以及 macOS 解析软链接后的真实位置别名 `/private/etc`、`/private/System`、`/private/var/db`。

二、用户凭据与启动配置（家目录内）
    1. 凭据目录整棵：`~/.ssh/**`（含 `~/.ssh` 本目录）；
    2. 钥匙串目录整棵：`~/Library/Keychains/**`（含目录本身）；
    3. shell 启动配置单文件（精确文件名，大小写不敏感）：
       `~/.zshrc`、`~/.zprofile`、`~/.zshenv`、`~/.zlogin`、`~/.zlogout`、
       `~/.bashrc`、`~/.bash_profile`、`~/.bash_login`、`~/.bash_logout`、
       `~/.profile`、`~/.cshrc`、`~/.tcshrc`、`~/.inputrc`；
    4. `~/.config/` 下的 shell 配置：整棵目录 `~/.config/fish/**`、`~/.config/zsh/**`、
       `~/.config/bash/**`（含目录本身），以及 `~/.config/` 直接子文件中的 shell 配置单文件（同第 3 条名单）。

三、任何指向上述位置的软链接父路径
    判定同时用「未解析的绝对路径」与 `resolve()` 后的真实路径两份候选：
    目标本身是软链接、或任一祖先目录是指向上述位置的软链接，都会在解析后命中，
    防止 `ln -s /etc XXX && 写入文件(XXX/hosts)` 这类软链接绕过。

### 拦什么、不拦什么

- **拦**（会改变系统状态的动作，默认拒绝）：写入文件、追加写入、删除文件、移动文件（源+目标两端）、
  复制文件（目标端）、创建目录、压缩文件（目标端）、解压文件（目标端）、清理全部临时资源（逐条登记资源）。
- **不拦**（只读，不属系统性破坏）：读取文件、列出目录、判断存在、获取大小、获取修改时间、
  获取文件权限、读取二进制文件、读取文件头部字节、搜索文件、查找祖先目录、登记临时资源。
- **不拦**（普通路径，护栏不介入）：家目录普通文件/目录、项目目录、`/tmp`、`/var/tmp`、
  `~/Library/Application Support/**`、用户自建任意工作目录。

### 显式放行（用户绝对自主权不被剥夺）

上列「拦」的能力都带可选参数 `允许危险路径`（逻辑型，默认 `假`）：

- 不传或 `假`：命中判据即返回**明确失败**，错误码 `危险路径`，说明含
  「目标路径命中危险路径护栏：<命中哪一条>；如确需操作，请显式传 允许危险路径=真」；
- 传 `真`：跳过护栏、照常执行，并在返回结果里**如实标注**「已按调用方显式放行危险路径」
  （`值` 为布尔的能力升级为 `{成功, 危险路径放行, 路径}`；`值` 为字典的能力追加 `危险路径放行` 键）；
- `允许危险路径` 传非逻辑型：`参数不合法`（不静默按假拒绝、也不静默按真放行）。

判据与实现集中在同包 `实现/危险路径.py`（单一事实源，含判据全文与代码注释）；
本层不做「更严边界」——需要更严由调用方在更上层传参选择，不在本层偷偷收紧。
