| 起始行 | 整数型 | 否 | None | 行窗口起始（须与结束行成对） |
| 结束行 | 整数型 | 否 | None | 行窗口结束（含） |
| 预期旧文本摘要 | 文本型 | 否 |  | 旧文本 SHA256 |

| 新文本 | 文本型 | 是 | None | 替换后的文本 |
| 根目录 | 文本型 | 否 |  | 用于计算相对路径 |
| 起始行 | 整数型 | 否 | None | 行窗口起始 |
| 结束行 | 整数型 | 否 | None | 行窗口结束 |
| 预期旧文本摘要 | 文本型 | 否 |  | 旧文本 SHA256 |
| 预期文件摘要 | 文本型 | 否 |  | 整文件 SHA256（乐观锁） |
| 写入 | 逻辑型 | 否 | True | 假=只预览差异不落盘 |
