# 嵌入缓存支持库

## 职责
文本嵌入向量的缓存读写：按 文本哈希 + 模型名 + 提供者 缓存与读取嵌入向量。
只负责缓存读写，**不调用嵌入模型**；嵌入生成由调用方/提供者完成。

## 存储
SQLite，默认 `工程缓存/嵌入缓存.db`（可由 数据库路径 参数覆盖）。表 `嵌入缓存`，缓存键 = `提供者|模型名|sha256(文本)`。

## 能力
| 能力 | 说明 |
|---|---|
| `嵌入缓存.查询嵌入` | 查询缓存向量，命中 `{命中=true, 向量=[...]}`，未命中 `{命中=false, 向量=null}` |
| `嵌入缓存.存储嵌入` | 存储一条缓存，同键覆盖 |
| `嵌入缓存.统计缓存` | 返回缓存条目数 |
| `嵌入缓存.清空缓存` | 清空全部缓存条目 |

## 调用
```bash
curl -X POST http://127.0.0.1:8866/网关/调用 -H 'Content-Type: application/json' \
  -d '{"能力id":"嵌入缓存.查询嵌入","参数":{"文本":"你好","模型名":"bge-m3","提供者":"本地"}}'
```

## 边界
- 只依赖 Python 标准库（sqlite3/hashlib/json），无第三方依赖。
- 不调用任何嵌入模型、不访问网络。
- 缓存删除只动缓存表，不触碰业务数据。
