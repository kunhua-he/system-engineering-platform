# 数据集合支持库（后端纯标准库原子能力）

原子集合能力：列表、字典与集合的常用操作。只依赖 Python 标准库，
无第三方依赖。全部公开能力返回统一结果（成功/值/错误/错误码），
不泄漏可变容器内部状态（一律返回新容器，原容器不变）。

## 公开能力

- 列表：列表添加 / 列表移除 / 列表排序 / 列表查找（未找到返回 -1）。
- 字典：字典设置 / 字典获取（键不存在返回默认值）。
- 集合：集合取并集 / 集合取交集。
- 高级：统计数量 / 按字段查找 / 过滤 / 映射转换 / 按字段排序。

## 调用方式

```python
from 支持库.后端.数据集合 import 列表添加, 字典获取, 按字段排序

结果 = 列表添加(["甲"], "乙")
if 结果.成功:
    新列表 = 结果.值

结果 = 字典获取({"甲": 1}, "乙", 默认值=0)
if 结果.成功:
    值 = 结果.值

结果 = 按字段排序([{"名称": "乙"}, {"名称": "甲"}], "名称")
if 结果.成功:
    有序列表 = 结果.值
```

## 错误码

参数不合法。

## 边界

- 参数缺失、类型非法（列表/字典/映射结构不符）返回 参数不合法；
  不吞异常、不以成功形状伪装失败。
- 实现只经包级中文入口（__init__.py）暴露；禁止深入 实现/ 目录。
