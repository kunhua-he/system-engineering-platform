## 公开命令

### `数据交换.序列化JSON`

- 名称：序列化JSON
- 返回：`结果型`
- 说明：把字典或列表数据序列化为 JSON 文本
- 参数：
  - `数据`；字典型；必填；要序列化的数据（字典或列表，须可 JSON 序列化）
- 调用入口：`__init__.py`（只能经包级入口调用）
- 返回外壳：成功返回 `成功=true, 值=实际值`；失败返回 `成功=false, 错误码, 错误说明`。

### `数据交换.反序列化JSON`

- 名称：反序列化JSON
- 返回：`结果型`
- 说明：把 JSON 文本解析为字典或列表
- 参数：
  - `文本型`；文本型；必填；JSON 文本
- 调用入口：`__init__.py`（只能经包级入口调用）
- 返回外壳：成功返回 `成功=true, 值=实际值`；失败返回 `成功=false, 错误码, 错误说明`。

### `数据交换.序列化CSV`

- 名称：序列化CSV
- 返回：`结果型`
- 说明：把行列表序列化为 CSV 文本
- 参数：
  - `行列表`；列表型；必填；行列表（每行为单元格列表）
- 调用入口：`__init__.py`（只能经包级入口调用）
- 返回外壳：成功返回 `成功=true, 值=实际值`；失败返回 `成功=false, 错误码, 错误说明`。

### `数据交换.反序列化CSV`

- 名称：反序列化CSV
- 返回：`结果型`
- 说明：把 CSV 文本解析为行列表
- 参数：
  - `文本型`；文本型；必填；CSV 文本
- 调用入口：`__init__.py`（只能经包级入口调用）
- 返回外壳：成功返回 `成功=true, 值=实际值`；失败返回 `成功=false, 错误码, 错误说明`。
