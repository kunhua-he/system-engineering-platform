# 重排服务支持库

## 职责
候选文档相关性重排：按查询对候选文档打分排序。

## 能力
| 能力 | 说明 |
|---|---|
| `重排服务.重排` | 重排候选文档，返回 文档+得分+原索引 |
| `重排服务.检查可用性` | 返回实现可用性 |

## 调用
```bash
curl -X POST http://127.0.0.1:8866/网关/调用 -H 'Content-Type: application/json' \\
  -d '{"能力id":"重排服务.重排","参数":{"查询":"祛斑","文档列表":["祛斑方案","美白"]}}'
```

## 边界
- 默认标准库词法实现（中文二元组+英文词），无第三方依赖、不调用模型。
- 模型重排提供者后续可插拔（接口冻结、内核可升级）。
