## 组件规范支持库.生成完整性摘要（生成完整性摘要）

**说明**：按唯一生成器口径计算正式包的文件清单 sha256 摘要数据（只计算不写盘）

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 包目录 | 文本型 | 是 | | 要生成摘要的正式包目录 |
| 包id | 文本型 | 否 | | 缺省时从目标包 包声明.json 读取 |
| 版本 | 文本型 | 否 | | 缺省时从目标包 包声明.json 读取 |

**返回结构**：结果型（统一结果：成功/值/错误）；值为摘要字典
（`包id`/`版本`/`摘要算法`/`文件清单[{路径, sha256}]`/`能力数`/`能力清单`/`能力定义摘要`）
**错误码**：参数不合法、包目录不存在、包声明不可读、包无正式文件

**调用示例**：

```python
from 支持库.后端.组件规范支持库 import 生成完整性摘要
摘要 = 生成完整性摘要(包目录="支持库/后端/组件规范支持库")
```

**验证状态**：已纳入验证场景：组件规范.模板生成到摘要闭环正向HTTP

## 组件规范支持库.生成模块模板（生成模块模板）

**说明**：按 模块名/类型/能力清单/依赖能力清单 生成模块包骨架与定向测试骨架；已存在一律拒绝覆盖

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 模块名 | 文本型 | 是 | | 中文/字母/数字/下划线，1-40 字 |
| 类型 | 文本型 | 否 | 基础模块 | 基础模块 或 功能模块 |
| 能力清单 | 列表型 | 是 | | `{名称, 参数, 返回, 说明}` 条目列表 |
| 依赖能力清单 | 列表型 | 否 | [] | `{能力, 版本}` 条目；须在支持库有提供者 |
| 系统根 | 文本型 | 否 | | 缺省按包位置向上定位 |
| 模块库根 | 文本型 | 否 | | 缺省 系统根/模块库 |
| 测试中心根 | 文本型 | 否 | | 缺省 系统根/测试中心 |

**返回结构**：结果型；值为 `{模块目录, 测试骨架, 文件数}`
**错误码**：参数不合法、参数类型不合法、类型不合法、能力重复、无提供者、路径逃逸、已存在

```python
    "模块名": "示例模块", "类型": "基础模块",
    "能力清单": [{"名称": "示例能力", "参数": [], "返回": "结果", "说明": "示例"}],
})
```

## 同入口导出的内部原子实现（非能力，供底座内部与测试直接调用）

`生成并写入完整性摘要`（写盘版，供模板生成器内部使用）、`扫描正式包`、`计算文件摘要`、`是否应当收录`、
`迁移旧格式摘要`、`摘要文件名`、`校验组件规范`、`组件类型表`、`九要素`、`规范校验结果`、
`生成支持库模板`、`生成技能模板`、`生成说明书`、`生成说明书文本`、`校验输出目标`、
`生成快照清单模板`、`校验快照模板`、`快照清单文件名`、`快照摘要文件名`、`激活指针文件名`。

**命名澄清**：`生成完整性摘要` 是**只计算不写盘**的唯一生成器；写盘版在入口叫 `生成并写入完整性摘要`
（原 `开发工具/组件规范/组件规范.py::生成完整性摘要`），二者同算法、形状一致，改名只为消歧。
