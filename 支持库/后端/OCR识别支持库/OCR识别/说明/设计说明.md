## OCR识别支持库.OCR识别.识别图片（识别图片）

**说明**：图片 OCR 识别：图片路径与图片字节二选一；文本模式返回 {文本}，词级数据模式返回 {词列表}

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 图片路径 | 文本型 | 否 | None | 图片文件绝对路径（与图片字节二选一） |
| 图片字节 | 字节集型 | 否 | None | 图片二进制内容（与图片路径二选一，经临时目录落盘后识别，即时清理） |
| 语言 | 文本型 | 否 | eng | tesseract 语言码，如 eng/chi_sim；缺失时返回 语言包缺失 |
| 词级数据 | 逻辑型 | 否 | False | true 返回词级数据 {词列表}（TSV 解析），false 返回 {文本} |
| 超时秒 | 双精度数型 | 否 | 60 | 外部进程超时（超过强杀进程组返回 超时） |
| 取消事件 | 资源引用型 | 否 | None | 取消令牌（threading.Event）；跨宿主调用置 None，取消语义经 取消令牌id 文本透传 |
| 输出上限字节 | 双精度数型 | 否 | 33554432 | stdout 输出上限，超过返回 超出限制 |
| 命令路径 | 文本型 | 否 | None | tesseract 可执行文件路径；优先于环境变量 Tesseract提供者_命令路径，其次默认 PATH 探测。显式路径不存在 → 工具缺失；不可执行 → 命令失败。错误消息与日志不泄露路径细节 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 文件不存在 |
| 工具缺失 |
| 命令失败 |
| 语言包缺失 |
| 识别失败 |
| 进程崩溃 |
| 超时 |
| 取消 |
| 超出限制 |
| 提供者不可用 |

**调用示例**：

```python
OCR识别支持库.OCR识别.识别图片(图片路径=值, 图片字节=值, 语言=值, 词级数据=值, 超时秒=值, 取消事件=值, 输出上限字节=值, 命令路径=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：支持库.资产验证（资产）、支持库.能力契约验证（契约）
