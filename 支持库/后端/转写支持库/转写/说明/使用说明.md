# MLX Whisper 转写提供者使用说明

## 定位

把 MLX Whisper（mlx_whisper，Apple Silicon 本地语音转写）隔离到**独立子进程**执行。
平台主进程、测试器和后端绝不加载 mlx_whisper；mlx_whisper 只在
实现/子进程入口.py 的隔离子进程内加载，崩溃不影响主进程。

只封装真实需要的 3 个能力（分组 **转写**）：

| 能力id | 功能 | 成功值 |
|---|---|---|
| 转写.检查可用性 | 模型是否配置/转写是否可用 | {可用, 模型名, 模型版本} |
| 转写.转写音频文件 | 音频文件转写为文本 | {文本, 语言, 模型名} |
| 转写.获取模型版本 | 模型与库版本 | {模型名, 模型版本} |

## 模型配置（禁止硬编码）

模型路径/模型名来自配置，优先级：**配置对象 > 环境变量**：

| 环境变量 | 含义 |
|---|---|
| MLXWhisper提供者_模型路径 | 本地模型目录绝对路径 |
| MLXWhisper提供者_模型名 | 模型名（如 mlx-community/whisper-tiny） |

配置对象传参示例（转写/检查/版本 通用）：

```python
转写音频文件("音频.wav", 配置={"模型路径": "/路径/模型目录"})
```

两者都为空 → **未配置模型**（如实返回，绝不伪装可用、绝不模拟转写成功）。

## 架构

```text
主进程调用者
  → MLXWhisper提供者.检查可用性 / 转写音频文件 / 获取模型版本
    → 主进程判定 未配置模型/模型缺失（配置与目录检查）
    → 启动一次性子进程（独立进程组，cwd=平台根）
      → 实现/子进程入口.py（内部才加载 mlx_whisper）
        → stdin 一行 JSON 请求，stdout 一行 JSON 响应
        → 完成后 os._exit(0)
```

转写循环内轮询：超时、取消判断（转写参数 取消判断 返回真 → 取消）、
输出上限（16MB）、进程退出；进程组 SIGTERM→SIGKILL 强杀回收，无残留。

## 生命周期覆盖

| 场景 | 行为 |
|---|---|
| 未配置模型 | 返回 未配置模型（如实，不伪装可用） |
| 模型目录缺失 | 返回 模型缺失 |
| 启动失败/库被禁用 | 返回 提供者不可用（可重试） |
| 执行超时 | 进程组 SIGTERM→SIGKILL 强杀，返回 超时（可重试） |
| 取消判断为真 | 进程组强杀，返回 取消 |
| 子进程崩溃/非零退出/无效响应 | 返回 进程崩溃（可重试） |
| 转写库报错/无文本 | 返回 转写失败 |
| 输出超限 | 返回 超出限制 |
| 停止/残留清理 | 每次调用结束后确保进程组终止，无残留进程/文件 |

## 模拟提供者不可用（测试用依赖注入）

禁止修改 sys.modules。通过环境变量让子进程按需禁用库：

```bash
MLXWhisper提供者_禁用库=mlx_whisper   # 子进程内不加载 → 提供者不可用
```

测试中使用 `mock.patch.dict(os.environ, {...})` 注入即可。

## 错误码

| 错误码 | 含义 |
|---|---|
| 未配置模型 | 模型路径与模型名均为空（如实返回，禁止模拟成功） |
| 模型缺失 | 配置了模型路径但目录不存在 |
| 转写失败 | mlx_whisper 转写报错或未返回文本 |
| 超时 | 子进程执行超过超时秒（可重试） |
| 取消 | 调用方取消判断为真，转写被终止 |
| 进程崩溃 | 子进程异常退出或返回无效响应（可重试） |
| 提供者不可用 | 子进程启动失败或 mlx_whisper 不可用（可重试） |
| 超出限制 | 子进程输出超过上限 |
| 参数不合法 | 文件路径等参数非法 |
| 文件不存在 | 音频文件不存在 |
