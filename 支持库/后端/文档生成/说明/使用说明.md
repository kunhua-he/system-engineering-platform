# 文档生成支持库使用说明

## 定位

四格式（DOCX/XLSX/PPTX/PDF）原子生成能力。生成后强制签名校验，
产物可信才返回；所有错误转为统一结果（成功/值/错误码/错误说明）。

## 能力

| 能力 | 输入 | 返回 |
|---|---|---|
| 生成DOCX | 参数 dict：`内容块列表` | 结果[生成产物] |
| 生成XLSX | 参数 dict：`工作表列表` | 结果[生成产物] |
| 生成PPTX | 参数 dict：`幻灯片列表` | 结果[生成产物] |
| 生成PDF | 参数 dict：`内容块列表` | 结果[生成产物] |
| 校验签名 | 格式、字节 | 结果 |

生成产物 = {格式, 字节, 媒体类型, 摘要(sha256), 诊断, 附加}；
附加含 提供者版本、生成耗时秒、字节数、签名校验结论。

## 参数结构（与 V3 Office生成器 兼容的中文键）

```python
DOCX参数 = {
    "内容块列表": [
        {"类型": "标题", "文本": "标题", "级别": 1},
        {"类型": "段落", "文本": "正文", "加粗": True, "对齐": "center"},
        {"类型": "表格", "表头": ["列甲", "列乙"], "行": [["值1", "值2"]]},
        {"类型": "分页"},
    ]
}
XLSX参数 = {"工作表列表": [{"表名": "数据表", "列": ["姓名", "数量"], "行": [["张三", 3]]}]}
PPTX参数 = {"幻灯片列表": [{"标题": "演示标题", "要点": ["要点一"], "备注": "备注"}]}
PDF参数 = {"内容块列表": [{"类型": "标题", "文本": "PDF标题"}, {"类型": "段落", "文本": "中文正文"}]}
```

## 调用示例

```python
from 支持库.后端.文档生成 import 生成DOCX, 生成PDF, 校验签名

结果 = 生成DOCX({"内容块列表": [{"类型": "段落", "文本": "你好"}]})
if 结果.成功:
    产物 = 结果.值
    字节 = 产物.字节            # bytes
    媒体类型 = 产物.媒体类型      # application/vnd...wordprocessingml.document
    摘要 = 产物.摘要            # sha256 hex
    版本表 = 产物.附加["提供者版本"]  # {"python-docx": "1.2.0"}
    耗时秒 = 产物.附加["生成耗时秒"]
```

## 错误码

| 错误码 | 含义 |
|---|---|
| 提供者不可用 | 对应第三方库未安装（python-docx/openpyxl/python-pptx/reportlab） |
| 参数不合法 | 参数非字典、内容块列表/工作表列表/幻灯片列表为空或无可渲染块 |
| 生成失败 | 生成异常、结果为空、签名校验未通过 |

## 签名校验规则

- docx：有效 ZIP + `[Content_Types].xml` + `word/document.xml`
- xlsx：有效 ZIP + `[Content_Types].xml` + `xl/workbook.xml`
- pptx：有效 ZIP + `[Content_Types].xml` + `ppt/presentation.xml`
- pdf：`%PDF` 头 + `%%EOF` 尾 + 可重新打开（fitz 优先，pdfplumber 兜底）
