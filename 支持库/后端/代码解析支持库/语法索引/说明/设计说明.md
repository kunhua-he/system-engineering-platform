## 第三方边界（tree-sitter）

tree-sitter 只归 **`支持库.适配层.TreeSitter提供者`**：本库不导入 `tree_sitter` /
`tree_sitter_typescript`，只消费它的**中性语法树**（中文节点种类 如 导入语句/类声明/调用表达式，
中文字段名 如 来源/名称/正文/调用目标），第三方 grammar 英文类型名不出适配层。

- 边界这么切：解析与节点模型是第三方事实（适配层的活）；「遍历哪些节点、产出哪类语法事实」
  是业务语义（本库的活）。本库的函数体里因此只有中文种类判定，没有第三方 API 调用。
- 提供者不可用（未安装 / 解析器构造失败）：本库退回**正则降级**（纯语法，只出导入与
  platform.modules.call 调用），`解析器` 字段如实标注 `正则降级`；降级由本库决定，提供者只报不可用。
- 迁移前本库在实现里直连第三方（依赖门禁报两条「第三方直连」违规）；迁移只搬边界，不改行为：
  同一批样本（含仓库自带验证场景的 TS/Vue 文本、破损源码、批量混合语法集）修前/修后输出逐字节一致。
