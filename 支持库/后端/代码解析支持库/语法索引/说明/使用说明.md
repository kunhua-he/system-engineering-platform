# 语法索引（支持库.后端.代码解析支持库.语法索引）

- 类型：支持库
- 版本：1.0.3
- 说明：代码语法索引原子能力：ast 解析 Python、tree-sitter 解析 TypeScript/Vue、批量分派解析。只产出有序语法事实（导入/符号/调用/字符串/类属性），不感知项目目录、不判定跨模块、不规范化表名；tree-sitter 不可用时正则降级。tree-sitter 第三方边界由 支持库.适配层.TreeSitter提供者 承载：本库只消费它的中性语法树（中文节点种类 + 中文字段名），不导入第三方。
- 入口：__init__.py
- 权威分工：**调用口径以本文为准**（能力/参数/返回/错误码/调用示例，由能力契约生成）；
  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。

## 能力
### 解析Python语法（`代码解析支持库.语法索引.解析Python语法`）
- 版本：1.0.0
- 一句话说明：ast 解析 Python 源码，产出导入/符号/调用/字符串型类属性四类有序语法事实，每条事实带同文件内跨类目单调递增的事件序号。符号只收集模块级与类体直接子节点（函数体内嵌套定义不收集）；调用与类属性深入函数体并补扫模块级顶层
- 所属支持库或模块：支持库.后端.代码解析支持库.语法索引
- 参数列表：代码文本:文本型
- 必填参数：代码文本
- 可选参数：无
- 返回结构：{'类型': '结果型', '值结构': {'导入列表': '有序：[{序号,路径,导入名,行号}]；from 相对导入（module 为空）不产出', '符号列表': '有序：[{序号,名称,类别,行号,结束行号}]，类别 class/function，类内函数名为 类名.函数名', '调用列表': '有序：[{序号,函数名,行号,位置字符串:[{序号,值}],关键字字符串:[{名称,值}],所在函数}]，所在函数为外层函数全名或 null', '类属性列表': '有序：[{序号,名称,值,行号}]，仅目标为简单名字且值为字符串常量的赋值；调用方按此还原原遍历顺序', '序号': '同一文件内跨全部类目单调递增的事件序号；按序号合并回放可复现原遍历的符号入表时序与表边落账顺序'}}（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 语法错误, 解析失败
- 调用示例：代码解析支持库.语法索引.解析Python语法()
- 依赖能力：无
### 解析脚本语法（`代码解析支持库.语法索引.解析脚本语法`）
- 版本：1.0.0
- 一句话说明：tree-sitter 解析 TypeScript/Vue 源码（不可用时正则降级），产出导入/符号/调用/字符串四类有序语法事实。vue 语法集抽取 <script> 块后逐块解析，每块行号自 1 起。第三方 tree-sitter 边界由 支持库.适配层.TreeSitter提供者 承载，本库只消费它的中性语法树；提供者不可用时正则降级
- 所属支持库或模块：支持库.后端.代码解析支持库.语法索引
- 参数列表：代码文本:文本型, 语法集:文本型
- 必填参数：代码文本
- 可选参数：语法集
- 返回结构：{'类型': '结果型', '值结构': {'导入列表': '有序：[{路径,行号,类别}]，类别 import / export-from；降级模式只产出 import', '符号列表': '有序：[{名称,类别,行号,结束行号}]，类别 class/function/method；降级模式为空', '调用列表': '有序：[{函数名,行号,参数字符串}]；降级模式只产出 platform.modules.call', '字符串列表': '有序：[{值,行号}]，tree-sitter 模式下全部 string 字面量；降级模式为空', '解析器': 'tree-sitter 或 正则降级'}}（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 解析失败
- 调用示例：代码解析支持库.语法索引.解析脚本语法(语法集=typescript)
- 依赖能力：无
### 批量解析语法（`代码解析支持库.语法索引.批量解析语法`）
- 版本：1.0.0
- 一句话说明：按语法集分派批量解析，结果严格保序，单文件失败隔离进失败列表
- 所属支持库或模块：支持库.后端.代码解析支持库.语法索引
- 参数列表：文件列表:列表型
- 必填参数：文件列表
- 可选参数：无
- 返回结构：{'类型': '结果型', '值结构': {'结果列表': '顺序与文件列表严格一致：[{路径, ...单文件事实集}]', '失败列表': '[{路径, 错误码, 错误说明}]，不影响其余文件'}}（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法
- 调用示例：代码解析支持库.语法索引.批量解析语法()
- 依赖能力：无
