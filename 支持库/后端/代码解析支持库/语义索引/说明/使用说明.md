# 语义索引 使用说明

## 定位
代码语义索引子包：把代码目录切块 → 生成嵌入 → 落 SQLite（块文本 + 向量 + 文件路径 + 起止行），并按 向量召回 + 关键词精排 返回候选块。切块复用 代码解析支持库.按规则切块，嵌入复用 大语言模型支持库.模型连接器 与 嵌入缓存；本包只做召回补充，不以向量相似度当事实，最终位置必须回 读取文件 按行区间取真实内容。

## 能力
| 能力id | 功能 | 返回 |
|---|---|---|
| 代码解析支持库.语义索引.建代码索引 | 把代码目录切成块 → 生成嵌入向量 → 落 SQLite（块文本 + 向量 + 文件路径 + 起止行）。切块复用 代码解析支持库.按规则切块，嵌入复用 大语言模型支持库.模型连接器 与 嵌入缓存（命中缓存不重算）。单文件失败隔离进 跳过清单。 | 结果型 |
| 代码解析支持库.语义索引.查代码块 | 向量召回 topN 后做关键词/符号精排（召回宽、精排严），返回带真实 文件路径 与 起始行/结束行 的候选列表。语义索引只做召回补充，最终位置必须回 读取文件 按行区间取真实内容，不以向量相似度当事实。 | 结果型 |

## 架构
主进程调用者 → 语义索引 公开函数 → 一次性子进程（实现/子进程入口.py）
→ stdin 一行 JSON 请求，stdout 一行 JSON 响应（骨架占位实现）。

## 生命周期
| 场景 | 行为 |
|---|---|
| 启动失败 | 提供者不可用（可重试） |
| 正常调用 | 成功结果（占位值） |
| 执行超时 | 超时（可重试） |
| 子进程崩溃/无效响应 | 提供者崩溃（可重试） |
| 语义索引_禁用库=1 | 提供者不可用（测试注入） |

## 错误码
| 错误码 | 含义 |
|---|---|
| 参数不合法 | 必填参数缺失或请求不合法 |
| 超时 | 执行超过超时秒 |
| 提供者崩溃 | 子进程异常退出或无效响应 |
| 提供者不可用 | 子进程启动失败或被禁用 |

## 第三方依赖
- 无。第三方必须单独支持库，模板内只允许声明为外部工具/受管
