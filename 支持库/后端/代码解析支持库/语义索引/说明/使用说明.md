## 代码解析支持库.语义索引.建代码索引（建代码索引）

**说明**：把代码目录切成块 → 生成嵌入向量 → 落 SQLite（块文本 + 向量 + 文件路径 + 起止行）。切块复用 代码解析支持库.按规则切块，嵌入复用 大语言模型支持库.模型连接器 与 嵌入缓存（命中缓存不重算）。单文件失败隔离进 跳过清单。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 索引根 | 文本型 | 是 | None | 要索引的代码目录 |
| 库文件 | 文本型 | 否 |  | SQLite 落点；空 = 工程缓存/语义索引/<目录名>.db |
| 嵌入模型名 | 文本型 | 否 | bge-m3 | 嵌入模型名 |
| 排除目录 | 列表型 | 否 | [] | 空 = 平台默认排除 |
| 批大小 | 整数型 | 否 | 32 | 每批嵌入条数 |
| 超时秒 | 双精度数型 | 否 | 60.0 | 子进程超时 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 目录不存在 |
| 嵌入不可用 |
| 索引写入失败 |

**调用示例**：

```python
代码解析支持库.语义索引.建代码索引(索引根=值, 库文件=值, 嵌入模型名=值, 排除目录=值, 批大小=值, 超时秒=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

## 代码解析支持库.语义索引.查代码块（查代码块）

**说明**：向量召回 topN 后做关键词/符号精排（召回宽、精排严），返回带真实 文件路径 与 起始行/结束行 的候选列表。语义索引只做召回补充，最终位置必须回 读取文件 按行区间取真实内容，不以向量相似度当事实。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 索引根 | 文本型 | 是 | None | 已建索引的根（用于定位默认库文件） |
| 查询 | 文本型 | 是 | None | 自然语言或符号名 |
| 库文件 | 文本型 | 否 |  | 空 = 用默认库文件 |
| 顶部数量 | 整数型 | 否 | 10 | 返回条数 |
| 文件模式 | 文本型 | 否 |  | 可选 glob 过滤 |
| 最小分数 | 双精度数型 | 否 | 0.0 | 低于该分数的丢弃 |
| 超时秒 | 双精度数型 | 否 | 60.0 | 子进程超时 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 索引不存在 |
| 嵌入不可用 |
| 索引读取失败 |

**调用示例**：

```python
代码解析支持库.语义索引.查代码块(索引根=值, 查询=值, 库文件=值, 顶部数量=值, 文件模式=值, 最小分数=值, 超时秒=值)
```
