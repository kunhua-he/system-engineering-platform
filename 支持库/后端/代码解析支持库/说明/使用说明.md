# 代码解析支持库

代码解析原子能力：解析代码字节/解析代码文件/按规则切块/解码文本/加载切块规则。

调用方式（40007 网关）：

```text
POST 40007 /网关/调用
{能力id: "代码解析支持库.解析代码字节", 参数: {原始字节, 文件id, 文件格式}}
```

只依赖 Python 标准库。
