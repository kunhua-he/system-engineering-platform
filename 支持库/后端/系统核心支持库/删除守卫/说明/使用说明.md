# 删除守卫支持库

## 职责
危险删除三重保护：受保护表拒绝 / 无条件删除拒绝 / 删除比例超上限拒绝。只做检查，不执行删除。

## 能力
| 能力 | 说明 |
|---|---|
| `删除守卫.检查删除` | 检查删除是否安全 |
| `删除守卫.检查清空` | 检查清空是否安全 |

## 调用
```bash
curl -X POST http://127.0.0.1:8866/网关/调用 -H 'Content-Type: application/json' \\
  -d '{"能力id":"删除守卫.检查删除","参数":{"目标表":"日志","删除比例":0.9}}'
```

## 边界
- 只依赖 Python 标准库；只判定不删除。
- 默认保护表：资产/用户/角色/权限/凭证/密钥/订单/交易。
