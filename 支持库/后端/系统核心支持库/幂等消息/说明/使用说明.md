## 系统核心支持库.幂等消息.生成id（生成id）

**说明**：生成幂等 id = sha256(会话id|内容) 截断 24 位，可带前缀。同一 会话id+内容 永远同一 id。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 会话id | 文本型 | 是 | None | 会话标识 |
| 内容 | 文本型 | 是 | None | 消息内容 |
| 前缀 | 文本型 | 否 | None | 可选前缀（字母数字下划线，截断16位） |

**返回结构**：{'类型': '结果型', '值结构': {'幂等id': '文本型', '算法': '文本型'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

```python
系统核心支持库.幂等消息.生成id(会话id=值, 内容=值, 前缀=值)
```
