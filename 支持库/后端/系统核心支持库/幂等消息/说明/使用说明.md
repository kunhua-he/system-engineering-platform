# 幂等消息支持库

## 职责
会话消息幂等 id 生成（借鉴 OpenCode SessionInput.admit）。

## 能力
| 能力 | 说明 |
|---|---|
| `幂等消息.生成id` | 生成幂等 id = sha256(会话id|内容) 截断 24 位 |
| `幂等消息.校验id` | 校验幂等 id 格式 |

## 调用
```bash
curl -X POST http://127.0.0.1:8866/网关/调用 -H 'Content-Type: application/json' \\
  -d '{"能力id":"幂等消息.生成id","参数":{"会话id":"s1","内容":"你好"}}'
```

## 边界
- 只依赖 Python 标准库；只生成不落库。
- 落库去重由调用方配合唯一约束实现。
