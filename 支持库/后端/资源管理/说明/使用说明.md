# 资源管理支持库（后端纯标准库原子能力）

原子资源操作：内容摘要、不可变快照、唯一运行目录、原子写入、原子替换、
比较并交换、资源级跨进程短锁、安全释放。只依赖 Python 标准库，无第三方
依赖。文件操作全部原子（临时文件 + fsync + rename）。

## 公开能力

- 创建内容摘要：分块读取文件生成 sha256 摘要（不加载全文件）。
- 创建不可变快照：复制目录 + 生成 快照摘要.json + 一致性校验支持。
- 创建唯一运行目录：临时目录语义，调用方负责释放。
- 原子写入：临时文件 + fsync + rename 原子落盘。
- 原子替换：原子替换文件内容（可选版本比较，不匹配返回 版本冲突）。
- 比较并交换：读取 → 比较 → 原子写回；并发冲突返回 版本冲突。
- 资源短锁：mkdir 原子性实现跨进程短锁（获取/释放/持有者是谁）。
- 安全释放：文件删除/目录递归删除，不存在视为幂等成功。

## 平台既有契约（保留原始返回形状）

以下能力为平台内部协作函数，被运行核心/模块库/合规验证器直接消费，
保留既有返回形状，由调用方包装为统一结果：

- 创建内容摘要 → 摘要文本（str）；文件不存在抛 FileNotFoundError。
- 创建唯一运行目录 → 目录路径（Path）。
- 原子写入 → 真值（True）。
- 原子替换 / 比较并交换 / 安全释放 → (成功标志, 消息) 二元组。
- 资源短锁 → 锁实例（获取/释放/持有者是谁 方法）。

## 调用方式

```python
from 支持库.后端.资源管理 import 创建内容摘要, 原子写入, 资源短锁, 安全释放资源

摘要 = 创建内容摘要("支持库/后端/资源管理/包声明.json")

原子写入("/tmp/示例.json", '{"值": 1}')

锁 = 资源短锁("/tmp/锁目录", "示例资源", 持有者="示例")
成功, 消息 = 锁.获取()
if 成功:
    锁.释放()

成功, 消息 = 安全释放资源("/tmp/示例目录")
```

## 错误码

参数不合法 / 版本冲突 / 资源不存在 / 资源被占用 / 超时 / 内部错误 / 写入失败。

## 边界

- 原子替换/比较并交换/安全释放/资源短锁 的失败都返回明确二元组
  （成功=False + 消息），不以成功形状伪装失败；不吞异常。
- 实现只经包级中文入口（__init__.py）暴露；禁止深入 实现/ 目录。
