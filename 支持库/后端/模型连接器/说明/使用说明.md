# 模型连接器支持库

## 职责
模型连接器：LLM/向量/重排 三个连接器 + 本地模型启动器，各返回六位句柄；其他能力持句柄调用模型。

## 能力
| 连接器 | 返回句柄 | 持句柄调用 |
|---|---|---|
| `模型连接器.连接LLM` | 句柄 | `生成对话(句柄, 消息列表)` |
| `模型连接器.连接向量模型` | 句柄 | `生成嵌入(句柄, 文本)` |
| `模型连接器.连接重排模型` | 句柄 | `执行重排(句柄, 查询, 文档列表)` |
| `模型连接器.启动本地模型` | 句柄 | 拉起 llama-server 等本地进程 |

## 句柄生命周期
- **默认 300 秒无人使用自动释放**（超时回收）；可 `续租句柄(句柄, 租约秒)` 延长。
- 显式 `释放句柄(句柄)`（幂等）；本地模型句柄释放时自动终止对应进程。
- **系统内存守卫**：连接前查系统真实可用内存（psutil），新连接预计占用超安全阈值（默认 80%）→ 返回 `资源不足`（防同时启动多个大模型撑爆内存）。
- 本地（本地路径/启动器/模型大小）与云端（url/api_key/模型/上下文长度）统一为连接配置。

## 边界
- 当前未注册真实调用器时，`生成对话/生成嵌入/执行重排` 返回 `提供者不可用`（不模拟成功）。
- 调用器由适配层 Provider 通过 `注册调用器(连接类型, 部署形态, 函数)` 接入；真实本地进程通过 `注册本地进程(句柄, 进程)` 绑定。接口冻结、内核可升级。
