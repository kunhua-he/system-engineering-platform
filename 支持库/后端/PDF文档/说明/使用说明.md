# PDF文档支持库（支持库.后端.PDF文档）

PDF 解析原子能力：**pdfplumber** 提取文本/表格/图像坐标，**PyMuPDF(fitz)** 检测加密与渲染图像字节，返回平台通用文档结果（`公共契约.基础类型.文档结构.通用文档`）。

## 调用方式

```python
from 支持库.后端.PDF文档 import 解析PDF

结果 = 解析PDF("/路径/文件.pdf")          # 全部默认预算
结果 = 解析PDF("/路径/文件.pdf", 最大页数=200, 最大字节数=50*1024*1024, 超时秒=30)
if 结果.成功:
    文档 = 结果.值                     # 通用文档
    print(文档.标题, len(文档.块列表), len(文档.资源列表))
    print(文档.提供者版本)              # {'pdfplumber': '0.11.10', 'fitz': '1.27.2.3'}
else:
    print(结果.错误码, 结果.错误说明)    # 如 文件损坏 / 文件加密 / 超出限制
```

## 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 文件路径 | 文本 | 必填 | PDF 文件路径（必须存在） |
| 最大页数 | 整数 | 500 | 页数上限，超限返回 `超出限制`；0=不限制 |
| 最大字节数 | 整数 | 209715200 | 文件大小上限（字节），超限返回 `超出限制`；0=不限制 |
| 超时秒 | 数字 | 60 | 软超时（秒），超时返回 `超时`；0=不限制 |

## 返回结构（结果[通用文档]）

- 块列表：`页面`（分页标记）/ `段落`（文本行）/ `表格`（表格数据）/ `图像`（坐标+资源引用），均带来源位置.页码。
- 资源列表：图像字节（base64），媒体类型 image/png|jpeg 等。
- 元数据：文档类型=PDF、格式=pdf、标题（首页首行）、保真级别=高、解析方式、警告、耗时秒、提供者版本、原始文件摘要（sha256）。

## 安全覆盖

| 场景 | 错误码 | 说明 |
|---|---|---|
| 损坏文件 | 文件损坏 | pdfplumber 打开/解析失败 |
| 加密文件 | 文件加密 | fitz needs_pass 检测；fitz 缺失时按 pdfplumber 异常特征推断 |
| 超页数 / 超大小 | 超出限制 | 打开前与打开后双重检查 |
| 文件不存在 / 参数不合法 | 文件不存在 / 参数不合法 | — |
| 解析超时 | 超时 | 每页软超时检查，可重试 |
| pdfplumber 缺失 | 提供者不可用 | 不跳过、不伪装成功，可重试 |
| fitz 缺失 | 降级成功 | 文本/表格/图像坐标正常，图像仅坐标不渲染，警告提示 |

渲染资源上限：单图最大像素 4000 万、每文档最多 50 张图，超限跳过并记录警告。

## 环境要求

- Python 3.14；第三方库 `pdfplumber`、`PyMuPDF`（fitz）需已安装。
- 测试生成 PDF 需 `reportlab`（仅测试中心使用，支持库本身不依赖）。

## 错误转换

底层异常一律转换为 `结果(成功=False, 错误=错误结构)`，不抛裸异常；可重试场景（提供者不可用/超时）错误结构.可重试=True。
