# 文本处理支持库（后端纯标准库原子能力）

原子文本处理能力：分割/合并/替换/查找/去空白/大小写/长度统计/按行分割。
只依赖 Python 标准库，无第三方依赖。全部公开能力返回统一结果
（成功/值/错误/错误码）。

## 公开能力

- 分割文本：按分隔符分割为片段列表。
- 合并文本：用分隔符连接片段列表。
- 替换文本：全文替换旧文本为新文本（旧文本为空返回 参数不合法）。
- 查找文本：返回目标首个位置（未找到返回 -1）。
- 去空白 / 转大写 / 转小写 / 统计长度 / 按行分割。

## 调用方式

```python
from 支持库.后端.文本处理 import 分割文本, 替换文本, 按行分割

结果 = 分割文本("甲,乙,丙", ",")
if 结果.成功:
    片段列表 = 结果.值

结果 = 替换文本("甲甲", "甲", "乙")
if 结果.成功:
    替换后 = 结果.值

结果 = 按行分割("第一行\n第二行")
if 结果.成功:
    行列表 = 结果.值
```

## 错误码

参数不合法。

## 边界

- 参数缺失或类型非法返回 参数不合法；不吞异常、不以成功形状伪装失败。
- 实现只经包级中文入口（__init__.py）暴露；禁止深入 实现/ 目录。
