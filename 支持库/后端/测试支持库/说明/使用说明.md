# 测试支持库（支持库.后端.测试支持库）

- 类型：支持库
- 版本：1.0.0
- 说明：验证编排原子能力：只读计算验证计划、验证命令白名单准入判定、验证结果统一判定（拒绝零测试成功/导入失败当跳过/未解释跳过/缓存假绿）。只依赖 Python 标准库，不执行任何命令。
- 入口：`__init__.py`（包级中文入口，`注册能力(注册表)` 注册三条能力）
- 权威分工：**调用口径以本文为准**（能力/参数/返回/错误码/调用示例，由能力契约生成）；
  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。

## 能力

### 验证命令白名单（`测试支持库.验证命令白名单`）

- 版本：1.0.0
- 一句话说明：纯函数准入判定：命令是否属于本仓允许的验证命令集合（精确 unittest 模块入口 / HTML 黑盒验证器 / 唯一发布入口），其余一律拒绝并把错误码放进返回值。
- 所属支持库或模块：支持库.后端.测试支持库
- 参数列表：命令:列表型, 仓库根目录:文本型, 校验存在:逻辑型
- 必填参数：命令
- 可选参数：仓库根目录, 校验存在
- 返回结构：{'类型': '结果型', '值结构': {'允许': '是否通过白名单（逻辑型）', '形态': '判定出的命令形态：unittest/HTML验证/正式发布/拒绝（文本型）', '错误码': '拒绝原因码，允许时为空串（文本型）', '消息': '判定说明（文本型）', '规范化命令': '归一后的命令列表（列表型，字符串列表）', '存在性校验': '本次是否做了存在性校验（逻辑型）'}}（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法（命令不是列表、或 `校验存在=真` 时仓库根目录不存在）；其余一律是**成功返回 + `允许=假` + `错误码=命令拒绝`**，不抛失败。
- 允许的三种命令形态（冻结契约，与 `MCP工具箱/验证门禁.py`、`技能库/技能/验证编排` 同源，值域完全一致）：

  | 形态 | 命令形状 |
  | --- | --- |
  | unittest | `["python3.14", "-m", "<精确模块，末段以 测试_ 开头>"]` |
  | HTML验证 | `["python3.14", "-m", "开发工具.HTML验证.验证器", "--制品", "<根内相对目录>", "--并发", "1-64"]` |
  | 正式发布 | `["python3.14", "开发工具/发布门禁/运行发布门禁.py"]` |

- 通用拒绝规则（与两处同源实现逐条一致）：禁止 shell 元字符 `;|&`$(){}<>`、禁止 `shell=`、禁止绝对路径与 `~`、禁止 `..` 路径逃逸、可执行程序只允许 `python3.14`、unittest 形态不接受额外参数。
- 调用示例：

  ```json
  {"操作": "调用能力", "能力id": "测试支持库.验证命令白名单",
   "参数": {"命令": ["python3.14", "-m", "测试中心.支持库.测试_测试支持库"], "校验存在": false}}
  ```

  真实返回：`{"成功": true, "值": {"允许": true, "形态": "unittest", "错误码": "", "消息": "命令通过白名单校验: python3.14 -m 测试中心.支持库.测试_测试支持库", "规范化命令": ["python3.14", "-m", "测试中心.支持库.测试_测试支持库"], "存在性校验": false}}`
- `校验存在=真`（默认）：额外校验测试模块文件 / HTML 制品目录在 `仓库根目录` 内真实存在；`校验存在=假` 时只做纯语法准入（供产物外的纯函数判定与 538 能力全表的静态准入使用）。
- 依赖能力：无

### 验证结果判定（`测试支持库.验证结果判定`）

- 版本：1.0.0
- 一句话说明：按真实执行输出（退出码/标准输出/标准错误/命令/跳过列表）判定 通过 或 阻断 并给理由；零测试成功、导入失败当跳过、未解释跳过、缓存假绿一律阻断。
- 所属支持库或模块：支持库.后端.测试支持库
- 参数列表：退出码:整数型, 标准输出:文本型, 标准错误:文本型, 命令:列表型, 跳过列表:列表型
- 必填参数：退出码
- 可选参数：标准输出, 标准错误, 命令, 跳过列表
- 返回结构：{'类型': '结果型', '值结构': {'判定': '通过 或 阻断（文本型）', '阻断码': '阻断时的错误码：验证失败/零测试/缓存假绿/导入失败当跳过/未解释跳过；通过时为空串（文本型）', '理由': '判定理由（文本型）', '检出': '列表，命中的检出名清单（列表型）', '真实执行证据': '输出里是否有真实执行证据（Ran N tests / N passed）（逻辑型）', '退出码': '回带的真实退出码（整数型）'}}（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法（退出码缺失或为逻辑型、命令/跳过列表不是列表）
- 判定顺序（冻结契约）：退出码非零 → 收集错误（ERROR/errors=）→ 跳过列表缺原因 → 导入失败当跳过 → 缓存假绿 → 零测试 → 未解释跳过 → 通过。
- **判定本身是一等结果**：无论通过还是阻断，能力调用都返回 `成功=真`，真实结论在 `值.判定`；只有参数不合法才 `成功=假`。调用方不应把「调用成功」当成「验证通过」。
- 调用示例：

  ```json
  {"操作": "调用能力", "能力id": "测试支持库.验证结果判定",
   "参数": {"退出码": 0, "标准输出": "Ran 0 tests in 0.000s\n\nOK\n",
            "命令": ["python3.14", "-m", "测试中心.支持库.测试_测试支持库"]}}
  ```

  真实返回：`{"成功": true, "值": {"判定": "阻断", "阻断码": "零测试", "理由": "未运行任何测试用例（no tests ran / ran 0 tests / 零测试门禁失败）", "检出": ["零测试"], "真实执行证据": true, "退出码": 0}}`
- 依赖能力：无
