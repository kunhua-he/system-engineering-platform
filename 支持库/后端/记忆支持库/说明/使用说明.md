## 记忆支持库.解析配置回退链（解析配置回退链）

**说明**：按 精确→泛化→全局 三级回退解析配置（TencentDB mps 模式化落地），返回匹配目标与回退路径

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 目标类型 | 文本型 | 是 | None | 配置归属类型 agent/team/instance |
| 目标标识 | 文本型 | 是 | None | 目标实体标识 |
| 层级 | 文本型 | 否 | None | 配置层级过滤 L1/L2/L3 |
| 配置表 | 列表型 | 是 | None | 配置候选列表 按优先级从高到低 |

**返回结构**：{'类型': '结果型', '值结构': {}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 解析失败 |

**调用示例**：

```python
记忆支持库.解析配置回退链(目标类型="agent", 目标标识="agent-001", 层级="L1",
                          配置表=[{"目标类型": "agent", "目标标识": "agent-001", "层级": "L1", "配置": {...}}])
```

**解析规则**：精确（目标类型+目标标识+层级）→ 泛化（目标类型+层级，目标标识为 "*"/空）→ 全局（仅层级）；命中项返回 `{匹配目标, 配置, 回退路径}`，未命中返回 `匹配目标=None`、`配置=None`、`回退路径=[]`。

**验证状态**：已纳入验证场景：记忆支持库.解析配置回退链正向（正向HTTP）
