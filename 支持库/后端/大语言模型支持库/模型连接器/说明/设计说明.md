## 大语言模型支持库.模型连接器.连接LLM（连接LLM）

**说明**：连接大语言模型，返回句柄。本地：部署形态=本地+本地路径/启动器；云端：部署形态=云端+url/api_key/模型/上下文长度。句柄默认 1800 秒无人使用自动释放；系统内存占用超阈值拒绝新连接。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 模型 | 文本型 | 是 | None | 模型名 |
| 提供者 | 文本型 | 否 | 本地 | 提供者标识 |
| 部署形态 | 文本型 | 否 | None | 本地/云端（默认按 url 推断） |
| 本地路径 | 文本型 | 否 | None | 本地模型文件路径 |
| 启动器 | 文本型 | 否 | llama-server | 本地模型启动器 |
| 模型大小字节 | 整数型 | 否 | None | 模型文件大小（内存守卫用） |
| url | 文本型 | 否 | None | 云端端点（如 http://127.0.0.1:8328/hermes-chat/v1） |
| api_key | 文本型 | 否 | None | 云端密钥 |
| 上下文长度 | 整数型 | 否 | None | 上下文窗口 |
| 协议 | 文本型 | 否 | chat_completions | 请求协议：chat_completions、codex_responses 或 anthropic_messages |
| 超时秒 | 整数型 | 否 | 1800 | 无人使用自动释放秒数 |
| 参数 | 字典型 | 否 | None | 可选启动配置：启动参数列表（列表型，追加到 llama-server 命令行，如 ["-c","40960","--cache-ram","0"]）；内存估算系数（数，覆盖内存守卫估算）；协议（LLM 会话协议） |

**返回结构**：{'类型': '结果型', '值结构': {'句柄': '整数型', '连接类型': '文本型', '模型': '文本型', '部署形态': '文本型', '超时秒': '整数型'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 资源不足 |

```python
大语言模型支持库.模型连接器.连接LLM(模型=值, 提供者=值, 部署形态=值, 本地路径=值, 启动器=值, 模型大小字节=值, url=值, api_key=值, 上下文长度=值, 协议=值, 超时秒=值)
