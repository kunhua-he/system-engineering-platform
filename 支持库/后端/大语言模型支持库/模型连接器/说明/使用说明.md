## 大语言模型支持库.模型连接器.连接LLM（连接LLM）

**说明**：连接大语言模型，返回句柄。本地：部署形态=本地+本地路径/启动器；云端：部署形态=云端+url/api_key/模型/上下文长度。句柄默认 1800 秒无人使用自动释放；系统内存占用超阈值拒绝新连接。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 模型 | 文本型 | 是 | None | 模型名 |
| 提供者 | 文本型 | 否 | 本地 | 提供者标识 |
| 部署形态 | 文本型 | 否 | None | 本地/云端（本地传绝对路径，由底座负责启动；云端传 url/api_key） |
| 本地路径 | 文本型 | 否 | None | 本地模型 GGUF 文件绝对路径 |
| 启动器 | 文本型 | 否 | None | 可选启动器；目录型向量/重排模型由底座内置服务启动 |
| 模型大小字节 | 整数型 | 否 | None | 模型文件大小（内存守卫用） |
| url | 文本型 | 否 | None | 云端端点（如 http://127.0.0.1:8328/hermes-chat/v1） |
| api_key | 文本型 | 否 | None | 云端密钥 |
| 上下文长度 | 整数型 | 否 | None | 上下文窗口 |
| 协议 | 文本型 | 否 | chat_completions | 请求协议：chat_completions 或 codex_responses |
| 超时秒 | 整数型 | 否 | 1800 | 无人使用自动释放秒数 |

**返回结构**：{'类型': '结果型', '值结构': {'句柄': '文本型', '连接类型': '文本型', '模型': '文本型', '部署形态': '文本型', '超时秒': '整数型'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 资源不足 |

**调用示例**：

```python
大语言模型支持库.模型连接器.连接LLM(模型=值, 提供者=值, 部署形态=值, 本地路径=值, 启动器=值, 模型大小字节=值, url=值, api_key=值, 上下文长度=值, 协议=值, 超时秒=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：支持库.资产验证（资产）、支持库.能力契约验证（契约）
