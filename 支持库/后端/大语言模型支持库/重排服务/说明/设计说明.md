## 大语言模型支持库.重排服务.重排（重排）

**说明**：对候选文档按与查询的相关性重排，返回 文档+得分+原索引。模型配置 预留模型重排（当前标准库实现）。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 查询 | 文本型 | 是 | None | 查询文本 |
| 文档列表 | 列表型 | 是 | None | 候选文档（字符串或含 文本/内容 字段的字典） |
| 模型配置 | 字典型 | 否 | None | 预留：{模型名, 提供者}，当前忽略 |
| 顶部数量 | 整数型 | 否 | None | 限制返回条数（默认全部） |

**返回结构**：{'类型': '结果型', '值结构': {'重排结果': '列表型（文档/得分/原索引）'}}（统一结果：成功/值/错误）
