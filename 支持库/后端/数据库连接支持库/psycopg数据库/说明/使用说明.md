## 数据库连接支持库.psycopg数据库.连接数据库（连接数据库）

**说明**：创建唯一同步 PostgreSQL 连接池并返回数据库句柄；调用方只持句柄，不接触连接对象。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 连接串 | 文本型 | 是 | None | postgresql:// 或 postgres:// 格式连接串 |
| 连接池大小 | 整数型 | 否 | 4 | 池内最大连接数，取值 1 到 100 |
| 超时秒 | 双精度数型 | 否 | 10 | 建连与借出连接超时秒数 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 提供者不可用 |
| 超时 |
| 连接失败 |
| 查询失败 |

**调用示例**：

```python
数据库连接支持库.psycopg数据库.连接数据库(连接串=值, 连接池大小=值, 超时秒=值)
```

## 数据库连接支持库.psycopg数据库.查询数据库（查询数据库）

**说明**：持数据库句柄执行查询并自动借还池连接；查询失败连接只丢弃不回池。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 数据库句柄 | 整数型 | 是 | None | 连接数据库 返回的数据库句柄 |
| SQL | 文本型 | 是 | None | 单条 SQL 语句，占位符用 %s |
| 参数 | 列表型 | 否 | [] | 参数化值列表，按占位符顺序传入 |
| 超时秒 | 双精度数型 | 否 | 30 | 语句超时秒数 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 句柄失效 |
| 超时 |
| 连接失败 |
| 查询失败 |

**调用示例**：

```python
数据库连接支持库.psycopg数据库.查询数据库(数据库句柄=值, SQL=值, 参数=值, 超时秒=值)
```
