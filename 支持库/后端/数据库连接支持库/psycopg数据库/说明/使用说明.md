# psycopg提供者 使用说明

psycopg（psycopg3）PostgreSQL 驱动独立提供者：连接/查询/事务执行/关闭。
一驱动一支持库，只 import psycopg（纯 Python 模式，主进程加载）。每次调用
自包含连接生命周期，连接对象与游标在调用路径内创建并在 finally 中关闭，
无持久连接状态、绝不泄漏。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| psycopg数据库.连接 | psycopg 连接测试：成功返回 {已连接: true, 提供者版本} |
| psycopg数据库.查询 | 查询：返回 {行列表: [{列名: 值}...]} |
| psycopg数据库.事务执行 | 事务执行：全部成功提交；任一失败回滚 |
| psycopg数据库.关闭 | 关闭：本提供者每次调用自包含连接，关闭为空操作 |

## 调用方式

只经 `支持库.适配层.psycopg提供者` 包级入口调用，禁止深入 `实现/` 目录。

```python
from 支持库.适配层.psycopg提供者 import 连接, 查询

结果 = 连接("postgresql://用户:密码@主机:5432/数据库", 超时秒=10)
if not 结果.成功:
    print(结果.错误码, 结果.错误说明)  # 提供者不可用 / 连接失败 / 超时 ...
```

## 参数结构

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 连接串 | 文本 | 是 | 无 | postgresql:// 格式连接串 |
| 超时秒 | 数字 | 否 | 10 | 连接超时秒数 |
| SQL | 文本 | 是 | 无 | SQL 语句（查询） |
| 参数 | 列表 | 否 | [] | 参数化值列表（查询） |
| SQL列表 | 列表 | 是 | 无 | SQL 语句列表（事务执行） |

## 错误码

- `参数不合法`：连接串非文本/非 postgresql:// 格式、超时秒非法、SQL 空、SQL列表 为空
- `提供者不可用`：psycopg 驱动未安装或不可导入
- `超时`：连接或语句执行超时
- `连接失败`：目标 PostgreSQL 不可达（拒绝连接/主机不可达等）
- `查询失败`：SQL 执行异常或连接释放失败

无数据库服务或连接串未配置时，一律返回明确的失败结果（提供者不可用/连接失败），
绝不假装连接成功。
