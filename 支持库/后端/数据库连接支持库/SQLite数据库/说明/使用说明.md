# SQLite数据库支持库（支持库.后端.数据库连接支持库.SQLite数据库）

- 类型：支持库
- 版本：1.0.3
- 说明：基于 Python 标准库 sqlite3 的本地数据库支持库：连接、查询、事务执行、关闭。
- 入口：__init__.py
- 权威分工：**调用口径以本文为准**（能力/参数/返回/错误码/调用示例，由能力契约生成）；
  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。
