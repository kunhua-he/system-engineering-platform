# 网络请求支持库说明

## 用途
HTTP 客户端原子能力：发送 HTTP 请求（GET/POST）与 URL 查询串构建。
属于外部协议边界能力，只经包级中文入口调用，禁止深入 实现/ 目录。

## 能力
- 网络请求.发送请求：发送 HTTP 请求，返回状态码/响应头/响应文本/错误信息；
  含 SSRF 防护（拒绝 file/ftp 协议与内网/私有/保留地址）、响应大小上限、
  超时控制、凭证安全（敏感请求头不进入错误信息）。
- 网络请求.构建查询串：把参数映射编码为 URL 查询串。

## 安全策略
- 协议白名单：仅 http/https。
- SSRF 防护：默认拒绝回环/内网/私有/保留/组播地址；`允许回环` 仅供项目
  策略显式放行本机服务（测试）时使用。
- 响应大小上限：`最大字节数` 超限即中止，防止无界读入内存。
- 凭证安全：Authorization/Cookie 等敏感请求头不记录到错误信息与结果。

## 使用示例
```python
from 支持库.后端.网络请求 import 发送请求, 构建查询串

结果 = 发送请求(地址="https://example.com/api", 方法="POST",
                请求参数={"数据": {"键": "值"}, "请求头": {"Content-Type": "application/json"}},
                超时秒=10, 最大字节数=5*1024*1024)
if 结果.成功:
    状态码 = 结果.值["状态码"]
查询串 = 构建查询串({"关键词": "华世", "页": 2}).值
```
