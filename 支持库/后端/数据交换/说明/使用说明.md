# 数据交换支持库（后端纯标准库原子能力）

原子数据交换能力：JSON 与 CSV 的序列化/反序列化。只依赖 Python 标准库，
无第三方依赖。全部公开能力返回统一结果（成功/值/错误/错误码），不泄漏
文件对象或裸句柄。

## 公开能力

- 序列化JSON：把字典或列表数据序列化为 JSON 文本。
- 反序列化JSON：把 JSON 文本解析为字典或列表。
- 序列化CSV：把行列表序列化为 CSV 文本。
- 反序列化CSV：把 CSV 文本解析为行列表。

## 调用方式

```python
from 支持库.后端.数据交换 import 序列化JSON, 反序列化JSON, 序列化CSV, 反序列化CSV

结果 = 序列化JSON({"名称": "示例", "数量": 1})
if 结果.成功:
    文本 = 结果.值

结果 = 反序列化JSON('{"名称": "示例"}')
if 结果.成功:
    数据 = 结果.值

结果 = 序列化CSV([["名称", "数量"], ["示例", 1]])
if 结果.成功:
    csv文本 = 结果.值

结果 = 反序列化CSV("名称,数量\n示例,1")
if 结果.成功:
    行列表 = 结果.值
```

## 错误码

参数不合法 / 序列化失败 / 反序列化失败。

## 边界

- 参数缺失或类型非法返回 参数不合法；序列化/解析失败如实返回对应失败结果，
  不吞异常、不以成功形状伪装失败。
- 实现只经包级中文入口（__init__.py）暴露；禁止深入 实现/ 目录。
