## 办公文档支持库.轻量文本解析.解析Markdown块（解析Markdown块）

**说明**：把 Markdown 文本切成中间块列表：语法集「完整」识别 8 类块（标题/段落/代码/表格/列表项/引用/分隔线/图像），语法集「简化」只识别 3 类块（标题/段落/代码）。行号自 1 起；空文本按语法集产出占位或不产出

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文本 | 文本型 | 是 | None | Markdown 文本，内部归一化 CRLF/CR |
| 语法集 | 文本型 | 否 | 完整 | 完整=8 类块；简化=3 类块（标题判定也更宽松） |
