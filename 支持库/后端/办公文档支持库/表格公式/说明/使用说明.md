## 办公文档支持库.表格公式.求值公式（求值公式）

**说明**：对 Excel 公式求值：非 = 开头原样返回；支持 SUM/AVERAGE/COUNT/MAX/MIN 与四则运算，AST 白名单求值禁用 eval；错误值沿用 Excel 语义（#VALUE!/#DIV/0!/#NAME?）

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 表达式 | 文本型 | 是 | None | 公式文本，可带 = 前缀 |
| 单元格字典 | 字典型 | 是 | None | 地址 → 文本值（如 {'A1': '3'}） |

**返回结构**：{'类型': '结果型', '值结构': {'结果文本': '求值结果或错误值文本'}}（统一结果：成功/值/错误）

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

