## 办公文档支持库.演示文稿.解析演示文稿（解析演示文稿）

**说明**：解析 PPT/PPTX 演示文稿为平台通用文档（幻灯片文本/备注/图像资源）；PPTX 原生经 python_pptx提供者 解析，PPT 先经 LibreOffice 转换再解析

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | 演示文稿文件路径（不存在返回 文件不存在） |
| 格式 | 文本型 | 否 |  | 演示文稿格式（ppt/pptx；缺省按扩展名推断；其他格式返回 参数不合法） |
| 最大幻灯片数 | 整数型 | 否 | 200 | 幻灯片数上限，超限返回 超出限制 |
| 最大字节数 | 整数型 | 否 | 209715200 | 文件大小上限（字节），超限返回 超出限制 |
| 超时秒 | 双精度数型 | 否 | 60 | 旧格式转换软超时（秒），超时返回 超时 |

**返回结构**：{'类型': '结果型', '值结构': {'值': '通用文档（块列表/资源列表/提供者版本/原始文件摘要）'}}（统一结果：成功/值/错误）
