## 办公文档支持库.文字文档.解析文字文档（解析文字文档）

**说明**：解析 DOC/DOCX 文字文档为平台通用文档（段落/表格/图像资源）；DOCX 原生经 python_docx提供者 解析，DOC 先经 LibreOffice 转换再解析

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | 文档文件路径（不存在返回 文件不存在） |
| 格式 | 文本型 | 否 | docx | 文档格式（doc/docx；其他格式返回 参数不合法） |
| 最大字节数 | 整数型 | 否 | 209715200 | 文件大小上限（字节），超限返回 超出限制 |
| 超时秒 | 双精度数型 | 否 | 60 | 旧格式转换软超时（秒），超时返回 超时 |

**返回结构**：{'类型': '结果型', '值结构': {'值': '通用文档（块列表/资源列表/元数据）'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 文件不存在 |
| 超出限制 |
| 文件损坏 |
| 提供者不可用 |
| 转换失败 |
| 超时 |

**调用示例**：

```python
办公文档支持库.文字文档.解析文字文档(文件路径=值, 格式=值, 最大字节数=值, 超时秒=值)
```
