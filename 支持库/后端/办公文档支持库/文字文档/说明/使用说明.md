# 文字文档支持库使用说明

## 定位

DOC/DOCX 文字文档解析原子能力。DOCX 经受管提供者能力
`文字文档.解析文字文档`（python_docx提供者）原生解析；旧格式 DOC
先经受管提供者能力 `文档转换支持库.LibreOffice转换.转换办公文件` 转 DOCX 再解析。
本支持库不直接 import 第三方库/适配层实现；调用器未装配时如实返回
`提供者不可用`。返回平台通用文档结构（公共契约.基础类型.文档结构）。

## 安全约束

- OOXML 按不可信 ZIP 处理：成员数/单项大小/总解压体积/压缩比上限，
  拒绝路径逃逸、宏文件与外部关系（本支持库纯标准库 zipfile 校验）。
- 损坏文件返回 `文件损坏`；超限返回 `超出限制`。
- 缺 python-docx / LibreOffice 返回 `提供者不可用`，不伪装成功。

## 调用示例

```python
from 支持库.后端.文字文档 import 解析文字文档

结果 = 解析文字文档("/tmp/报告.docx", "docx")
if 结果.成功:
    文档 = 结果.值          # 通用文档
    块列表 = 文档.块列表     # 标题/段落/表格/图像 块
else:
    错误码 = 结果.错误码
```

旧格式：

```python
结果 = 解析文字文档("/tmp/旧报告.doc", "doc")
# 内部经 LibreOffice 转 docx 后解析，警告含 converted_from_doc
```

## 错误码

| 错误码 | 含义 |
|---|---|
| 文件不存在 | 源文件不存在 |
| 参数不合法 | 格式非 doc/docx |
| 提供者不可用 | 调用器未装配 / python-docx 或 LibreOffice 缺失 |
| 文件损坏 | OOXML 校验失败或解析失败 |
| 超出限制 | 大小/成员数/压缩比超限 |
| 转换失败 | 旧格式转换失败 |
| 超时 | 转换执行超时（可重试） |

## 调用边界

- 本包只经 `公共契约.能力契约.调用器.获取能力调用器` 调用受管提供者
  能力（能力id：`文字文档.解析文字文档` / `文档转换支持库.LibreOffice转换.转换办公文件`）；
  依赖契约声明空（无第三方包依赖，提供者由运行核心装配）。
- 公开入口只返回统一结果（`公共契约.基础类型.结果类型.结果`），
  不泄漏第三方对象/文件对象/裸句柄。
