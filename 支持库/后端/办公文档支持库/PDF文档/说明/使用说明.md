## 办公文档支持库.PDF文档.解析PDF（解析PDF）

**说明**：解析 PDF 为平台通用文档（文本/表格/图像，经 PDF隔离提供者 隔离子进程执行），返回 结果[通用文档]

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | PDF 文件路径（不存在返回 文件不存在） |
| 最大页数 | 整数型 | 否 | 500 | 页数上限，超限返回 超出限制；0=不限制 |
| 最大字节数 | 整数型 | 否 | 209715200 | 文件大小上限（字节），超限返回 超出限制；0=不限制 |
| 超时秒 | 双精度数型 | 否 | 60 | 解析软超时（秒），超时返回 超时；0=不限制 |

**返回结构**：{'类型': '结果型', '值结构': {'值': '通用文档（块列表/资源列表/元数据）'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 文件不存在 |
| 超出限制 |
| 文件损坏 |
| 文件加密 |
| 提供者不可用 |
| 提供者崩溃 |
| 超时 |

**调用示例**：

```python
办公文档支持库.PDF文档.解析PDF(文件路径=值, 最大页数=值, 最大字节数=值, 超时秒=值)
```
