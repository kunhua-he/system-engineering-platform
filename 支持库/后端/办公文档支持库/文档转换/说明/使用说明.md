# 文档转换支持库使用说明

## 定位

受控调用 textutil / LibreOffice 的文档格式转换原子能力。所有解析器对旧格式
（doc/xls/ppt）或跨格式（转 txt/html/pdf 等）的需求统一走本支持库，禁止
各模块自行启动外部进程。外部进程边界由受管提供者能力承担：
`文档转换支持库.textutil转换.转换文本文件` / `文档转换支持库.LibreOffice转换.转换办公文件` /
`文档转换支持库.textutil转换.检查提供者` / `文档转换支持库.LibreOffice转换.检查提供者`。
本支持库不直接 import 适配层实现/启动外部进程；调用器未装配时如实返回
`提供者不可用`，不伪装成功。

## 安全约束（受管提供者承担）

- 结构化参数列表调用，禁止 `shell=True`。
- 独立进程组（`start_new_session=True`），超时先 SIGTERM 进程组、宽限后
  SIGKILL 兜底。
- 输出大小上限，超限即截断/中止。
- 临时目录（textutil 输出、LibreOffice 用户配置）用后必清理。
- 缺少外部程序返回错误码 `提供者不可用`，不伪装成功。

## 调用示例

```python
from 支持库.后端.文档转换 import 检查提供者, 转换文本文件, 转换办公文件

状态 = 检查提供者("全部")
# 值: {"textutil": "可用", "libreoffice": "可用"}

文本结果 = 转换文本文件("/tmp/旧文档.doc", "txt")
if 文本结果.成功:
    文本 = 文本结果.值["文本"]

路径结果 = 转换办公文件("/tmp/旧表格.xls", "xlsx", 输出目录="/tmp/out")
if 路径结果.成功:
    新路径 = 路径结果.值["路径"]
```

## 错误码

| 错误码 | 含义 |
|---|---|
| 提供者不可用 | 调用器未装配 / textutil/LibreOffice 未安装 |
| 文件不存在 | 源文件不存在 |
| 参数不合法 | 目标格式/上限参数非法 |
| 转换失败 | 外部程序退出非零或未生成输出 |
| 超时 | 执行超过超时秒数（可重试） |
| 超出限制 | 输出超过最大输出字节 |

## 调用边界

- 本包只经 `公共契约.能力契约.调用器.获取能力调用器` 调用受管提供者
  能力；依赖契约声明空（无第三方包依赖，提供者由运行核心装配）。
- 公开入口只返回统一结果（`公共契约.基础类型.结果类型.结果`），
  不泄漏第三方对象/文件对象/裸句柄。
