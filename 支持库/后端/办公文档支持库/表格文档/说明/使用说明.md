# 表格文档支持库使用说明

## 定位

XLS/XLSX 表格文档解析原子能力。XLSX 经受管提供者能力
`表格文档.解析表格文档`（openpyxl提供者）原生解析（工作表、单元格、
公式/值策略）；旧格式 XLS 先经受管提供者能力 `LibreOffice转换.转换办公文件`
转 XLSX 再解析。本支持库不直接 import 第三方库/适配层实现；调用器
未装配时如实返回 `提供者不可用`。返回平台通用文档结构，每个工作表
一个 `工作表` 块（文本 + 表格数据二维列表）。

## 公式/值契约

- 默认 `data_only=True` 读缓存值（保存时已计算的值）。
- 缓存缺失（公式未计算保存）时单元格值为 `None` → 显示为空字符串。
- 需要公式文本本身时由上层（V3 适配层）按需用 `data_only=False` 补充。

## 安全约束

- OOXML 按不可信 ZIP 处理：成员数/单项大小/总解压体积/压缩比上限，
  拒绝路径逃逸与外部关系（本支持库纯标准库 zipfile 校验）。
- 损坏文件返回 `文件损坏`；超表数/超行数/超大小返回 `超出限制`。
- 缺 openpyxl / LibreOffice 返回 `提供者不可用`，不伪装成功。

## 调用示例

```python
from 支持库.后端.表格文档 import 解析表格文档

结果 = 解析表格文档("/tmp/数据.xlsx", "xlsx")
if 结果.成功:
    文档 = 结果.值
    for 块 in 文档.块列表:      # 每个工作表一个 工作表 块
        print(块.来源位置.工作表, 块.表格数据[:2])
```

## 错误码

| 错误码 | 含义 |
|---|---|
| 文件不存在 | 源文件不存在 |
| 参数不合法 | 格式非 xls/xlsx |
| 提供者不可用 | 调用器未装配 / openpyxl 或 LibreOffice 缺失 |
| 文件损坏 | OOXML 校验失败或解析失败 |
| 文件加密 | 工作簿已加密 |
| 超出限制 | 大小/表数/行数/压缩比超限 |
| 转换失败 | 旧格式转换失败 |
| 超时 | 转换执行超时（可重试） |

## 调用边界

- 本包只经 `公共契约.能力契约.调用器.获取能力调用器` 调用受管提供者
  能力（能力id：`表格文档.解析表格文档` / `LibreOffice转换.转换办公文件`）；
  依赖契约声明空（无第三方包依赖，提供者由运行核心装配）。
- 公开入口只返回统一结果（`公共契约.基础类型.结果类型.结果`），
  不泄漏第三方对象/文件对象/裸句柄。
