# 文档生成支持库使用说明

## 定位

四格式（DOCX/XLSX/PPTX/PDF）原子生成能力。生成后强制签名校验，
产物可信才返回；所有错误转为统一结果（成功/值/错误码/错误说明）。
第三方生成经能力调用器调用受管提供者能力：
`文字文档.生成文字文档`（python_docx提供者）、
`表格文档.生成表格文档`（openpyxl提供者）、
`演示文稿.生成演示文稿`（python_pptx提供者）、
`文档转换支持库.PDF生成.生成PDF`（reportlab提供者）；
PDF 重开签名校验经受管提供者能力 `PDF隔离提供者.校验PDF`。
本支持库不直接 import 第三方库/适配层实现；调用器未装配时如实返回
`提供者不可用`。

## 能力

| 能力 | 输入 | 返回 |
|---|---|---|
| 生成DOCX | 参数 dict：`内容块列表` | 结果[生成产物] |
| 生成XLSX | 参数 dict：`工作表列表` | 结果[生成产物] |
| 生成PPTX | 参数 dict：`幻灯片列表` | 结果[生成产物] |
| 生成PDF | 参数 dict：`内容块列表` | 结果[生成产物] |
| 校验签名 | 格式、字节 | 结果 |

生成产物 = {格式, 字节, 媒体类型, 摘要(sha256), 诊断, 附加}；
附加含 提供者版本、生成耗时秒、签名校验结论。

## 参数结构（与 V3 Office生成器 兼容的中文键）

```python
DOCX参数 = {
    "内容块列表": [
        {"类型": "标题", "文本": "标题", "级别": 1},
        {"类型": "段落", "文本": "正文", "加粗": True, "对齐": "center"},
        {"类型": "表格", "表头": ["列甲", "列乙"], "行": [["值1", "值2"]]},
        {"类型": "分页"},
    ]
}
XLSX参数 = {"工作表列表": [{"表名": "数据表", "列": ["姓名", "数量"], "行": [["张三", 3]]}]}
PPTX参数 = {"幻灯片列表": [{"标题": "演示标题", "要点": ["要点一"], "备注": "备注"}]}
PDF参数 = {"内容块列表": [{"类型": "标题", "文本": "PDF标题"}, {"类型": "段落", "文本": "中文正文"}]}
```

## 调用示例

```python
from 支持库.后端.文档生成 import 生成DOCX, 生成PDF, 校验签名

结果 = 生成DOCX({"内容块列表": [{"类型": "段落", "文本": "你好"}]})
if 结果.成功:
    产物 = 结果.值
    字节 = 产物.字节            # bytes
    媒体类型 = 产物.媒体类型      # application/vnd...wordprocessingml.document
    摘要 = 产物.摘要            # sha256 hex
    版本表 = 产物.附加["提供者版本"]  # 提供者报告版本（可能为空字典）
    耗时秒 = 产物.附加["生成耗时秒"]
```

## 错误码

| 错误码 | 含义 |
|---|---|
| 参数不合法 | 参数非字典/内容列表为空/格式非法 |
| 提供者不可用 | 调用器未装配或对应生成提供者缺失 |
| 生成失败 | 提供者生成异常/产物为空/签名校验未通过 |

## 调用边界

- 本包只经 `公共契约.能力契约.调用器.获取能力调用器` 调用受管提供者
  能力；依赖契约声明空（无第三方包依赖，提供者由运行核心装配）。
- 公开入口只返回统一结果（`公共契约.基础类型.结果类型.结果`），
  不泄漏第三方对象/文件对象/裸句柄。
