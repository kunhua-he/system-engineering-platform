# 网络请求支持库（后端纯标准库原子能力）

原子网络请求能力：HTTP GET/POST 发送与查询串构建。只依赖 Python 标准库
（urllib/ipaddress），无第三方依赖。全部公开能力返回统一结果
（成功/值/错误/错误码）。

## 公开能力

- 发送请求：发送 HTTP GET/POST，返回 {状态码, 响应头, 响应文本, 错误信息}。
- 构建查询串：把参数映射编码为 URL 查询串（空映射返回空串）。

## 安全约束

- SSRF 防护：仅允许 http/https；默认拒绝 回环/内网/私有/保留地址，
  可显式 允许回环 用于本机测试。
- 响应大小上限：超出 最大字节数 中止读取，错误码=响应超限。
- 凭证安全：authorization/x-api-key/cookie 等敏感头不写入错误信息。
- 响应句柄显式 close 释放，不泄漏裸句柄。

## 调用方式

```python
from 支持库.后端.网络请求 import 发送请求, 构建查询串

结果 = 发送请求(地址="https://示例.主机/路径", 方法="GET", 超时秒=10)
if 结果.成功:
    状态码 = 结果.值["状态码"]
    响应文本 = 结果.值["响应文本"]

结果 = 构建查询串({"名称": "示例"})
if 结果.成功:
    查询串 = 结果.值
```

## 错误码

参数不合法 / 请求已取消 / 网络超时 / 网络失败 / 响应超限。

HTTP 错误状态码（4xx/5xx）作为响应返回（值.状态码 + 值.错误信息），
传输层失败（超时/连接失败/解析失败）才返回失败结果。
