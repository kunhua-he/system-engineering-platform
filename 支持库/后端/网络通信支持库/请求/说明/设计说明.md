## 网络通信支持库.请求.发送请求（发送请求）

**说明**：发送 HTTP 请求，适配主流场景：GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS、JSON/表单/原始字节、自定义请求头/Cookie、代理、SSL验证开关、重定向控制、超时/SSRF防护/响应上限

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 地址 | 文本型 | 是 | None | 目标地址 http/https |
| 方法 | 文本型 | 否 | GET | GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS |
| 请求头 | 映射型 | 否 | None | 自定义请求头 {键:值} |
| 请求体 | 任意型 | 否 | None | 请求体：dict(自动JSON)/str/bytes |
| 超时秒 | 双精度数型 | 否 | 10 | 连接/读取统一超时 |
| 最大字节数 | 整数型 | 否 | 5242880 | 响应大小上限，超限中止 |
| 允许回环 | 逻辑型 | 否 | False | 是否允许访问回环地址（本机测试用） |
| 代理 | 文本型 | 否 | None | 代理地址 http://127.0.0.1:端口 |
| SSL验证 | 逻辑型 | 否 | None | false 跳过 SSL 证书验证 |
| 跟随重定向 | 逻辑型 | 否 | None | false 禁止自动重定向 |
| Cookie | 文本型 | 否 | None | Cookie 字符串（可选） |

**返回结构**：{状态码, 响应头, 响应文本, 错误信息}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 响应超限 |
| 网络超时 |
| 网络失败 |
| HTTP错误 |

**调用示例**：

```python
网络通信支持库.请求.发送请求(地址=值, 方法=值, 请求头=值, 请求体=值, 超时秒=值, 最大字节数=值, 允许回环=值, 代理=值, SSL验证=值, 跟随重定向=值, Cookie=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：支持库.资产验证（资产）、支持库.能力契约验证（契约）
