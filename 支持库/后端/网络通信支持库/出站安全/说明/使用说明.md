# 出站安全支持库

出站 URL 的 SSRF 防护（只判定，不发起 HTTP 请求）。

## 能力

`网络通信支持库.出站安全.校验出站URL`

- 入参：`地址`（必填）、`解析DNS`（选填，默认 true）、`DNS超时秒`（选填，默认 10.0）
- 返回：`{允许: 逻辑型, 原因: 文本型, 地址: 文本型}`
- 允许时 `地址` 为规范化 URL；拒绝时 `原因` 为中文说明

## 检查项

1. 仅允许 http/https，URL 不得内嵌认证凭据
2. 字面 IP 直接判定；主机名可选 DNS 解析后逐地址判定
3. 云元数据地址与主机名始终封锁（169.254.169.254 / metadata.google.internal 等）
4. 运营商 NAT 网段 100.64.0.0/10 一并封锁
5. IPv4-mapped IPv6（::ffff:…）按内嵌 IPv4 判定

## 说明

`解析DNS=false` 时只按字面主机名判定（不做解析），适合调用方自己会再做一次解析校验的场景。
