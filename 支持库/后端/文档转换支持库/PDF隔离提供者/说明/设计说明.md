| 参数 | 类型 | 必填 | 默认值 | 说明 |

| 文件路径 | 文本型 | 是 | None | 待解析文件绝对路径 |
| 最大页数 | 整数型 | 否 | 500 | 页数上限，0=不限制 |
| 最大字节数 | 整数型 | 否 | 0 | 文件大小上限，0=不限制 |
| 超时秒 | 双精度数型 | 否 | 90 | 子进程执行超时 |
