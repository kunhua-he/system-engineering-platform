## 文档转换支持库.PDF文本表格.解析PDF（解析PDF）

**说明**：pdfplumber 解析 PDF：文本块/表格块 → 通用文档字典；加密检测/页数大小上限

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | PDF 文件绝对路径 |
| 最大页数 | 整数型 | 否 | 500 | 页数上限 |
| 最大字节数 | 整数型 | 否 | 209715200 | 文件大小上限 |
| 超时秒 | 双精度数型 | 否 | 60 | 解析超时 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 文件不存在 |
| 参数不合法 |
| 提供者不可用 |
| 文件损坏 |
| 文件加密 |
| 超出限制 |
| 超时 |

**调用示例**：

```python
文档转换支持库.PDF文本表格.解析PDF(文件路径=值, 最大页数=值, 最大字节数=值, 超时秒=值)
```
