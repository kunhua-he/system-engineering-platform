## 内部.演示文稿.解析（解析演示文稿）

**说明**：解析 pptx 为平台通用文档字典（幻灯片块{类型/文本/来源位置.幻灯片}、备注入附加字段、图像入资源列表），值结构兼容 通用文档.转字典()

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | 待解析 pptx 文件绝对路径 |
| 格式 | 文本型 | 否 |  | 仅支持 pptx；空=按扩展名推断 |
| 最大幻灯片数 | 整数型 | 否 | 200 | 幻灯片数上限，超过返回 超出限制 |
| 最大字节数 | 整数型 | 否 | 209715200 | 文件大小/解压总量上限，超过返回 超出限制 |
| 超时秒 | 双精度数型 | 否 | 60 | 保留供 ppt 转换链兼容，pptx 原生解析不使用 |

**返回结构**：结果[通用文档]（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 文件不存在 |
| 参数不合法 |
| 提供者不可用 |
| 文件损坏 |
| 超出限制 |

**调用示例**：

```python
内部.演示文稿.解析(文件路径=值, 格式=值, 最大幻灯片数=值, 最大字节数=值, 超时秒=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：支持库.资产验证（资产）、支持库.能力契约验证（契约）

## 内部.演示文稿.生成（生成演示文稿）

**说明**：按 内容参数（幻灯片列表：标题/要点/备注）生成 pptx，返回 结果[生成产物字典]（字节b64/媒体类型/摘要/格式/字节数/诊断）

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 内容参数 | 字典型 | 是 | None | 含 幻灯片列表：每项 {标题/name/文本, 要点/bullets, 备注/notes}；至少一张幻灯片 |

**返回结构**：结果[生成产物]（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 提供者不可用 |
| 生成失败 |

**调用示例**：

```python
内部.演示文稿.生成(内容参数=值)
```
