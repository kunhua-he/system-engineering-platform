## 内部.表格文档.解析（解析表格文档）

**说明**：解析 XLSX 为通用文档字典：工作表块含 类型/文本/表格数据/来源位置.工作表；公式/值契约：数据模式=True 取缓存值，缓存缺失→None→空字符串→整行空则过滤该行；数据模式=False 返回公式文本。OOXML 按不可信 ZIP 校验。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | 待解析 xlsx 文件绝对路径 |
| 数据模式 | 逻辑型 | 否 | True | true=取缓存值 false=公式文本 |
| 最大工作表数 | 整数型 | 否 | 50 | 工作表数上限 |
| 最大行数 | 整数型 | 否 | 200000 | 单表行数上限 |
| 最大字节数 | 整数型 | 否 | 209715200 | 文件大小上限 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 文件不存在 |
| 参数不合法 |
| 提供者不可用 |
| 文件损坏 |
| 文件加密 |
| 超出限制 |

**调用示例**：

```python
内部.表格文档.解析(文件路径=值, 数据模式=值, 最大工作表数=值, 最大行数=值, 最大字节数=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：支持库.资产验证（资产）、支持库.能力契约验证（契约）

## 办公文档支持库.表格文档.生成表格文档（生成表格文档）

**说明**：按 内容参数（工作表列表：表名/行列表；每项可选 单元格映射 A1地址→值、样式映射 地址→样式字典、合并范围、列宽映射、行高映射）生成 xlsx，返回 结果[生成产物字典]（字节b64/媒体类型/摘要）

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 内容参数 | 字典型 | 是 | None | 含 工作表列表：每项 {表名, 行列表[{列名:值}], 单元格映射{A1:值}, 样式映射{A1:{bold,italic,underline,strikethrough,fontSize,fontName,color,fillColor,对齐,wrapText,borderType}}, 合并范围:[A1:B2], 列宽映射{A:宽度}, 行高映射{行号:高度}} |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 提供者不可用 |
| 生成失败 |

**调用示例**：

```python
办公文档支持库.表格文档.生成表格文档(内容参数=值)
```
