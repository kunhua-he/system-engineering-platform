## 文档转换支持库.textutil转换.转换文本文件（转换文本文件）

**说明**：textutil 转换：输入文件 → 目标格式（txt/html/rtf/doc/docx 互转）；返回 文本内容

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入路径 | 文本型 | 是 | None | 输入文件绝对路径 |
| 目标格式 | 文本型 | 是 | None | txt/html/rtf/doc/docx |
| 超时秒 | 双精度数型 | 否 | 60 | 转换超时 |
| 最大输出字节 | 整数型 | 否 | 209715200 | 输出大小上限 |
| 输出目录 | 文本型 | 否 | None | 可选输出目录（默认临时目录自动清理） |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 文件不存在 |
| 提供者不可用 |
| 转换失败 |
| 超时 |
| 超出限制 |

**调用示例**：

