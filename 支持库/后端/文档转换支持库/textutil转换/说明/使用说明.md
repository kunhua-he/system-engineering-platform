# textutil提供者 使用说明

textutil 系统能力独立提供者：文本格式转换（txt/html/rtf/doc/docx 互转、提取文本）。
macOS 系统能力，受控子进程调用；缺少 textutil 返回 提供者不可用（未配置），不伪装成功。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| 文档转换支持库.textutil转换.检查提供者 | 检查 textutil 是否可用（真实独立进程探针 textutil -help + macOS 版本）；缺失 → 提供者不可用 |
| 文档转换支持库.textutil转换.转换文本文件 | textutil 转换：输入文件 → 目标格式（txt/html/rtf/doc/docx 互转）；返回 文本内容 |

## 调用方式

只经 支持库.适配层.textutil提供者 包级入口调用，禁止深入 实现/ 目录。

```python
from 支持库.适配层.textutil提供者 import 检查提供者, 转换文本文件

探针 = 检查提供者()
if not 探针.成功:
    print("提供者不可用:", 探针.错误说明)   # textutil 缺失/未配置

结果 = 转换文本文件("/tmp/示例文档.rtf", "txt", 超时秒=60)
if 结果.成功:
    print(结果.值)   # {文本, 格式, 字节数, 输出路径}
```

## 参数

| 能力 | 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 检查提供者 | 超时秒 | 数字 | 否 | 30 | 版本探针超时秒 |
| 转换文本文件 | 输入路径 | 文本 | 是 | - | 输入文件绝对路径 |
| 转换文本文件 | 目标格式 | 文本 | 是 | - | txt/html/rtf/doc/docx |
| 转换文本文件 | 超时秒 | 数字 | 否 | 60 | 转换超时 |
| 转换文本文件 | 最大输出字节 | 整数 | 否 | 209715200 | 输出大小上限 |
| 转换文本文件 | 输出目录 | 文本 | 否 | 临时目录 | 可选输出目录（默认临时目录自动清理） |

## 错误码

| 错误码 | 场景 |
| --- | --- |
| 参数不合法 | 空路径/空格式/非法超时 |
| 文件不存在 | 输入文件不存在 |
| 提供者不可用 | textutil 不可用或探针失败（可重试） |
| 转换失败 | textutil 退出码非 0 或未产出文件 |
| 超时 | 转换超时（可重试） |
| 超出限制 | 输出文件超过 最大输出字节 |

## 安全约束

结构化参数列表（禁 shell=True）；独立进程组；超时+强制终止；输出大小上限与
输出目录隔离；临时目录/子进程/句柄全路径释放。
