## 内部.文字文档.解析（解析文字文档）

**说明**：解析 DOCX 为通用文档字典：段落块/表格块/图像资源；OOXML 按不可信 ZIP 校验

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | 待解析 docx 文件绝对路径 |
| 格式 | 文本型 | 否 | docx | doc/docx |
| 最大字节数 | 整数型 | 否 | 209715200 | 文件大小上限 |
| 超时秒 | 双精度数型 | 否 | 60 | 保留兼容 |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 文件不存在 |
| 参数不合法 |
| 提供者不可用 |
| 文件损坏 |
| 超出限制 |

**调用示例**：

```python
内部.文字文档.解析(文件路径=值, 格式=值, 最大字节数=值, 超时秒=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：支持库.资产验证（资产）、支持库.能力契约验证（契约）

## 内部.文字文档.生成（生成文字文档）

**说明**：按 内容参数（内容块列表：标题/段落/表格/分页，兼容 数据 嵌套与 加粗）生成 DOCX，返回 结果[生成产物字典]（字节b64/媒体类型/摘要）

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 内容参数 | 字典型 | 是 | None | 含 内容块列表：每项 {类型: 标题/段落/表格/分页, 文本, 级别, 加粗, 表头, 行, 数据{文本/表头/行}} |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 提供者不可用 |
| 生成失败 |

**调用示例**：

```python
内部.文字文档.生成(内容参数=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：支持库.资产验证（资产）、支持库.能力契约验证（契约）
