# python_docx提供者 使用说明

python-docx 独立提供者：DOCX 解析与生成的唯一 python-docx 代码收拢点（纯 Python，主进程导入）。
OOXML 按不可信 ZIP 校验；缺少 python-docx 返回 提供者不可用（未配置），不伪装成功。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| 内部.文字文档.解析 | 受文字文档后端调用的 DOCX 解析实现；不是公开能力 owner |
| 内部.文字文档.生成 | 受文档生成后端调用的 DOCX 生成实现；不是公开能力 owner |

## 调用方式

只经 支持库.后端.文档转换支持库.python_docx提供者 包级入口调用，禁止深入 实现/ 目录。

```python
from 支持库.后端.文档转换支持库.python_docx提供者 import 解析文字文档, 生成文字文档

结果 = 解析文字文档("/tmp/示例文档.docx", 格式="docx")
if 结果.成功:
    print(结果.值)   # 通用文档字典：块列表（段落/表格）+ 资源列表

结果 = 生成文字文档({"内容块列表": [{"类型": "标题", "文本": "示例"}, {"类型": "段落", "文本": "正文"}]})
if 结果.成功:
    print(结果.值)   # 生成产物字典：字节b64/媒体类型/摘要/字节数
```

## 参数

| 能力 | 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 解析文字文档 | 文件路径 | 文本 | 是 | - | 待解析 docx 文件绝对路径 |
| 解析文字文档 | 格式 | 文本 | 否 | docx | doc/docx |
| 解析文字文档 | 最大字节数 | 整数 | 否 | 209715200 | 文件大小上限 |
| 解析文字文档 | 超时秒 | 数字 | 否 | 60 | 保留兼容 |
| 生成文字文档 | 内容参数 | 字典 | 是 | - | 内容块列表：标题/段落/表格/分页 |

## 错误码

| 错误码 | 场景 |
| --- | --- |
| 文件不存在 | 待解析文件不存在 |
| 参数不合法 | 空路径/内容参数非字典/内容块列表为空 |
| 提供者不可用 | python-docx 未安装（可重试） |
| 文件损坏 | OOXML 不可信 ZIP 检查未通过、python-docx 打开失败（损坏/伪装） |
| 超出限制 | 文件大小/成员数/单项大小/总解压体积/压缩比超限 |
| 生成失败 | python-docx 生成异常或产出为空 |

## 安全约束

OOXML 按不可信 ZIP 校验：成员数（500）/单项大小（50MB）/总解压体积（200MB）/
压缩比（100）上限、路径逃逸拒绝、外部关系拒绝；压缩包句柄全路径关闭。
