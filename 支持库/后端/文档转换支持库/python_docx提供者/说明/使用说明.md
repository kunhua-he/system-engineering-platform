# python_docx提供者（支持库.后端.文档转换支持库.python_docx提供者）

- 类型：支持库
- 版本：1.0.3
- 说明：python-docx 独立提供者：DOCX 解析与生成的唯一 python-docx 代码收拢点（纯 Python，主进程导入）。OOXML 按不可信 ZIP 校验。
- 入口：__init__.py
- 权威分工：**调用口径以本文为准**（能力/参数/返回/错误码/调用示例，由能力契约生成）；
  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。

## 能力
### 解析文字文档（`内部.文字文档.解析`）
- 版本：1.0.0
- 一句话说明：解析 DOCX 为通用文档字典：段落块/表格块/图像资源；OOXML 按不可信 ZIP 校验
- 所属支持库或模块：支持库.后端.文档转换支持库.python_docx提供者
- 参数列表：文件路径:文本型, 格式:文本型, 最大字节数:整数型, 超时秒:双精度数型
- 必填参数：文件路径
- 可选参数：格式, 最大字节数, 超时秒
- 返回结构：结果型（统一结果：成功/值/错误码/错误说明）
- 错误码：文件不存在, 参数不合法, 提供者不可用, 文件损坏, 超出限制
- 调用示例：内部.文字文档.解析(格式=docx, 最大字节数=209715200, 超时秒=60.0)
- 依赖能力：无
### 生成文字文档（`内部.文字文档.生成`）
- 版本：1.0.0
- 一句话说明：按 内容参数（内容块列表：标题/段落/表格/分页，兼容 数据 嵌套与 加粗）生成 DOCX，返回 结果[生成产物字典]（字节b64/媒体类型/摘要）
- 所属支持库或模块：支持库.后端.文档转换支持库.python_docx提供者
- 参数列表：内容参数:字典型
- 必填参数：内容参数
- 可选参数：无
- 返回结构：结果型（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 提供者不可用, 生成失败
- 调用示例：内部.文字文档.生成()
- 依赖能力：无
