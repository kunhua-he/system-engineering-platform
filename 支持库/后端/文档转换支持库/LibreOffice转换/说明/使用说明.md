## 文档转换支持库.LibreOffice转换.转换办公文件（转换办公文件）

**说明**：LibreOffice 转换：输入文件 → 目标格式（doc/xls/ppt → 现代格式、任意格式 → pdf）；文本格式返回 文本，二进制返回 字节b64

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 输入路径 | 文本型 | 是 | None | 输入文件绝对路径 |
| 目标格式 | 文本型 | 是 | None | txt/pdf/docx/xlsx/pptx 等 |
| 超时秒 | 双精度数型 | 否 | 60 | 转换超时 |
| 最大输出字节 | 整数型 | 否 | 209715200 | 输出大小上限 |
| 输出目录 | 文本型 | 否 | None | 可选输出目录（默认临时目录自动清理） |

**返回结构**：结果型（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 文件不存在 |
| 提供者不可用 |
| 转换失败 |
| 超时 |
| 超出限制 |

**调用示例**：

```python
文档转换支持库.LibreOffice转换.转换办公文件(输入路径=值, 目标格式=值, 超时秒=值, 最大输出字节=值, 输出目录=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。
