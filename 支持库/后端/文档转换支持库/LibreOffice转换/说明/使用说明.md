# LibreOffice提供者 使用说明

LibreOffice 外部应用独立提供者：文档格式转换（doc/xls/ppt → 现代格式、任意格式 → pdf）。
独立进程组+超时+输出上限+目录隔离；缺少 LibreOffice 返回 提供者不可用（未配置），不伪装成功。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| 文档转换支持库.LibreOffice转换.检查提供者 | 检查 LibreOffice 是否可用（真实版本探针 soffice --version），返回版本；缺失 → 提供者不可用 |
| 文档转换支持库.LibreOffice转换.转换办公文件 | LibreOffice 转换：输入文件 → 目标格式；文本格式返回 文本，二进制返回 字节b64 |

## 调用方式

只经 支持库.适配层.LibreOffice提供者 包级入口调用，禁止深入 实现/ 目录。

```python
from 支持库.适配层.LibreOffice提供者 import 检查提供者, 转换办公文件

探针 = 检查提供者()
if not 探针.成功:
    print("提供者不可用:", 探针.错误说明)   # LibreOffice 未安装/未配置

结果 = 转换办公文件("/tmp/示例文档.docx", "pdf", 超时秒=60)
if 结果.成功:
    print(结果.值)   # 文本格式: {文本, 格式, 字节数}；二进制: {字节b64, 格式, 字节数}
```

## 参数

| 能力 | 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 检查提供者 | 超时秒 | 数字 | 否 | 30 | 版本探针超时秒 |
| 转换办公文件 | 输入路径 | 文本 | 是 | - | 输入文件绝对路径 |
| 转换办公文件 | 目标格式 | 文本 | 是 | - | txt/pdf/docx/xlsx/pptx 等 |
| 转换办公文件 | 超时秒 | 数字 | 否 | 60 | 转换超时 |
| 转换办公文件 | 最大输出字节 | 整数 | 否 | 209715200 | 输出大小上限 |
| 转换办公文件 | 输出目录 | 文本 | 否 | 临时目录 | 可选输出目录（默认临时目录自动清理） |

## 错误码

| 错误码 | 场景 |
| --- | --- |
| 参数不合法 | 空路径/空格式/非法超时与上限 |
| 文件不存在 | 输入文件不存在 |
| 提供者不可用 | LibreOffice 未安装或探针失败（可重试） |
| 转换失败 | soffice 退出码非 0 或未产出文件 |
| 超时 | 转换超时（可重试） |
| 超出限制 | 输出文件超过 最大输出字节 |

## 安全约束

结构化参数列表（禁 shell=True）；独立进程组；启动/执行超时+强制终止兜底；
输出目录隔离；临时目录/子进程/句柄全路径释放。
