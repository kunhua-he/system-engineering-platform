# 协议白名单支持库

## 职责
LLM API 端点协议白名单校验（借鉴 OpenCode runner/model.ts）。

## 能力
| 能力 | 说明 |
|---|---|
| `协议白名单.校验端点` | 校验 api类型 是否在白名单内，openai-compatible 必须有 http/https url |
| `协议白名单.查询白名单` | 返回白名单列表 |

## 调用
```bash
curl -X POST http://127.0.0.1:8866/网关/调用 -H 'Content-Type: application/json' \\
  -d '{"能力id":"协议白名单.校验端点","参数":{"api类型":"openai-compatible","base_url":"http://127.0.0.1:8328"}}'
```

## 边界
- 只依赖 Python 标准库；只校验不请求。
- 白名单：openai / anthropic / openai-compatible（必须有 http/https url）。
