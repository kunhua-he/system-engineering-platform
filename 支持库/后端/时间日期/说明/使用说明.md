# 时间日期支持库（后端纯标准库原子能力）

原子时间日期能力：获取当前时间/格式化/解析/时间戳转换/计算间隔。
固定 Asia/Shanghai 时区（不依赖进程机器隐式本地时区），只依赖 Python
标准库（zoneinfo 系统时区库）。全部公开能力返回统一结果
（成功/值/错误/错误码）。

## 公开能力

- 获取当前时间：返回 ISO 格式文本（含 T，秒精度；可选 IANA 时区参数）。
- 格式化为文本：时间戳按 strftime 格式化为文本。
- 解析文本时间：时间文本按 strptime 格式解析为时间戳。
- 时间戳转换：时间戳转换为 {年, 月, 日, 时, 分, 秒} 结构。
- 计算间隔：两个时间戳间隔秒数（保留 3 位小数）。

## 调用方式

```python
from 支持库.后端.时间日期 import 获取当前时间, 格式化为文本, 解析文本时间

结果 = 获取当前时间()
if 结果.成功:
    当前时间 = 结果.值

结果 = 格式化为文本(0)
if 结果.成功:
    文本 = 结果.值   # "1970-01-01 08:00:00"

结果 = 解析文本时间("2026-01-01 12:00:00")
if 结果.成功:
    时间戳 = 结果.值
```

## 错误码

参数不合法。

## 边界

- 时间戳缺失、类型非法（非数字）、未知时区、时间文本与格式不匹配均返回
  参数不合法；不吞异常、不以成功形状伪装失败。
- 注入时钟/恢复默认时钟 仅测试用，不属公开能力；实现只经包级中文入口
  （__init__.py）暴露。
