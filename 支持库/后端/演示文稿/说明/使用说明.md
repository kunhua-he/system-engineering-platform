# 演示文稿支持库使用说明

## 定位

演示文稿（ppt/pptx）解析原子能力。pptx 用 python-pptx 原生解析；
ppt 旧格式先经 `支持库.后端.文档转换` 的 LibreOffice 转换链转为 pptx
再解析。返回平台通用结果 `结果[通用文档]`（结构见
`公共契约/基础类型/文档结构.py`）。

## 解析产物结构

- 文档类型：`演示文稿`；格式：`ppt`/`pptx`；
  解析方式：`原生`（pptx）/ `转换`（ppt）。
- 块列表：每个幻灯片一个 `类型="幻灯片"` 块，`文本`=该页全部文本
  （文本框段落 + 表格单元格，逐行拼接），`来源位置.幻灯片`=序号。
- 备注：非空时入该幻灯片块的 `附加["备注"]`；
  该页图像资源索引列表入 `附加["图像资源引用"]`。
- 资源列表：幻灯片图像（`类型="图像"`，含媒体类型/文件名/描述/字节数据b64）。
- `提供者版本`：`{"python-pptx": 版本}`；`原始文件摘要`：源文件 sha256。

## 安全约束

- pptx 按 OOXML 不可信 ZIP 检查：文件数、单项大小、解压总量、压缩比、
  路径逃逸、宏（vbaProject.bin）、外部文件引用，违规返回
  `文件损坏` 或 `超出限制`。
- 损坏或扩展名伪装文件返回 `文件损坏`；
  超幻灯片数/超文件大小返回 `超出限制`。
- 缺少 python-pptx 返回 `提供者不可用`，不伪装成功。
- ppt 转换链的临时目录与产物用后必清理；转换失败/超时/提供者缺失
  原样回传错误码。

## 调用示例

```python
from 支持库.后端.演示文稿 import 解析演示文稿

结果 = 解析演示文稿("/tmp/演示.pptx")
if 结果.成功:
    文档 = 结果.值
    for 块 in 文档.块列表:
        print(块.来源位置.幻灯片, 块.文本, 块.附加.get("备注", ""))

# 旧格式（自动走 LibreOffice 转换链）
结果 = 解析演示文稿("/tmp/旧版.ppt", 格式="ppt", 超时秒=90)

# 限制资源
结果 = 解析演示文稿("/tmp/演示.pptx", 最大幻灯片数=50, 最大字节数=104857600)
```

## 错误码

| 错误码 | 含义 |
|---|---|
| 文件不存在 | 源文件不存在 |
| 参数不合法 | 格式非法（仅支持 ppt/pptx） |
| 提供者不可用 | 缺 python-pptx，或 ppt 链缺 LibreOffice |
| 文件损坏 | 不可信 ZIP 检查未通过/损坏/伪装/宏 |
| 超出限制 | 超幻灯片数/超文件大小/超解压总量 |
| 转换失败 | LibreOffice 转换失败 |
| 超时 | ppt 转换链超时（可重试） |
