# 网页解析支持库（后端纯标准库原子能力）

原子网页解析能力：提取网页标题与网页正文。仅用 Python 标准库
html.parser，不依赖任何第三方。全部公开能力返回统一结果
（成功/值/错误/错误码）。

## 公开能力

- 提取网页标题：提取 <title> 标签文本并去除首尾空白；无标题返回空字符串；
  HTML 实体自动解码。
- 提取网页正文：提取 body 文本，剔除 script/style 标签内容，连续空白
  归一化为单个空格，截断到 最大长度（默认 20000）。

## 调用方式

```python
from 支持库.后端.网页解析 import 提取网页标题, 提取网页正文

结果 = 提取网页标题("<html><head><title>示例标题</title></head></html>")
if 结果.成功:
    标题 = 结果.值

结果 = 提取网页正文("<html><body><p>示例正文</p></body></html>", 最大长度=20000)
if 结果.成功:
    正文 = 结果.值
```

## 错误码

参数不合法 / 解析失败。

## 边界

- 网页内容非字符串、最大长度非非负整数返回 参数不合法；
  解析异常返回 解析失败；不吞异常、不以成功形状伪装失败。
- 实现只经包级中文入口（__init__.py）暴露；禁止深入 实现/ 目录。
