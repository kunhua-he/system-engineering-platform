# psycopg提供者 设计说明（设计权威）

> 本文是该库的**设计哲学与边界权威**：它为什么这样切、管什么、不管什么、失败如何表达。
> 调用口径——能力、参数、返回结构、错误码与调用示例——以同目录 `使用说明.md` 为准（由能力契约生成）。
> 两份说明都计入包指纹，任何改动都要升包版本。

psycopg（psycopg3）驱动的**翻译层**（第三方库边界）：唯一直接接触 psycopg 的地方，把驱动英文 API
翻译成中文原语供支持库调用。本层**不对注册表贡献数据库操作能力**，对外 PostgreSQL 能力（连接数据库/
查询数据库/事务执行数据库/连接池状态/关闭数据库连接）统一归 `支持库.后端.数据库连接支持库.psycopg数据库`。
一驱动一支持库，只 import psycopg（纯 Python 模式，主进程加载）。每次调用
自包含连接生命周期，连接对象与游标在调用路径内创建并在 finally 中关闭，
无持久连接状态、绝不泄漏。

## 公开能力

本层只注册**一条**能力：`支持库.适配层.psycopg提供者.检查可用性`（无副作用健康探针）。
下列数据库操作能力**不由本层提供**（2026-09-14 数据库收口后归 `支持库.后端.数据库连接支持库.psycopg数据库`）：

| 能力id | 归属 |
| --- | --- |
| psycopg数据库.连接 | 支持库.后端.数据库连接支持库.psycopg数据库 |
| psycopg数据库.查询 | 支持库.后端.数据库连接支持库.psycopg数据库 |
| psycopg数据库.事务执行 | 支持库.后端.数据库连接支持库.psycopg数据库 |
| psycopg数据库.关闭 | 支持库.后端.数据库连接支持库.psycopg数据库 |

## 调用方式

只经 `支持库.适配层.psycopg提供者` 包级入口调用，禁止深入 `实现/` 目录。

```python
from 支持库.适配层.psycopg提供者 import 打开连接, 解析连接串, 校验连接串

连接串 = "postgresql://主机:5432/数据库"      # 认证段可省略；库名等分量支持 %XX 转义
问题 = 校验连接串(连接串)   # None 表示形状合法（scheme 白名单 postgresql/postgres）；mysql:// 等返回拒绝原因
参数 = 解析连接串(连接串)   # {host, port, dbname, user, 口令}：各 URL 分量统一反转义
```

## 参数结构

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 连接串 | 文本 | 是 | 无 | postgresql:// 或 postgres:// 格式连接串（scheme 白名单；各分量支持 %XX 转义） |
| 超时秒 | 数字 | 否 | 10 | 连接超时秒数 |
| SQL | 文本 | 是 | 无 | SQL 语句（查询） |
| 参数 | 列表 | 否 | [] | 参数化值列表（查询） |
| SQL列表 | 列表 | 是 | 无 | SQL 语句列表（事务执行） |

连接串各 URL 分量（用户/口令/主机/库名）统一做 URL 反转义：`%XX` 形态的库名若原样下传，驱动会按字面量找库，连接必然失败。scheme 不合法（`mysql://` 等）由 `校验连接串` 直接拒绝，不下传给驱动试探。

## 错误码

- `参数不合法`：连接串非文本/scheme 不在 postgresql://|postgres:// 白名单内、超时秒非法、SQL 空、SQL列表 为空
- `提供者不可用`：psycopg 驱动未安装或不可导入
- `超时`：连接或语句执行超时
- `连接失败`：目标 PostgreSQL 不可达（拒绝连接/主机不可达等）
- `查询失败`：SQL 执行异常或连接释放失败

无数据库服务或连接串未配置时，一律返回明确的失败结果（提供者不可用/连接失败），
绝不假装连接成功。
