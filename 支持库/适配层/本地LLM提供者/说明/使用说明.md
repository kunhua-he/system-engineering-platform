# 本地LLM提供者使用说明

## 定位

本地大模型（Qwen 系列等）对话能力的独立提供者。与 `MLXWhisper提供者` 同构：
模型路径/模型名来自配置，MLX/Ollama 只在隔离子进程加载，主进程零导入第三方。

## 配置

| 项 | 环境变量 | 说明 |
|---|---|---|
| 模型路径 | `本地LLM提供者_模型路径` | 模型目录绝对路径 |
| 模型名 | `本地LLM提供者_模型名` | 模型别名（如 qwen3:32b，Ollama 模式） |

优先使用调用方传入的配置字典 `配置={模型路径/模型名}`，缺省读环境变量。
两者皆空 → 返回 `未配置模型`（绝不伪装可用）。

## 能力

| 能力id | 用途 |
|---|---|
| `对话.检查可用性` | 探针：{可用, 模型名, 模型版本} |
| `对话.生成` | 生成回复：{文本, 模型名, 是否截断} |
| `对话.获取模型信息` | 可用清单/当前模型/库版本 |

## 调用示例

```python
from 支持库.适配层.本地LLM提供者 import 生成, 检查可用性

结果 = 检查可用性()
if 结果.成功:
    print(结果.值)
else:
    print(结果.错误码, 结果.错误说明)

结果 = 生成(提示="你好", 系统提示="你是一个助手", 最大生成token=1024, 温度=0.7)
if 结果.成功:
    print(结果.值["文本"])
```

## 行为边界

- 未配置模型 → `未配置模型`（如实返回，禁止模拟成功）。
- 模型路径非目录 → `模型缺失`。
- 子进程超时（默认 600s）→ SIGTERM 再 SIGKILL 整个进程组。
- 输出超 16MB → 终止并返回 `超出限制`。
- 非零退出码/无效 JSON → `进程崩溃`（可重试）。
- 统一结果：成功/值/错误码/错误说明/可重试。
