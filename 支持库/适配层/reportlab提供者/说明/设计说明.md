独立 PDF 生成提供者，reportlab 隔离在一次性子进程中执行（主进程绝不 import reportlab）：
参数预校验与结果归并在 实现/子进程管理器.py，第三方库只在 实现/子进程入口.py 内加载。
渲染逻辑唯一实现在本包 实现/生成PDF.py（表格渲染在 实现/渲染表格.py）。
中文字体优先注册系统字体，失败回退内置 CID 字体。

后端腿 `支持库.后端.文档转换支持库.PDF生成` 的同名件已降为转调门面（同一模块对象），
本包是该配对的唯一实现；能力 id、参数、返回与错误码两腿逐字不变。

## 公开能力

- `PDF生成.生成PDF(参数) → 结果[生成产物字典]`

## 调用示例

```python
from 支持库.适配层.reportlab提供者 import 生成PDF

结果 = 生成PDF({
    "标题": "月度报告",
    "段落列表": [
        "本月销售稳步增长。",
        {"文本": "重点客户续约完成。", "加粗": True},
    ],
    "表格列表": [
        {"表头": ["产品", "销量"], "行": [["苹果", "3"], ["香蕉", "5"]]},
    ],
})
if 结果.成功:
    产物 = 结果.值
    # 产物: 字节b64 / 媒体类型 / 摘要 / 字节数 / 提供者版本 / 诊断
else:
    print(结果.错误码, 结果.错误说明)
```

## 参数结构

| 键 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 标题 | 文本 | 否 | 文档标题（居中大字） |
| 段落列表 | 列表 | 否 | 元素为文本或字典 `{文本, 加粗}` |
| 表格列表 | 列表 | 否 | 元素为字典 `{表头: [单元格], 行: [[单元格]]}` |

标题/段落列表/表格列表至少提供一项；两项列表必须为列表。

## 错误码

- `参数不合法`：参数非字典、列表类型错误或内容为空
- `提供者不可用`：子进程起不来或 reportlab 环境不可用（隔离形态下由唯一实现判定，可重试）
- `生成失败`：reportlab 渲染异常、生成结果为空，或子进程超时/崩溃（真实原因写进错误说明）

## 隔离形态

主进程绝不 import reportlab：`实现/子进程管理器.py` 预校验参数后拉起一次性子进程
（独立进程组，cwd=平台根），`实现/子进程入口.py` 在子进程内 import reportlab 并调用
本包渲染器；调用返回前进程组一律回收（终止 → 宽限 → 强杀 → 复查），不留残留进程。
错误码不因隔离而扩张：子进程超时/崩溃一律归并到 `生成失败`。

## 中文字体策略

优先注册 `/System/Library/Fonts/PingFang.ttc`、
`/System/Library/Fonts/STSong.ttf`、`/System/Library/Fonts/Supplemental/Songti.ttc`；
全部失败时回退 reportlab 内置 `STSong-Light` CID 字体（无需字体文件）。
