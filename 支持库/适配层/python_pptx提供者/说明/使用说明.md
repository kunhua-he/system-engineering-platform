# python-pptx 提供者使用说明

## 定位（版本 1.0.0）

`支持库/适配层/python-pptx提供者/` 是 python-pptx 的独立提供者适配层，把
演示文稿（pptx）的解析与生成能力收拢到一处，直接 `import pptx`（纯 Python，
主进程加载）。供 支持库.后端.演示文稿 与 支持库.后端.文档生成 改造后委托调用，
也可被项目适配层直接使用。

## 公开能力

| 能力id | 入口函数 | 说明 |
|---|---|---|
| 演示文稿.解析演示文稿 | 解析演示文稿 | pptx → 结果[通用文档]（幻灯片块/备注/图像资源） |
| 演示文稿.生成演示文稿 | 生成演示文稿 | 幻灯片列表 → 结果[生成产物字典]（字节b64/媒体类型/摘要） |

调用方式（能力注册表）与直接导入均可用：

```python
from 支持库.适配层.python-pptx提供者 import 解析演示文稿, 生成演示文稿

结果 = 解析演示文稿("示例.pptx")
文档 = 结果.值                      # 通用文档对象；文档.转字典() 为通用文档字典
字典 = 结果.值.转字典()             # 块列表[].转字典() 含 类型/文本/来源位置.幻灯片

结果 = 生成演示文稿({"幻灯片列表": [{"标题": "标题", "要点": ["要点一"], "备注": "备注"}]})
产物 = 结果.值                      # 含 字节b64/媒体类型/摘要/格式/字节数/诊断
```

## 参数

- 解析演示文稿：文件路径（必填）；格式（默认 ""，仅支持 pptx）；最大幻灯片数
  （默认 200）；最大字节数（默认 209715200）；超时秒（默认 60，保留供 ppt 转换链
  兼容，pptx 原生解析不使用）。
- 生成演示文稿：内容参数（必填字典），含 幻灯片列表：每项
  {标题/name/文本, 要点/bullets, 备注/notes}，至少一张幻灯片。

## 返回结构（与 公共契约.基础类型.文档结构 兼容）

- 解析：值 为 通用文档（文档类型="演示文稿"、格式="pptx"、块列表、资源列表），
  块 类型="幻灯片"，来源位置.幻灯片=页码，文本=形状文本（含文本框/表格），
  备注/图像资源引用 入附加字段；转字典() 与平台 通用文档.转字典() 一致。
- 生成：值 为字典，键含 字节b64（base64 文本）、媒体类型、摘要（sha256）、
  格式、字节数、诊断——与 生成产物.转字典() 兼容并附加 字节b64。

## 错误码

| 错误码 | 场景 |
|---|---|
| 文件不存在 | 待解析文件不存在 |
| 参数不合法 | 格式非 pptx、内容参数非字典、幻灯片列表为空/无可渲染项 |
| 提供者不可用 | 缺少 python-pptx（可重试） |
| 文件损坏 | OOXML 不可信 ZIP 检查未通过、无法打开（损坏/伪装） |
| 超出限制 | 文件大小/解压总量超限、幻灯片数超限 |
| 生成失败 | pptx 生成异常或结果为空 |

## 安全约束

OOXML 按不可信 ZIP 处理：条目数上限（5000）、单项大小/压缩比（1000）/
解压总量上限、路径逃逸（绝对路径/`..`）、宏（vbaProject.bin）、
外部 file: 引用全部拒绝。

## 目录结构（七同步 + 能力定义）

```text

├── __init__.py             # 包级中文入口（文件路径加载实现）+ 注册能力
├── 包声明.json              # 包身份与能力声明
├── 能力定义.json            # 能力定义唯一事实源（能力列表）
├── 能力契约/参数契约.json    # 能力参数/返回/错误码契约
├── 实现/演示文稿.py          # python-pptx 解析与生成实现（≤160 行）
├── 说明/使用说明.md          # 本文件
├── 验证场景引用.json         # 验证场景引用
└── 完整性摘要.json           # 文件清单与 sha256
```

注意：目录名含连字符，不能作 Python 模块名导入，统一按文件路径加载
（importlib.util.spec_from_file_location），公开入口在 __init__.py。
