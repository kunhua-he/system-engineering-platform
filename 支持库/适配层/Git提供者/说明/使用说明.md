# Git提供者（支持库.适配层.Git提供者）

- 类型：支持库
- 版本：1.0.1
- 说明：Git 外部命令独立提供者：worktree 创建/查询/关闭、提交、回滚、挑拣合入、当前状态、获取当前提交哈希。分支名/路径/提交哈希结构化参数白名单（拒绝空格/换行/;|&`$ 等元字符），全部命令以 subprocess 参数列表受管执行（禁 shell 拼接）。
- 入口：__init__.py
- 权威分工：**调用口径以本文为准**（能力/参数/返回/错误码/调用示例，由能力契约生成）；
  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。
