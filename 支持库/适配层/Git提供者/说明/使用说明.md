# Git提供者 使用说明

Git 外部命令独立提供者：worktree 创建/查询/关闭、提交、回滚、挑拣合入、当前状态、获取当前提交哈希。
一个第三方（git）一个提供者，不混装其他命令。

## 公开能力

| 能力id | 功能 | 成功值 |
|---|---|---|
| Git操作.检查提供者 | git --version 真实探针 | {git, 版本} |
| Git操作.创建工作区 | git worktree add [-b 分支名] 路径 [起始点] | {路径, 分支} |
| Git操作.查询工作区 | git worktree list --porcelain 摘要 | {工作区列表} |
| Git操作.关闭工作区 | 非强制 git worktree remove | {已关闭} |
| Git操作.提交 | git add 指定路径 + git commit | {提交, 消息, 路径列表} |
| Git操作.回滚 | git revert --no-edit | {回滚, 新提交} |
| Git操作.挑拣合入 | git cherry-pick | {挑拣合入, 新提交} |
| Git操作.当前状态 | status/log 摘要 | {分支, 未提交修改, 最近提交} |
| Git操作.获取当前提交哈希 | git rev-parse HEAD + 分支 | {提交哈希, 分支} |

## 安全边界

- **参数白名单**：分支名/起始点 禁止 空白 与 `;|&`$"'`、C0 控制字符
  （中文等可打印字符放行，git 自身规则如 `..`/尾斜杠由 git 校验）；
  提交哈希只允许 7-40 位十六进制；路径必须为绝对路径；三者一律拒绝
  空格/换行/`;|&`$` 等 shell 元字符。
- **禁 shell 拼接**：全部 git 调用使用 subprocess 参数列表执行（`git -C 仓库 …`），
  绝不使用 shell=True 或字符串拼接。
- **受管执行**：独立进程组（start_new_session）+ 超时 SIGTERM→SIGKILL 进程组回收；
  标准输出上限 4MB；超限返回 超出限制。
- **路径越界**：提交路径必须解析后落在仓库目录内，否则 路径越界。
- **关闭工作区非强制**：存在未提交修改（含未跟踪文件）时返回 未提交修改 拒绝关闭。

## 生命周期覆盖

| 场景 | 行为 |
|---|---|
| 正常调用 | 返回统一结果，值为各能力成功值 |
| git 缺失/启动失败 | 提供者不可用（可重试） |
| 执行超时 | 进程组 SIGTERM→SIGKILL 强杀，返回 超时（可重试） |
| 输出超限 | 超出限制 |
| revert/cherry-pick 冲突 | 自动 `--abort` 恢复干净状态，返回 冲突（详情带 中止成功） |
| 关闭工作区有未提交修改 | 未提交修改（非强制拒绝） |
| 仓库目录不存在/非仓库 | 仓库不存在（获取当前提交哈希 除外：该能力统一 命令失败） |
| 获取当前提交哈希 detached HEAD | 正常返回，分支字段为 HEAD |

## 错误码

| 错误码 | 含义 |
|---|---|
| 参数不合法 | 白名单拒绝（元字符/相对路径/空值）或参数类型错误 |
| 仓库不存在 | 目录不存在或不是 git 仓库 |
| 未提交修改 | 关闭工作区前发现未提交修改（非强制拒绝） |
| 冲突 | revert/cherry-pick 冲突，已自动中止 |
| 路径越界 | 提交路径不在仓库目录内 |
| 命令失败 | git 非零退出且非上述语义 |
| 提供者不可用 | 无法启动 git（可重试） |
| 超时 | 命令执行超过超时秒（可重试） |
| 超出限制 | git 输出超过上限 |

## 调用方式

只经 `支持库.适配层.Git提供者` 包级入口调用，禁止深入 实现/ 目录。
