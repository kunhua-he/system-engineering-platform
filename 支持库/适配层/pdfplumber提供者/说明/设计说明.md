# pdfplumber提供者 设计说明（设计权威）

> 本文是该库的**设计哲学与边界权威**：它为什么这样切、管什么、不管什么、失败如何表达。
> 调用口径——能力、参数、返回结构、错误码与调用示例——以同目录 `使用说明.md` 为准（由能力契约生成）。
> 两份说明都计入包指纹，任何改动都要升包版本。

pdfplumber 独立提供者：PDF 文本与表格解析。纯 Python，主进程导入（缺库 → 提供者不可用）。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| PDF文本表格.解析PDF | pdfplumber 解析 PDF：文本块/表格块 → 通用文档字典；加密检测/页数大小上限 |
| PDF文本表格.提取表格 | 提取指定页表格数据（二维数组） |

## 调用方式

只经 支持库.适配层.<包名> 包级入口调用，禁止深入 实现/ 目录。
