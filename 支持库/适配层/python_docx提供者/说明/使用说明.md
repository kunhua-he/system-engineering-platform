# python_docx提供者 使用说明

python-docx 独立提供者：DOCX 解析与生成的唯一 python-docx 代码收拢点（纯 Python，主进程导入）。OOXML 按不可信 ZIP 校验。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| 文字文档.解析文字文档 | 解析 DOCX 为通用文档字典：段落块/表格块/图像资源；OOXML 按不可信 ZIP 校验 |
| 文字文档.生成文字文档 | 按 内容参数（内容块列表：标题/段落）生成 DOCX，返回 结果[生成产物字典]（字节b64/媒体类型/摘要） |

## 调用方式

只经 支持库.适配层.<包名> 包级入口调用，禁止深入 实现/ 目录。
