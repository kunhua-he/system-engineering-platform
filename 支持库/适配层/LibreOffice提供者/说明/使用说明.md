# LibreOffice提供者 使用说明

LibreOffice 外部应用独立提供者：文档格式转换（doc/xls/ppt → 现代格式、任意格式 → pdf）。独立进程组+超时+输出上限+目录隔离。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| LibreOffice转换.检查提供者 | 检查 LibreOffice 是否可用，返回版本或缺失说明 |
| LibreOffice转换.转换办公文件 | LibreOffice 转换：输入文件 → 目标格式；文本格式返回 文本，二进制返回 字节b64 |

## 调用方式

只经 支持库.适配层.<包名> 包级入口调用，禁止深入 实现/ 目录。
