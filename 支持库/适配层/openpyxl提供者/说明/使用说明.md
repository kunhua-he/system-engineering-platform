# openpyxl 提供者使用说明

## 定位

XLSX 解析与生成的**唯一 openpyxl 代码收拢点**（主进程直接 import，纯 Python）。
支持库后端（表格文档 / 文档生成）不再直接触碰 openpyxl，统一经本提供者调用。

## 公开能力

```text
调用者
  → openpyxl提供者.解析表格文档(文件路径, 数据模式=True) → 结果[通用文档字典]
  → openpyxl提供者.生成表格文档(内容参数dict) → 结果[生成产物字典]
```

注册能力 id（适配层提供者前缀，平台惯例同 PDF隔离提供者）：

| 注册能力 id | 领域契约名（后端组合层委托入口） |
|---|---|
| openpyxl提供者.解析表格文档 | 内部.表格文档.解析 |
| openpyxl提供者.生成表格文档 | 表格文档.生成表格文档 |

说明：`内部.表格文档.解析` 已由 支持库.后端.表格文档 占用（发现器
强制能力 id 唯一），本提供者按适配层惯例注册 `openpyxl提供者.*` 前缀 id；
后端组合层改造时按 支持库.后端.PDF文档 → PDF隔离提供者 的委托模式接入。

## 公式/值契约（数据模式）

| 数据模式 | 行为 |
|---|---|
| True（默认） | `data_only=True` 取缓存值；缓存缺失 → None → 空字符串 → 整行空则过滤该行 |
| False | 返回公式文本本身（如 `=SUM(A1:A2)`） |

单元格一律字符串化（数字 95 → "95"）；read_only 双开值遍历，逐工作表产出
工作表块：`{类型: "工作表", 文本, 来源位置: {工作表: 表名}, 资源引用: None, 表格数据: 行列表}`，
值结构兼容 `公共契约.基础类型.文档结构.通用文档.转字典()`。

## 生成内容参数

```python
{"工作表列表": [
    {"表名": "成绩单", "列": ["姓名", "分数"], "行": [["张三", 95], {"姓名": "李四", "分数": 88}]},
    {"标题": "汇总", "rows": [["合计"], [183]]},   # 兼容 name/columns/rows 键
]}
```

- 表名键：`表名`/`name`/`标题`（默认"工作表"，截断 31 字符）；
- 列键：`列`/`columns`；行键：`行`/`rows`；行支持 list/tuple/dict；
- 单元格支持 文本/标注/value/name 字典；至少一个可写单元格，否则 参数不合法。

## 生成产物字典

```python
{"格式": "xlsx", "字节b64": "...", "媒体类型": "...spreadsheetml.sheet",
 "摘要": "sha256", "诊断": [...], "提供者版本": {...}, "字节数": N}
```

## 安全与错误码

OOXML 按**不可信 ZIP** 处理：成员数/单项大小/总解压大小/压缩比上限、
路径逃逸拒绝、外部关系拒绝；底层异常一律转稳定错误码，不泄漏。

| 错误码 | 场景 |
|---|---|
| 文件不存在 | 路径不是文件 |
| 参数不合法 | 数据模式非布尔 / 内容参数或工作表列表非法 / 无可写单元格 |
| 提供者不可用 | openpyxl 缺失或导入失败（可重试） |
| 文件损坏 | 非 ZIP / 伪装文本 / 缺 workbook / 成员路径越界 / 外部关系 |
| 文件加密 | openpyxl 报加密包（含 password/encrypt） |
| 超出限制 | 文件大小 / 成员数 / 单项大小 / 总解压体积 / 压缩比超限 |
| 生成失败 | 生成异常或空字节 |

## 依赖注入（测试用）

测试通过 `mock.patch.object(表格文档实现, "加载提供者", return_value={"openpyxl": None, "版本": {...}})` 模拟提供者不可用，禁止修改 sys.modules。
