# psycopg2提供者 使用说明

psycopg2提供者独立提供者：连接/查询/事务执行/关闭。一驱动一支持库，只 import 对应驱动。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| psycopg2数据库.连接 | pg8000 连接测试：成功返回 {已连接: true} |
| psycopg2数据库.查询 | 查询：返回 {行列表: [{列名: 值}...]}；注意 pg8000 参数化值返回字符串 |
| psycopg2数据库.事务执行 | 事务执行：全部成功提交；任一失败回滚 |
| psycopg2数据库.关闭 | 关闭：本提供者每次调用自包含连接，关闭为空操作 |

## 调用方式

只经 支持库.适配层.<包名> 包级入口调用，禁止深入 实现/ 目录。
