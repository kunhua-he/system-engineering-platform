## 定位

把 **tesseract OCR 外部命令** 封装为独立支持库提供者：图片 OCR 识别
（文本 / 词级数据）、语言包列表、版本探针。tesseract 是外部应用
（非 pip 包，依赖锁声明最低版本 5.0.0），所有调用一律经 **受管进程**
执行：独立进程组（start_new_session）、killpg 强杀、超时、取消、
输出上限、临时文件清理、零残留。

## 公开能力（分组 OCR识别）

| 能力id | 功能 | 成功值 |
|---|---|---|
| OCR识别.识别图片 | 图片 OCR 识别（路径/字节二选一） | {文本} 或 {词列表} |
| OCR识别.语言包列表 | 列出已安装语言包 | {语言列表, 数据目录, 数量} |
| OCR识别.版本探针 | 探测版本与可用性 | {tesseract, 版本, 满足最低版本} |

## 命令路径配置覆盖体系

tesseract 可执行文件路径按优先级解析：**函数参数 `命令路径` > 环境变量
`Tesseract提供者_命令路径` > 默认 PATH 探测（which tesseract）**。

| 配置场景 | 行为 |
|---|---|
| 未显式配置，PATH 探测命中 | 使用探测路径（默认行为） |
| 未显式配置，PATH 未找到 | 返回 工具缺失（可重试） |
| 显式路径不存在 | 返回 工具缺失（可重试） |
| 显式路径存在但不可执行 | 返回 命令失败（可重试） |
| 版本低于最低版本 5.0.0 | 版本探针 返回 版本不兼容（可重试，详情含当前/最低版本） |

配置细节（路径值）不会出现在错误消息与日志中，只描述配置状态，
避免敏感配置泄露。

## 关键实现决策

- **绝对路径坑（实测）**：Homebrew tesseract（5.5.2）无法读取绝对路径
  图片（Leptonica fopen 失败）。一律以图片所在目录为 cwd + **相对文件名**
  启动；图片字节输入经临时目录落盘后同样以相对名调用，finally 即时清理。
- **零临时文件**：识别输出走 `stdout` 目标（文本 / TSV 词级），tesseract
  不落任何文件；库内唯一临时文件是字节输入落盘，用完即清。
- **错误分类**：语言包缺失（stderr 含 traineddata/Failed loading language）
  / 识别失败（图片不可读等）/ 进程崩溃（信号杀死）/ 超时 / 取消 /
  超出限制 / 工具缺失 / 提供者不可用；退出码非 0 一律不伪装成功。

## 生命周期覆盖

| 场景 | 行为 |
|---|---|
| tesseract 未安装 / 显式路径不存在 | 如实返回 工具缺失（可重试），不伪装成功 |
| 显式路径不可执行 | 返回 命令失败（可重试） |
| 版本低于最低版本 | 版本探针 返回 版本不兼容（可重试） |
| 正常调用 | 统一结果；值为 文本/词列表/语言列表/版本信息 |
| 执行超时 | 进程组 SIGTERM→SIGKILL，返回 超时（可重试） |
| 取消事件被设置 | 终止进程组，返回 取消（可重试） |
| 输出超上限 | 终止进程组，返回 超出限制 |
| 进程被信号杀死 | 返回 进程崩溃（可重试） |
| 语言包缺失 | stderr 分类 → 语言包缺失 |
| 停止/残留清理 | 每次调用后进程组终止、管道关闭、临时目录清理，零残留 |

## 模拟未配置（测试用依赖注入）

禁止修改 sys.modules。测试通过 `mock.patch.object(提供者, "_查找工具",
return_value=None)` 注入工具缺失语义；本机真实缺失时测试如实
`skipTest("本机未配置 tesseract")`，绝不模拟成功。

## 图片字节参数两种形态（跨宿主可序列化）

识别图片 的 图片字节 参数同时接受二进制与 base64 文本（S0.1 公开契约
只允许跨宿主可序列化数据，二进制一律以中文 base64 字段传递）：

```python
结果 = 识别图片(图片字节=二进制字节)          # 本机直接调用
结果 = 识别图片(图片字节="iVBORw0KGgo...")    # 跨宿主/契约调用示例（base64 文本）
```

base64 文本非法 → 参数不合法。取消事件 参数类型为 资源引用
（threading.Event），跨宿主调用置 None，取消语义经 取消令牌id 文本透传。

## 参数与调用示例

| 能力 | 必填参数 | 可选参数 | 调用示例 |
| --- | --- | --- | --- |
| 识别图片 | 图片路径 或 图片字节（二选一） | 语言/词级数据/超时秒/取消事件/输出上限字节/命令路径 | `识别图片(图片字节=字节, 语言="eng")` |

聚合契约逐能力对称）；公开导出 `__all__` 含全部能力函数与 `注册能力`。

## 错误码

| 错误码 | 含义 |
|---|---|
| 参数不合法 | 路径与字节二选一被违反 / 语言空 / 超时非正数 等 |
| 文件不存在 | 图片路径不存在 |
| 工具缺失 | tesseract 不在 PATH，或显式配置路径不存在（可重试） |
| 命令失败 | 显式配置路径存在但不可执行（可重试） |
| 版本不兼容 | 版本低于最低版本 5.0.0（可重试，仅版本探针） |
| 语言包缺失 | traineddata 无法加载 |
| 识别失败 | tesseract 运行失败且非语言包问题（可重试） |
| 进程崩溃 | 进程被信号杀死或返回无效词级数据（可重试） |
| 超时 | 执行超过超时秒（可重试） |
| 取消 | 取消事件被设置（可重试） |
| 超出限制 | stdout 输出超过上限 |
| 提供者不可用 | 命令启动失败或退出码非 0（可重试） |
