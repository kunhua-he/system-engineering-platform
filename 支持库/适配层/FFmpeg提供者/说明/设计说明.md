FFmpeg 外部命令独立提供者：ffprobe 媒体探测（时长/流/格式）、ffmpeg 转码/音轨抽取/抽帧。外部进程受管执行（独立进程组+超时+取消整组回收+输出上限截断+临时文件零残留）；缺少 ffmpeg/ffprobe 返回 提供者不可用（未配置语义），不伪装成功。进程组启动与整组终止全部收口在 `公共契约.运行时`（`平台适配.子进程组启动标志()` / `进程终止.强制结束子进程`），调用点不写平台判断。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| FFmpeg媒体.检查提供者 | 检查 ffmpeg/ffprobe 是否可用，返回版本；缺失 → 提供者不可用 |
| FFmpeg媒体.探测媒体 | ffprobe 探测：返回 {时长秒, 流列表, 格式, 大小字节, 比特率}；损坏 → 损坏媒体 |
| FFmpeg媒体.提取音频 | 提取首个音频轨（wav/mp3/aac/m4a/ogg/flac）；无音轨 → 无音轨；超长 → 超长媒体 |
| FFmpeg媒体.转码 | ffmpeg 转码（mp4/mkv/webm/mov/avi）；编码选项白名单：分辨率/视频码率/音频码率/帧率 |
| FFmpeg媒体.抽取帧 | ffmpeg 抽帧（jpg/png，时间点秒）：返回 {字节b64, 格式, 宽度, 高度}；宽度/高度为输出帧实测真实尺寸 |

## 调用方式

只经 支持库.适配层.FFmpeg提供者 包级入口调用，禁止深入 实现/ 目录。

## 统一错误码

参数不合法 / 文件不存在 / 提供者不可用 / 损坏媒体 / 无音轨 / 超长媒体 / 超时 / 取消 / 进程崩溃 / 超出限制

## 行为约束

- 外部进程独立进程组启动（`平台适配.子进程组启动标志()`），超时/取消经 `进程终止.强制结束子进程()` 整组回收（含孙进程），零残留；
- stdout/stderr 受限读取超限截断并继续排空，防管道阻塞；
- 临时输出文件 try/finally 强制清理；输出路径 显式指定时保留文件不清理；
- 抽帧返回的 宽度/高度 为输出帧文件经 ffprobe 受控探测链实测的真实尺寸，禁止固定值/硬编码；
- 编码选项走白名单（键与值格式双重校验），禁 shell、结构化参数列表。
