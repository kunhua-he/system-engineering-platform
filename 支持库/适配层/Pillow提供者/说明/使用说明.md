# Pillow 提供者使用说明

## 定位

把 Pillow（PIL，C 原生扩展）隔离到**独立子进程**执行。
平台主进程、测试器、后端和发布门禁绝不直接加载 PIL，原生扩展的
崩溃、资源占用与解释器关闭行为全部封闭在一次性子进程内。

只封装当前真实需要的 9 个能力（分组 **图像解码**），不翻译 SDK：

| 能力id | 功能 | 成功值 |
|---|---|---|
| 图像解码.解码图像 | 打开并完整解码图像 | {格式, 宽度, 高度, 模式} |
| 图像解码.像素统计 | 统计像素与平均颜色 | {宽度, 高度, 像素数, 平均颜色{红,绿,蓝}} |
| 图像解码.生成占位图 | 生成纯色/渐变/文本占位图 | {图像b64, 格式, 宽度, 高度} |
| 图像解码.生成缩略图 | 按最大边长生成等比例缩略图（只缩不放大） | {图像b64, 格式, 宽度, 高度} |
| 图像解码.图像EXIF转置 | 按 EXIF orientation 转置图像方向 | {图像b64, 格式, 宽度, 高度} |
| 图像解码.透明背景合成 | RGBA/LA/P 透明图像与背景色合成（输出 RGB PNG） | {图像b64, 格式, 宽度, 高度} |
| 图像解码.计算感知哈希 | 计算感知哈希（aHash/dHash/pHash，64 位确定性） | {哈希, 哈希类型} |
| 图像解码.缩放图像 | 精确缩放（宽高至少一个，缺省一侧按纵横比推算） | {图像b64, 格式, 宽度, 高度} |
| 图像解码.重编码图像 | 重编码为 JPEG/PNG/WebP（质量 1-100） | {图像b64, 格式, 宽度, 高度} |

## 架构

```text
主进程调用者
  → Pillow提供者.解码图像 / 像素统计 / 生成占位图 / 生成缩略图 /
    图像EXIF转置 / 透明背景合成 / 计算感知哈希 / 缩放图像 / 重编码图像
    → 启动一次性子进程（独立进程组，cwd=平台根）
      → 实现/子进程入口.py（内部才 import PIL）
        → stdin 一行 JSON 请求，stdout 一行 JSON 响应
        → 完成后 os._exit(0) 跳过模块销毁
```

图像字节一律经 base64 传入子进程；字节上限 64MB，像素上限 4000 万
（像素统计 2500 万），超限返回 **超大**；新增能力 超时秒 参数
上限 60 秒，超限返回 **参数不合法**。

### 子进程自举（第二十八阶段）

入口启动时依次把 平台客户端环境目录 与 平台根 加入 sys.path（幂等）：
- 部署布局：解析 `工程缓存/制品仓库/平台客户端环境/当前.json`
  激活指针（或入口文件 `parents[5]`），使部署客户端重写为
  `平台客户端.` 前缀的导入可直接解析；
- 源码布局：回退入口文件 `parents[4]`（平台根）；
- 清空 PYTHONPATH 后最小调用（如 解码图像）仍成功，不依赖外部
  环境变量桥接；
- 测试/部署可用环境变量 `Pillow提供者_客户端环境目录` 覆盖环境目录。

## 生命周期覆盖

| 场景 | 行为 |
|---|---|
| 启动失败 | 返回 提供者不可用（可重试） |
| 正常调用 | 返回统一结果，值为 解码信息/统计信息/占位图/缩略图/转置/合成/哈希/缩放/重编码信息 |
| 执行超时 | 进程组 SIGTERM→SIGKILL 强杀，返回 超时（可重试） |
| 子进程崩溃/非零退出 | 返回 提供者崩溃（可重试），下次调用重新启动 |
| 无有效响应 | 返回 提供者崩溃 |
| 停止/残留清理 | 每次调用结束后确保进程组终止，无残留进程/文件 |
| 字节状态 | 空字节/非法参数/格式未知/文件损坏/超大 逐类映射稳定错误码 |

## 模拟提供者不可用（测试用依赖注入）

禁止修改 sys.modules。通过环境变量让子进程按需禁用库：

```bash
Pillow提供者_禁用库=PIL   # 子进程内不加载 PIL → 提供者不可用
```

测试中使用 `mock.patch.dict(os.environ, {...})` 注入即可，不触碰 sys.modules。

## 错误码

| 错误码 | 含义 |
|---|---|
| 参数不合法 | 空字节/宽高非正整数/占位类型非法/颜色不合法/哈希类型非法/格式非法/质量越界/超时秒超上限（主进程或子进程判定） |
| 提供者不可用 | 子进程启动失败或 Pillow 被禁用/缺失（可重试） |
| 提供者崩溃 | 子进程异常退出或返回无效响应（可重试） |
| 超时 | 子进程执行超过超时秒（可重试） |
| 格式未知 | 字节内容无法识别为任何图像格式 |
| 文件损坏 | 图像打开或完整解码/编码失败（数据损坏/截断） |
| 超大 | 字节超过 64MB、像素数超过能力上限或子进程输出超过 64MB |
