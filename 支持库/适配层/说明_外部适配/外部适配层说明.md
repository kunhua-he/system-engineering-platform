# 外部适配层说明

## 定位

平台无关的外部资源适配契约与模拟提供者。**当前只实现契约、模拟提供者
和验证场景**，不安装第三方库、不连接真实服务。

真实数据库、真实服务器、真实 DLL 的连接逻辑放到未来的**提供者适配层**，
不得写入核心支持库。

## 适配器清单

| 适配器 | 类型 | 模拟能力 |
|--------|------|----------|
| 数据库适配器 | 数据库 | 检查可用/版本/连接/执行最小操作(SELECT)/关闭；坏查询→协议错误 |
| HTTP服务适配器 | HTTP服务 | 检查可用/版本/连接/请求(/超时→超时, /错误→内部错误)/关闭 |
| 本地进程适配器 | 本地进程 | 检查可用/版本/启动/执行命令/停止；坏命令→参数错误 |
| 动态库适配器 | 动态库 | 检查可用/版本/加载/调用函数/卸载；缺函数→版本不兼容 |

## 统一接口（外部适配器 契约基类）

```python
检查可用() -> 结果     # 未安装/不可访问返回明确错误码
获取版本() -> 结果
建立连接() -> 结果     # 成功后资源状态=已连接
执行最小操作(参数) -> 结果
关闭连接() -> 结果     # 成功后资源状态=已关闭
完整生命周期(参数)     # 检查→版本→连接→操作→关闭 顺序执行，任一失败即停
```

资源状态机：未连接 → 已连接 → 已关闭；每次状态变更记录到 状态记录。

## 错误码区分（外部适配统一）

未安装 / 不可访问 / 参数错误 / 版本不兼容 / 协议错误 / 超时 / 内部错误

## 使用方式

```python
from 外部适配层.数据库适配器 import 数据库适配器
适配器 = 数据库适配器()
适配器.完整生命周期({"查询": "SELECT 1"})  # 返回结果列表
```
