## 一、根下两类内容

`支持库/适配层/` 根下混放两类内容（历史遗留形态，2026-09-17 收口时逐项登记）：

1. **正式包**：带 `包声明.json` 的 `*提供者/` 目录，属第三方翻译层的正式支持库，
   不受「系统适配器豁免」，按 `AGENTS.md`《每个支持库必备》交齐要件。
2. **内部适配器**：不带 `包声明.json` 的目录与根级散装 `.py`，属 `AGENTS.md`
   「系统适配器豁免」所指的**不对外提供能力契约**的内部件；`扫描正式包` 以
   `包声明.json` 为标记，不收录它们。

本文件只登记第 2 类。第 1 类的权威说明在各包 `说明/使用说明.md` 与 `说明/设计说明.md`。

## 三、与编译器的关系

`开发工具/项目编译/项目编译器.py` 在编译制品时**只复制固定表**，不遍历根下全部内容：

- `运行时适配文件`（第 28 行）= `__init__.py`、`脱敏模式.py`、`系统探针.py`、`适配契约.py`
- 固定复制目录（第 172、636 行）= `提供者注册表`、`密码签名提供者`、`数据库适配器`、
  `HTTP服务适配器`、`本地进程适配器`、`动态库适配器`、`配置契约`

因此 `密钥提供者/`、`提供者配置读取/`、`配置安全/`、`提供者配置/`、`MySQL提供者/`、
`模型服务.py`、`模型HTTP提供者.py`、`密码适配.py` **不进闭包式制品**。
`密钥提供者/` 不在表内是有意为之（见 `__init__.py::创建密钥提供者` docstring）。

**给后续改动者**：把根级散装 `.py` 移进子目录会**改变依赖防火墙的豁免判定**
（`运行核心/依赖防火墙.py:451-468`：豁免只覆盖「根下直接文件」与「`*提供者/` 子目录」，
不覆盖其他子目录）——搬动前必须先确认该文件不 import 第三方，否则会新增违规。
