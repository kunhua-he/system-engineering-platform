# textutil提供者 使用说明

textutil 系统能力独立提供者：文本格式转换（txt/html/rtf/doc/docx 互转、提取文本）。macOS 系统能力，受控子进程调用。

## 公开能力

| 能力id | 说明 |
| --- | --- |
| textutil转换.检查提供者 | 检查 textutil 是否可用 |
| textutil转换.转换文本文件 | textutil 转换：输入文件 → 目标格式（txt/html/rtf/doc/docx 互转）；返回 文本内容 |

## 调用方式

只经 支持库.适配层.<包名> 包级入口调用，禁止深入 实现/ 目录。
