## 预定公开命令

### `数据库.mysql.连接`

- 参数：`地址` 文本、`端口` 整数、`账号` 文本、`密码引用` 文本、`数据库` 文本；可选 `连接超时秒`、`字符集`。
- 返回：`结果[数据库句柄]`，包含服务器版本和事务状态。
- 成功状态：`可用`；失败不得返回伪造句柄。

### `数据库.mysql.执行SQL`

- 参数：`数据库句柄`、`SQL` 文本；可选 `参数` 列表、`最大行数`、`截止时间`。
- 返回：`结果[{列,行,影响行数,最后插入id}]`；没有结果集时 `列`、`行` 为空。
- 约束：必须参数化，禁止拼接 SQL；句柄失效、超时和驱动错误必须返回稳定错误码。

### `数据库.mysql.开始事务`

- 参数：`数据库句柄`、可选 `截止时间`。
- 返回：`结果[{事务状态:"进行中"}]`。

### `数据库.mysql.提交事务` / `数据库.mysql.回滚事务`

- 参数：`数据库句柄`、可选 `截止时间`。
- 返回：`结果[{事务状态:"已提交"或"已回滚"}]`。

### `数据库.mysql.断开`

- 参数：`数据库句柄`、可选 `截止时间`。
- 返回：`结果[{已断开:true}]`，重复断开必须幂等。

## 错误和状态

错误码至少包括：`参数不合法`、`外部未安装`、`连接失败`、`认证失败`、`数据库不存在`、`SQL语法错误`、`事务状态错误`、`超时`、`句柄过期`、`执行失败`、`资源未清理`。

```text
未登记 → 连接中 → 可用 → 执行中 → 可用
                     └→ 事务中 → 可用
                     └→ 故障 → 回收中 → 已释放
可用 → 关闭中 → 已释放
```

在真实 MySQL 服务、驱动依赖、连接失败、事务回滚、超时取消和零残留验证完成前，不得新增 `包声明.json`，也不得把本目录计入正式支持库数量。
