# 组件控件 设计说明（设计权威）

> 本文是该库的**设计哲学与边界权威**：它为什么这样切、管什么、不管什么、失败如何表达。
> 调用口径——能力、参数、返回结构、错误码与调用示例——以同目录 `使用说明.md` 为准（由能力契约生成）。
> 两份说明都计入包指纹，任何改动都要升包版本。

句柄层级固定为：`窗口句柄 -> 页面句柄 -> 组件句柄`。编辑框的 `页面句柄` 是直接父级，窗口句柄通过页面元数据关联；组件不能跨页面绑定。

编辑框常用属性：`文本`、`占位文本`、`左`、`上`、`宽度`、`高度`、`可见`、`禁用`、`只读`。事件：`输入`、`改变`、`获得焦点`。事件只绑定能力 id 和参数模板。
