## 为什么要有这个包（立包依据）

`前端核心/`（3 个 py 文件）**0 个 `包声明.json`**，前端契约（页面/窗口/组件/渲染请求）
在能力面上**不可校验**；而发布门禁等消费方此前直接 import 前端核心（见
`开发文档/未完成事项.md` 条目 C-6）。按哲学第 7 条 7 项「能力不足就补底座，不许收窄约束」：
不放开 import、不留第二入口，而是**把这层校验补成正式包的能力面**，调用方改按能力 id 调用。

## 架构对比（第 11 条 1 项：做新功能先问架构）

| 维度 | 候选A：调用方继续 import 前端核心 | 候选B：本包提供只读校验能力（**采用**） |
|---|---|---|
| 层数 | 0（但每个消费方各自判断，判定散落 N 处） | +1 层能力面：口径集中一张表 + 一个通用校验器 |
| IO / 计算 | 无 | 无（纯内存，不打开文件与连接） |
| 失败面 | 每个消费方自己解析数据类，字段改了不知道，静默判绿 | 口径漂移时逐条出问题列表；能力面可被 HTML 黑盒真实验证 |
| 边界 | 消费方直连非正式目录（第二套腿） | 只经唯一能力调用入口；`前端核心` 仍是语义唯一实现 |

**结论**：选B。A不改耗时、只把失败面推向调用方，且违反「唯一调用腿」；B的代价是
一张口径表需要与 `前端核心.py` 同步，用「改那边必须同批改本表」的纪律固定（写进
`实现/契约口径.py` 的模块注释与使用说明）。

## 分层与文件职责

```text
__init__.py            包级中文入口：注册能力(注册表)，四条能力的参数名序与 能力定义.json 一致
实现/契约口径.py       字段与枚举口径表（唯一数据表；语义来源 前端核心/前端核心.py 五个数据类）
实现/结构校验.py       通用逐字段校验器：字段路径 + 原因 → 问题列表（顺序稳定、确定性）
实现/入参边界.py       入参类型/体积判定 + 结论文案（与 能力定义.json 的空值、输入上限逐条对应）
实现/提供者.py         四条公开能力的边界串接与统一结果归一
说明/使用说明.md       调用方式、字段表、错误码、装配与真实调用、踩坑记录
验证场景引用.json      四条能力的正向目标步骤 + 反向断言（结构不合法 / 坏入参被拒）
```

文件都在 160 行以内（本包最大文件 `结构校验.py` 约 110 行），职责单一。

## 关键设计判定

1. **不复制 前端核心 的判定逻辑**：本包只判「键 / 类型 / 枚举取值是否在口径内」，
   不判状态流转、不派发渲染、不调后端能力。字段名与枚举取值来自
   `前端核心/前端核心.py` 的五个数据类，逐字对应（含默认值与注释里的枚举）。
2. **渲染请求只认一种 JSON 形态**：`前端核心.渲染请求.转字典` 的扁平四键
   （`窗口id`/`标题`/`状态表`/`宿主类型`）。理由：`前端核心` 只给 `渲染请求` 和
   `执行单元声明` 定义了 `转字典`，`窗口定义` 没有 JSON 形态；若同时接受嵌套与扁平两种
   写法，等于「同一字段两种合法形态」，类型校验退化为结构猜测（哲学第 5 条「类型值的
   唯一形态」）。因此把 `能力定义.json` 中校验渲染请求的说明同步改成扁平口径（原本
   写「内嵌窗口定义…递归校验」与 `前端核心` 的 转字典 事实不符）。
3. **结构不合法不算调用失败**：统一结果只有「成功/失败」两态，结构不合法是**校验结论**，
   用 `参数不合法` 顶替会让调用方分不清「参数传错」与「描述写错」。所以失败只留给
   边界错误（非 JSON 对象 / 含非 JSON 值 / 超 256 KB），其余走 `值.有效` + `值.问题列表`。
   本包声明的错误码只有 `参数不合法` 一个，与网关状态映射（400）同一条。
4. **确定性**：问题排序固定（先自创字段按字典序、再按契约字段声明顺序），同一输入恒得同一输出；
   无随机、无时间、无环境依赖，幂等、可并发（线程与进程安全）。
5. **约束不空转**（第 1 条 4 项）：`能力定义.json` 里声明的每一条行为都落在代码上——
   输入上限（256 KB / 1000 项）真判、空值（非字典）真判、错误码真产生、枚举真比。
   没有恒真判定。

## 未做与不做

- **不做**渲染、状态机、事件派发、后端能力调用：属 `前端核心` 与渲染提供者（第 2 条 1 项）。
- **不做**落盘、缓存、句柄：纯计算，故 `资源预算.json` 的子进程上限与文件句柄上限均为 0。
- **不新增** `前端核心` 的第二套语义实现：本包只读校验，`前端核心` 仍是唯一语义实现。
