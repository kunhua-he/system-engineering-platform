# 浏览器宿主 设计说明（设计权威）

> 本文是该库的**设计哲学与边界权威**：它为什么这样切、管什么、不管什么、失败如何表达。
> 调用口径——能力、参数、返回结构、错误码与调用示例——以同目录 `使用说明.md` 为准（由能力契约生成）。
> 两份说明都计入包指纹，任何改动都要升包版本。

公开入口：`from 支持库.前端.浏览器宿主 import 启动网页服务`。

本库只负责本地静态页面、浏览器拉起和服务句柄。页面配置 `网关地址` 与 `能力id` 后，浏览器请求统一转发到 `POST /网关/调用`；本库不接收任意 Python 回调，也不提供独立的 `/api/调用` 执行接口。
