# 窗口描述支持库

类型：支持库。平台无关窗口定义描述模型，只做描述结构与参数校验，不做真实渲染。

## 能力

- 创建窗口定义(窗口id, 标题, 宽度, 高度)：创建窗口定义字典（含组件列表与默认属性）
- 校验窗口定义(窗口定义)：校验窗口定义结构合法性（必填字段与尺寸类型）
- 序列化窗口定义(窗口定义)：将窗口定义字典序列化为 JSON 文本
- 反序列化窗口定义(文本)：从 JSON 文本还原窗口定义字典并校验结构合法性

## 调用边界

本库为原子能力支持库，无外部依赖；公开入口只返回统一结果
（成功时 值 内为结构化描述数据），禁止泄漏内部对象。

## 错误码

- 参数不合法：参数缺失、类型错误或必填字段不完整
- 反序列化失败：JSON 文本解析失败或还原后的定义校验不通过
- 内部错误：调用服务异常

失败统一返回 结果.失败（成功=false，错误码+错误说明），不抛异常。
