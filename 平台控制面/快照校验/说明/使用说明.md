## 平台控制面.快照校验.校验状态兼容范围（校验状态兼容范围）

**说明**：校验快照的状态兼容范围与回滚许可是否覆盖目标状态结构版本（判定，不执行回滚）。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 快照id | 文本型 | 是 | None | 核心快照id |
| 存储目录 | 文本型 | 否 | 工程缓存/平台控制面 | 平台权威状态库所在目录；留空取默认目录 |
| 目标状态结构版本 | 文本型 | 否 |  | 要比对的状态结构版本；留空取平台状态当前目标版本 |
| 项目id | 文本型 | 否 |  | 调用方项目标识 |

**返回结构**：结果型（统一结果：成功/值/错误码/错误说明/可重试/详细信息）

| 值字段 | 说明 |
| --- | --- |
| 允许回滚 | 逻辑型，true=回滚许可为真且目标版本落在快照状态兼容范围内 |
| 说明 | 文本型，判定结论原文 |
| 快照状态兼容范围 | 文本型，快照记录里的兼容范围原文（形如 1.0.0-1.4.0） |
| 目标状态结构版本 | 文本型，本次比对使用的目标版本 |
| 回滚许可 | 逻辑型，快照记录里的回滚许可 |
| 迁移方式 | 文本型，快照记录里的迁移方式 |

**实测真实返回**（2026-09-17 进程内装配真调，装配能力数 662）：

```json
（快照不存在）{"成功": true, "错误码": "", "值": {"允许回滚": false, "说明": "核心快照不存在: 验证场景不存在的快照", "快照状态兼容范围": "", "目标状态结构版本": "9.9.9", "回滚许可": false, "迁移方式": ""}}
（空快照id）  {"成功": false, "错误码": "参数不合法", "错误说明": "快照id不能为空"}
```

**未命中口径（2026-09-17 收口）**：快照不存在时返回 `成功=True` + `允许回滚=false` + 说明「核心快照不存在: <id>」，
与同包 `查询核心快照`（`是否命中=false`）、`校验核心快照`（`有效=false`）**三者一致**。依据本包
`说明/设计说明.md`「**没命中不是失败**：未命中必须与「读取失败」严格区分（治「内部故障与被测缺陷不可区分」）」——
快照不存在时，「目标版本能否回滚」的真实回答本来就是否定的，属**判定结论**而非内部故障。
`读取记录失败` 只留给真正的库读错误。

| 参数不合法 |
| 存储目录不可用 |
| 读取记录失败 |
