# 授权 设计说明

- 包id：平台控制面.授权
- 类型：支持库（平台控制面 正式根下的治理能力面）
- 能力数：9

## 归属与分层

- 授权是 `平台控制面` 正式根下的治理能力面，不与 支持库/模块库 混层。
- 角色授予事实唯一落 平台控制面.平台状态（权威状态库的角色授予表 + 证据账本），本包不另立事实源。
- `平台控制面/授权.py` 是授权语义唯一实现（五角色/等级表/操作最小角色/会话表/判定）；本包 `实现/能力入口.py` 只做边界校验与统一结果映射。

## 为什么这条能力面必须有正式包

治理层原先 0 个 `包声明.json` → 能力注册表里调不到 → 治理工具只能 import 实现，形成越层依赖。补正式包后，授权动作经能力 id 调用，越层依赖随之消失（决策记录 0012「波2：给治理层功能面补正规包」）。

## 不可能力化的部分（不硬凑）

- 会话表是进程内状态机（令牌→身份/角色/过期时间），不对外暴露为独立能力；对外只暴露 注册/切换/刷新/校验 四个动作。
- `_授予`（内部写入原语）不单独切能力，它是 引导授予/授予角色 的共用实现步骤。

## 兼容性（不改调用方）

本包目录与既有 `授权.py` 同名，包目录优先导入。入口按文件路径显式载入`../授权.py` 并原样再导出全部公开名字（授权服务/五角色常量/角色等级/操作最小角色/稳定错误码），平台内既有 `from 平台控制面.授权 import …` 继续可用，行为逐字不变。
