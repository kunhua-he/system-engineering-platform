# 统一入口 使用说明

- 包id：平台控制面.统一入口
- 版本：1.0.0

本包是 `平台控制面` 正式根下的治理能力面正式包；调用方只经唯一能力调用入口按能力 id 调用。

## 能力清单

| 能力id | 名称 | 版本 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 平台控制面.统一入口.执行稳定操作 | 执行稳定操作 | 1.0.0 | 操作:文本型（必填），参数:字典型，令牌:文本型，存储目录:文本型 | {'操作': '文本型，本次执行的稳定操作名', '调用者': '文本型，令牌对应的身份id', '结果': '字典型，该稳定操作的统一结果（成功/错误码/消息与业务字段）'} | 用户与 Agent 统一能力入口：按稳定操作名执行真实操作，全程 授权 → 执行 → 证据，返回统一结果；未登记操作、令牌缺失或参数非法一律明确失败。 |
| 平台控制面.统一入口.查询稳定操作表 | 查询稳定操作表 | 1.0.0 | 无 | {'操作表': '列表型，平台稳定操作名', '数量': '整数型，稳定操作个数'} | 查询统一入口的 12 个稳定操作名（唯一权威列表，供各视图与门禁对齐操作口径）。 |

## 调用方式

开发工具（进程外）统一口径：自装配后按能力 id 调用。

```python
from 后端核心.后端核心 import 后端核心
后端 = 后端核心(系统根)
后端.启动()
结果 = 后端.调用("平台控制面.统一入口.执行稳定操作", {…})
```

## 错误码

- `执行稳定操作`：参数不合法、操作失败
- `查询稳定操作表`：稳定操作表为空
