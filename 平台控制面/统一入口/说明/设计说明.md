# 统一入口 设计说明

- 包id：平台控制面.统一入口
- 类型：支持库（平台控制面 正式根下的治理能力面）
- 能力数：2

## 归属与分层

- 统一能力入口是 `平台控制面` 正式根下的治理能力面。
- 12 个稳定操作与统一结果结构唯一在同层 `统一入口.py` 实现；本包只做边界校验与结果映射。
- 会话令牌与 平台控制面.授权 面**共用同一份会话表**（入口按存储目录取共享授权服务），否则跨面令牌必然失效。

## 为什么只切两条能力（宁少勿滥）

本面对外动作 = 执行一个稳定操作 + 读稳定操作表。把 12 个稳定操作各切一条能力，等于把同一条分派逻辑复制 12 份契约面，不增加任何能力；视图与门禁需要的操作清单由 `查询稳定操作表` 提供。

## 不可能力化的部分（不硬凑）

- `注册提供者` / `导入签名密钥` / `注册健康检查` 是受信注册路径（平台维护者/引导），不是对外能力面，不切能力。
- 验证组件的进程组终止与输出上限是执行内部机制，不另立能力。

## 兼容性（不改调用方）

本包目录与既有 `统一入口.py` 同名，包目录优先导入。入口按文件路径显式载入`../统一入口.py` 并原样再导出 统一能力服务 / 命令行入口 / 稳定操作表，平台内既有 `from 平台控制面.统一入口 import …` 继续可用，行为逐字不变。
