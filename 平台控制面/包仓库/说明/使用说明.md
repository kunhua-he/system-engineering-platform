## 平台控制面.包仓库.校验平台客户端制品（校验平台客户端制品）

**说明**：校验平台客户端制品：真实重读磁盘逐一比对文件摘要，并校验 Ed25519 签名与信任元数据目标，篡改或半成品一律判不通过。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 制品摘要 | 文本型 | 是 | None | 待校验制品的标识摘要（入库时生成），必填；空值或非法摘要判 参数不合法 |
| 状态目录 | 文本型 | 否 |  | 平台状态库所在目录；留空取实现层默认目录（工程缓存/制品仓库/平台客户端状态） |
| 制品根目录 | 文本型 | 否 |  | 制品内容寻址根目录；留空取实现层默认目录，客户端制品目录由它派生出“平台客户端制品”子目录 |
| 环境目录 | 文本型 | 否 |  | 平台客户端安装环境目录（外部调用方稳定路径所在）；留空取实现层默认目录 |
| 信任目录 | 文本型 | 否 |  | 可信仓库元数据（根信任/目标/快照）所在目录；留空取实现层默认目录 |

**返回结构**：结果型（通过/消息）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

```python
后端.调用("平台控制面.包仓库.校验平台客户端制品", {"制品摘要": "…", "状态目录": "…", "制品根目录": "…", "环境目录": "…", "信任目录": "…"})
```

## 平台控制面.包仓库.校验平台客户端稳定路径（校验平台客户端稳定路径）

**说明**：校验平台客户端稳定路径：激活指针可读 → 已安装目录存在 → 目录摘要与指针一致 → 指针指向的制品目录存在且摘要一致，任一不符即判无效并给出可诊断原因。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 状态目录 | 文本型 | 否 |  | 平台状态库所在目录；留空取实现层默认目录 |
| 制品根目录 | 文本型 | 否 |  | 制品内容寻址根目录；留空取实现层默认目录 |
| 环境目录 | 文本型 | 否 |  | 安装环境目录（当前.json 与 平台客户端 目录所在）；留空取实现层默认目录 |
| 信任目录 | 文本型 | 否 |  | 可信仓库元数据目录；留空取实现层默认目录 |
| 客户端制品目录 | 文本型 | 否 |  | 客户端制品目录；留空时由 制品根目录 派生（制品根目录/平台客户端制品），两者都留空取实现层默认目录 |

**返回结构**：结果型（有效/消息/激活路径）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

```python
后端.调用("平台控制面.包仓库.校验平台客户端稳定路径", {})
```

## 平台控制面.包仓库.校验已安装包完整性（校验已安装包完整性）

| 包id | 文本型 | 是 | None | 已安装包的包id，必填 |
| 版本 | 文本型 | 是 | None | 已安装包的版本号，必填 |
| 期望摘要 | 文本型 | 否 |  | 期望的内容摘要；留空只重算不比对（用于取当前摘要），非空时必须逐字一致 |

**返回结构**：结果型（校验成功/证据）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

```python
后端.调用("平台控制面.包仓库.校验已安装包完整性", {"仓库根目录": "…", "包id": "…", "版本": "…", "期望摘要": "…"})
```

## 平台控制面.包仓库.校验可重复构建（校验可重复构建）

**说明**：校验可重复构建：同一冻结输入在两个全新工作区构建的文件摘要必须完全一致，同时给出变化输入的构建摘要，供调用方判定“输入变化摘要必须变化”。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 冻结输入 | 字典型 | 是 | None | 冻结输入：必须含非空 文件表（相对路径 → 文件内容），可选 构建时刻/主机名 |
| 变化输入 | 字典型 | 是 | None | 与冻结输入做对照的变化输入，结构与冻结输入相同 |
| 工作区根目录 | 文本型 | 否 |  | 变化输入构建所用工作区根目录（不存在即创建）；留空时用一次性临时工作区，调用结束即清理 |

**返回结构**：结果型（双工作区一致/基线摘要/变化摘要/消息）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

```python
后端.调用("平台控制面.包仓库.校验可重复构建", {"冻结输入": {"文件表": {"主.py": "值 = 1\n"}}, "变化输入": {"文件表": {"主.py": "值 = 2\n"}}})
```
