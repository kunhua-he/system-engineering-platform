**说明**：读取一条平台权威状态记录（只读）：按表名与主键取值，返回记录字典或明确失败。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |

| 表 | 文本型 | 是 | None | 平台状态表名（证据/需求/工作包/能力条目/占用租约/制品/信任/策略/发布/激活指针/核心快照/角色授予/能力反馈等） |
| 主键列 | 文本型 | 是 | None | 该表的主键列名 |
| 主键值 | 文本型 | 是 | None | 主键值 |
| 项目id | 文本型 | 否 |  | 调用方项目标识（随存储实例登记，用于故障定位） |

| 值字段 | 说明 |
| --- | --- |
| 记录 | 字典型或空值型，命中时返回整行记录字典，未命中返回 null |
| 是否命中 | 逻辑型，true = 该记录存在 |

**实测真实返回**（2026-09-16 进程内装配真调，装配能力数 645）：
