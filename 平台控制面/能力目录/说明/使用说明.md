## 平台控制面.能力目录.登记消费者契约（登记消费者契约）

**说明**：登记消费者对能力的契约（请求/响应约束/错误码/超时/释放要求）并落盘：契约结构不齐备即判 契约非法 并返回问题原文，同一消费者同一能力为覆盖写。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 消费者id | 文本型 | 是 | None | 消费者标识（外部调用方名），必填；空值判 消费者必填 |
| 能力id | 文本型 | 是 | None | 被消费的能力id，必填；空值判 能力必填 |
| 契约 | 字典型 | 是 | None | 消费者契约对象：请求{参数列表,示例}、响应约束{返回键,结构}、错误码集、超时、释放要求 五项齐备；结构不合法判 契约非法 并返回问题原文 |
| 存储目录 | 文本型 | 否 |  | 消费者契约存储目录（其下 消费者契约.json）；留空取平台默认目录 工程缓存/平台控制面 |

**返回结构**：结果型（消费者id、能力id、消息、记录）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 消费者必填 |
| 能力必填 |
| 契约非法 |

**调用示例**：

```python
后端.调用("平台控制面.能力目录.登记消费者契约", {"消费者id": "…（消费者标识（外部调用方名），必填；空值判 消费者…）", "能力id": "…（被消费的能力id，必填；空值判 能力必填…）", "契约": "…（消费者契约对象：请求{参数列表,示例}、响应约束…）"})
```

## 平台控制面.能力目录.申请文件租约（申请文件租约）

**说明**：按项目根相对路径批量原子认领文件租约：任一条越界即整体 路径越界 硬失败；任一条被活跃租约占用即整体 文件已被占用 并回带占用者与占用开始时间，绝不静默成功、绝不跳条认领。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 修改路径 | 列表型 | 是 |  | 项目根相对路径列表（批量原子认领）；绝对路径、`..` 越界、`~` 写法一律判 路径越界，空表判 参数不合法 |
| 所有者 | 文本型 | 是 |  | 租约所有者（会话/工作包标识），必填；空值判 参数不合法，冲突时会回带该占用者 |
