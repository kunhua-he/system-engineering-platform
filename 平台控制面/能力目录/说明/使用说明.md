## 平台控制面.能力目录.申请文件租约（申请文件租约）

**说明**：按项目根相对路径批量认领文件租约（内容指纹版 + 冲突策略）：任一条越界即整体 路径越界；缺省策略下任一条被活跃租约占用即整体 文件已被占用 并回带占用者与占用开始时间；冲突策略=跳过占用 时能拿的拿到、被占的进 冲突清单；每条认领现场登记内容指纹（sha256）并写一条「上锁」流水；校验指纹=真 时声明指纹与现场不一致即整体 内容已变更。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 修改路径 | 列表型 | 是 |  | 项目根相对路径列表（批量原子认领）；绝对路径、`..` 越界、`~` 写法一律判 路径越界，空表判 参数不合法 |
| 所有者 | 文本型 | 是 |  | 租约所有者（会话/工作包标识），必填；空值判 参数不合法，冲突时会回带该占用者 |
| 任务 | 文本型 | 是 |  | 承载任务说明（租约必须能追到哪次开工），必填；空值判 参数不合法 |
| 持有秒 | 双精度数型 | 否 | 300.0 | 本次租约时长（秒），缺省 300 秒；负数或超过 86400 秒判 参数不合法 |
| 存储标签 | 文本型 | 否 |  | 预留的互斥域标签（如包路径/工作包id），缺省空串；只记录不参与判定 |
| 存储目录 | 文本型 | 否 |  | 文件租约存储目录（其下 文件租约.json）；留空取平台默认目录 工程缓存/平台控制面 |
| 校验指纹 | 逻辑型 | 否 |  | 是否校验内容指纹；真 时声明指纹与现场不一致即整体 内容已变更（拒绝按旧认知认领） |
| 冲突策略 | 文本型 | 否 |  | 撞车处理：留空或「整体拒绝」=任一条被占即整批失败（老行为）；「跳过占用」=能拿的拿到、被占的进 冲突清单（改哪个锁哪个，不整批冻结） |

**返回结构**：结果型（租约清单、租约id清单、申请数、认领数、冲突清单、流水问题）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |

| 路径越界 |
| 文件已被占用 |
| 内容已变更 |
| 内容指纹不可用 |
| 存储目录不可用 |
