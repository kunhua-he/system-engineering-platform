## 平台控制面.提供者.采样资源（采样资源）

**说明**：真实采样当前进程资源（内存峰值/文件句柄/临时空间）并合并资源监督执行单元峰值；采样失败如实标注，不伪装数值。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 临时目录 | 文本型 | 否 |  | 临时空间采样根目录；留空取系统临时目录，给出但不可读即明确失败 |

**返回结构**：结果型（统一结果：成功/值/错误码/错误说明/可重试/详细信息）

| 值字段 | 说明 |
| --- | --- |
| 内存峰值MB | 双精度数型，getrusage 真实峰值（macOS 字节/Linux KB 已换算） |
| 文件句柄数 | 整数型，当前进程真实句柄数（/proc/self/fd 或 /dev/fd） |
| 临时空间字节 | 整数型，采样根目录内文件字节合计 |
| 线程峰值 | 整数型，资源监督执行单元线程峰值 |
| 并发峰值 | 整数型，资源监督执行单元并发峰值 |
| 队列峰值 | 整数型，资源监督执行单元队列峰值 |
| 采样时间 | 文本型，本地时区时间戳 |

**实测真实返回**（2026-09-16 进程内装配真调，装配能力数 645）：

```json
{"内存峰值MB": 145.41, "文件句柄数": 10, "临时空间字节": 510696,
 "线程峰值": 0, "并发峰值": 0, "队列峰值": 0, "采样时间": "2026-09-16 23:58:30"}
```

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 采样失败 |

**调用示例**：

```python
后端.调用("平台控制面.提供者.采样资源", {"临时目录": ""})
```

## 平台控制面.提供者.审计平台控制面（审计平台控制面）

**说明**：治理面专属依赖防火墙静态审计：动态导入/反射导入/深入实现目录/直连外部服务四类规则，逐文件 AST 判定并返回违规清单。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 目标目录 | 文本型 | 否 |  | 被审计目录；留空取平台控制面目录（本面默认治理对象），给出但不可读即明确失败 |

**返回结构**：结果型

| 值字段 | 说明 |
| --- | --- |
| 审计文件数 | 整数型，本次真实解析的 .py 文件数 |
| 违规数 | 整数型，违规条数 |
| 违规清单 | 列表型，每条形如 [来源层→目标] 规则 @ 文件:行号 |
| 无违规 | 逻辑型，true = 违规数为 0 |

**实测真实返回**：

```json
{"审计文件数": 86, "违规数": 58,
 "违规清单": ["[平台控制面→平台控制面.包仓库.实现.能力入口] 跨包深入实现目录 @ 平台控制面/包仓库/__init__.py:27"],
 "无违规": false}
```

> **口径提示（勿误读）**：违规数非 0 **不等于**平台控制面坏了。第三类规则「任何导入不得深入实现目录」
> 与正式包的标准入口写法（入口 `__init__.py` 依赖同包 `实现/`）在当前口径下相互冲突，兄弟面
> （`平台状态`/`发布管理`/`授权`/`备份恢复`）同样命中——这是**规则与入口规范之间的口径问题**，
> 详见同目录 `设计说明.md`「已知边界」。发布前请以发布门禁的现场输出为准，本能力只给原始清单。

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 目录不可用 |

**调用示例**：

```python
后端.调用("平台控制面.提供者.审计平台控制面", {})
```

## 平台控制面.提供者.只读激活指针（只读激活指针）

**说明**：控制面不可用时的调用面只读视图：只读打开权威状态库取激活指针（不启动统一能力服务、不执行结构迁移、未命中如实返回）。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 存储目录 | 文本型 | 否 |  | 平台权威状态库所在目录；留空取平台默认目录（工程缓存/平台控制面），相对路径按平台根解析 |
| 指针id | 文本型 | 是 | None | 激活指针id（发布指针主键） |

**返回结构**：结果型

| 值字段 | 说明 |
| --- | --- |
| 指针 | 字典型或空值型，命中时为 指针id/目标/版本/栅栏令牌/状态，未命中为 null |
| 是否命中 | 逻辑型，true = 该激活指针存在 |

**实测真实返回**（查询一个未登记的指针id）：

```json
{"指针": null, "是否命中": false}
```

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 存储目录不可用 |

**调用示例**：

```python
后端.调用("平台控制面.提供者.只读激活指针", {"存储目录": "", "指针id": "平台客户端"})
```
