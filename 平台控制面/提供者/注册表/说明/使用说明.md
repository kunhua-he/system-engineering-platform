## 平台控制面.提供者.注册表.登记提供者（登记提供者）

**说明**：登记一个提供者（委托到目标能力）：校验预算声明并建立资源监督执行单元，追加注册证据。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 存储目录 | 文本型 | 否 |  | 平台权威状态库所在目录；留空取平台默认目录（工程缓存/平台控制面） |
| 能力id | 文本型 | 是 | None | 被登记的提供者能力id（注册键） |
| 目标能力id | 文本型 | 是 | None | 真实被执行的目标能力id（经唯一能力调用入口调用） |
| 预算 | 字典型 | 是 | None | 资源预算声明：内存上限/线程上限/子进程上限/并发调用上限/队列长度/文件句柄上限/临时空间上限/单次调用超时/每分钟重启次数/空闲回收时间（**10 项**） |

**返回结构**：结果型

| 值字段 | 说明 |
| --- | --- |
| 能力id | 文本型，被登记的提供者能力id |
| 目标能力id | 文本型，委托执行的目标能力id |
| 已登记 | 逻辑型，true = 登记成功 |
| 消息 | 文本型，注册结果说明 |

**实测真实返回**（2026-09-16 进程内装配真调，装配能力数 645）：

```json
{"能力id": "说明书.委托提供者", "目标能力id": "平台控制面.提供者.动态库提供者.宿主可用性",
 "已登记": true, "消息": "提供者已注册: 说明书.委托提供者"}
```

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 存储目录不可用 |
| 注册被拒绝 |

```python

          {"存储目录": "", "能力id": "说明书.委托提供者",
           "目标能力id": "平台控制面.提供者.动态库提供者.宿主可用性",
           "预算": {"内存上限": 128, "线程上限": 4, "子进程上限": 2, "并发调用上限": 4,
```

## 平台控制面.提供者.注册表.调用提供者（调用提供者）

**说明**：经资源监督有界执行调用已登记提供者（信号量/超时/释放/证据）；未登记或目标能力失败一律明确失败。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 存储目录 | 文本型 | 否 |  | 平台权威状态库所在目录；留空取平台默认目录（工程缓存/平台控制面） |
| 能力id | 文本型 | 是 | None | 已登记的提供者能力id |
| 参数 | 字典型 | 否 | None | 传给提供者调用函数的参数对象 |
| 超时秒 | 双精度数型 | 否 | 0.0 | 单次调用超时秒；0 表示用预算里的 单次调用超时 |

**返回结构**：结果型

| 值字段 | 说明 |
| --- | --- |
| 能力id | 文本型，被调用的提供者能力id |
| 值 | 目标能力真实返回值（失败时本能力返回失败） |

**实测真实返回**（委托目标是 `宿主可用性`，故 `值` 即该能力的真实返回）：

```json
{"能力id": "说明书.委托提供者",
 "值": {"可用": true, "状态": "可用", "平台": "darwin", "说明": ""}}
```

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 存储目录不可用 |
| 提供者未登记 |
| 调用失败 |

**调用示例**：

```python
后端.调用("平台控制面.提供者.注册表.调用提供者",
          {"存储目录": "", "能力id": "说明书.委托提供者", "参数": {}})
```
