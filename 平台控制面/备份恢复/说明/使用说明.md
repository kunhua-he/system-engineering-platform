## 平台控制面.备份恢复.声明备份契约（声明备份契约）

**说明**：声明四类权威数据的备份契约（只读，不触碰磁盘）：每类给出恢复点、恢复时限秒、保留周期与恢复顺序，校验方法以方法名（校验方法名）对外，保证返回值可 JSON 化。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 覆盖表 | 字典型 | 否 | None | 契约盖写对象：可给 恢复点/恢复时限秒/保留周期，也可按类名给一个对象做该类盖写；不是对象判 参数不合法 |
| 存储根目录 | 文本型 | 否 |  | 备份源数据根目录（权威状态.db / 制品 / 项目锁.json 所在）；留空取平台运行数据根 工程缓存/运行数据（声明契约不读写该目录，仅作契约身份） |

**返回结构**：结果型（契约表、类数）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

```python
后端.调用("平台控制面.备份恢复.声明备份契约", {})
```

## 平台控制面.备份恢复.执行备份（执行备份）

**说明**：真实备份四类权威数据到时间戳快照子目录并落 备份清单.json：WAL 先合并、逐类真实复制与摘要计算；数据源缺失的类在清单里如实标记缺失（不伪造、不补默认值），该缺失会被 校验备份 判失败。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 备份目录 | 文本型 | 是 | None | 备份落点根目录（其下新建 快照_<时间戳>/），必填；空值判 参数不合法 |
| 存储根目录 | 文本型 | 否 |  | 备份源数据根目录（权威状态.db / 制品 / 项目锁.json 所在）；留空取平台运行数据根 工程缓存/运行数据 |

**返回结构**：结果型（清单）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |

**调用示例**：

```python
后端.调用("平台控制面.备份恢复.执行备份", {"备份目录": "…（备份落点根目录（其下新建 快照_<时间戳>/），…）"})
```

## 平台控制面.备份恢复.校验备份（校验备份）

**说明**：校验备份：定位清单 → 逐类内容摘要核对 → 逐类真实校验方法（sqlite integrity_check / 证据哈希重放 / 制品逐文件 sha256 / 项目锁必填字段）。通过=False 是校验结论（正常答复），备份目录内无任何备份则失败码为 备份不存在。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 备份目录 | 文本型 | 是 | None | 备份目录（含 备份清单.json，或其下有时间戳快照子目录），必填；空值判 参数不合法 |
| 存储根目录 | 文本型 | 否 |  | 备份源数据根目录（权威状态.db / 制品 / 项目锁.json 所在）；留空取平台运行数据根 工程缓存/运行数据（校验以清单里的快照目录为准） |

**返回结构**：结果型（通过、原因）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 备份不存在 |

**调用示例**：

```python
后端.调用("平台控制面.备份恢复.校验备份", {"备份目录": "…（备份目录（含 备份清单.json，或其下有时间戳…）"})
```

## 平台控制面.备份恢复.恢复备份（恢复备份）

**说明**：按契约恢复顺序把四类数据恢复到目标目录，恢复后逐类真实校验；目标目录现有权威状态比本备份更新时带回退警告（旧快照重放必须被调用方看到）。备份目录内无任何备份则失败码为 备份不存在。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 备份目录 | 文本型 | 是 | None | 备份目录（含 备份清单.json，或其下有时间戳快照子目录），必填；空值判 参数不合法 |
| 目标目录 | 文本型 | 是 | None | 恢复目标目录（不存在即创建），必填；空值判 参数不合法 |
| 存储根目录 | 文本型 | 否 |  | 备份源数据根目录（权威状态.db / 制品 / 项目锁.json 所在）；留空取平台运行数据根 工程缓存/运行数据（恢复以清单里的快照目录为准） |

**返回结构**：结果型（成功、恢复顺序、结果、目标目录、回退警告）（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 备份不存在 |

**调用示例**：

```python
后端.调用("平台控制面.备份恢复.恢复备份", {"备份目录": "…（备份目录（含 备份清单.json，或其下有时间戳…）", "目标目录": "…（恢复目标目录（不存在即创建），必填；空值判 参数…）"})
```
