# 公共基础类型目录（易语言式调用模型）

> 这些类型属于公共契约和系统核心，不属于某个业务支持库。支持库只能把外部值转换为本目录中的类型；模块和调用方只看这些类型，不看 Python、数据库驱动或模型 SDK 类型。

## 类型表

| 类型名 | 语义 | 允许值/边界 | 常见来源 |
| --- | --- | --- | --- |
| `逻辑型` | 布尔值 | `真` / `假`，禁止用 0/1 文本替代 | 条件、能力可用性、开关 |
| `字节型` | 单个无符号字节 | 0~255 | 二进制协议、音频块 |
| `整数型` | 有符号整数 | 由系统核心固定为 **64 位** | 计数、端口、行数、宽高、字节数、文件大小 |
| `长整数型` | 有符号长整数 | 由系统核心固定为 **128 位** | 超出 64 位的大哈希、雪花 id、加密大数 |
| `单精度数型` | 32 位浮点数 | IEEE 754 单精度 | 音频采样、比例、低精度测量 |
| `双精度数型` | 64 位浮点数 | IEEE 754 双精度 | 坐标、金额计算中间值、超时秒 |
| `文本型` | Unicode 文本 | UTF-8 传输；长度受契约限制 | SQL、提示、路径、错误说明 |
| `字节集型` | 有界二进制集合 | 必须声明最大字节数 | 文件内容、图片、音频块 |
| `列表型` | 有序同类或结构化元素集合 | 元素类型和最大数量必须声明 | 行列表、消息列表、参数列表 |
| `字典型` | 字符串键到声明类型值的映射 | 键集合和每个值类型必须声明 | 配置、结构化返回 |
| `日期时间型` | 带时区时间 | ISO-8601；默认 Asia/Shanghai | 截止时间、创建时间 |
| `资源引用型` | 平台托管制品引用 | 不传裸路径/指针；包含摘要和大小 | 文件、图片、模型、音频 |
| `句柄型` | 平台托管有状态资源句柄 | 不透明、带租约、不可伪造 | MySQL 连接、LLM 流、窗口 |
| `结果型` | 统一成功/失败外壳 | 成功或失败二选一 | 所有可能失败的命令 |
| `空值型` | 明确没有值 | 只能写 `空值`，不能用空文本冒充 | 无返回值的关闭/释放 |
| `JSON值型` | 结构化 JSON 值（对象/数组/数字/字符串/布尔/空 的任意组合） | 必须可 JSON 序列化；与 `任意型` 的区别是**有校验**（`任意型` 无校验、不入正式类型表） | YAML 解析结果、集合元素、句柄承载的结构化值 |

四类数值类型的机器校验边界已冻结：`整数型` 为有符号 64 位（-2⁶³ 至
2⁶³-1），`长整数型` 为有符号 128 位（-2¹²⁷ 至 2¹²⁷-1）；浮点类型只接受
有限的 Python 浮点值，`单精度数型` 必须可编码为 IEEE 754 binary32，
`双精度数型` 使用 IEEE 754 binary64。所有类型均拒绝布尔值和隐式类型转换。

> 边界值的事实源是机器表 `公共契约/基础类型/数值类型.py:数值类型定义`
> （实测：`整数型` 64 位、`长整数型` 128 位），本文件是它的镜像，两侧必须同批改。
> 历史口径（`整数型` 32 位 / `长整数型` 64 位）已由华哥 2026-09-16 裁决作废：
> 取 64 位是为了向下兼容 32 位的同时装下 EB 级字节数与纳秒时间戳，两档语义不重复
> （`2**64` 判 `整数型` 假、`长整数型` 真）。**制品构建在裁决之前时会仍带旧口径，
> 表现为「同一数值在源码判 整数型 通过、在旧制品判不符合」——那是陈旧制品，不是实现缺陷。**

## 命名冻结

正式契约、说明书、命令目录和示例只使用标准易语言式类型名，不再出现半截类型名或 Python 风格类型名：

```text
逻辑型、字节型、整数型、长整数型、单精度数型、双精度数型、
文本型、字节集型、列表型、字典型、日期时间型、资源引用型、
句柄型、结果型、空值型、JSON值型
```

本清单与机器表 `公共契约/基础类型/类型表.py:正式类型表` 必须逐项一致（各 16 项，机器表是唯一事实源，本文件是它的镜像，两侧新增/删除必须同批改）。

历史契约中的 `布尔`、`文本`、`整数`、`浮点数`、`数字`、`字典`、`列表`、`字节集` 只能在迁移解析器内部识别，不能继续写入新的契约或文档。`单精度整数型`、`双精度整数型` 不是正式类型名；整数按 `整数型` 或 `长整数型` 区分，精度只用于数值型。

## 类型校验规则

1. 类型是契约字段，不由实现函数运行时猜测。
2. `逻辑型` 不接受整数、文本和空值自动转换。
3. 整数与浮点不自动互转；需要转换必须显式声明转换命令和舍入规则。
4. `文本型`、`字节集型`、`列表型`、`字典型` 必须声明大小/数量上限。
5. `资源引用型` 和 `句柄型` 只能由运行核心签发，调用方不能自行拼接。
6. 失败只能返回 `结果型(成功=false)`，不能返回空列表、0、空文本或假句柄伪装成功。

## 类型转换原子能力

类型转换不是模块流程，而是核心支持库中的原子能力。转换必须显式调用，不能由参数校验器偷偷猜测或自动改变调用方值。

| 能力 id | 参数 | 返回 | 规则 |
| --- | --- | --- | --- |
| `类型转换.文本转整数` | `文本`、可选 `进制` | `结果型<整数型>` | `'123'` → `123`；空白可按契约裁剪；小数、非法字符、溢出返回稳定错误 |
| `类型转换.文本转长整数` | `文本`、可选 `进制` | `结果型<长整数型>` | 支持 128 位范围；溢出拒绝 |
| `类型转换.整数转文本` | `整数` | `结果型<文本型>` | 使用十进制稳定格式，不添加本地化分隔符 |
| `类型转换.长整数转文本` | `长整数` | `结果型<文本型>` | 使用十进制稳定格式 |
| `类型转换.文本转单精度数` | `文本` | `结果型<单精度数型>` | 非法文本、NaN、无穷和溢出拒绝 |
| `类型转换.文本转双精度数` | `文本` | `结果型<双精度数型>` | 非法文本、NaN、无穷和溢出拒绝 |
| `类型转换.数值转文本` | `数值`、可选 `小数位数` | `结果型<文本型>` | 舍入规则必须显式；禁止金额隐式二进制浮点转文本 |
| `类型转换.逻辑转文本` | `逻辑值` | `结果型<文本型>` | 只返回约定的 `真`/`假` |
| `类型转换.文本转逻辑` | `文本` | `结果型<逻辑型>` | 只接受契约列出的真值/假值集合，其他文本拒绝 |
| `类型转换.校验类型` | `值`、`目标类型` | `结果型<逻辑型>` | 只检查，不转换，不修改输入 |

示例：

```text
'123'（文本型）
  → 类型转换.文本转整数
  → 123（整数型）
```

```text
'12.3'（文本型）
  → 类型转换.文本转整数
  → 失败：类型转换失败（不能静默截断为 12）
```
