# 配置适配说明

## 配置分类（冻结）

| 分类 | 存放位置 | 内容 |
|------|----------|------|
| 包声明配置 | 支持库/模块自身目录 | 包id/名称/类型/版本/说明/能力清单/参数契约/依赖关系/错误码声明 |
| 支持库默认配置 | 支持库/默认配置/默认配置.json | 默认编码/超时/重试/缓存策略/资源限制/行为开关 |
| 项目配置 | 项目适配层/项目配置/ | 启用的支持库/模块、外部服务地址、数据库连接标识、进程启动参数、环境名称、资源目录、配置覆盖项 |
| 提供者配置 | 外部适配层/提供者配置/ | 数据库驱动名称、HTTP 协议设置、进程启动方式、动态库路径、外部服务版本要求、联通性检查参数 |
| 运行时状态 | 代码对象（不写文件） | 连接状态/进程句柄/窗口状态/临时缓存/当前请求/生命周期状态/运行时错误/临时变量 |

## 覆盖顺序（固定，不可变）

```text
支持库默认配置
  → 项目默认配置
  → 当前环境配置（开发配置.json / 发布配置.json）
  → 外部提供者配置
  → 运行入口显式覆盖
```

## 读取规则

- 统一配置读取器（配置读取.py）负责 JSON 读取、来源追踪、缺失/类型/未知项报告
- 配置合并（配置合并.py）固定五层顺序，每项记录来源
- 配置校验（配置校验.py）负责必填/类型/未知项/敏感检测
- 禁止实现代码偷偷读取任意配置文件
- 禁止未知字段静默接受；禁止缺失必填配置自动伪造默认值
- 禁止密钥直接写入仓库配置

## 敏感配置边界

- 配置文件中不得直接保存密码、令牌和私钥；只允许保存环境变量名称或外部密钥引用
- 读取时发现疑似明文密钥（配置名含 密码/令牌/私钥/密钥/token/secret 且值符合密钥特征）必须返回警告或失败
- 说明书和搜索结果只能显示"敏感配置"，不得输出实际值
