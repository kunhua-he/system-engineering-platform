# 项目适配层说明

## 职责

项目适配层不是业务项目本身，也不是支持库。它只负责：

1. 声明项目身份（项目声明.json）
2. 绑定需要的支持库（支持库绑定）
3. 绑定需要的模块（模块绑定）
4. 生成依赖锁（依赖锁定.json）
5. 定义项目目录（路径适配）
6. 定义项目配置（配置适配）
7. 定义项目公开入口（运行入口/项目入口.py）
8. 定义项目验证范围（项目声明.验证范围）

## 边界

```text
系统级支持库与模块库
    ↓
项目适配层（本目录）
    ↓
任意具体项目
```

项目代码只能通过 项目入口.调用(能力id, 参数) 使用能力；
禁止直接深入 支持库/某包/实现/ 或 模块库/某模块/实现/。

## 返回约定

所有调用返回系统级统一结果结构：

```json
{"成功": true, "值": ..., "错误": {"错误码": "", "消息": "", "来源": ""}}
```

禁止返回第三方对象、内部类实例、文件句柄和不可序列化对象。
