## 步骤 2：把网关凭证注入客户端（**必须先做**，否则薄壳 fail-closed）

薄壳只认环境变量 `系统库网关凭证`（`薄壳/网关转发.py:17`），缺了直接返回 `网关凭证缺失` 且不转发（`:32-38`）。
本机 shell 里**没有**这个变量，值在 40007 的 launchd plist 里。取值（**只进内存/只进客户端 env，不写进 git 文件**）：

```bash
# 从 40007 的 plist 读值，导出成 ASCII 变量名 MCP_GATEWAY_TOKEN（待切换样例引用的就是它）
export MCP_GATEWAY_TOKEN="$(plutil -extract EnvironmentVariables.系统库网关凭证 raw -o - ~/Library/LaunchAgents/com.huashi.gateway-40007.plist)"
[ -n "$MCP_GATEWAY_TOKEN" ] && echo "已取到凭证（长度 ${#MCP_GATEWAY_TOKEN}）" || echo "取值失败，停下排查"

# 要长期生效（GUI 启动的客户端也拿得到）：写进 ~/.zshrc（值走 plist，不写明文）
grep -q MCP_GATEWAY_TOKEN ~/.zshrc || cat >> ~/.zshrc <<'EOF'
export MCP_GATEWAY_TOKEN="$(plutil -extract EnvironmentVariables.系统库网关凭证 raw -o - ~/Library/LaunchAgents/com.huashi.gateway-40007.plist 2>/dev/null)"
EOF
```

**为什么用 ASCII 变量名 `MCP_GATEWAY_TOKEN` 而不是直接用 `${系统库网关凭证}`**：客户端插值对非 ASCII 变量名的支持**未实测**（不猜）；JSON 里的**键**照旧写中文 `系统库网关凭证`（薄壳读的就是这个键名），只把**引用的变量名**取 ASCII，规避插值风险。
