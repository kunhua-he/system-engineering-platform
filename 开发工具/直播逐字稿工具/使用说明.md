# 直播逐字稿 · 批量队列工具
> 本目录是 **`开发工具/直播逐字稿工具/`**（2026-09-16 由 `模块库/直播逐字稿/工具/` 归位——运维 CLI 不属模块能力层，归位后复用审计 9 处 → 0 处）。
> 下列命令均在**本目录**内执行，脚本路径均为相对本目录的文件名。


消费者侧调用工具：**不在模块内**，通过平台唯一网关 `POST http://127.0.0.1:40007/网关/调用`
调用 `直播逐字稿.全自动精校`，把整批录屏逐场跑成两份权威稿（还原稿 + 总结稿）。

## 文件

| 文件 | 作用 |
|---|---|
| `批量精校队列.py` | 批量队列：逐场出两份稿，断点续跑、失败重试、并发多场；路径/凭证/模型/行业词全部由调用方传 |
| `安装或卸载队列常驻.py` | 把队列注册成 LaunchAgent 常驻（系统托管，不依赖终端会话）；plist 按参数现渲染，包内不留部署产物 |

## 用法

```bash
# 先写配置包（键见下），再跑
python3.14 批量精校队列.py --配置 队列配置.json --最短场次 3        # 试跑最短 3 场
python3.14 批量精校队列.py --配置 队列配置.json                    # 全量
python3.14 批量精校队列.py --配置 队列配置.json --仅主播 03_示例主播 --并发场次 3 --重试次数 3

# 常驻（无人值守）
python3.14 安装或卸载队列常驻.py 安装 --配置 队列配置.json --标签 自己的标签 --日志路径 /绝对路径/00_批量日志.log
python3.14 安装或卸载队列常驻.py 状态 --日志路径 /绝对路径/00_批量日志.log
python3.14 安装或卸载队列常驻.py 卸载 --标签 自己的标签
```

## 配置包（调用方传参，底座零写死）

```json
{
  "项目根": "/绝对路径/素材根目录",
  "权威根": "/绝对路径/成稿落点根目录",
  "网关凭证": "调用方自己的网关凭证",
  "模型密钥": "调用方自己的模型密钥",
  "模型端点": "http://<主机>:<端口>/v1",
  "模型名": "调用方自己的模型名",
  "网关": "http://127.0.0.1:40007/%E7%BD%91%E5%85%B3/%E8%B0%83%E7%94%A8",
  "附加术语": "必须原样保留的词",
  "输出结构": "分节结构",
  "附加要求": "易错词校正、行业口径"
}
```

- `项目根`/`权威根`/`网关凭证`/`模型密钥`/`模型端点`/`模型名` 六项必填，缺任意一项脚本**直接报错退出并打印用法**
  —— 底座不猜业务路径、不内置默认凭证、不写死模型端点。
- `网关` 非必填，缺省走平台本机网关；`附加术语`/`输出结构`/`附加要求` 非必填，**缺省即不传参数**（底座不填任何默认行业词）。
- 每个键都可用同名环境变量回退，环境变量优先：`逐字稿项目根`、`逐字稿权威根`、`逐字稿网关`、
  `系统库网关凭证`、`HERMES_CUSTOM_CUSTOM_API_KEY`、`逐字稿模型端点`、`逐字稿模型名`、
  `逐字稿附加术语`、`逐字稿输出结构`、`逐字稿附加要求`；配置包路径也可用 `逐字稿队列配置`。

## 设计要点（都是踩过坑后的选择）

1. **并发场次的依据**：GPU 只在**转写**阶段争用（约占一场三分之一时间），**裁决**阶段是在等远程模型，
   所以并行多场能提升总吞吐；默认 1，GPU 富余时可提到 2~3。
2. **句柄（模型连接）每场独立**：句柄默认 1800 秒无人使用即被回收，整批复用会在长批中途失效
   （实测报「句柄不存在」，整场判不通过）。
3. **失败重试 + 退避**：上游端点会间歇返回 503/超时。队列重试 3 次，模块内也会识别瞬时错误退避重试。
4. **断点续跑**：已有稿子默认跳过（`--强制` 可重跑）；缓存目录按「场次 × 模式」隔离，重跑只补缺。
5. **进度可查**：进度与日志都写在权威根下：`00_批量进度.json`、`00_批量日志.log`。
6. **常驻而非挂终端**：批量任务要跑十几小时，挂在交互式会话上会被会话清理 SIGTERM 打断；
   LaunchAgent 由系统托管，异常自动拉起、重启机器也能回来。

## 行业细节怎么给（底座通用，业务细节由调用方传）

队列把配置包里的 `附加术语`/`输出结构`/`附加要求` 原样透传给 `直播逐字稿.全自动精校`，
底座自身不写死任何行业内容；没传就不传该参数，由能力自己的中性缺省（按内容自然分节）兜底：

```json
{
  "附加术语": "品牌词、专有名词……",
  "输出结构": "核心卖点 / 活动政策 / 门店与位置 / …",
  "附加要求": "「斑」不能写成「班」……"
}
```
