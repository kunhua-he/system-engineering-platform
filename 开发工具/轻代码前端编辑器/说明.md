# 轻代码前端编辑器
<!-- 机器管理｜类型：仓库内其他文档｜生成器：开发工具.MD文档生成 -->


这是底座的图形化前端编辑器，不要求业务开发者手写 HTML、JavaScript 或 tkinter。

1. 启动：`python3.14 开发工具/轻代码前端编辑器/启动编辑器.py`
2. 从左侧拖入文本、输入框、按钮、状态区或容器；拖到容器内部即可嵌套。
3. 单击选择，双击直接编辑文字/输入框；常用属性在右侧，能力 id 等高级字段默认折叠。
4. 页面改动会在停止操作约 0.5 秒后自动写入 `工程缓存/轻代码前端编辑器/页面.json`，不需要点击保存。
5. 顶部选择“软件项目”或“网页项目”，该选择会随页面 JSON 保存。

编译页面：

```bash
python3.14 开发工具/轻代码前端编辑器/编译页面.py 工程缓存/轻代码前端编辑器/页面.json
```

页面 JSON 是前端工程模型的唯一持久化事实源；编辑器服务会补齐 `工程id`、`修订号`、不可变 `对象id`，所有读取、预览、提交和编译都通过**动态会话令牌**保护的 `POST /内部/工程请求`，由 `操作` 字段选择。旧 `/工程/请求` 直接返回 404；令牌缺失或不符返回 403——令牌在启动时随机生成并注入页面，前端请求带 `X-IDE-Token` 头，后端用常量时间比较校验；**旧的固定头 `X-Internal-Call: 1` 已失效**；旧修订提交会返回 409 编辑冲突，不会覆盖他人修改。

编译器输出规范化制品并列出能力依赖，运行器只读取制品、绑定统一网关能力和选择浏览器/桌面宿主。IDE 和未来 Agent 都应使用同一提交协议，不应直接覆盖页面文件。
