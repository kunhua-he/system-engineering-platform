- 包id：运行核心.运行状态监督
- 版本：1.0.0
- 类型：支持库（运行核心正式根下的只读/判定能力面）

> 本文是本包的**调用权威**：能力、参数、返回结构、错误码与调用示例。
> 设计与边界（为什么这样切、管什么、不管什么、失败如何表达、判据唯一出处）
> 以同目录 `设计说明.md` 为准。

| 能力id | 名称 | 版本 | 返回 | 说明 |

> 依赖方向判据唯一实现在 `运行核心/依赖防火墙.py`，本包只做边界校验与结果归一。

## 运行核心.运行状态监督.查询状态结构版本（查询状态结构版本）

**说明**：查询权威状态库的结构版本与目标版本（只读，不迁移结构）。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 存储目录 | 文本型 | 否 | 工程缓存/平台控制面 | 状态库所在目录（目录下取 `权威状态.db`）；留空取平台默认目录。相对路径按 `依赖防火墙.系统根` 解析；非文本型判 参数不合法 |

**返回结构**：结果型（目标结构版本/库中结构版本/是否需要迁移/库文件存在/库文件路径）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| 目标结构版本 | 文本型 | 代码侧目标结构版本（判据来源 `运行核心.权威状态`） |
| 库中结构版本 | 文本型 | 库内 `元信息.结构版本` 实际值；库不存在、无记录或表缺失时为空串 |
| 是否需要迁移 | 逻辑型 | `true` = 库中版本与目标版本不一致或库缺失 |
| 库文件存在 | 逻辑型 | `true` = 该目录下存在 `权威状态.db` |
| 库文件路径 | 文本型 | 实际探查的库文件路径 |

**错误码表**：

| 错误码 | 触发条件 |
| --- | --- |
| 参数不合法 | `存储目录` 不是文本型 |
| 读取失败 | 库文件存在但只读探查失败（打不开、不是数据库、库忙/超时）；可重试 |

**调用示例**：

```python
运行核心.运行状态监督.查询状态结构版本(存储目录="工程缓存/平台控制面")
```

**验证状态**：已纳入验证场景：运行状态监督.只读三项正向调用（查询空目录的状态结构版本）

## 运行核心.运行状态监督.校验状态完整性（校验状态完整性）

**说明**：校验权威状态库的表/列结构完整性与磁盘完整性（只读，不迁移结构）。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 存储目录 | 文本型 | 是 | null | 待校验的状态库所在目录（目录下取 `权威状态.db`）；空值判 参数不合法 |

**返回结构**：结果型（完整/说明/问题列表/库中结构版本/目标结构版本）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| 完整 | 逻辑型 | `true` = 表/列齐全且磁盘完整性检查为 `ok` |
| 说明 | 文本型 | 校验结论原文（不完整时给首个问题） |
| 问题列表 | 列表型 | 缺失表/缺失列/完整性检查失败等原文明细（全部，按规则表版本升序） |
| 库中结构版本 | 文本型 | 库内记录的结构版本（缺表/无记录时为空串） |
| 目标结构版本 | 文本型 | 代码侧目标结构版本 |

**口径三条（必读）**：

1. **库不存在不是「失败」而是判定结论**：返回 `成功=true` + `值.完整=false` + `问题列表=["状态库不存在: …"]`；
   只有「打不开 / 不是数据库 / 库忙」才返回 `错误码=读取失败`。
2. **`完整` 只管结构：不判版本一致**。「库中结构版本 ≠ 目标结构版本」由调用方按两个版本字段自行比较
   （这样 `平台状态` 这类子类库扩展了表之后仍能如实报 `完整=true`）。
3. **判据是基础结构**：按 `权威状态.校验规则表` 校验（含 `PRAGMA integrity_check`），
   子类库（如 `平台控制面.平台状态`）的扩展表不在本能力判定范围内。

**错误码表**：

| 错误码 | 触发条件 |
| --- | --- |
| 参数不合法 | `存储目录` 为空或不是文本型 |
| 读取失败 | 只读校验失败（打不开、不是数据库、库忙/超时）；可重试 |

**调用示例**：

```python
运行核心.运行状态监督.校验状态完整性(存储目录="工程缓存/平台控制面")
```

**验证状态**：已纳入验证场景：运行状态监督.只读三项正向调用（空目录校验状态完整性判不完整）、
运行状态监督.坏入参与域外目录明确失败（空存储目录被阻断）

## 运行核心.运行状态监督.审计依赖（审计依赖）

**说明**：AST 依赖方向审计（只读）：按 `依赖防火墙.允许依赖表` 与强制拒绝规则扫描目标目录，
返回违规清单与审计文件数；**解析源码，不改被审计文件**。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 目标目录 | 文本型 | 否 | 空（=审计整个系统根） | 待审计目录；留空审计整个系统根。相对路径按 `依赖防火墙.系统根` 解析；必须在系统根之内，否则判 参数不合法（层判定以系统根为基准） |

**返回结构**：结果型（成功/违规表/违规数/审计文件数/审计目录）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| 成功 | 逻辑型 | `true` = 零违规（**注意：这是「审计结论」，与统一信封的 `成功` 不是一回事**） |
| 违规表 | 列表型 | 每项含 `来源层`/`目标`/`规则`/`文件`/`行号` |
| 违规数 | 整数型 | 违规条数 |
| 审计文件数 | 整数型 | 实际解析的源码文件数（`工程缓存`/`测试中心`/`示例项目`/`开发文档` 与 `__pycache__` 在建表时剪枝） |
| 审计目录 | 文本型 | 实际审计目录（绝对路径） |

**口径三条（必读）**：

1. **有违规也返回 `成功=true`**：信封 `成功` 表示「审计执行成功」，`值.成功` 才是「零违规」判定。
2. **目标目录必须在系统根内**：`依赖防火墙` 的层判定以 `系统根` 为基准，域外目录无法层判定，
   本能力直接判 `参数不合法`（不把被审计实现的 `ValueError` 当结果）。
3. **审计文件数为 0 是真实读数**（该目录下没有 `.py`），不是「跳过」。

**错误码表**：

| 错误码 | 触发条件 |
| --- | --- |
| 参数不合法 | `目标目录` 不是文本型 / 不存在或不是目录 / 不在系统根内 / 系统根解析结果不是目录 |
| 读取失败 | 读取待审计源码失败（OSError）；可重试 |

**调用示例**：

```python
运行核心.运行状态监督.审计依赖(目标目录="运行核心/运行状态监督")
```

**验证状态**：已纳入验证场景：运行状态监督.只读三项正向调用（审计本包目录依赖方向）、
运行状态监督.坏入参与域外目录明确失败（不存在的目标目录被阻断）

> 域外目录（不在系统根内，含任何静态绝对路径）在实现里同样判 `参数不合法`，
> 但**不进包级场景**：HTML 验证器的场景契约硬禁静态绝对路径（`路径安全.py:24-26`），
> 这条边界由本包反向验证脚本（`审计依赖(目标目录="/")` → `400 参数不合法`）单独取证。

## 调用方式（唯一入口）

进程内或跨进程都只经**唯一能力调用入口** `调用能力(能力id, 参数)`；HTTP 走
`POST http://127.0.0.1:40007/网关/调用`：

```bash
curl -X POST http://127.0.0.1:40007/网关/调用 \
  -H 'Content-Type: application/json' -H 'X-System-Credential: <凭证>' \
  -d '{"操作":"调用能力","能力id":"运行核心.运行状态监督.校验状态完整性",
       "参数":{"存储目录":"工程缓存/平台控制面"}}'
```

调用方（模块、开发工具、外部项目与 Agent）**不得 import 本包 `实现/`**，只按能力 id 调用。
