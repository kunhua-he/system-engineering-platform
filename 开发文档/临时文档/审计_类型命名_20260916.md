### 4.2 每批都要加的定向检查（防止回潮）

在 `开发工具/发布门禁/运行发布门禁.py` 的「中文边界」段（现 `:1107-1109`）旁加三项，作为增量门禁：

```python
# 检查一：裸 True/False（正式代码，排除第三方 API 参数与协议回调）
# 检查二：契约类型位置非正式名
# 检查三：英文错误码
```

**检查一的实现要点**（必须有豁免白名单，否则会造出大量假红）：
- 排除：`json=`/`ensure_ascii=`/`daemon=`/`block_on_close=`/`protocol_version=` 等第三方参数行；
- 排除：`开发工具/HTML验证/场景执行器.py`、`测试中心/**`（`tempfile` 官方 API，`未完成事项.md:161` 已定豁免）；
- 排除：`公共契约/基础类型/逻辑类型.py` 本体（它必须写 `真 = True`）；
- **只对「正式代码七根」生效**，`测试中心`／`示例项目`／`项目适配层` 不计。

**检查二的实现要点**：类型位置只认 `类型`／`值结构` 两个键，取值必须 ∈ `正式类型表`，允许 `<...>` 容器形式；非正式名报红，未知名 fail-closed。

**检查三的实现要点**：正则 `错误码\s*=\s*"[A-Za-z0-9_\-]+"` 与 `错误码_[A-Za-z]+` 双扫。
