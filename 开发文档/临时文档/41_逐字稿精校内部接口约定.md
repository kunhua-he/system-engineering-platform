# 逐字稿全自动精校 —— 模块内部接口约定（批次1 冻结）

> 本文件冻结 `模块库/直播逐字稿` 内部实现文件之间的函数签名与缓存数据结构。
> 任何实现文件不得自行改名、改结构；不一致即集成失败。
> 对外只有一个能力：`直播逐字稿.全自动精校`。

## 一、对外能力契约（唯一入口）

```text
能力id：直播逐字稿.全自动精校
参数：
  源文件路径 文本型 必填     视频或音频绝对路径（自动判别）
  导出路径   文本型 必填     精校逐字稿输出绝对路径（.md / .docx）
  缓存目录   文本型 必填     中间产物绝对路径（分片/复核/证据/裁决/质检）
  模式       整型   必填     1..N，见 模式数据/模式注册表.json
  分片秒数   整型   默认300
  附加术语   文本型 默认""
  模型配置   字典型 默认null
  超时秒     双精度数型 默认3600
返回：结果型 值 = { 精校稿路径, 模式, 模式名称, 字数, 时长秒, 质检, 缓存目录, 状态 }
```

## 四、内部函数签名（冻结）

```python
# 实现/入参校验.py
校验入参(参数: dict, 注册表: dict) -> 结果 | None      # 通过返回 None；失败返回 结果.失败
支持的媒体扩展名() -> set[str]

# 实现/模式注册表.py
读取模式注册表() -> dict                                # 整表（包内 模式数据/模式注册表.json）
取模式(编号: int) -> dict | None

# 实现/缓存与续跑.py
准备缓存(缓存目录: str) -> dict[str, Path]              # 建目录，返回命名路径表
读指纹(缓存: dict) -> dict | None
写指纹(缓存: dict, 指纹: dict) -> None
指纹一致(旧: dict | None, 新: dict) -> bool
写状态(缓存: dict, 状态: dict) -> None
读JSON(路径: Path) -> dict | None
写JSON(路径: Path, 数据: dict) -> None

# 实现/疑难标记.py
标记疑难(分片转写列表: list[dict], 阈值: dict | None = None) -> dict   # {"疑难段":[…],"死循环区间":[…]}
默认阈值() -> dict

# 实现/复核调度.py
聚类区间(疑难段: list[dict], 间隔秒: int = 60) -> list[dict]
复核区间(源音频路径: str, 区间: dict, 调用能力, 轮数: int = 3, 模型配置: dict | None = None) -> dict

# 实现/证据包.py
生成证据包(底稿行: list[str], 复核列表: list[dict], 死亡区间: list[dict], 附加术语: str) -> str

# 实现/精校裁决.py
裁决区间(区间: dict, 底稿文本: str, 证据文本: str, 提示词: str, 调用能力, 模型配置=None) -> dict
# 返回 {"区间id":1,"精校文本":"…","状态":"完成|失败","错误码":"","错误说明":""}

# 实现/排版合成.py
合成全文(模式: dict, 段落列表: list[dict], 元信息: dict) -> str
统一数字形式(文本: str) -> str

# 实现/质检门禁.py
质检(原始文本: str, 精校文本: str, 模式: dict) -> dict

# 实现/导出落盘.py
原子写文本(目标路径: str, 内容: str) -> 结果
```

## 五、硬约束（每个实现文件都遵守）

- 全中文命名；只允许标准库。
- 不 import 支持库/提供者/实现目录；需要底层能力时经 `获取能力调用器().调用能力(能力id, 参数)`。
- 任何失败返回 `结果.失败(错误码, 错误说明, 来源="直播逐字稿")`，不抛裸异常给调用方。
- 不写死主播名、目录名、路径；一切来自参数。
- 单个实现文件 80～160 行。
