# 项目级Markdown逐份蒸馏与删除审计

## 审计流程（华哥确认的硬规则）

本任务不按文件名、日期、关键词、文件大小或目录位置自动判断删除。每一份Markdown必须完整阅读，再逐项对照当前源码、正式能力索引、统一入口、当前主文档和最新提交，最后人工裁决。

逐份流程：

```text
完整读取单个Markdown
  → 提取它声称的目标、入口、能力、流程、版本和结论
  → 逐项核对当前源码、契约、正式索引、真实验证和主文档
  → 标记：仍执行 / 部分执行 / 已被新版本替代 / 从未执行 / 与当前口径冲突
  → 写入本审计表
  → 裁决：保留原文 / 蒸馏到唯一事实源后删除 / 整体过期直接删除 / 暂缓
```

禁止：

- 禁止按“临时文档”“2026-08-26”“调研报告”等名称直接删除；
- 禁止只读标题、尾部或文件摘要代替完整阅读；
- 禁止用脚本按关键词自动裁决；
- 禁止把设计方案当作已执行事实；
- 禁止把旧验证结果当作当前版本证据；
- 禁止删除仍包含未执行决策、未解决风险或唯一历史依据的文件；
- 删除前必须记录具体原因、已吸收位置和可回退方式。
