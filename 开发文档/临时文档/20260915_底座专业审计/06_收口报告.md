## 五、AGENTS.md 待批补丁（MCP 访问守卫，`### MCP 连接与阻断` 段）

访问守卫分两层：**B 层 = 回环 + Host/Origin，始终生效**；**A 层 = 令牌，默认不启用**，设置环境变量 `MCP工具箱_访问令牌` 后生效（缺失/错误返回 401，同时接受 `Authorization: Bearer <令牌>` 与 `X-MCP-Token`）。
- **启用**：`env "MCP工具箱_访问令牌=<ASCII 令牌>" ./MCP工具箱/启动HTTP服务.sh 8766`。令牌**必须是 ASCII**（两个客户端都拒绝非 ASCII 头值）；bash 不能 `export`/不能用中文变量名，故用 `env` 传入，脚本内部以 `printenv` 读取。
- **客户端 header**：`opencode.json` 用 `Bearer {env:MCP工具箱_访问令牌}`；`.mcp.json` 只能用 ASCII 名 `${MCP_TOOLKIT_TOKEN}`（Claude Code 的 `${}` 不解析中文变量名）→ 启用时需**同名同值**额外导出该 ASCII 别名。
- **回退**：未设令牌即不强制（两处 header 展开为空值，实测对未启令牌的 8766 仍 200 且客户端连通）；此时 8766 只由 B 层保护，**本机任意进程仍可无凭证调用全部工具**。
