## 二、逐条发现

### 【重要-1】注册表类型名非正式、且不在网关别名表内 → 网关边界类型校验被静默跳过（运行期假绿）

- **级别**：重要（安全/契约边界）
- **影响**：契约声明的参数类型约束在运行期完全不生效。任何 JSON 值都能穿透网关直达实现，实现内部再做（或不做的）处理；实现若直接强转，会把 Python 异常原文当错误说明外泄。
- **证据**：
  - `支持库/前端/组件控件/__init__.py:14` `("窗口句柄", "句柄")`；`:16` `("组件句柄", "句柄"), ("属性名", "文本"), ("属性值", "任意")`；`:17` `("组件句柄", "句柄")`
  - `支持库/后端/并发控制支持库/__init__.py:107` `{"名称": "等待秒", "类型": "数值型", ...}`；`:133`、`:153` `{"名称": "退避秒", "类型": "数值型", ...}`
  - 契约侧真值：`支持库/前端/组件控件/能力契约/参数契约.json`（组件句柄=整数型、属性值=字典型）；`支持库/后端/并发控制支持库/能力契约/参数契约.json`（等待秒/退避秒=双精度数型）
  - 网关归一化表只覆盖 12 个历史短名，**不含** `句柄` / `任意` / `数值型`：`运行核心/统一网关/网关核心.py:283-289`；未命中即落到「无校验」分支（`类型匹配 = {...}.get(类型)` → `None`，`:304` `elif 类型匹配 is not None and not 类型匹配(...)` 直接跳过）
