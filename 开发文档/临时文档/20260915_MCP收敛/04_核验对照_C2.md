## 六、`generate_module_template` 专项判定：**上轮判断"不做成能力"被推翻**

### 6.1 上轮判定的原文与依据

### 6.3 推翻部分（结论层）——决定性实测

**"AI 直接跑命令"这条路现场不存在**：

| 生成器 | 有没有 CLI 入口 | 证据 |

也就是说：`生成模块模板` 是一个**keyword-only 的 Python 函数**（`模块名`/`类型`/`能力清单: list[dict]`/`依赖能力清单: list[dict]`），**参数是嵌套结构，命令行无法表达，且没有任何命令行入口**。全仓唯一调用它的生产方式就是 `项目服务.py:833` 的**函数 import + 调用**。

### 6.4 为什么应该登记成原子能力（不只是一个函数）

1. **它已经是底座对外的公开面**：MCP 用 `Tool` 把它作为底座能力暴露（`项目服务.py:450`），调用方视角它就是能力；不登记，收敛后这个公开面凭空消失。
