## 二、升级目标与不做事项

### 目标

1. 以支持库公开能力提供受管浏览器会话，而不是把 Browser Use/agent-browser 作为业务代码可见依赖。
2. 所有浏览器会话、页面、Profile 快照、临时目录、子进程组、CDP连接和日志都进入统一句柄/租约/资源账本。
3. Profile 认证数据库采用“临时 SQLite 文件 → 完成后原子替换”，目标文件被旧浏览器占用时不等待锁。
4. 所有外部命令具备有界标准输出/标准错误、明确超时、取消、进程组回收和残留核对。
5. Provider 缺失、浏览器启动失败、CDP失联、超时、取消、快照失败和回收未收敛均返回统一失败，不包装成成功。
6. Hermes 后续如接入，最终只调用底座公开 HTTP 能力，不把 Hermes 内部实现变成底座第二执行腿。

### 明确不做

- 不把 Hermes 源码、Browser Use SDK 或 agent-browser 代码复制进底座。
- 不在底座主进程直接导入第三方浏览器库、CDP SDK或不可控原生扩展。
- 不新增第二个能力执行入口，不让浏览器宿主页面自行执行浏览器命令。
- 不把“静态网页宿主”改造成浏览器自动化执行器；两者职责保持分离。
- 不默认读取华哥主 Chrome 全量 Profile；登录态使用必须显式授权、白名单和受管快照。
- 不在未验证时把 Hermes 现有直连修复删除；先完成底座真实能力和下游接入验收，再按硬切换规则收口。
- 不连接正式业务数据库，不修改模型端口、代理端口和长期运行配置。

## 三、候选分层（开工后以代码地图和契约核准为准）

```text
Hermes / V3 / 其他正式调用方
  → 唯一 HTTP：POST /网关/调用
  → 浏览器自动化支持库公开能力
  → 浏览器自动化 Provider 适配层
  → 受管外部浏览器执行单元（Browser Use CLI / agent-browser / 可替换实现）
  → Chromium/CDP/Profile快照/操作系统资源
```

候选公开能力先按最小原子粒度评估，不预先冻结实现名：

- 创建浏览器会话
- 打开页面或导航
- 读取页面状态/文本
- 执行受限页面操作
- 获取截图或页面证据
- 关闭浏览器会话
- 查询会话健康与资源状态

所有有状态操作必须先取得句柄；资源 id 只能作为句柄内的二次定位参数。能力 id、参数、返回、错误码、句柄超时秒和资源预算在契约评审后冻结。

## 四、必须覆盖的失败矩阵

| 场景 | 预期 | 证据 |
|---|---|---|
| Provider 不存在 | 明确“提供者不可用”，不自动下载、不假成功 | 统一错误结果 |
| 浏览器启动失败 | 有界返回，子进程组已回收 | 进程/端口残留为0 |
| CDP 端点失联 | 会话标记失败或待回收，不继续写入 | 状态读回 |
| Profile 快照目标库被占用 | 不等待目标锁；临时库完成后原子替换 | 1秒级失败/成功边界测试 |
| 源库损坏或读取超时 | 明确快照失败，不启动伪登录会话 | 错误码+无新会话 |
| stdout/stderr 超限 | 截断并返回结构化超限错误 | 输出上限证据 |
| 操作超时 | 取消/回收进程树、端口、临时目录 | 资源账本读回 |
| 用户取消 | 终态明确，不伪装成功 | 取消结果+回收证据 |
| 重复关闭 | 幂等返回“已结束并已释放” | 两次关闭结果 |
| 旧守护进程残留 | 不复用错误 Profile/CDP；可识别并回收 | stale session 证据 |
| 快照目录越界/非白名单 | 边界拒绝 | 负向 HTTP 黑盒 |
| 多会话并发 | 不串会话、不共享错误句柄 | 会话隔离证据 |
