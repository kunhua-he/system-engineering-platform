## 四、全量重生成的反证（为什么必须先立白名单）

| 结果 | 包数 | 含义 |
|---|---|---|
| 与生成物**逐字相同** | 6 | 无需任何动作 |
| 差异**只落在 `- 版本：` 行** | 105 | 即本次 P1 要治的「版本头滞后」——差异纯粹是版本号 |
| 差异**含生成器词汇外行** | 5 | 重生成会**删掉人工段落** |

`FFmpeg媒体` 更是在**内容层**持有生成器产不出的正确参数。**全量重生成 = 有损覆盖，禁止。**

## 六、剩余风险

1. **模板表是「源派生」而非「实跑派生」**：前缀表读自生成器源码字面。若某包说明书存在恰好以
   生成器前缀开头、但内容被人工改写的行（如 `- 调用示例：` 被手改），模板判定会**漏判**。
   实测已抓到 2 个此类包（见第三节增补建议区），**已单列**。
2. **乙支 23 包中有 4 包第 4 行与包声明不一致**（`支持库/适配层/TreeSitter提供者` 1.0.0←1.0.1、
   `模块库/开工编排` 1.0.0←1.0.1、`模块库/能力目录` 1.0.0←1.0.1 等），另有 3 包第 4 行根本不是版本行
   （`支持库/前端/前端契约校验`、`支持库/后端/组件规范支持库`、`模块库/测试资源`）。
   因属人工权威资产，本路**不动**，作为遗留项。
3. **白名单为文件级，非段落级**：B 类 6 包中，受保护的只是手写行；其余行仍是生成器口径。
   若未来要重生成这 6 包，必须先做**行级合并**（保手写行、刷生成行），不能整文件覆盖。
4. **悬空引用未修**：`支持库/后端/组件规范支持库/说明/使用说明.md:11` 引用的「收口方案」不存在（上游方案 P0-3）。
   本路只做白名单与版本头，未处置。

# -*- coding: utf-8 -*-
"""逐包比对 说明/使用说明.md 第4行版本头 vs 包声明.json.版本。四口径输出。只读。"""
import os, re, json
根 = os.path.abspath(".")
模板前缀 = ["- 类型：", "- 版本：", "- 说明：", "- 入口：", "- 权威分工：**调用口径以本文为准**",
            "  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。",

            "- 不合法时错误码："]
模板正则 = [re.compile(r"^# .+（.+）$"), re.compile(r"^## (依赖能力|能力|可配置项)$"),
            re.compile(r"^### .+（`.+`）$"), re.compile(r"^### .+（类型: .+）$"),
            re.compile(r"^- 能力 `.+` 版本约束 `.*`$"), re.compile(r"^$")]
def 是模板行(行):
    return any(行.startswith(p) for p in 模板前缀) or any(r.match(行) for r in 模板正则)

说明书, 声明 = {}, {}
for 当前, 目录们, 文件们 in os.walk(根):
    if "工程缓存" in 当前.split(os.sep) or ".git" in 当前.split(os.sep):

    if "包声明.json" in 文件们: 声明[当前] = os.path.join(当前, "包声明.json")

分片 = {"全仓": [0, 0], "甲支": [0, 0], "甲支非白名单(P1域)": [0, 0], "白名单": [0, 0]}
明细 = []
for 说明目录, 路径 in sorted(说明书.items()):
    包目录 = os.path.dirname(说明目录)
    文本 = open(路径, encoding="utf-8").read()
    行们 = 文本.split("\n")
    是甲 = "权威分工：**调用口径以本文为准**" in 文本

    可比 = 声明版本 is not None and 说明书版本 is not None
    不一致 = 可比 and 说明书版本 != 声明版本
    for 名, 命中 in (("全仓", 可比), ("甲支", 是甲 and 可比),
                     ("甲支非白名单(P1域)", 是甲 and not 是白 and 可比), ("白名单", 是白 and 可比)):
        if 命中:
            分片[名][0] += 1
            if 不一致: 分片[名][1] += 1
    if 不一致:

print(f"{'分片':<24}{'可比':>6}{'不一致':>8}")
for 名, (总, 不) in 分片.items():
    print(f"{名:<24}{总:>6}{不:>8}")
print(f"\n不一致明细（{len(明细)} 条）：")
for 包, a, b in 明细: print(f"  {a} ← {b}   {包}")
