# 逐字稿全自动精校 —— 落地计划（2026-09-10）

> 目标（华哥口径）：用户只给 **3 个绝对路径 + 1 个模式号**（源文件 / 导出 / 缓存 / 模式），
> 底座全自动跑完，最终**只有一份精校逐字稿**落到导出路径。视频与音频自动适配。
> 流程图的设计稿见 `开发文档/当前流程图.md` 第九节（唯一权威流程图）。

## 一、唯一入口（对外只有一个能力）

```text
POST http://127.0.0.1:40007/网关/调用
能力id：直播逐字稿.全自动精校
参数：源文件路径(文本型,必填) / 导出路径(文本型,必填) / 缓存目录(文本型,必填) / 模式(整型,必填)
      分片秒数(整型,默认300) / 附加术语(文本型,默认空) / 模型配置(字典型,默认null) / 超时秒(双精度数型,默认3600)
返回：结果型 { 精校稿路径, 模式, 模式名称, 字数, 时长秒, 质检, 缓存目录, 状态 }
```

## 二、落点（分层不允许越界）

| 落点 | 改动 | 原因 |
|---|---|---|
| `支持库/后端/转写支持库/转写` | 新增参数「返回分段」（逻辑型，默认 false）+ 返回 `分段` 指标 | 疑难标记需要 avg_logprob / compression_ratio / no_speech_prob；属转写原子能力的详细模式 |
| `模块库/直播逐字稿/模式数据/模式注册表.json` | 新增（8 类模式） | 模式 = 排版模板 + 裁决提示词 + 质检规则；加模式只加数据，不改主流程 |
| `模块库/直播逐字稿/实现/*.py` | 新增多个单一职责实现文件 | 主文件只调度；文件 80-160 行 |
| 模块契约/包声明/能力数据/验证场景/完整性摘要 | 由唯一编译入口生成与校验 | 禁止手写漂移 |

## 三、批次（每批完成即验收，不跨批欠账）

```text
批次1 地基（主代理亲做，必须唯一）
  · 转写支持库「返回分段」契约+实现+测试（1.0.0 → 1.1.0，默认行为不变）
  · 模块库.直播逐字稿 新增「全自动精校」能力：四参校验 + 模式路由 + 缓存/指纹/续跑骨架
  · 缓存目录结构落地（00_元数据…10_质检）
  · 出口：真实 HTTP 跑通「视频/音频绝对路径 → 缓存底稿（含分段指标）」

批次2 疑难与复核
  · 疑难标记（低置信度/高压缩比/无语音/数字专名/死循环段识别）
  · 疑难聚类（间隔≤60s 合并）+ 3 轮独立复核
  · 证据包（底稿 + 3 轮 + 术语表，按段可取）

批次3 裁决与排版
  · LLM 逐段裁决（大语言模型支持库；无疑难段直接精校；不确定标【听不清】/【待确认】）
  · 8 模式排版合成（模式分叉点）

批次4 质检与交付
  · 质检硬门禁（通用 + 模式附加项；不过 → 导出路径不落半成品）
  · 原子导出（临时文件 → 校验 → rename）+ 幂等（源文件+模式+参数指纹命中即复用）

批次5 端到端真实冒烟
  · 用真实直播短样本（或裁剪片段）跑完整链路，验 40007 真实 HTTP 返回与导出文件

批次6 收口
  · 项目说明.md / 未完成事项.md 更新；临时文档删除；Git 提交
```

## 五、硬约束

- 只允许标准库；第三方只出现在 `支持库/适配层/` 提供者。
- 模块只经 `获取能力调用器().调用能力(能力id, 参数)` 组合底层，禁止 import 实现目录。
- 全中文命名（变量/函数/文件/目录/注释）；`id` 保留英文。
- 传参必须完整；缺参、类型漂移、多余参数一律立即失败，不兜底不降级。
- 失败不产半成品：导出路径只在质检通过后原子写入。
- 缓存目录可续跑：任一阶段产物存在且任务指纹一致 → 跳过该阶段。

## 六、已知风险

- Whisper 品牌词误识别（华世王镞 → 华氏王族，CER 约 20.63%）：靠「附加术语」+ 术语表补偿 + 质检门禁兜底，不指望模型自愈。
- 长直播转写耗时：分片级独立超时与续跑是硬需求，不能整场一把梭。
- 模式排版质量属主观项：先出结构（标题层级/段落形态），再按真实稿件迭代。
