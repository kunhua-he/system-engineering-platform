## 三、冷启动定义

全新 Python 进程、清空项目源码 `PYTHONPATH`、无测试预注册、无历史全局单例、只使用已安装制品与声明配置：
装配→注册→调用全链路成立。任何经 `sys.path` 拼接、包 `__path__`、源码目录、测试预注册、直接导入 `实现/` 或全局状态残留跑通的链路均不算完成。

## 四、幂等定义

同一包 id、版本、契约摘要、实现摘要完全一致可重放（重复装配结果一致）；任一不同必须冲突失败且不留半装配状态。

## 五、成功定义

能力确实经过生产注册表调用并返回统一结果+完整调用证据（请求id、模块版本、能力id、支持库包id、提供者版本、制品摘要、成功/失败、资源释放结论）。
仅导入、仅目录存在、直接调用实现、测试注入调用器均不算成功。

## 六、强制验收目标（本阶段）

1. 37 个正式支持库逐包权威 13/13；发布门禁删除"债务披露放行"。
2. 11 个正式模块逐能力：声明=注册=搜索=客户端可见。
3. 全新进程冷启动制品装配+调用成功；反向破坏（删包声明/注册入口/契约/锁/实现任一项）生产链失败。
4. 唯一注册表/唯一提供者路由/唯一调用器注入点；测试直接导入实现或预注册无法假绿。
5. 客户端制品一致性成为正式发布门禁检查点，反向篡改阻断。
6. 提供者异常/超时/取消/崩溃后线程/进程/端口/临时目录/句柄零残留。

## 七、对外开发接入（S0.2 更新）

平台面向**开发**（Agent 开发业务项目、开发者写业务代码）。核心是 **HTTP 能力网关**，
MCP 只是网关上一层的可选适配。

```text
         HTTP 能力网关（核心底座）
  搜索能力   查看契约   执行能力
    │          │          │
    ▼          ▼          ▼
  调用方：Agent · 业务程序 · 任何语言
```

网关之上三种用法：

```text
      HTTP 网关
      ┌─┬─┬─┐
      ▼ ▼ ▼
  MCP 适配  本地同级  直接 HTTP
  （可选）  （复制本地）  （curl/任意语言）
```

### 7.1 HTTP 能力网关 = 核心底座

- 纯 HTTP 接口，任何语言、任何工具可直接调用，不依赖 MCP 协议；
- 提供三件事：搜索能力、查看契约（使用声明）、执行能力；
- 执行返回统一结果（成功/值/错误码/错误说明）+ 完整证据链；
- 内部只走能力注册表与唯一能力调用器，禁止另起执行路径。

### 7.2 MCP = 网关上的可选适配层

- MCP 不再承载平台逻辑，只是把网关的"搜索/查看/执行"包装成 agent 工具；
- 仅在 agent 需要"强制注入工具"时使用，简化为一层薄映射；
- 无 agent 场景可完全不用 MCP。

### 7.3 本地同级

- 支持库/模块库复制到本地项目，直接导入中文函数调用；
- 不依赖网关服务，本地独立运行；与网关调用语义一致。

### 7.4 本地/云端不敏感

- 网关可运行在本机或云端；本地同级复制到本机；
- 底层都是同一套装配与调用事实，部署形态不同，调用语义一致。

### 7.5 开发工具链属性

- 面向开发过程（Agent 开发、业务项目集成），不是单次调用；
- 搜索→查看契约→执行→结果与证据链，形成开发闭环。
