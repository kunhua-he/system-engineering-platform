## 二、形状（`渲染文本回执` 固定三段）

```
┌─ 首行 = 判据 ────────────────────────────────────────────┐
│  成功且无值 → 1                                          │
│  成功且有值 → 值的正文（文本原样铺开，不加包装）           │
│  失败       → -1                                         │
└──────────────────────────────────────────────────────────┘
            ↓ 其后：除 成功／值 外的每个非空键一行 `键：值`
┌─ 附注（逐键保留，嵌套缩进 2 空格）──────────────────────┐
│  错误码：参数不合法                                       │
│  错误说明：能力id必填                                     │
│  值裁剪：                                                │
│    已裁剪：真                                            │
└──────────────────────────────────────────────────────────┘
```

- **判据在首行**：`-1` 就是失败，其余两态都是成功 —— agent 不用读句子猜。
- **协议层本来就不要求 JSON**：`tools/call` 回包是 `[{type:"text", text:…}]`，
  那一层 JSON 是薄壳自己加的（`json.dumps(数据)`），加多少由出口定。
- **绝不静默丢键**：键集见 §四，可丢的只有「常量回声 / 内部实现计数」那一档（本轮**未动**，见 §七）。

### 4.1 必须进回执

| 键 | 语义 | 出现条件 |
