### B-1【阻断】发布门禁「非正式类型名」判据面静默塌缩为空集

- **文件:行号**：`开发工具/发布门禁/运行发布门禁.py:1023-1024`（常量）、`:1100-1105`（读取器）、`:1252`（调用）、`:1260`（判据）
- **类别**：恒空判定项（第 1.4 条「恒真/恒空的门禁」）

**现场证据（源码片段）**

```python
# 运行发布门禁.py:1023-1024
_历史短名源 = ("运行核心", "统一网关", "网关核心.py")
_历史短名变量 = "类型短名映射"

# :1100-1105
def _防回潮历史短名集(根: Path) -> frozenset[str]:
    """历史短名集：现场读 ``运行核心/统一网关/网关核心.py:类型短名映射``（不另列）。"""
    集合 = _读模块字面量(根.joinpath(*_历史短名源), _历史短名变量)
    if isinstance(集合, dict):
        return frozenset(str(键) for 键 in 集合)
    return frozenset()          # ← 读不到就返回空集，**静默**

# :1260
def _像类型名(文本: str) -> bool:
    return bool(文本) and (文本.endswith("型") or 文本 in 历史短名)   # 历史短名 == 空集 ⇒ 后半恒假
```

**复现（按同一 AST 口径重实现读取器，只读）**

```
读取源 = 运行核心/统一网关/网关核心.py
读取变量 = 类型短名映射
AST 找到模块级赋值 = False
⇒ _防回潮历史短名集 返回 = frozenset() （空集，静默）
模块里该名字的真实形态 = ['from 运行核心.统一网关.类型规格 import 类型短名映射, 类型匹配表, 数值类型名, _类型表自检, 校验能力参数']
对照：运行核心/统一网关/类型规格.py 里 类型短名映射 = 字面量赋值，项数 18
```

**为什么它无论如何都返回同一结论**：该符号已搬去 `运行核心/统一网关/类型规格.py:86`（18 项），
`网关核心.py:546` 只剩 `from … import 类型短名映射`；而 `_读模块字面量`（`:989-1009`）只认
`ast.Assign` / `ast.AnnAssign` 的字面量赋值，**不跟随 import 再导出** → 恒返回 `None` → 恒返回 `frozenset()`。
于是 `_像类型名` 的「历史短名」那一支**永久恒假**：凡是「不带『型』后缀但属于历史短名」的写法
（如 `文本` 写成 `文本` 而非 `文本型`）在过扫描面时不再被拉进正式表比对。

**影响面（掩盖什么真实问题）**：掩盖「声明面用了历史短名而非正式类型名」这一类违规。
被判据自身设计要抓的目标（`类型短名映射` 的 18 个短名）**一个都不会被抓到**，
且因为存量本来就报「干净通过、基线 0」，这个塌缩**在门禁输出上完全不可见**（无任何告警）。

**最小改法**：`_历史短名源 = ("运行核心", "统一网关", "类型规格.py")`（一行）。
更彻底的改法：`_读模块字面量` 增加「遇到 `from X import 名列` 时跟随到 X 读取」一步——
否则同类搬迁会再次造成同一塌缩。

**是否建议现在修**：**建议现在修**（一行改动；但 `运行发布门禁.py` 是共享文件，需与在途改动避让）。

> 与同批件的关系：`开发文档/分析/审计_重复腿与旁路_20260919.md:209` 已从「重复腿」角度报过
> 同一现场（含「读取器返回 None」的实测）。本报告**不重复立案**，只补两件它没做的：
> ① 按第 1.4 条把该现象定性为「判据面静默塌缩」；② 给出「`_像类型名` 后半恒假」这条后果链。
