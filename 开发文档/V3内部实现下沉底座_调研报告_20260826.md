## 二、下沉判定（唯一值铁律）

**判据**：V3 功能 vs 底座已有能力
- 底座已有 → V3 删实现，改调网关（复用）
- 底座没有 → 底座新建支持库/模块，V3 再调

### 逐类判定

| 类目 | 核心功能 | 底座现状 | 下沉方式 | 优先级 |
|---|---|---|---|---|
| **数据存储-记忆** | 记忆读写/向量/相似度 | 无记忆库 | **新建记忆支持库** | P0 |
| **数据存储-状态库** | SQLite 单一事实源 | 有会话存储(SQLite) | 升级会话存储 或 新建状态库支持库 | P0 |
| **数据存储-文件账本** | CAS 写入/污染检测 | 有资源管理(原子写入/快照) | 复用资源管理，补账本模块 | P1 |
| **系统进程** | 进程/命令/工作区 | 有进程管理+版本控制Git | 复用已有，补缺口 | P1 |
| **内容编辑** | 上下文/代码/编辑/搜索 | 有文件系统+正则+搜索 | 组装模块库，V3 删实现 | P1 |
| **智能体工具-看板** | 协作看板 | 无 | 新建看板支持库 | P2 |
| **智能体工具-交付收口** | 证据汇总/交付 | 无 | 新建交付模块 | P2 |
| **运维管理** | 数据库维护/用量 | 有系统信息 | 补运维支持库 | P2 |
| **OpenCode工具** | SDK/PTY/队列 | 无 | 新建 OpenCode 对接模块 | P3 |
| **用户认证** | 认证/权限 | 有权限审批 | 升级权限审批 | P3 |
| **基础能力** | 契约/补丁/验证 | 大部分已有 | 复用+组装 | P3 |
| **Hermes工具** | 任务管理 | 无 | 新建任务管理模块 | P4 |
| **高阶编排** | 编排 | 无 | 新建编排模块 | P4 |

## 三、第一批（P0）：记忆 + 状态库

### 3.1 记忆支持库（新建）
- 来源：`数据存储/记忆工具.py`（645 行）+ `记忆迁移.py`（58 行）
- 能力：记忆写入/追加/计划/完成/删除/搜索/最近/列出
- 依赖：向量生成复用 `大语言模型支持库.模型连接器.生成嵌入`（BGE-M3 本地）
- 存储：SQLite `工程缓存/记忆库.db`

### 3.2 状态库支持库（新建 或 升级会话存储）
- 来源：`数据存储/项目状态库.py`（676 行）
- 能力：开工任务/授权租约/文件占用/反馈/观测/工具调用 等状态表
- 关系：与会话存储（Agent 会话）不同——状态库是「项目工作台状态」，独立

## 四、V3 改造模式（统一）

```
V3 业务代码（接口不变）
  ↓
V3 工具模块薄壳（只留函数签名 + 组装参数）
  ↓ 经 底座客户端.py
HTTP 40006 搜索/契约 + 40007 执行
  ↓
底座支持库（唯一实现）
```

- 每次下沉一个类目，V3 冒烟测试通过再推
- V3 对外 MCP 工具接口不变，业务无感
