# 系统工程平台 · 中间件网关契约

> 本文件是网关 API、被动发现、跨区域调用状态机和资源租约的唯一详细契约。上位原则以 `开发文档/项目说明.md` 为准；支持库原子能力以 `开发文档/支持库总览.md` 和包内契约为准；模块流程以 `开发文档/模块库总览.md` 和包内契约为准。

## 流程图

```text
IDE/业务程序/模块客户端
          |
          | HTTP JSON：目标类型 + 目标id + 契约版本 + 参数
          v
唯一中间件网关
  ├─ 请求身份/权限/大小/截止时间校验
  ├─ 被动发现声明索引（不导入、不启动）
  ├─ 未发现 → 立即错误
  ├─ 已发现 → 契约校验 → 创建/复用执行单元
  ├─ 状态机：接收→发现→装配→执行→完成/失败→排空→释放
  └─ 租约、预算、取消、证据、统一返回
          |
          v
网关内部运行核心执行器
  └─ 按网关授权启动一个 Provider/模块执行单元并回传事件
          |
          v
支持库原子能力 / 模块流程 / 受管 Provider
```

## 1. 区域和调用边界

“区域”包括：模块包、支持库包、Provider 进程、运行核心、项目适配层和外部服务。只要跨区域，就必须走网关 API；以下调用均禁止：

- 模块 `import 支持库`、`import Provider`、读取对方 `实现/` 或共享内部对象；
- 支持库直接调用另一个包的实现函数；
- 模块自行启动端口、进程、数据库连接或第三方 SDK；
- 通过全局单例、`sys.path`、裸句柄或旁路脚本绕过网关。

包内部的私有纯计算可以直接调用，但不能越过包边界。网关 API 是唯一跨区事实源；MCP、IDE 插件、本地客户端都只能调用它，不能复制执行逻辑。

## 2. 被动发现语义

网关启动只加载声明索引和完整性摘要，不加载模块实现、支持库实现或第三方 Provider。请求到达后才发现并装配目标：

| 请求情况 | 网关动作 | 结果 |
| --- | --- | --- |
| 目标 id 不在声明索引 | 不启动任何资源，不尝试模糊匹配 | `MODULE_NOT_FOUND` 或 `CAPABILITY_NOT_FOUND` |
| 目标存在但契约版本不兼容 | 不启动执行单元 | `CONTRACT_VERSION_UNSUPPORTED` |
| 目标存在但 Provider 未配置 | 可创建失败证据，不伪造启动 | `PROVIDER_UNAVAILABLE` |
| 目标存在且契约有效 | 按资源策略创建/复用执行单元 | 进入 `装配中` |

“发现”只证明声明存在；“可调用”还必须通过契约、依赖、权限、资源预算和 Provider 健康检查。发现失败不得返回空值、空列表或 `成功=True`。

## 3. 网关请求与返回（调用方最小面）

调用方只需要目标和参数。请求 id、契约版本、截止时间、资源预算、租约等由网关内部生成或校验，不要求普通调用者填写。

### 3.1 调用请求

```json
{
  "目标": "媒体处理.探测媒体",
  "参数": {"文件路径": "/受管制品/输入.mp4"}
}
```

### 3.2 统一返回

```json
{
  "成功": true,
  "值": {},
  "错误码": "",
  "错误说明": "",
  "可重试": false,
  "句柄": "可选；不接收则执行完成后自动释放"
}
```

调用方稳定依赖的只有 `成功`、`值`、`错误码`、`错误说明`、`可重试` 和可选 `句柄`。状态、证据、资源释放由网关内部记录；底层异常、第三方对象和密码不得直接泄漏。

### 3.3 最小 API

```text
POST /网关/调用
  入参：目标 + 参数；可选句柄
  出参：统一返回 + 可选句柄

POST /网关/请求（操作=资源状态）
  入参：句柄
  出参：句柄生命周期状态；不返回模块私有数据

POST /网关/请求（操作=资源续租）
  入参：句柄 + 租约秒
  出参：新的租约截止时间

POST /网关/请求（操作=资源关闭）
  入参：句柄
  出参：释放结果（幂等）
```

## 4. 状态机

```text
已接收
  → 校验中
  → 被动发现
       ├─ 未发现 → 已失败（NOT_FOUND）
       └─ 已发现 → 装配中
                      ├─ 装配失败 → 已失败
                      └─ 执行中
                           ├─ 成功 → 排空中
                           ├─ 业务失败 → 排空中
                           ├─ 超时/取消 → 回收中
                           └─ 崩溃 → 回收中
                                        ↓
                                      已释放
```

状态推进只能由网关控制面写入；Provider 只能回报事件，不能自行把失败改成成功。终态必须是 `已完成`、`已失败`、`已取消` 或 `已回收` 之一；所有终态都要有资源释放结论。

## 5. 资源和租约

- 一次性纯计算：请求到达后按需启动/调用，完成后释放。
- 有状态能力：网关返回一个不透明 `句柄`；后续请求只需携带句柄，句柄内部映射由网关决定。
- 不接收句柄：按一次性调用处理，完成、失败、超时或取消后自动释放。
- 句柄过期：执行单元进入 `排空中/回收中`，再次调用返回 `EXECUTION_HANDLE_EXPIRED`，禁止资源偷偷复活。
- 预算包括超时、并发、队列、内存、输出字节、临时目录、进程和句柄上限。
- 释放幂等；重复释放不得重复 kill、close 或删除其他 owner 的资源。

## 6. IDE 与旁路引用模式

开发者不需要手写底层 HTTP。IDE 读取能力/模块契约，生成中文客户端桩代码：

```text
导入模块("媒体处理", 契约版本="1.0.0")
结果 = 媒体处理.探测媒体(文件路径="输入.mp4")
如果 结果.成功 == 假：
    输出(结果.错误码, 结果.错误说明)
```

生成器只生成“调用网关”的客户端，不生成支持库实现的 import。目标未发现时，IDE 运行即得到 `MODULE_NOT_FOUND/CAPABILITY_NOT_FOUND`；不能因为本地存在同名目录而自动旁路调用。

## 7. 当前实现差距与开工项

当前模块源码已出现 `获取能力调用器().调用能力(...)` 这种内部注入调用；它可以作为网关客户端的内部实现，但还不能作为跨区域 HTTP 事实源。开工必须落到：

1. 在 `运行核心/统一网关` 或现有唯一 HTTP 网关中实现上述 `/网关/调用`、`资源状态`、`资源续租`、`资源关闭` 操作；句柄只作外部精准查询键，不跨模块共享模块内部对象。
2. 将 `公共契约/能力契约/调用器.py` 收敛为“目标 + 参数 + 可选句柄”的网关客户端协议；禁止模块直接获得进程内支持库注册表。
3. 被动发现只读取声明索引；按请求装配目标，未发现能力直接返回错误。
4. 为“未发现、版本不兼容、Provider 不可用、超时、取消、崩溃、重复释放”补齐真实返回和资源释放测试。
5. IDE/说明书生成器只从契约生成调用桩和返回类型，保持一个能力 id 一个调用入口。
