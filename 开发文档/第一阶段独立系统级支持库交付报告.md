## 二、公共契约（6 类）

1. **包声明**：包id/名称/类型/版本/说明/入口/依赖/能力，JSON 声明解析，必填字段校验
2. **能力契约**：能力注册表，重复注册拒绝，契约调用（未知参数拒绝），搜索
3. **基础类型**：统一结果（成功/值/错误/错误码/说明）
4. **错误结构**：错误码枚举 + 来源 + 可恢复性
5. **生命周期**：声明→发现→校验→安装→解析→运行→停止→卸载状态机
6. **版本规则**：x.y.z 比较、兼容性、升级方向

### 主验收命令（第二阶段起统一使用）

```bash

```

真实结果：**58 tests 全部成功，退出码 0**，连续多轮稳定。

### 验收命令缺陷修复记录

原任务书命令 `python3.14 -m unittest discover -s 测试中心 -p '测试_*.py' -v` 实测：
```text
Ran 0 tests
NO TESTS RAN
```
**根因**：unittest discover 的 `VALID_MODULE_NAME` 正则只认 ASCII 标识符，中文测试文件名（测试_*.py）被直接跳过，且 discover 默认顶层目录与系统根同名包冲突。
**修复**：`测试中心/__init__.py` 提供 load_tests 协议手动加载全部中文测试文件；`测试中心/运行测试.py` 为主验收命令，内置三重门禁：
- 零测试门禁：测试数量为零时返回非零（禁止零测试成功）
- 导入失败门禁：任一测试文件导入失败时返回非零
- 失败门禁：任一测试失败返回非零
**废弃**：`unittest discover` 命令已从 AGENTS.md / README.md 移除主命令地位，禁止再作为验收依据。

### 新增零测试门禁测试（6 用例）

验证：空套件判定、非空套件判定、主函数零套件返回非零、主函数真实套件返回零、导入失败门禁检测、无失败时门禁通过。
