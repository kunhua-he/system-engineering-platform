# 系统工程平台 · 调用接入指南

> 文档性质：面向调用者（业务项目 / Agent / 开发者）的接入说明。
> 唯一事实源见 `开发文档/第三十阶段S0生产事实冻结.md`。

## 总体流程

```text
        HTTP 能力网关
  搜索能力   查看契约   执行能力
    │          │          │
    ▼          ▼          ▼
  调用方：Agent · 业务程序 · 任何语言
```

网关之上三种用法：

```text
      HTTP 网关
      ┌─┬─┬─┐
      ▼ ▼ ▼
  MCP 适配  本地同级  直接 HTTP
  （可选）  （复制本地）  （curl/任意语言）
```

## 一、平台能做什么

平台把通用能力原子化、服务化：文件处理、文档转换、媒体处理、数据库访问、
外部程序调用等，统一经能力注册表登记，经唯一能力调用器调用，全链路留证据。

现有规模：37 个正式支持库、11 个正式模块、148 条聚合契约能力。

## 二、HTTP 能力网关（核心底座）

纯 HTTP 接口，任何语言、任何工具直接调用，不依赖 MCP 协议。

三个接口：

| 接口 | 作用 |
|---|---|
| 搜索能力 | 按关键词找能力 |
| 查看契约 | 看某个能力的参数/返回/错误码（使用声明） |
| 执行能力 | 真正调用，返回统一结果 + 证据链 |

返回统一结果格式：

```text
成功      是否成功
值        成功时的返回值
错误码    失败时的机器可读错误码
错误说明  失败时的人类可读说明
```

## 三、MCP 适配层（可选）

仅在 Agent 需要"强制注入工具"时使用。MCP 只做一层薄映射：
把网关的搜索/查看/执行包装成 Agent 工具，不承载平台逻辑。

无 Agent 场景可完全不用 MCP。

## 四、本地同级（复制到本地）

支持库/模块库复制到本地项目后，直接导入中文函数调用：

```python
from 支持库.后端.文件系统 import 读取文件

结果 = 读取文件(文件路径="公共契约/能力契约/契约.py", 编码="utf-8")
if 结果.成功:
    print(结果.值)
```

不依赖网关服务，本地独立运行。

## 五、项目接入流程（新项目）

1. 项目适配层声明：声明项目版本、配置、权限、路径、密钥引用与项目别名。
2. 依赖锁定：锁定依赖版本。
3. 模块绑定：绑定要用的模块版本。
4. 配置合并：合并项目配置。
5. 运行入口：提供项目运行入口。

示例：`示例项目/适配层示例/运行入口/运行.py` 是最小运行样板。

## 六、验证与发布

```bash
python3.14 测试中心/运行测试.py              # 常规层
python3.14 测试中心/运行测试.py --范围 慢速    # 慢速（强杀/压力/真实外部提供者）
python3.14 测试中心/运行测试.py --范围 全部    # 顺序执行全部
python3.14 开发工具/发布门禁/运行发布门禁.py   # 正式发布唯一判定
```

唯一验收入口是 `测试中心/运行测试.py`；零测试、导入失败、未解释跳过、
缓存假绿均判失败。发布门禁只有"通过/阻断"两种结果。

## 七、接入红线

1. 全中文命名：变量、函数、类、文件、目录、注释一律中文。
2. 只允许 Python 标准库：第三方依赖必须封装在 `支持库/适配层/` 对应提供者。
3. 禁止绕过能力调用器：不直接导入 `实现/`、不拼接 `sys.path`、不注册测试预注入调用器。
4. 禁止读取业务项目数据：不导入、不引用任何业务项目代码/数据库/配置/测试。
5. 跨包调用只经公开契约与包级中文入口。

## 八、常见问题

- 能力返回"未装配"：能力必须由加载器装配后调用，禁止直接导入支持库/提供者绕过能力调用服务。
- 搜索不到能力：先确认能力已登记（能力注册表），再检查关键词。
- 验证被锁拒绝：已有全量验证运行中，等它结束或用 `--测试文件` 做工作包验证。
