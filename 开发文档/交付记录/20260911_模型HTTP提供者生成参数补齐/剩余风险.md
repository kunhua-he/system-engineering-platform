# 剩余风险

1. **热态与冷态行为仍然不一致（根因面，未修）**。
   热接入重载 `支持库/后端` 会把模块级 `调用函数表` 重置为 `{}`，冷启动则非空。
   两条路径走的是**不同实现**（`_HTTP调用模型` 兜底 vs 注册的 `调用对话`）。
   本次只是把两者对齐到同一契约，漂移本身依旧存在 —— 下一次任一侧单独改动，
   仍会出现「热态过、冷启动炸」。建议后续让热接入重载时重新执行注册
   （而不是清空），使热态与冷态同源。

2. **缺少签名自检门禁**。
   `注册调用器()` 不校验注册函数能否容纳 `生成对话` 展开的键集。
   建议用 `inspect.signature` 在注册时校验，不匹配即报错，别等冷启动。
   本次已用回归测试兜住 `调用对话` 这一处，但同类漂移在其它调用器上仍可复发。

3. **流式路径的生成参数仍被丢弃**（既有设计面，不在本包范围）。
   `模型连接器.流式生成对话` 的签名不接收 `温度/最大令牌数/工具/响应格式`，
   流式载荷因此静默丢弃这四个参数。非流式已补齐，流式未动。

4. **`支持库/适配层` 不可热挂载**。
   该目录无 `包声明.json`，本文件任何改动都需重启 40007（决策记录 0008 第 4 条）。
   重启前必须确认无进行中任务，否则会掐断其它会话的在途请求。
