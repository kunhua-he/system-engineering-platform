## 四之三、正式验收命令的**超时口径**（2026-09-15 实测，必须写进文档）

`开发工具/HTML验证/验证器` 的**单步 HTTP 超时默认 15 秒**（`开发工具/HTML验证/常量.py:默认超时秒`）。
重提供者场景（`转写支持库.转写.*`、`媒体转写.*`、`直播逐字稿.*`、`网页浏览.*`）冷启动要加载模型或拉起浏览器，**单步超过 15 秒就会被判超时**，表面现象是：

```
✗ [直播逐字稿.全自动精校正向] 统一返回缺字段: ['值', '请求id', '耗时毫秒']（返回契约）
```

看着像「能力返回坏了」，其实是**验证器把请求掐了**、拿不到完整信封。实测反证：同参数直接调 40007 → **HTTP 200**、真返回 `Transcription success.`、耗时 **9.5 秒**。

**正式验收命令必须带 `--超时秒`**：

```bash
python3.14 -B -m 开发工具.HTML验证.验证器 \
  --制品 工程缓存/制品仓库/平台客户端环境/平台客户端 \
  --并发 32 --实例数 3 --端口池 45080-45082 --超时秒 90
```
