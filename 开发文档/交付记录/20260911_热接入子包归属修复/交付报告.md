## 背景

`支持库.后端.代码解析支持库` 既是真实活包，又新增了独立成包的子包
`支持库.后端.代码解析支持库.语法索引`。此时 `热接入.py` 必然失败：

```
支持库.后端.代码解析支持库: 注册未声明:
['代码解析支持库.语法索引.批量解析语法',
 '代码解析支持库.语法索引.解析Python语法',
 '代码解析支持库.语法索引.解析脚本语法']
```

## 根因（三步定位）

1. `计算包指纹` 覆盖包目录整棵子树，新增 `语法索引/` 使父包永远处于「变更」态，
   每次热接入都会走一遍父包门禁。
2. `_校验热接入包` 的包id前缀分支把子命名空间实现算作父包自己的实现，
   要求父包声明这些能力。
3. `发现全部` 禁止同一能力 id 出现在两份声明里，所以把子能力补进父包声明
   必然撞成「能力 id 重复」。

三者叠加 = 该配置在旧代码下**无解**，不是本包写法问题。

## 修复

`热接入()` 收集本轮已独立发现的包 id 集合，传入 `_校验热接入包`；
前缀归属分支改为只覆盖**未独立成包**的子域：

```python
elif (实现.包id.startswith(声明.包id + ".")
      and 实现.包id not in 独立包id集合):
    注册能力集合.add(能力id)
```

即：已被发现器独立发现的子包（自身有 包声明.json）由它自己的声明登记，
父包不重复登记；聚合壳目录下的纯分组子域仍由顶层声明覆盖。
