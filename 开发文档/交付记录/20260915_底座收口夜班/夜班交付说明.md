## 二、调用方只需记住四条（详见 `开发文档/网关调用最小示例.md`）

```js
const r = await fetch("http://127.0.0.1:40007/网关/调用", {
  method: "POST", headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ 操作: "调用能力", 能力id: "文档读取.结构化读取", 参数: { 文件路径: "/tmp/a.md" } })
}).then(r => r.json());
```

1. **多传字段不会失败**：顶层、操作参数、能力入参里的未知字段一律忽略（网关边界剔除）。
2. **只有两类会报错**：必填参数缺失、参数类型不符（`参数不合法` + 点名哪个字段）。
3. **版本不一致不失败**：返回里带 `请求版本` / `当前版本` / `版本差异`；只有强制约束不满足才失败。
4. **信封只增不减**：新增字段只追加，旧键语义永不改。

长任务走「任务提交 → 任务查询 → 任务取消」，不要用同步调用硬扛。
