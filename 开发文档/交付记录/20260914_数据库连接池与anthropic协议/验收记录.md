## 三、唯一同步池（`支持库/后端/数据库连接支持库/psycopg数据库`）

**删旧**（华哥「不保留旧的，全换新的，别搞多条轮子」）：旧的四条「连接串一次性能力」`连接 / 查询 / 事务执行 / 关闭` **连实现带注册带契约全部删除**，不留兼容入口；旧文档里的「兼容入口」表述一并清掉。

**新唯一链（5 个公开能力，句柄传参）**：

```text
连接数据库(连接串, 连接池大小, 超时秒) → 数据库句柄 + 连接池状态
  → 查询数据库(数据库句柄, SQL, 参数, 超时秒) → 行列表
  → 事务执行数据库(数据库句柄, SQL列表, 超时秒) → 已提交
  → 连接池状态(数据库句柄) → 最大/已创建/空闲/借出/已关闭
  → 关闭数据库连接(数据库句柄) → 已关闭（重复关闭幂等）
```

**实现要点**：纯标准库有界池（`LifoQueue` + 信号量），调用方只持句柄、不接触连接对象；查询失败连接只丢弃不回池；池关闭时统一释放并把句柄置失效。

### 两条真实缺陷（均由本轮并发/真实调用暴露并修复）

1. **并发越界（多线程压测暴露）**：原实现「检查已创建数 < 大小」与 `新建` 非原子，24 线程并发时借出连接数冲到 **7**（池上限 4），超限连接最终被 `queue.Full` 分支静默丢弃。修复：把并发上限收敛为信号量（**许可 = 借出权，归还即释放**），建连数另受池大小约束。修复后 **24 线程 × 6 轮 = 288/288 成功，峰值借出 3 ≤ 4，0 失败，0.03 秒**。
   - 过程中一次错误实现（许可按「连接存在」计数）导致空闲连接长期占满许可、压测 288 里只成功 3 条并超时 —— 属同一件事第二次报错，按新铁律停下读原理后改成「借出权」语义，未反复重试。
2. **契约不一致**：`查询数据库` 对非整数句柄回「句柄失效」，而 `关闭数据库连接` 对同类输入回「参数不合法」。统一为**类型不符 → 参数不合法**（新增 `_校验句柄类型`，三处调用点齐改），`连接池状态` 的错误码声明同步补 `参数不合法`。
