## 一、V3 现有记忆体系（封装源）

**位置**：`华世王镞_v3/MCP工具箱/工具模块/数据存储/`
- `记忆工具.py`（645 行）：记忆计划/追加/完成/删除/搜索/写入/最近 + 向量 + 余弦相似度
- `项目状态库.py`（676 行）：SQLite 状态库，含 `项目记忆`/`记忆向量` 两张记忆表

**数据结构**：
```
项目记忆(标识 PK, 名称, 记忆类型, 深度, 状态, 标签, 智能体, 正文, 创建时间, 更新时间)
记忆向量(标识 PK, 向量, 更新时间)
```

**能力清单**（从记忆工具.py 提取）：
| 能力 | 说明 |
|---|---|
| 记忆写入 | 写入一条项目记忆（带向量） |
| 记忆追加 | 追加更新已有记忆 |
| 记忆计划 | 创建计划型记忆 |
| 记忆完成 | 标记记忆完成 |
| 记忆删除 | 删除记忆 |
| 记忆搜索 | 语义搜索（向量相似度） |
| 记忆最近 | 最近记忆列表 |
| 记忆列出 | 列出全部记忆 |

## 二、封装设计（唯一值）

**新支持库**：`记忆支持库`（独立支持库，与 6 大聚合库平级）

```
记忆支持库
├── 记忆操作（原子）
│   ├── 记忆支持库.记忆操作.写入记忆
│   ├── 记忆支持库.记忆操作.追加记忆
│   ├── 记忆支持库.记忆操作.计划记忆
│   ├── 记忆支持库.记忆操作.完成记忆
│   ├── 记忆支持库.记忆操作.删除记忆
│   ├── 记忆支持库.记忆操作.搜索记忆
│   ├── 记忆支持库.记忆操作.最近记忆
│   └── 记忆支持库.记忆操作.列出记忆
└── 向量检索（原子，可复用大语言模型支持库.模型连接器.生成嵌入）
    ├── 记忆支持库.向量检索.计算相似度
    └── 记忆支持库.向量检索.加载向量
```

**依赖**（唯一值铁律）：
- 向量生成 → 调 `大语言模型支持库.模型连接器.生成嵌入`（已有）
- 数据存储 → SQLite 独立库文件（`工程缓存/记忆库.db`）
- 不重复实现向量生成/余弦相似度之外的逻辑
