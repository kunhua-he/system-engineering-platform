## 批次四：模式穷举扩展

本批次针对前面的问题模式做全仓库横向扫描，以下为全部新增命中簇（具体文件和行号已同步到债务清单）：

- **A 身份归属簇**：句柄、资源、事务、锁、任务、审计、反馈、任务观测、调用历史和治理工具存在空身份或任意标识放行；限流进入/离开也没有令牌配对。
- **B 路径边界簇**：临时上下文、开工 id、资源清单、物料清单、工作区、组件工作目录和提供者目录存在字符串前缀判断、`lstrip` 或未 `realpath` 校验。
- **C HTTP 输入输出簇**：能力连接器、模型提供者、平台 HTTP 提供者、示例启动器、文件上传等仍有无界请求体或响应读取。
- **D 子进程/IPC 输出簇**：系统探针、Git/PDF/LibreOffice/PyMuPDF/textutil/进程管理和任务进程存在 `communicate()` 或 `recv_bytes()` 先全量读取再限制/不限制的问题。
- **E 线程与并发簇**：MCP 能力网关、浏览器宿主、轻代码编辑器、示例服务使用无上限线程 HTTP；PDF 文本表格和提供者生命周期以 daemon 线程处理超时，可能长期累积。
- **F 文件、日志和 stdin 无界簇**：办公文档、文件系统、会话存储、Agent 查询、协作状态、任务观测、使用反馈和安全审计存在全量读取或无结果条数/字段大小上限。
- **G 临时目录生命周期簇**：进程组管理启动失败、诊断复现和部分提供者异常路径可能留下 `mkdtemp` 目录；成功路径已确认有清理的项目另行标注。
- **H 限流与状态增长簇**：拒绝记录、维度状态表和审计结果可无界增长；任务/流式入口忽略项目/用户/能力维度。
- **I 包注册与扫描事实源簇**：6 个聚合支持库吞异常；发现器、正式索引、完整性扫描和注册运行时口径不一致；跨类型重复包 id 可静默覆盖。
- **J 防火墙与发布接入簇**：动态导入属性形式漏检，语法/读取错误静默跳过，示例/验证器排除过宽；依赖防火墙和公开调用完整性门禁未接入正式发布主链。

本批次确认：之前清单中的问题大多不是单点，而是同源实现模式的重复实例。已发现命中均已落盘；尚未宣称仓库不存在清单外问题，后续修复后必须按同样模式复扫。
