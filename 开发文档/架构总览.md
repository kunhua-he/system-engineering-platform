## 图 2 · 一次能力调用的全链路（时序）

```mermaid
sequenceDiagram
    autonumber
    participant 调用方 as 调用方<br/>Agent / 业务项目 / 脚本
    participant 薄壳 as MCP 薄壳<br/>stdio · 3 工具 · 无端口
    participant 网关 as 本地网关<br/>127.0.0.1:40007
    participant 核心 as 网关核心<br/>协议 · 权限 · 限流
    participant 服务 as 唯一能力调用服务
    participant 注册表 as 能力注册表
    participant 包 as 支持库 / 模块库
    participant 提供者 as 适配层 Provider
    participant 执行 as 受管执行单元
    participant 句柄 as 句柄体系 / 资源协调

    调用方->>薄壳: capability_call(能力id, 参数)
    薄壳->>薄壳: 读环境变量「系统库网关凭证」
    Note over 薄壳: 缺失 → 网关凭证缺失<br/>fail-closed，不发起转发
    薄壳->>网关: POST /网关/调用<br/>Authorization: Bearer 凭证
    网关->>网关: 路径白名单 → 大小上限 → Content-Length → 凭证 → CORS → 拒 chunked
    Note over 网关: 不在白名单 → 404 未知路径<br/>凭证缺失/错误 → 401 权限不足<br/>跨域未授权 → 403 / chunked → 400 / 超 64MB → 413
    网关->>核心: 操作=调用能力
    核心->>核心: 操作在允许表 → 能力id非空 → 参数对照契约 → 句柄状态 → 限流 → 幂等
    Note over 核心: 能力不存在 404 / 契约不存在 404<br/>参数不合法 400 / 句柄无效 400 / 句柄已过期 400<br/>权限不足 403 / 限流 429 / 幂等键冲突 409
    核心->>服务: 调用(能力id, 参数, 上下文, 超时秒)
    服务->>注册表: 解析 能力id
    注册表-->>服务: 唯一 owner（支持库.xxx / 模块库.xxx）
    服务->>包: 包级公开入口
    包->>提供者: 参数校验 → 调 Provider
    提供者->>执行: 子进程 / 连接 / 线程<br/>独立进程组 · 有界输出 · 超时 killpg
    执行-->>提供者: 原始结果
    提供者-->>包: 统一结果
    包-->>服务: 统一结果（成功 / 值 / 错误码 / 错误说明）
    opt 本次调用需要跨请求持有资源
        服务->>句柄: 登记资源 → 返回句柄（1..999999）
        句柄-->>服务: 句柄
    end
    服务-->>核心: 统一结果
    核心-->>网关: HTTP 信封<br/>请求id / 操作 / 成功 / 值 / 错误码 / 错误说明 / 句柄 / 耗时毫秒
    网关-->>薄壳: HTTP 200 或 4xx / 5xx
    薄壳-->>调用方: 统一回执（含 HTTP 状态码与转发路径）

    Note over 句柄,执行: 句柄超时收回：创建 → 有效 → 使用 → 超时/取消/释放<br/>→ 确认回收 → 已失效；回收三态：已结束并已释放 / 结束请求已发出但未收敛 / 未找到且已幂等
```

**三个关键点**：① 凭证 **fail-closed**（薄壳缺凭证直接不发起转发；网关 401）；
② 错误码在**网关边界**按契约收敛成公开状态码（404 / 400 / 403 / 429 / 409）；
③ 需要跨请求持有的资源走**句柄**，不靠进程名或端口号。

## 图 3 · 源码 → 制品 → 发布 → 热接入（交付流水线）

```mermaid
flowchart LR
    S1["① 改包<br/>支持库 / 模块库 / 技能库<br/>能力搜索去重 + 包要素齐备<br/>+ 全量重算摘要（不闭合 0/N）<br/>+ 环境自检"]
    T1["② 统一编译器<br/>开发工具/项目编译/项目编译器.py（1.4.0）<br/>按目标依赖闭包算指纹<br/>指纹不变 → 命中旧制品"]
    T2["③ 制品目录 · 内容寻址 · 只读<br/>工程缓存/制品仓库/平台客户端制品/平台客户端-摘要<br/>自带运行入口 · 不回读开发源码"]
    V1["④ HTML 黑盒验证器<br/>开发工具/HTML验证/验证器.py --制品 制品目录<br/>启动制品进程发真实 GET/POST<br/>只看状态码 + 成功/值/错误码/请求id/耗时毫秒"]
    P1["⑤ 发布门禁<br/>开发工具/发布门禁/运行发布门禁.py<br/>HTML 黑盒 + 制品检查 + 发布事务"]
    P2["⑥ 激活指针切换<br/>平台客户端环境/当前.json<br/>实测：版本 105 / 栅栏令牌 105"]
    P3["不通过 → 不切换指针<br/>旧版本继续可用"]
    R1["⑦ 热接入<br/>运维脚本/热接入.py<br/>POST /网关/热接入（空请求体）<br/>实测约 0.2 秒 · 不重启进程"]
    R2["⑧ 增量装配生效<br/>网关重新发现 新增包 / 变更包<br/>已装配包运行态与句柄全部保留<br/>单包失败 → 保持旧版继续跑"]

    S1 --> T1 --> T2 --> V1 --> P1
    P1 --> P2 --> R1 --> R2
    P1 --> P3
```

**三条硬约束**：① 制品**内容寻址且只读**，验证期间不许往里写任何东西（运行态走受管缓存）；
② 不通过就**不切指针**，旧版本继续可用；③ 热接入**不重启进程**，已装配包与句柄全部保留。

## 图 5 · 句柄与资源状态机

```mermaid
stateDiagram-v2
    [*] --> 有效: 申请（登记归属：项目 / 所有者 / 能力）
    有效 --> 续租: 续租（延长租约）
    续租 --> 有效
    有效 --> 已过期: 心跳超时
    已过期 --> 已回收: 回收（按登记的归属回收）
    有效 --> 已回收: 主动关闭（幂等）
    已回收 --> [*]
```

**回收按状态机登记的归属**（项目 / 所有者 / 能力），**禁止按端口号盲杀**；
重复关闭幂等，句柄不存在才报「句柄无效」。
