| 能力域 | 当前入口 | 可用性 |
|---|---|---|

| 图像、媒体、OCR、网页分析 | `模块库/` | 可用性取决于 Provider 环境 |

## 怎么用

### 1. 直接验证平台

```bash
python3.14 测试中心/运行测试.py
python3.14 开发工具/发布门禁/运行发布门禁.py
```

### 2. 搜索和调用能力

```bash
python3.14 开发工具/能力搜索/能力搜索器.py --能力 读取文件
```

HTTP 能力入口：

```text
GET  /能力/搜索
GET  /能力/契约/{能力id}
POST /能力/执行
```

请求和返回字段以 `公共契约/HTTP路由契约.json`、包内 `能力契约/` 和统一结果为准。

### 3. 编译独立项目

```bash
PYTHONDONTWRITEBYTECODE=1 python3.14 -B \
  示例项目/可双击演示/开发文件夹/编译.py \
  --输出 示例项目/可双击演示/产物文件夹/20260822-demo
```

制品必须包含 `编译清单.json`、`制品来源.json`、`制品完整性摘要.json` 和 `运行入口/启动.py`。制品从自己的目录启动，不回读开发源码树。

### 4. 启动独立演示

```bash
PYTHONDONTWRITEBYTECODE=1 python3.14 -B \
  示例项目/可双击演示/产物文件夹/20260822-demo/运行入口/启动.py \
  --端口 45082 --不自动打开
```

打开 `http://127.0.0.1:45082/`。演示页面的能力调用通过 `/api/call` 转到制品内本地网关。

### 5. 启动 Agent MCP 适配

```bash
./MCP工具箱/启动HTTP服务.sh 8766
```

地址为 `http://127.0.0.1:8766/mcp/`。MCP 只是 Agent 工具适配层，不是业务运行时。客户端必须先 `initialize`，声明 `Accept: application/json, text/event-stream`，保存 `mcp-session-id`，再调用 `project_context`、工具和验证入口。连接失败时可以用 Python、curl 或本地 HTML 后端代理访问同一地址，不得复制另一套工具实现。

## 选择支持库还是模块库

- 原子能力、单一第三方/系统边界、参数和错误转换：放支持库。
- 多个公开能力组合成业务流程：放模块库。
- 项目配置、权限、路径、版本和密钥引用：放项目适配层。
- 装配、调用、租约、超时、取消、释放和证据：由运行核心统一管理。
- 正式调用方只能经过包级公开入口；不能导入 `实现/`、Provider 或第三方库。

## 当前不可用或不应使用

- `模块库/_模板`：仅模板，不是正式能力。
- `工程缓存/`：仅生成物、日志、摘要、受管制品和 Provider 环境；不作为源码导入路径。
- `开发文档/源码参考研究/`：只读研究资料，不是正式包、运行时或能力目录。
- 直接调用包内实现、复制第二套网关、把流式 `调用id` 当资源句柄：均不受支持。

## 资源与项目适配

- 资源句柄是不透明查询键，由网关登记、授权、关闭并记录回收结果；不传递第三方对象、线程、连接或模块内部对象。
- 文件、目录、进程、临时目录和句柄都必须先登记，终态统一释放；原子写入使用临时文件、同步和替换，冲突返回版本冲突，不覆盖他人结果。
- 项目适配层只负责项目声明、模块绑定、版本/权限/路径和密钥引用；配置按默认值、项目文件、环境变量、启动参数、请求覆盖的顺序合并，敏感值不得写日志。
- 受管 Provider 缺失、版本不符、超时、取消、输出超限或资源未释放时，能力返回明确不可用/失败结果，不把“声明存在”当作可用。

## 传参类型：句柄与 id（权威类型，防越过）

> 2026-08-26 华哥裁决，唯一权威类型约定。所有能力一次传参必须遵循，防止直接传 id 绕过能力进程。

### 1. 句柄 = 万能参数（一次传参必须用）

- **句柄指向「模块/支持库的某一个能力的进程/实例」**，由连接器创建返回。
- 多个连接 = 多个句柄，各自精准命中对应进程（如同时连 10 个库 = 10 个句柄）。
- 调用形式：`能力(句柄, 资源参数…)` —— 句柄是第一参数，定位能力进程。
- 句柄由 `公共契约/句柄体系.py` 管理：六位数字、状态机（创建/有效/失效）、租约、超时自动释放、显式释放（幂等）。

### 1.5 句柄超时（华哥口径，权威）

- **沉默超时**：句柄 N 秒无人调用 → 状态机主动回收并终止进程（会话存储/连接型）；不是常驻。
- **持续使用重置**：一直有人调用，每次调用都重置超时倒计时（永不静默过期）。
- **模块主动申报**：每个会启动句柄的支持库/模块必须申报「句柄超时秒」（它自身需要多久），写在 `包声明.json` 的 `句柄超时秒` 字段。
  - 常驻型（会话存储/模型连接）：申报大值（默认 1800 秒 = 30 分钟）。
  - 短暂型（word 读取、重排、删除守卫、模板渲染等）：申报小值（如 60 秒），用完自动过期。
  - **不申报 → 默认 30 分钟（1800 秒）**。
- **手动释放**：用户随时可调 `释放句柄` 立即终止（幂等）。
- **超时语义**：沉默到期 = 状态机主动退出进程（不是进程暴毙；暴毙是另一回事）。

### 2. id = 数据库主键（只作二次传参）

- **id 是句柄内的资源定位**（如 会话id、输入id、表主键），在句柄已指向能力进程后使用。
- **一次传参禁止直接传 id 绕过句柄**：直接传 id 等于跳过能力进程的治理/租约/生命周期，直连内部，视为多条腿，禁止。
- 正确：`执行SQL(句柄, sql语句)`、`会话存储.追加消息(句柄, 会话id, …)`。
- 错误：不拿句柄，直接 `执行SQL(连接id, …)` 绕进数据库内部。

### 3. 判定规则

| 场景 | 一次传参 | 二次传参 |
|---|---|---|
| 首次接触某能力实例 | 必须：连接器返回句柄 | — |
| 已持句柄、定位具体资源 | 句柄（第一参数） | id（资源定位） |
| 直接传 id 不传句柄 | ❌ 禁止（绕过能力进程） | — |

### 4. 落地范围

- 新增连接器型能力（会话存储、模型连接器、数据库等）一律：连接器返回句柄 → 操作持句柄 + 资源 id。
- 能力契约 `参数` 第一项固定为 `句柄`（类型 `文本型`，必填 `true`，说明“能力连接句柄”）。
- 违反判定的调用直接返回 `句柄失效` 或 `参数不合法`，不降级执行。
- **资源回收由状态机统一维护（华哥口径 2026-08-26）**：会启动句柄的模块/支持库，启动时调 `句柄体系.登记资源()` 把资源（PID/端口/连接/临时文件）绑定到句柄；句柄失效（超时/释放/进程暴毙）时，状态机自动 `核查回收()` 所有绑定资源——杀进程树（killpg）、清端口、删文件、关连接，不旁路拼独立回收能力。连接器本身不再各自实现回收逻辑。
