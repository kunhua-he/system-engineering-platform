## 能做什么

| 能力域 | 当前入口 | 可用性 |
|---|---|---|
| 文件、文本、数据集合、时间日期 | `支持库/后端/` 对应包 | 可用，按包契约调用 |
| 文档、表格、演示文稿、PDF | `支持库/后端/` + 受管 Provider | 可用性取决于 Provider 环境 |
| 图像、媒体、OCR、网页分析 | `模块库/` | 可用性取决于 Provider 环境 |
| 窗口、页面、组件描述 | `支持库/前端/` | 可用，组件契约为唯一字段来源 |
| 轻代码前端 IDE | `开发工具/轻代码前端编辑器/启动编辑器.py` | 可用；测试编译是操作名，F5 只是快捷键 |
| 独立项目编译 | `开发工具/项目编译/项目编译器.py` | 可用，生成自包含制品 |
| HTTP 能力网关 | `MCP工具箱/能力网关.py` 或运行核心本地网关 | 可用，路由见 `公共契约/HTTP路由契约.json` |
| Agent 工具接入 | `MCP工具箱/项目服务.py` | 可选；MCP 断开时可用 Python/curl/本地 HTML 后端代理直连同一 HTTP 服务 |

## 怎么用

### 1. 直接验证平台

```bash
python3.14 测试中心/运行测试.py
python3.14 开发工具/发布门禁/运行发布门禁.py
```

### 2. 搜索和调用能力

```bash
python3.14 开发工具/能力搜索/能力搜索器.py --能力 读取文件
```

HTTP 能力入口：

```text
GET  /能力/搜索
GET  /能力/契约/{能力id}
POST /能力/执行
```

请求和返回字段以 `公共契约/HTTP路由契约.json`、包内 `能力契约/` 和统一结果为准。

### 3. 编译独立项目

```bash
PYTHONDONTWRITEBYTECODE=1 python3.14 -B \
  示例项目/可双击演示/开发文件夹/编译.py \
  --输出 示例项目/可双击演示/产物文件夹/20260822-demo
```

制品必须包含 `编译清单.json`、`制品来源.json`、`制品完整性摘要.json` 和 `运行入口/启动.py`。制品从自己的目录启动，不回读开发源码树。

### 4. 启动独立演示

```bash
PYTHONDONTWRITEBYTECODE=1 python3.14 -B \
  示例项目/可双击演示/产物文件夹/20260822-demo/运行入口/启动.py \
  --端口 45082 --不自动打开
```

打开 `http://127.0.0.1:45082/`。演示页面的能力调用通过 `/api/call` 转到制品内本地网关。

### 5. 启动 Agent MCP 适配

```bash
./MCP工具箱/启动HTTP服务.sh 8766
```

地址为 `http://127.0.0.1:8766/mcp/`。MCP 只是 Agent 工具适配层，不是业务运行时。客户端必须先 `initialize`，声明 `Accept: application/json, text/event-stream`，保存 `mcp-session-id`，再调用 `project_context`、工具和验证入口。连接失败时可以用 Python、curl 或本地 HTML 后端代理访问同一地址，不得复制另一套工具实现。

## 选择支持库还是模块库

- 原子能力、单一第三方/系统边界、参数和错误转换：放支持库。
- 多个公开能力组合成业务流程：放模块库。
- 项目配置、权限、路径、版本和密钥引用：放项目适配层。
- 装配、调用、租约、超时、取消、释放和证据：由运行核心统一管理。
- 正式调用方只能经过包级公开入口；不能导入 `实现/`、Provider 或第三方库。

## 当前不可用或不应使用

- `模块库/_模板`：仅模板，不是正式能力。
- `工程缓存/`：仅生成物、日志、摘要、受管制品和 Provider 环境；不作为源码导入路径。
- `开发文档/源码参考研究/`：只读研究资料，不是正式包、运行时或能力目录。
- 直接调用包内实现、复制第二套网关、把流式 `调用id` 当资源句柄：均不受支持。

## 资源与项目适配

- 资源句柄是不透明查询键，由网关登记、授权、关闭并记录回收结果；不传递第三方对象、线程、连接或模块内部对象。
- 文件、目录、进程、临时目录和句柄都必须先登记，终态统一释放；原子写入使用临时文件、同步和替换，冲突返回版本冲突，不覆盖他人结果。
- 项目适配层只负责项目声明、模块绑定、版本/权限/路径和密钥引用；配置按默认值、项目文件、环境变量、启动参数、请求覆盖的顺序合并，敏感值不得写日志。
- 受管 Provider 缺失、版本不符、超时、取消、输出超限或资源未释放时，能力返回明确不可用/失败结果，不把“声明存在”当作可用。
