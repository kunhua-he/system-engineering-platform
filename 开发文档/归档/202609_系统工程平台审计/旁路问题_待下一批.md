## B1　个人蒸馏支持库.查询上下文 —— 无法写出正向场景

- **现象**：`支持库/后端/个人蒸馏支持库/验证场景.json` 中 `查询上下文` 只有负向步骤（`成功=false / 状态码=500 / 错误码=个人蒸馏不可用`）。
- **门禁口径**：`开发工具/HTML验证/场景加载.py::_校验场景全集` 强制 `正向目标能力 == 公开能力`——每个公开能力必须至少有一个 `预期成功=true` 的目标步骤，负向步骤不计入。
- **阻塞原因**：`查询上下文` 依赖外部服务 `http://127.0.0.1:8898/接口/v1/人格/当前`（环境变量 `V3个人蒸馏地址`）。实测该接口对任意合法参数（含服务自带默认 `用户:华哥` / `个人/默认`）**恒返回 HTTP 500**（上游无数据/未播种）；缺参时返回 422。故不存在可稳定通过的正向断言。
- **门禁无豁免**：`开发工具/公开调用完整性门禁.py` 无“外部依赖能力排除”开关（已确认）。
- **待决选项（下一批择一）**：
  1. 上报上游修复 `8898` 的 `/接口/v1/人格/当前`（播种或修 500），使其可返回 200，再补正向场景；
  2. 若该能力在本平台侧不应公开，从 `能力定义.json` / `包声明.json` 摘除，并同步六环产物（搜索数据 / 说明书 / 场景）；
  3. 给门禁加“外部依赖能力”标注与豁免通道（属架构改动，需华哥拍板）。
- **影响**：六环门禁 `个人蒸馏支持库` 恒缺 1 项目标，无法转绿。

## B2　检查点恢复.保存检查点 —— 运行期注册参数表缺 `中断原因`（契约漂移）

- **来源**：2026-09-11 补账子代理（工具执行 + 检查点恢复）实测发现。
- **现象**：`支持库/后端/系统核心支持库/检查点恢复/__init__.py` 注册 `保存检查点` 的参数表**缺 `中断原因`**。网关按**运行期注册**校验入参，传 `中断原因` 会返回 400「收到未知参数 中断原因」。
- **漂移三方**：`能力定义.json` 与 `能力数据/能力搜索数据.json` 都声明了 `中断原因`，`实现/` 也支持它；唯独运行期注册表没有 → 声明与运行期不一致。
- **修复点**：改 `支持库/后端/系统核心支持库/检查点恢复/__init__.py` 的注册参数表，补 `中断原因`（补账子代理被禁止改 `__init__.py`，故顺延）。
- **当前规避**：补账场景已绕开该参数（改用 `登记中断` 承载中断语义），所以门禁可过，但运行时该参数仍是坏的。
- **优先级**：中（真实运行时缺陷，非仅治理账）。

## B4　代码解析支持库.解析代码文件 —— 必填标 false 但无默认规则文件（软风险）

- **来源**：2026-09-11 静态普查子代理（A/B 类缺陷全仓普查）附带发现。
- **现象**：`解析代码文件` 的 `规则文件路径` 参数标为**必填 false**，但包内**无任何默认规则文件**，且该方法无条件调用 `加载切块规则()`。只传三个必填参数（文件id/路径/扩展名）必然返回 `失败("代码解析失败","未配置切块规则文件路径")`。
- **同类**：`解析代码字节` 同理会失败，但它有 `规则` 字典参数可替代（传入即可绕过）。
- **建议（择一）**：把 `规则文件路径` 标 `必填 true`；或随包附默认 `切块规则.json`。
- **优先级**：低（契约标注不精确，非崩溃；有 `规则` 参数的路子可绕过）。
