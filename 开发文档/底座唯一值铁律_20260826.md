# 底座唯一值铁律（2026-08-26 华哥口径 · 权威）

> 华哥核心表达（原文还原）：所有支持库都是唯一值，任意功能都是唯一值，
> **包含代码内部实现**。不允许代码内部有重复的。
> 如果是重复的，要么就是调用第三方库的那个，要么就是直接调用支持库的。

## 一、唯一值铁律

1. **能力唯一**：任意功能（能力）在整个底座只有一个实现，能力 id 全局唯一。
2. **代码内部唯一**：同一个功能的代码实现不允许出现第二份。哪怕内部实现逻辑有重叠，也不允许复制粘贴式重复。
3. **复用规则**：当功能重复时，只有两种合法路径——
   - **调用第三方库**：如果已有第三方库封装了该能力（适配层/内部层支持库），直接调用，不自己实现。
   - **调用支持库**：如果底座已有支持库提供该能力，直接经能力调用器调用，不绕过重写。
4. **禁止**：新写一份实现来「覆盖」或「绕过」已有能力。发现重复 → 先定位已有唯一实现 → 复用或升级它。

## 二、判定方法

当发现「两个文件实现相似功能」时，按此判定：
- 是否同一个能力？ → 是 → 必须合并成一个（唯一值）
- 是否不同能力但底层相同？ → 是 → 底层抽到支持库，两个能力都调用它
- 是否已有第三方库实现？ → 是 → 经适配层调用，不重写
- 是否已有支持库实现？ → 是 → 经能力调用器调用，不重写

## 三、落地

- 新增能力前：先搜索底座是否已有相同/相似能力（全库搜索能力id）
- 发现重复：定位已有实现 → 复用 or 升级 → 删除重复的
- 架构分层调用：业务层(模块) → 支持库(原子) → 第三方(内部层/适配层)，层层唯一
