文档、README、AGENTS.md 多处使用：

```bash

```

```text

退出码：1
```

```bash
python3.14 -m 开发工具.发布门禁.运行发布门禁 --help
退出码：0
```

根因落点：`运行发布门禁.py` 在第 31 行先导入 `公共契约`，第 55～61 行才计算并插入项目根目录；直接脚本执行时，根目录修复逻辑已经晚于第一次导入。

**影响：** 按文档复制命令会失败；正式发布唯一判定入口在“文档命令形态”下不可直接执行。

**建议：** 将发布门禁的根目录定位/`sys.path` 初始化移动到所有项目内模块导入之前，并保留模块方式作为标准调用；修复后必须分别验证直接脚本、`-m` 模式、制品参数和正式门禁。
