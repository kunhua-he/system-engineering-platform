### 8.3.2 并行维修期禁止 `git add -A`（2026-09-18 新增，来自一次真实污染）

> **教训**：我用 `git add -A` 提交时，**子代理的反向验证正在跑**，其**刻意写入的变异值**
> （`动态库提供者.调用动态库` 的 `0.0.0-篡改`、`平台状态.写入记录` 的 `记录.状态=已被篡改的状态`）

>
> **判据（此后一律照做）**：
> ① **提交一律用精确路径 `git add <文件>…`，禁用 `git add -A` / `git add .`**（并行维修期尤其）；
> ② 提交前 `git status --short` 核对清单 —— **出现不属于本次任务的条目就停手**，先问清来源；

>    正确姿势：**等子代理报「已还原」再提交**，或提交前 `git diff --cached` 逐文件确认无
>    `篡改` / `反向样本` / `临时` 字样；
> ④ 同一理由：**共享制品仓库（`工程缓存/制品仓库/`）在并行期也会竞态** ——
