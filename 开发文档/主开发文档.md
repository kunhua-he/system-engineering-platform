## 快速验收命令
```bash
python3.14 -m 开发工具.HTML验证.验证器 --制品 <待发布制品目录>
# 多实例制品池：一次部署 N 个制品进程、端口池隔离，实例间零端口竞争
python3.14 -m 开发工具.HTML验证.验证器 --制品 <待发布制品目录> --实例数 3 --端口池 45080-45180
# 唯一全量验收：HTML 高并发批量验证制品（unittest 只做开发期定向冒烟，禁止全量）
python3.14 -m 开发工具.HTML验证.验证器 --制品 <待发布制品目录> --并发 32
python3.14 -m 开发工具.发布门禁.运行发布门禁
```
