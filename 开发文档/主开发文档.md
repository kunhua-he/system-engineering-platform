## 快速验收命令
```bash
python3.14 -m 开发工具.HTML验证.验证器 --制品 <待发布制品目录>
# 多实例制品池：一次部署 N 个制品进程、端口池隔离，实例间零端口竞争
python3.14 -m 开发工具.HTML验证.验证器 --制品 <待发布制品目录> --实例数 3 --端口池 45080-45180
# 唯一全量验收：HTML 高并发批量验证制品（unittest 只做开发期定向冒烟，禁止全量）
python3.14 -m 开发工具.HTML验证.验证器 --制品 <待发布制品目录> --并发 32
python3.14 -m 开发工具.发布门禁.运行发布门禁
# 拿到仓库先跑这个：本机能不能跑、缺什么（21 项，有不支持项就非零退出）
python3.14 -m 开发工具.环境自检
# 摘要重算（改过包后必跑；只报不写加 --只报。会级联重算聚合父包）
python3.14 -m 开发工具.全量重算摘要 [--只报]
# 依赖锁重建（换平台/换环境后跑；默认干跑只报差异，加 --执行 才写盘）
python3.14 -m 开发工具.重建依赖锁
```

## 开工阅读顺序

```text
步骤 0：python3.14 -m 开发工具.环境自检
   ↓ 先确认本机能不能跑（解释器/平台/依赖锁/收口层能力/装配冒烟），有不支持项就别往下走
步骤 1：AGENTS.md
   ↓ 项目硬规则、子代理继承协议、允许修改目录、验收门禁
步骤 2：开发文档/项目说明.md
   ↓ 唯一权威事实源：当前版本、能力入口、契约、避坑规则
步骤 3：开发文档/未完成事项.md
   ↓ 唯一债务清单；未完成项只从这里读
步骤 4：开发文档/当前流程图.md
   ↓ 单链路传参总览与调用、治理、验证、发布流程
步骤 5：目标目录的使用说明.md
   ↓ 该包的入口、调用示例、失败处理
步骤 5.5：要新建支持库/模块/技能包时，先读对应指南
   ↓ 开发文档/规范/新建支持库与模块指南.md / 开发文档/规范/新建技能包指南.md（照着做才能一次命中）
步骤 5.6：要新建/大规模改动前，对号入座本文件「文档地图 B 栏（规范）」
   ↓ 规范类文档只在 开发文档/规范/ 下；包级规范在各包 说明/设计说明.md
步骤 6：开发文档/决策记录/
   ↓ 需要知道“为什么这么定”时再读，不参与日常开工
步骤 7：开发文档/参考资料/外部源码研究/
   ↓ 仅用于选型与结构参考，不作为当前实现依据
```

判断哪份文档是当前事实时，优先级为：

```text
当前代码 + 真实请求验证
    > AGENTS.md 与 项目说明.md
    > 包级使用说明
    > 决策记录
    > 参考资料与归档
```

如果不同文档冲突，不得自行猜测：先以当前代码和真实请求复核，再更新权威文档。
