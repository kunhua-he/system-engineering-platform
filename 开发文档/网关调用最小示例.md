# 网关调用最小示例

本文件只说明外部程序如何通过 HTTP 调用支持库和模块。完整参数、返回字段、错误码和资源预算，以 `能力详情` 返回的能力契约为准。

## 地址

```text
http://127.0.0.1:8866
```

网关默认只监听本机回环地址。远程部署时使用实际网关地址和端口，不使用代理端口 `4780`。

## 第一步：读取目录

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"能力目录","参数":{}}'
```

首次只返回支持库、模块库、包名称、简介和能力数量，不加载全部命令正文。

也可以用 `GET /健康` 检查网关状态。

## 第二步：查看包和能力

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"包详情","参数":{"包id":"模块库.文档读取"}}'
```

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"能力详情","参数":{"能力id":"文档读取.结构化读取"}}'
```

只有真正准备调用时，才读取单项能力的参数、返回、错误码、依赖和调用示例。

## 第三步：调用能力

```bash
curl -X POST http://127.0.0.1:8866/网关/调用 \
  -H 'Content-Type: application/json' \
  -d '{
    "操作":"调用能力",
    "能力id":"文档读取.结构化读取",
    "参数":{"路径":"/tmp/a.md"}
  }'
```

`/网关/请求` 也接受同样的 `POST` 请求体；`/网关/调用` 是调用动作的简写入口。模块和支持库都使用同一套入口，不直接暴露各自端口。

## JavaScript 调用

```js
const response = await fetch("http://127.0.0.1:8866/网关/调用", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    操作: "调用能力",
    能力id: "文档读取.结构化读取",
    参数: { 路径: "/tmp/a.md" }
  })
});
const result = await response.json();
```

统一返回至少包含：

```json
{
  "成功": true,
  "值": {},
  "错误码": "",
  "错误说明": ""
}
```

## 句柄

默认不返回句柄；调用完成后自动释放资源。需要跨请求保持状态时，在请求中传入 `"获取句柄": true`，网关返回不透明句柄，后续请求携带 `"句柄"`。关闭、超时、异常和过期回收由网关和运行核心负责。

## 凭证

启用凭证后，在请求头携带：

```text
Authorization: Bearer <网关凭证>
```

凭证只从受控环境变量加载，不写入 HTML、代码仓库或日志。
