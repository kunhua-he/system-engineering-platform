# 网关调用最小示例

本文件只说明外部程序如何通过 HTTP 调用支持库和模块。完整参数、返回字段、错误码和资源预算，以 `能力详情` 返回的能力契约为准。

## 地址

```text
http://127.0.0.1:8866
```

网关默认只监听本机回环地址。远程部署时使用实际网关地址和端口，不使用代理端口 `4780`。

## 第一步：读取目录

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"能力目录","参数":{}}'
```

首次只返回支持库、模块库、包名称、简介和能力数量，不加载全部命令正文。目录默认分页，每页 20 个包；返回 `总包数`、`偏移`、`限制`、`下一偏移` 和 `是否完成`，把 `下一偏移` 传回即可继续读取。

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"能力目录","参数":{"偏移":20,"限制":20}}'
```

也可以用 `GET /健康` 检查网关状态。

## 第二步：查看包和能力

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"包详情","参数":{"包id":"模块库.文档读取"}}'
```

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"能力详情","参数":{"能力id":"文档读取.结构化读取"}}'
```

只有真正准备调用时，才读取单项能力的参数、返回、错误码、依赖和调用示例。

## 第三步：调用能力

```bash
curl -X POST http://127.0.0.1:8866/网关/调用 \
  -H 'Content-Type: application/json' \
  -d '{
    "操作":"调用能力",
    "能力id":"文档读取.结构化读取",
    "参数":{"路径":"/tmp/a.md"}
  }'
```

`/网关/请求` 也接受同样的 `POST` 请求体；`/网关/调用` 是调用动作的简写入口。模块和支持库都使用同一套入口，不直接暴露各自端口。

## JavaScript 调用

```js
const response = await fetch("http://127.0.0.1:8866/网关/调用", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    操作: "调用能力",
    能力id: "文档读取.结构化读取",
    参数: { 路径: "/tmp/a.md" }
  })
});
const result = await response.json();
```

统一返回至少包含：

```json
{
  "成功": true,
  "值": {},
  "错误码": "",
  "错误说明": ""
}
```

## 句柄

默认不返回句柄；调用完成后自动释放资源。需要跨请求定位同一批资源时，在请求中传入 `"获取句柄": true`，网关返回固定六位数字句柄（例如 `004281`，保留前导零）。句柄不是模块内部对象；每个模块仍在自己的 owner 内执行增删改查，后续模块只把它作为 `资源句柄` 精准查询条件。

查询句柄状态：

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"资源状态","句柄":"004281","参数":{}}'
```

关闭句柄：

```bash
curl -X POST http://127.0.0.1:8866/网关/请求 \
  -H 'Content-Type: application/json' \
  -d '{"操作":"资源关闭","句柄":"004281","参数":{}}'
```

`资源续租` 的参数为 `{"句柄":"004281","租约秒":300}`。句柄必须是六位数字；过期、跨项目或跨所有者时，网关明确拒绝。网关只返回生命周期状态，不替代模块内部业务查询。

## 凭证

启用凭证后，在请求头携带：

```text
Authorization: Bearer <网关凭证>
```

凭证只从受控环境变量加载，不写入 HTML、代码仓库或日志。
