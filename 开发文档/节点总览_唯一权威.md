## 一、支持库：唯一原子能力（无业务逻辑，契约冻结，内核可独立升级）

### 1.1 核心后端（14 个，含 2026-08-26 新增 6 个）

| 支持库 | 原子能力 | 职责边界 | 来源 |
|---|---|---|---|
| 文件系统 | 读取/写入/复制/移动/删除/列出 等 | 文件操作，不解析内容 | 既有 |
| 数据集合 | 列表/字典/集合/排序/查找/过滤/映射 | 集合操作 | 既有 |
| 文本处理 | 分割/替换/清洗/统计 等 | 文本加工 | 既有 |
| 时间日期 | 获取/格式化/解析/计算 等 | 时间处理 | 既有 |
| 数据交换 | JSON/序列化 等 | 数据格式交换 | 既有 |
| 网络请求 | 发送请求/响应解析 | 网络 I/O | 既有 |
| 文档生成/转换/文字文档/表格文档/演示文稿/PDF文档 | 各文档格式生成与转换 | 文档格式 | 既有 |
| 网页解析 | 页面解析/提取 | 网页内容解析 | 既有 |

### 1.2 模型连接器（14 个能力，模型调用唯一入口）

| 能力 | 职责 |
|---|---|
| 连接LLM / 连接向量模型 / 连接重排模型 | 连接器，返回六位句柄（本地/云端统一配置） |
| 启动本地模型 | 拉起本地模型进程（llama-server），句柄超时/释放自动终止 |
| 注册本地进程 | 真实子进程绑定句柄（适配层调用） |
| 生成对话 / 生成嵌入 / 执行重排 | 持句柄调用模型 |
| 续租句柄 / 释放句柄 / 查询句柄状态 | 句柄生命周期（默认 300s 自动释放，可续租，释放幂等） |
| 资源快照 | 系统内存 + 活跃连接（内存守卫，超 80% 阈值拒绝新连接） |
| 加载环境配置 / 查询环境配置 | env 统一参数（支持库不独立传参） |

### 1.3 支持库纪律（硬性）
- 能力边界固定最小化，不实现任何业务逻辑
- 不调模型（嵌入缓存/重排服务尤其注意）、不调其他支持库
- 契约冻结、传参固定；内核可单点小版本升级（1.0.0→1.0.1→1.1.0）
- 传参统一从 env 读取（`加载环境配置`），显式传参可覆盖

## 二、模块：功能唯一性封装（接收完整传参，组合支持库，无业务逻辑）

| 模块 | 组合哪些支持库 | 说明 |
|---|---|---|
| 文件管理 | 文件系统 + 资源管理 | 文件读写/复制/移动/删除/列出/摘要 |
| 文档读取 / 文档解析 / 文档生成 | 文档格式支持库 | 文档格式处理封装 |
| OCR | 图像 + 文字识别提供者 | 图片文字识别 |
| 图像处理 | 图像提供者 | 图片处理 |
| 媒体处理 / 媒体转写 | FFmpeg/ASR 提供者 | 音视频处理/转写 |
| 网页分析 | 网络请求 + 网页解析 | 网页分析 |
| 简单窗口 | 窗口描述 + 状态描述 | 桌面窗口控制 |
| 自修复工具 | 文件系统 + 数据集合 | 自修复流程封装 |
| **知识检索** | 嵌入缓存 + 重排服务 + 文件系统 | 知识检索流程（查缓存→加载→重排） |

### 模块纪律（硬性）
- 按功能保持唯一（word 读取就一个，不搞变体）
- 只接收传参，一次性传完（模型配置/路径/条件一次给）；模块内核自动实现
- 经 `能力调用器.调用能力()` 组合支持库，不直接 import 支持库实现
- 无完整业务逻辑；失败不伪绿（子能力失败透传）
- 内核可单独更新，功能只保一个

## 三、业务层（V3 等）：业务逻辑

- 用支持库 → 传参（用 LLM → 传模型配置）
- 用模块 → 一次性传参（查询/知识库路径/模型/url 全给）
- 业务逻辑（判断用哪个模型、格式化输出）只在业务层
- 归属：`华世王镞_v3/后端服务/` 等业务项目

## 四、调用链与纪律

```
V3 业务层（组装传参）
  ↓ 一次性传参
模块（功能唯一性封装，经能力调用器）
  ↓
支持库（原子能力，无业务逻辑）
  ↓
适配层/第三方
```

1. 业务层不直接调支持库实现（经模块/调用器）
2. 模块不直接 import 支持库实现（经能力调用器）
3. 支持库不调业务层、不调其他支持库
4. 支持库之间不独立传参（统一 env 定义）
5. 每个能力id 唯一归属（检查：`能力定义.json` 全量无重复）
