## 三、依赖锁定与装配校验（新增）

### 依赖锁定文件校验（项目适配层/依赖锁定/锁定校验.py）

六项校验，**任一漂移必须失败，不允许自动忽略**：
1. 包是否存在（锁定包 vs 当前发现）
2. 版本是否一致
3. 能力版本是否一致
4. 完整性摘要是否一致（内容寻址 sha256 前16位，可重复）
5. 依赖顺序是否正确（锁定顺序 vs 解析拓扑顺序）
6. 锁定文件结构是否合法（包列表存在且为列表）

### 装配前检查（加载器/生命周期管理/管理器.py）

- 重复包 id 必须失败（发现器）
- 重复能力 id 必须失败（发现器）
- 多提供者冲突必须失败（提供者选择器）
- 缺失依赖必须失败（依赖解析器）
- 循环依赖必须失败（依赖解析器）
- 版本不满足必须失败（依赖解析器）
- 类型错误必须失败（类型不在 支持库/模块 → 失败）

### 装配后检查

- 所有声明能力都能从注册表获得（缺失即回滚）
- 所有模块依赖均已解析（装配前依赖解析保证）
- 所有公开入口均可调用（注册表.获取 校验）
- 装配结果可重复生成（两次装配能力数/顺序一致）
- 装配失败不留半成品状态（回滚到上一稳定状态）

## 四、生命周期管理（升级为 9 态）

```text
未发现 → 已发现 → 已校验 → 已锁定 → 已装配 → 可运行 → 已停止 → 已卸载
```

（公共契约/生命周期/生命周期.py 重写）

- **非法状态跳转必须失败**：目标必须恰好前进一步、幂等或回滚一步，否则记录失败（错误码"状态跳转非法"），状态不变
- **重复装配幂等**：已装配→已装配 允许
- **重复停止幂等**：已停止→已停止 允许
- **装配失败必须可回滚**：回滚记录（操作名称"回滚"，成功=False），状态回到上一稳定状态
- **记录字段**：包id、版本、当前状态、操作名称、成功（bool）、错误码、错误说明
- **不允许吞掉异常**：未知状态抛 ValueError；安装异常转为 装配失败 错误并回滚

装配系统流转链：已发现（扫描）→ 已校验（依赖校验）→ 已锁定（依赖锁定）→ 已装配（入口加载+注册）→ 可运行（装配完成）。


每个适配器提供：检查是否可用、获取版本、建立连接或启动资源、执行最小操作、关闭连接或释放资源、返回统一结果、记录资源状态（未连接→已连接→已关闭）。

**当前只实现契约、模拟提供者和验证场景，不安装第三方库、不连接真实服务**；真实数据库/服务器/DLL 连接逻辑归未来提供者适配层，不写入核心支持库。

模拟错误场景：坏查询→协议错误、/超时→超时、/错误→内部错误、坏命令→参数错误、缺函数→版本不兼容、驱动不可用→外部未安装（可重试）。
