## 单仓架构文档

每个开源项目根目录的 `ARCHITECTURE.md` 是该项目自己的架构定位文件，统一格式为：

1. 上方文本式架构流程图；
2. 下方模块职责、核心数据流、关键类/函数、API/CLI、技术栈和代码路径。

## 源码规则

- 源码参考库默认只读，不安装依赖、不跑服务、不生成模型权重或运行数据库。
- 分析结论写入对应 `ARCHITECTURE.md` 或 `00_catalog/历史分析/`，不修改原项目源码。
- 同一远程仓库只保留一个本地副本。
