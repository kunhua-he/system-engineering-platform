# 源码参考研究归档

本目录收录 `/Users/hekunhua/Documents/Agent/github 源码参考/` 的研究成果，不复制原始源码仓库。

## 归档边界

- 每个开源项目只归档一份项目根 `ARCHITECTURE.md`。
- `细探-*.md`、探索稿和临时回执属于施工材料；已人工吸收后不再归档。
- 原始源码、依赖、模型、数据库、构建产物和凭据不进入本目录。
- 单项目事实以对应项目的 `ARCHITECTURE.md` 为准；跨项目裁决仍以源码参考库主文档和本系统工程平台权威文档为准。

## 目录

- `项目/`：按源码参考库原分类保存项目架构文档。
- `参考库主文档/`：源码参考库入口、主开发文档和目录索引的只读归档。

本归档是系统工程平台的研究输入，不改变系统工程平台的支持库、模块库和运行核心职责边界。
