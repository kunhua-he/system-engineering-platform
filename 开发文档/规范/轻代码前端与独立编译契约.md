# 轻代码前端与独立编译契约

## 目录标准

```text
项目根/
├── 项目声明.json                 # 项目身份、版本、前端/模块入口
├── 前端/
│   ├── 页面/*.json               # 页面、组件排序、事件和能力绑定
│   ├── 组件/*.json               # 可复用组件模板（可选）
│   └── 主题/*.json               # 颜色、尺寸、布局主题（可选）
├── 模块/流程/*.json               # 工作流步骤和能力参数映射（可选）
├── 资源/                          # 图片、字体、静态文件（可选）
└── 运行入口/                      # 项目自己的启动逻辑（可选）
```

## 页面 JSON

页面必须包含 `页面id`、`标题`、`路由`、`组件列表`。组件必须包含 `组件id`、`类型`、`属性`、`事件`。`组件列表` 数组顺序就是渲染顺序；事件中的能力调用只能写 `属性.能力id` 和参数模板，不允许写 Python、网关地址或实现路径。

## 编译规则

```text
页面/流程 JSON
  -> 收集能力id、模块id
  -> 能力反向解析所属包
  -> 模块依赖闭包（能力依赖/包依赖）
  -> 复制固定运行核心 + 实际使用支持库 + 实际使用模块
  -> 生成编译清单.json + 独立运行入口
```

编译入口（必须指定本次变更小单元）：

```bash
python3.14 开发工具/项目编译/项目编译器.py <项目目录> --输出 <独立输出目录> --文件 前端/页面/首页.json
# 也可使用：--能力 <能力id> 或 --组件 <组件id>
```

输出目录是独立项目制品，不包含开发网关、开发工具、未使用支持库或未使用模块。编译发现空引用、未知能力、未知模块或不可解析依赖时必须阻断。

## 交付目录

```text
独立项目制品/
├── 前端/编译页面/index.html       # 跨 macOS/Windows 的唯一页面制品
├── 运行入口/启动.py               # 通用启动器
├── 运行入口/启动网页.command      # macOS 双击入口
├── 运行入口/启动网页.bat          # Windows 双击入口
├── 编译清单.json
├── 公共契约/ 后端核心/ 运行核心/ 前端核心/
├── 支持库/                         # 只包含实际使用的支持库与运行时内部适配器
└── 模块库/                         # 只包含实际使用的模块
```

默认不生成 exe。exe 是平台相关的二次封装，可在 Windows 上用 PyInstaller 包装 `运行入口/启动.py`；HTML、JSON 和独立运行时才是跨平台权威制品。
