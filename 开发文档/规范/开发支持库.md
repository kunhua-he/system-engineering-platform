**步骤 0 的取证**（AGENTS.md 已按此固化，提交 `203921fc`）：

```bash
TOKEN="$(plutil -extract EnvironmentVariables.系统库网关凭证 raw -o - \
         ~/Library/LaunchAgents/com.huashi.gateway-40007.plist)"
curl -sS http://127.0.0.1:40007/健康 -H "Authorization: Bearer $TOKEN"
⇒ {"状态":"健康","能力数":720}       # 能力数 > 0 ⇒ 本机可跑
```
