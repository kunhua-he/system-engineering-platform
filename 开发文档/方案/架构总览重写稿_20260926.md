## 二、一次调用的五道关

```text
调用方
  │ ① 工具面：回包裁剪（超限转全量回执指针，取回须 返回字符数=0）
  ▼
薄壳（开发宿主）
  │ ② 网关转发：能力id 必须带包前缀（短名 ⇒ 能力未注册）；未知参数在网关边界忽略
  ▼
网关
  │ ③ 参数校验：按契约行序收位置数组；类型规格/字段名册判型；进程内未知参数 ⇒ 参数不合法
  │ ④ 执行：实现跑在制品里；长任务走异步腿（同参重发即续查）
  ▼
结果信封 ⑤：成功无值＝1 ｜ 成功有值＝正文 ｜ 失败＝-1（附 按契约行序的 参数表/数组样例/照抄式样）
```

写类能力在 ④ 之前多一道 **写入授权**（见 §三）。

## 三、写入与租约（一条链，不许旁路）

```text
开工准备 ──► 开工即占（修改路径全量申报 ⇒ 原子认领；任一被占即整体失败）
                │ 认领即解锁「目标 ＋ 待建父链」（内核只读锁开窗）
                ▼
             改 ──► 唯一写腿（文件操作 / 文本补丁；穿锁＝解锁→写→回锁，新建文件继承父目录锁）
                ▼
             提交 ──► git 钩子：commit-msg 验开工ID、pre-commit 验锁；只用精确路径（禁 add -A）
                │      提交之后上锁回去（回锁）
                ▼
          收工释放（租约终结；同路径可立即再申请）

回收腿：平台控制面/能力目录/实现/文件租约维护.py::回收过期文件租约
        （三半并集：到点 ｜ 心跳停摆 ｜ 所有者进程消失）
★重构落点：租约持有者身份改挂「开工ID＋会话」，不挂网关 PID
           —— 否则上线链的重启会作废自己刚认领的租约（本批实测两次）
```

## 四、编译与上线（整个项目只有 2 个公开编译测试能力）

```text

   │ 静态编译 → 组编译口命令（预算＝调用方超时−60，**恒小于调用方超时**）
   ▼
开发编译口/编译口.py（全轮预算；耗尽 ⇒ 剩余项不起子进程、记未核验，不占通过位）
   步骤1 影响面 → 步骤2 生成物全自动 → 步骤3b 门禁并行 → 步骤4 复跑确认 → 步骤5 定向测试
   ▼
五态结论：干净通过 ｜ 债务冻结 ｜ 只报告 ｜ 未核验 ｜ 失败

动态编译 ＝ 静态的全部内容 ＋ 真跑定向测试（唯一差别）

上线 ＝ 构建平台客户端制品(安装=真) → 重启网关
   · 上线=真 在编译红时静默跳过构建 ⇒ 别靠它上线
   · 生效面：薄壳＝源码树（当场生效）；能力＝制品（必须重建 ＋ 重启）
```

## 七、易语言对照：抄 7 ／ 不抄 3

| # | 抄什么 | 我方落点 |
|---|---|---|
| 1 | 宏表单一声明源 | §五 |
| 2 | 索引编进符号名 ⇒ 链接期防错位 | 支持库安装.py 的 getattr 猜入口 |
| 3 | 前缀内嵌 ＋ 状态位 ＋ 尾插字段 | 能力定义.json 顶层 版本（现递增牵动四处） |
| 4 | 返回槽与参数分离 ＋ 显式有值位 | 结果类型.py 信封（「成功但无值」三态） |
| 5 | DETACH / DELETE 分离 ＋ 幂等解绑 | 句柄体系.py（禁悬挂 id） |
| 6 | 号段隔离 ＋ 按宿主分层 | §六 |
| 7 | 66/72 份 lib2.h 同哈希 ⇒ 单一共享底座 | 反证「不保留旧腿」正确，坚持 |

| # | 别抄 | 为什么 |
|---|---|---|
| 1 | 同一 bit 双语义（数组/传址共用 0x20000000） | ABI 级歧义 |
| 2 | 结构体无 cbSize，靠一个状态位扩展 | 无法跳过未知尾字段 |
| 3 | 整包复制底座（71 份副本／555 死注释／338 TODO） | 与「唯一实现」正面冲突 |

## 八、门禁覆盖：哪面有门禁、哪面是盲区

| 面 | 编译口门禁 | 缺口 |
|---|---|---|
| 装配/生命周期 | **零门禁** | 装配锁跨进程、幂等漂移无判据 |
| 失败 | 部分 | 静默吞错无判据 |
| 传参 | 有 | 类型校验四处并存、放行三处 |
| 返回 | 部分 | 信封多套并存无判据 |
| 判据覆盖 | 本面即门禁 | 依赖防火墙不在门禁清单 |
| 并发资源 | **零门禁** | 上限多处各写、无界容器无判据 |
| 制品上线 | 只报告 | 可复现校验自指 |

盲区（有实现、两处门禁都不调）：`依赖防火墙.审计依赖`、`运行状态监督.审计依赖`、包体检、门面核验、跨平台部署验证、模块合规、错误码文案派生、**单腿铁律（至今无判据）**。
