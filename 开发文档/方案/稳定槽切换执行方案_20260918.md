## 八、★ 实测补充（2026-09-18 18:1x 读源码后**必须修正前述步骤**）

### 8.1 两个关键事实

**事实一：`启动运行核心网关.py` 无参数。**
现场读全文确认：端口 **硬编码 40007**、地址硬编码 `127.0.0.1`，
**没有 `--端口` / `--缓存根目录` 参数**，靠 `sys.path.insert(0, ".")` + plist 的
`WorkingDirectory` 定位。⇒ **步骤 1「在 48001 起一份旁路」不成立**，
必须先解决「同源码同端口不能双开」的问题，或改走**临时改写端口**的旁路（见 8.4）。

**事实二：★ 缓存根会随制品模式改变（数据会不会"消失"的关键）。**
`公共契约/运行时/运行缓存.py:65 解析运行数据根` 规则：
```
显式覆盖（环境变量 系统底座_工程缓存根）
  → 制品稳定根（系统根.name == "平台客户端" 时：~/Library/Caches/系统工程平台/运行缓存）
  → 源码工程缓存（<工程根>/工程缓存）
```
切到制品后 `系统根.name == "平台客户端"` 成立 → **缓存根自动变成平台稳定缓存根**，
**不再是源码树的 `工程缓存`**。

### 8.2 现场数据现状（★ 两处都在用，且内容不同）

| | 源码树 `工程缓存/运行数据/` | 平台稳定根 `~/Library/Caches/系统工程平台/运行缓存/运行数据/` |

### 8.4 修正后的切换步骤（**待口径裁决后执行**）

**方案甲（推荐）：显式钉住缓存根为正式位置**
