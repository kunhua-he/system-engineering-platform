## 二、哲学定性（逐条）

**先纠一处引证错误（本轮实测推翻）**：此前我把「未知参数一律忽略」记为「哲学第 5 条 2 项刻意设计」。**不成立** —— 5.2 原文讲的是「**版本**不对齐默认不失败，只有强制参数才失败」，与未知参数无关。「未知参数忽略」是**实现层对 5.2 的推导**（`运行核心/统一网关/协议/类型规格.py:135` 注释引用了 5.2 条号）。

| 卡点 | 哲学定性 | 结论 |
|---|---|---|
| 1 丢键不截断 | 工具定义自称「**不会静默截断**」（`工具清单.py:140`），实际行为是丢整键 —— **比截断更隐蔽**；且 11.2⑤ 要求「只取需要的字段/页/行，返回指针而不是全文」 | **真缺陷**：违反自己声明的口径。与既有《返回体量分档统一方案》同族，应并入其口径 |
| 2 大输出无切片 | 11.2⑤ 同一锚点；《返回体量分档方案》已立**参数侧**口径（`细节级别` 三档），**输出侧未覆盖** | **真缺陷**：缺的是两段式在输出侧的对应物 |
| 3 手工包 shell | 无哲学条款；`执行命令` 按「可执行文件+参数」直启是**有意的注入面收敛** | **不是缺陷**（有意设计）。但「每次手工包 + 转义」的真实成本并入卡点 4 |
| 4 双层转义 | 12.3⑥「把条款结论直接写成一句话操作指令」的精神：调用方不该为传一个值付转义成本 | **真缺陷（体验级）** |
| 5 写类乐观锁 | 12.1② 要求并发靠**租约硬锁**；9.4④ 要求有副作用须声明**幂等键/重放语义/状态版本**；**13.1 明定「靠开发者记得单独跑」不算强制点** —— 而 `多会话并行开发规约.md:261-265` 自己写着「零件在、通道通、靠自觉」「不许对外声称写盘已强制乐观锁」 | **真缺陷，且哲学已明确要求**：现状是**纸面规则**（13.1 口径） |
| 6 诊断不自带 | **14.3**：「必须回到那个工具，把调用方需要手填的信息改成工具自己从既有事实推导；推不出来就当场报错并给出该填什么，**不许沉默、不许猜默认值**」；12.3⑦ 禁止把主会话的探索转包给执行者 | **真缺陷，是 14.3 的直接要求** |
| — 未知参数静默忽略 | 1.2③「静默长期兼容：**禁止**」+ 14.3 + 决策记录 `0018`（「比例被静默忽略 ⇒ **话在说谎**」） | **真缺陷方向**，且**与权威文档正面冲突**（见第六节待裁定） |

**工具描述体量的哲学定性（本方案最重要的一条）**：

- `项目说明.md:77`：「**Agent 只记两个动作**：`搜索能力` → `调用能力`；MCP 薄壳只暴露 3 个工具（**防全量 schema 污染 Agent 上下文**）」
- 12.4①：「**同一条规则不得在多处各自表述**」
- 12.3⑨：注入形态用「**句柄 + 一句取用提示**」，**不把正文复制进提示词**
- 12.3⑥：任务信**不得写条款号**（实测 6 次探索、0 次动手）
- `规范/任务类型规范.json:6`：「只返回命中的那几类；每条强规范 **≤ 40 字**，细节一律走**原文位置**按需跳转」

⇒ 结论：**`capability_call` 描述里那 9 段 ★ 规则，是「同一规则的第二个表述处」，违 12.4①**；而且它们**已经由 `开工准备` 的 `通用纪律.工具姿势` 无条件送达**（`任务类型规范.json` 实测 3 处命中）。描述里应只留「**一句话 + 3 步内可达的操作指令**」，细节走指针。

### 3.5 写类并发（**生态无先例，我们已领先**）

| 项 | 内容 |
|---|---|
| 结论 | 规范 schema 里 **0 个** ETag / If-Match / version 字段；参考服务器（filesystem/git/memory/fetch）**无任何版本守卫** |
| 我们 vs 生态 | `servers/src/filesystem/lib.ts:265-345` 的精确替换**比我们弱**：JS `String.replace(字符串,…)` **只替换第一处、从不检查唯一性**，多处命中时静默改第一处。我们的 `应用精确替换` 不唯一即拒绝并回带候选行号 —— **严格性高于生态最好实践** |
| 值得抄 ① | **原子写**（`:333-341`）：`tempfile` 写 + `os.rename` 原子替换，防「校验与写入之间被换符号链接」；写后**恢复权限位**（`:349-355`，rename 换 inode 会丢权限，且 chmod 失败不得让已成功的写失败） |

| 标准库可复刻 | **能**：`hmac` + `hashlib` + `base64` + `json` + `tempfile` + `os.replace` 全是标准库 |
