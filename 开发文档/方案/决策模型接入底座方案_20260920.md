## 三、接入链路（复用既有，不新建）

```text
调用方（业务层 / V3 / Agent）
  ↓ 大语言模型支持库.模型连接器.连接决策模型(本地路径=…, 模型=…)
  ↓   ├─ 供应链校验：受管内未登记即拒绝（存在性→字节数→sha256）
  ↓   └─ _构建本地启动命令 识别 HuggingFace 格式（含 config.json 的权重目录）
  ↓ 拉起 支持库/适配层/模型服务.py --model-type 决策 --model-path … --port <动态>
  ↓ 独立进程 + 动态端口 + 句柄 + 租约 + 空闲回收 + 本地模型看守
  ↓ 大语言模型支持库.模型连接器.执行决策(句柄, 文本, 问题列表)
  ↓ HTTP POST /v1/decision → 返回 结果型{选项/概率/置信度}
```

**为什么 Laya 正好能接**：它是标准 HuggingFace 目录结构（`config.json` + `model.safetensors` + `encoder/` + `tokenizer/`），底座既有链路已经能识别并拉起 HF 格式（`_识别模型源` 返回 `HuggingFace`），本次只是给「决策」这一类型补分派与端点。

## 四、对外契约（待定，需华哥裁决）

### 4.1 拟新增能力（2 个）

| 能力id | 参数 | 返回 |
|---|---|---|
| `大语言模型支持库.模型连接器.连接决策模型` | 模型、提供者、部署形态、本地路径、启动器、模型大小字节、url、api_key、超时秒 | `结果型{句柄: 整数型}` |
| `大语言模型支持库.模型连接器.执行决策` | 句柄、文本、问题 | `结果型{答案: 列表型}` |

### 4.2 「问题」的形状

沿用 Laya 原生三型（`choice` / `score` / `noul`），由调用方传入问题定义：

```json
{
  "环节": {
    "type": "choice",
    "instructions": "这段直播话术属于哪个环节？",
    "criteria": {"开场留人": "…", "讲产品成分": "…", "讲用法": "…"}
  }
}
```

返回：`{选项: "开场留人", 概率: {...}, 置信度: 0.76}`

**置信度是这套模型的核心价值** —— 它经严格真分数规则训练，置信度统计上可信（实测：答对时 0.76–0.98，答错时 0.17–0.53），上层可据此决定「是否需要人工」。

## 六、已知风险与边界
