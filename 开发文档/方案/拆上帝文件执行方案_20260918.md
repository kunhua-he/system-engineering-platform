## 七、回退

- **单文件级**：`git revert <该文件那次提交>`（一次只拆一个文件 ⇒ 回退粒度天然是单文件）。
- **整批级**：本方案**不产生跨文件依赖**（每次都是"搬代码 + 原文件 re-export"），因此任意一次可独立回退。
- 拆到一半发现门面保不住 ⇒ **立刻停手、`git checkout -- <文件>`、把原因记进 `未完成事项.md`**，不硬推。

## 八、★ 被否决的做法（别再试）

| 被否决 | 为什么 |
|---|---|
| 用 `from X import *` 维持门面 | 引入隐式符号，门面核验会看到"新增符号"，且 IDE/静态检查全失效 |
| 拆的同时顺手改逻辑 | 拆与改分离 —— 混在一起后反向验证无法区分"拆坏了"还是"改坏了" |
| 并行拆多个文件 | 8 个文件互相 import，并行拆的冲突不可控；且一提交一文件，回退粒度会糊掉 |
| 先 import 模块再比对门面 | 触发装配（几十秒 + 副作用），拆到一半可能 import 不进去；用 AST |
| 只靠"跑测试全绿"当门面证明 | 测试覆盖不到的方法签名照样可能被改；必须机械比对签名 |
| 用报告里的行数当基线 | 报告是 7306，**HEAD 实测 7930**；报告数字只作对照 |
