### 1.4 「测的是哪个包」——按 import 目标推断（五级判据，实测）

用 `ast` 解析 201 个 `测试_*.py` 的**全部 import**（`ast.walk`，覆盖函数体内延迟导入），只取仓库 14 个顶层包名，五级判据**优先级从高到低**：

| 优先级 | 判据 | 说明 | 实测命中 |
|---|---|---|---|
| ① | **末段同名** | `测试_XXX.py` 去前缀后的 `XXX` == 某 import 模块的**末段**（`测试_数据类.py` → `公共契约.基础类型.数据类`） | **54** |
| ② | **路径段同名** | `XXX` 出现在某 import 模块路径的**中间段**（`测试_加载器.py` → `运行核心.加载器.*`）；排除通用包后再取 | **9** |
| ③ | **非通用具体包** | 按「前两段」统计后唯一/同域/沿用当前域（`测试_镜像签名.py` → `支持库.适配层.密码签名提供者`） | **117** |
| ④ | **沿用当前域目录** | 只剩通用信封/契约包时的**确定性回退**：文件原在哪个域目录，就留哪个域 | **12** |
| ⑤ | **人工裁决** | 无生产 import / 非测试资产 / 包占位 / 以上全并列 | **11** |
| — | 合计 | ①54 + ②9 + ③117 + ④12 + ⑤11 | **203**（另有 1 个删除项） |
| — | 其中标 `【需人工复核】` | ③ 具体包并列且当前目录无法定夺 | **6（已在映射表逐行标出）** |

**「通用信封/契约包」定义**（几乎人人 import、不具区分度，不参与判据 ③ 定域）：
```
公共契约.基础类型   公共契约.能力契约   公共契约.版本规则   公共契约.运行时
```

> 判据 ④ 的口径是「**信封是契约、不是被测对象**」；这与 2.2 域定义里「不收只是顺带 import 公共契约做类型断言的」完全一致。

### 2.2 域定义与边界（消解歧义 —— 这是全案的判据核心）

| 域 | 收什么 | 不收什么 |
|---|---|---|
| `公共契约/` | 直接 import `公共契约.*` 的测试；**跨域契约门禁**（句柄/数值/包声明等无单一生产 import 的门禁） | 只是**顺带** import 公共契约做类型断言的（按被测对象定域） |
| `支持库/` | 被测对象是 `支持库.*` 任一包（`适配层/` 提供者、`后端/` 原子能力、`前端/` 宿主） | 模块库组合流程 |
| `模块库/` | 被测对象是 `模块库.*` 模块 | 模块内部委托的支持库原子能力（属支持库域） |
| `运行核心/` | `运行核心.*` ＋ **`后端核心.*`** | 加载器测试（**已并入本域**，见 2.3） |
| `平台控制面/` | `平台控制面.*` ＋ **`前端核心.*`** | 开发工具侧的工具测试 |
| `开发工具/` | `开发工具.*` ＋ **`客户端.*`** | 用开发工具**夹具**去测支持库/模块库的（按被测对象定域） |
| `启动监督器/` | `启动监督器.*`（含其支持库依赖） | — |
| `项目适配/` | `项目适配层.*` | — |
| `示例项目/` | `示例项目.*` | — |

**并入理由（实测，不是随意）**：
- `后端核心/` **只有 `后端核心.py` 一个文件**（`ls 后端核心/` = `后端核心.py` + `__pycache__`），为 4 个测试新开一个域不划算 → 并入 `运行核心/`（它就是运行核心里层）。
- `前端核心/` **只有 3 个文件**（`前端核心.py`/`浏览器交互.py`/`渲染提供者.py`），仅 1 个测试 → 并入 `平台控制面/`。
- `客户端/` **只有 `构建平台客户端.py`**，2 个测试 → 并入 `开发工具/`。

**「域 = 被测对象所在顶层包」是唯一判据**；一个测试文件只进一个域，即使它 import 了多个域。

## 四、冲突预警

### 4.1 同名测试文件：**实测为 0**（本方案最大的冲突风险不存在）

| 检查 | 实测结果 | 取证 |
|---|---|---|
| 197 个 `测试_*.py` 的 **basename 跨目录重复** | **无**（全部唯一） | 遍历 `测试中心/**/测试_*.py` 统计 `Counter(basename)`，重复项 = 空 |

### 4.3 语义冲突：同一生产模块被多域测试覆盖（**不构成冲突，但要写进口径**）

归口按**被测对象**定域，不按 import 关系，因此「一个测试同时覆盖多域」属正常。实测 Top 5：

| 生产模块 | 被几个测试覆盖 | 归口后落在 |
|---|---|---|
| `公共契约.能力契约.契约` | **39** | 各域都有（多数在 公共契约/） |

| `后端核心.后端核心` | **24** | 运行核心/、模块库/、支持库/ |

**口径**：**禁止**因为「它 import 了 X」就把同一文件复制到多个域（1.2 不保留旧腿）。一个文件只进**被测对象所在域**。

### 4.4 归口后的防复发判据（建议同批接进发布门禁，对齐 12.5 / 13.1）

| # | 判据 | 检查内容 | 为什么必要 |
