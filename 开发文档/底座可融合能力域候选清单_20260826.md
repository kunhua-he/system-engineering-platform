# 底座可融合能力域候选清单（调研 · 2026-08-26）

> 底座当前 328 能力覆盖了 Agent 主流场景，但全球头部实现中仍有
> 底座还没覆盖的领域。以下按「融合价值+冲突度」排序。

---

## 一、高价值候选（建议优先调研）

### 1. 浏览器自动化
- **顶级项目**：browser-use（★12k）、Playwright MCP
- **底座现状**：有 browser_exec 工具，但底座无浏览器自动化能力
- **融合价值**：高（Agent 操作网页是核心场景）
- **融合方式**：新建「浏览器操作支持库」或「模块库」，封装 Playwright 原子能力
- **冲突度**：不冲突，全新域

### 2. 代码沙箱执行
- **顶级项目**：E2B（★10k）、SmolVM
- **底座现状**：有进程管理（执行命令/启动进程），但无隔离沙箱、无代码解释器
- **融合价值**：高（安全执行用户代码是 Agent 核心需求）
- **融合方式**：新建「代码执行支持库」（沙箱模式）+ 模块库（解释器模式）
- **冲突度**：补充进程管理，不冲突

### 3. 记忆系统（长期记忆）
- **顶级项目**：Mem0（★5k）、MemGPT
- **底座现状**：有会话存储（短期），无长期记忆层
- **融合价值**：中高（Agent 跨会话记忆）
- **融合方式**：可接入 Mem0 API 或自建「记忆支持库」
- **冲突度**：补充会话存储，不冲突

---

## 二、中等价值候选

### 4. 任务调度/定时器
- **顶级项目**：cron/LaunchAgent（已有）、Celery
- **底座现状**：有 cronjob 工具，但底座无定时能力
- **融合价值**：中（常驻任务需要）
- **融合方式**：补「调度支持库」（cron表达式/一次/周期）
- **冲突度**：不冲突

### 5. 审批流程引擎
- **顶级项目**：HILA、CHAP
- **底座现状**：有权限审批（单次动作校验），无多步审批流程
- **融合价值**：中（企业级 Agent 需要）
- **融合方式**：升级权限审批 → 支持多步审批流程
- **冲突度**：低（升级现有，不新建）

### 6. 混合检索（BM25+向量）
- **顶级项目**：RAGFlow、FastGPT
- **底座现状**：有知识检索（模块库）+ 嵌入缓存，无混合检索
- **融合价值**：中（检索质量提升）
- **融合方式**：升级知识检索模块，加 BM25 混合
- **冲突度**：低（升级现有模块）

---

## 三、低价值/冲突候选（跳过）

### 7. 绘图/图表生成
- 底座已通过模块库/文档生成间接支持，新建支持库价值低
### 8. WebSocket 实时通信
- 业务场景少，V3 层已有 HTTP 网关
### 9. 数据库迁移
- sqlite-utils 风格，底座暂不需要

---

## 四、建议优先级

| 优先级 | 域 | 工作量 | 融合类型 |
|---|---|---|---|
| P0 | 浏览器自动化 | 中 | 新建支持库 |
| P1 | 代码沙箱 | 中 | 新建支持库 |
| P2 | 记忆系统 | 小 | 新建支持库 |
| P3 | 任务调度 | 小 | 新建支持库 |
| P4 | 审批流程 | 小 | 升级现有 |
| P4 | 混合检索 | 小 | 升级现有 |
