# 一、总账怎么读（状态四态，永不共用一个词）

```
✅ 机器强制
     有判据模块 + 已在发布门禁（不可绕过）里真实调用
     判据：把违规改进去 → 发布门禁必须报红

🟡 半强制
     有判据模块，但门禁未接线 / 只报告不阻断 / 只在单元测试里
     判据：能指出"缺哪一步接线"

🔵 人工强制
     流程纪律，无机器判据（如"发现即记录""审计分三轮"）
     不判为缺陷，但**必须写明"谁在强制"** —— 否则等同纸面

⚠️ 纸面规则
     既无机器判据、也无明确人工强制点
     ⇒ **这是本总账要消灭的东西**（对应拟新增哲学第 13 条 P-3）
```

**读法**：只看"⚠️"那段就能知道还差什么。其余是留档。
