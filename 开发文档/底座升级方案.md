### 1.1 目标

把当前系统工程平台收敛为易语言式的通用底座：

    确认需求
      → 能力搜索与复用判断
      → 选择基础类型 / 核心支持库原子命令 / 外部 Provider / 模块流程
      → 冻结参数、返回、错误码、状态机、资源预算和依赖
      → 编译唯一契约
      → 包级注册入口装配
      → 运行核心统一调用、租约、超时、取消、回收和证据
      → 模块组合流程
      → HTTP 网关返回统一结果
      → 反向破坏、冷启动、真实失败和零残留验证
      → 发布门禁

最终必须满足：一个能力 id 只有一个 owner、一个契约来源、一个注册路径；一个外部服务/驱动/协议只归属一个支持库；支持库只做原子动作，模块只做领域流程，运行核心只做治理；所有参数和返回使用公共易语言式基础类型；LLM 是可选能力；缺契约、缺注册、缺依赖锁、缺真实返回或缺释放证据的能力不能发布。

### 1.2 本次不做

本计划阶段不新增业务功能，不复制开源项目，不把所有 Provider 一次接入，不把未实现的 MySQL/远程 LLM 写成可用能力，不以“测试通过”替代真实外部验证。

### 3.1 基础类型

正式名称只允许：逻辑型、字节型、整数型、长整数型、单精度数型、双精度数型、文本型、字节集型、列表型、字典型、日期时间型、资源引用型、句柄型、结果型、空值型。

历史契约中的文本、整数、布尔、浮点数、数字、字典、列表只能由迁移解析器识别，不能继续生成新契约。类型转换属于核心支持库原子能力：

    '123'（文本型） → 类型转换.文本转整数 → 123（整数型）

'12.3' 转整数必须失败，禁止静默截断或四舍五入。

### 3.2 核心支持库

    支持库/
    └── 核心/
        ├── 类型转换/
        ├── 类型校验/
        ├── 数据编码/
        ├── 错误处理/
        └── 资源引用/

支持库/核心是能力域；每个子目录是独立包、独立能力 id、独立契约和独立验证。子支持库只做原子动作，不能编排业务流程。没有包声明.json 的占位目录不计入正式包。

### 3.3 LLM 判定

    节点输入
      → 能否由确定性规则完成？
          ├─ 能：不声明 LLM
          └─ 不能：是否需要生成/理解/分类/抽取/Embedding/重排？
                    ├─ 否：寻找专用支持库
                    └─ 是：声明最小抽象能力，由运行核心选择 Provider

文件读写、执行 SQL、哈希、时间计算、格式转换、状态流转、资源释放不得默认声明 LLM。Ollama、Chat、Responses、Anthropic、本地模型是独立 Provider；模块只声明对话.*、Embedding.*、重排.*，不声明 SDK 包。

### P0.5：契约测试编译器与原则检查

这是开发者每次完成一个支持库、子支持库或模块后立即运行的快速入口；IDE 的 F5 可以调用它，但它本身不是 IDE 专属按钮，也不是简单的 py_compile 或全量发布门禁。

**唯一入口（当前实现）**

```text
开发工具/快速编译/运行快速编译.py
```

```bash
# 当前包：契约、类型、入口、注册、依赖和最小装配试跑
python3.14 开发工具/快速编译/运行快速编译.py --包目录 支持库/核心/类型转换

# 当前文件所属包：由路径反推包目录
python3.14 开发工具/快速编译/运行快速编译.py --文件 支持库/核心/类型转换/实现/类型转换.py

# 工作区原则检查：不启动真实外部 Provider
python3.14 开发工具/快速编译/运行快速编译.py --范围 工作区 --不执行外部

# 当前包契约样例和确定性能力试跑
python3.14 开发工具/快速编译/运行快速编译.py --包目录 模块库/文档读取 --执行样例
```

**快速编译的固定顺序**

```text
读取目标包
  → 目录结构检查
  → JSON/能力定义严格解析
  → 易语言式类型检查
  → 能力定义与派生契约摘要检查
  → 参数/返回/错误码/状态机/资源预算闭合检查
  → 包级入口和注册能力 AST 检查
  → 依赖图、依赖锁和 Provider 选择检查
  → 临时注册表装配试跑
  → 确定性能力最小调用
  → 资源释放和临时目录检查
  → 输出结构化报告和退出码
```

**F5 必须直接发现的原则错误**

- 缺包声明、能力定义、能力契约、入口、注册能力或资源预算；
- 使用旧短类型、任意类型、参数顺序漂移、返回结构漂移；
- 声明能力未注册、注册能力未声明、同一能力重复 owner；
- 派生文件不是由当前能力定义生成，摘要不一致或被手工修改；
- 模块直接导入支持库实现、Provider、第三方或实现目录；
- 依赖能力不存在、依赖循环、依赖锁缺失/版本不符；
- LLM 被声明为隐式依赖，或节点声明了不需要的 LLM；
- 统一结果被裸字典、裸字符串、裸句柄或异常替代；
- 确定性失败被空值、空列表、0 或假成功包装；
- 注册表试装配失败、关闭后仍有线程/进程/临时资源。

**真实 Provider 的边界**

F5 默认不下载模型、不启动数据库、不调用远程 API。Provider 缺失时输出 `未验证/外部依赖不可用`，退出码不能是成功；只有明确传入 `--执行外部` 且环境指纹和权限契约满足时，才执行真实 Provider 冒烟。真实 Provider 的超时、取消、崩溃和零残留仍由慢速测试和发布门禁验证，不能由一次 F5 试跑替代。

**固定退出码**

| 退出码 | 含义 | 是否允许继续开发 |
| ---: | --- | --- |
| 0 | 契约、原则检查、装配试跑和适用的样例全部通过 | 可以 |
| 10 | 契约/类型/入口/依赖原则错误 | 不可以，先修当前包 |
| 20 | 注册表装配或唯一 owner 冲突 | 不可以，先修装配 |
| 30 | 确定性样例真实返回失败 | 不可以，先修实现 |
| 40 | 资源释放不完整或发现残留 | 不可以，先修资源治理 |
| 50 | 外部 Provider 未配置或不可达 | 不算绿；只能标记未验证，进入慢速验证 |

F5 报告落在 `工程缓存/快速编译/`，包含包指纹、能力清单、失败文件/行号、退出码、是否执行外部、调用结果和资源残留；工程缓存可删除，不能作为正式事实源。

### P1：类型和能力条目冻结

落点：公共契约/基础类型、公共契约/能力契约/契约.py、开发工具/契约编译/聚合契约解析.py、开发工具/契约编译/能力定义编译器.py。

### P3：包契约和入口

落点：支持库/**/__init__.py、模块库/**/__init__.py、运行核心/加载器/包安装、开发工具/组件合规/合规测试包.py。

必须修复：合规测试回退实现目录；只验证首个能力；模块/测试直接导入实现；契约、入口参数和返回类型漂移。每个声明能力逐项注册、逐项调用、逐项记录；少一项即非零。LLM 不从已移除的本地 Provider 迁移，后续按云端协议支持库重新立项。

### P4：唯一装配和调用

    python3.14 测试中心/运行核心/测试_唯一注册表调用器.py

### P5：运行资源和状态机

落点：运行核心/任务调度/任务系统.py、任务进程.py、租约管理.py、资源协调、运行环境管理器/提供者生命周期.py、启动监督器/健康监督.py。

修复：持久化异常不能继续成功；入队任务必须有终态；关闭必须停止并 join 后台线程；无探针不能健康成功；租约过期、取消、超时、崩溃必须回收。正常、失败、超时、取消、崩溃、重复关闭后，线程、进程、端口、临时目录、句柄和证据必须对账。

### P6：外部 Provider

顺序：标准库 Provider → 文件/文档 → FFmpeg/OCR/ASR → 数据库 → LLM → GPU/浏览器。每个 Provider 补依赖锁、环境指纹、版本探针、权限、资源预算、隔离策略和真实失败验证。原生扩展和不可控全局状态不得进主进程。

### P7：模块流程

顺序：文件管理/网页分析 → 文档读取/文档解析/文档生成 → OCR/图像处理/媒体处理 → 媒体转写 → 自修复工具。

文档读取失败必须透传；文档解析必须解包统一结果并拒绝坏块；自修复必须解包结果；简单窗口必须有界、关闭释放、TTL 回收；模块不得导入 Provider/实现目录。模块必须有自己的流程状态、产物、失败、取消和恢复语义。

### P8：三类高风险 Provider

数据库：MySQL 先真实服务/驱动/权限验证，再建立支持库/适配层/MySQL提供者；PostgreSQL/SQLite 从控制面旁路迁移。每个数据库只保留连接、执行SQL、事务、断开；执行SQL返回列、行、影响行数和最后插入 id；密码只用密钥引用。

LLM：Ollama、Chat、Responses、Anthropic、本地模型独立包；统一对话检查、生成、流式、关闭流；无模型/密钥/端点时如实失败，禁止模拟成功。

ASR：MLX Whisper、Whisper、云 ASR 只替换 Provider；语音识别原子能力与媒体转写模块分离。

### P9：发布

唯一命令：

    python3.14 开发工具/HTML验证/验证器.py --制品 <编译产物目录> --并发 8
    python3.14 开发工具/发布门禁/运行发布门禁.py

开发期只运行本次改动对应的明确测试文件或模块化`unittest`入口，不把已退役的测试中心总运行器当作正式发布命令；正式发布只认编译制品真实HTML/HTTP黑盒和发布门禁。

以下任一项直接阻断：零测试、导入失败、未解释跳过、裸返回、空错误码、缺证据、缺依赖锁、错版本/摘要、双 Provider、冷启动装配失败、资源残留、旧缓存缺环境摘要、外部 Provider 未真实执行。
