## 二、代码开发到发布流程

```text
修改模块 / 组件 / 能力
        │
        ▼
统一编译器
        │
        ├─ 只编译本次变更小单元
        ├─ 检查能力是否登记
        ├─ 检查参数和返回契约
        ├─ 检查依赖是否闭合
        ├─ 检查模块边界是否越界
        └─ 生成独立编译制品
        │
        ▼
HTML黑盒验证器
        │
        ├─ 启动编译制品
        ├─ 真实发送GET/POST请求
        ├─ 检查HTTP状态码
        ├─ 检查成功/值/错误码/错误说明
        ├─ 检查请求id和耗时
        └─ 检查进程、端口、线程和临时文件是否残留
        │
        ▼
发布门禁
        │
        ├─ 制品完整性检查
        ├─ 真实HTTP验证检查
        ├─ Provider和资源检查
        ├─ 发布事务检查
        └─ 证据与当前版本指纹检查
        │
        ├─ 通过 → 发布
        └─ 失败 → 回到对应环节修复
```

## 三、各入口的实际分工

```text
能力发现网关 8866
  → 搜索能力、读取契约
  → 只读，不执行业务能力

业务执行网关
  → POST /网关/调用
  → 普通业务能力唯一执行入口

流式服务
  → POST /网关/流式
  → 统一调用器负责执行
  → 流式HTTP只负责事件传输

MCP
  → Agent工具适配层
  → 转发到统一能力入口
  → 不复制能力注册和执行逻辑

浏览器宿主
  → 提供静态页面
  → 转发请求
  → 不直接执行业务能力

轻代码IDE
  → POST /内部/工程请求
  → 读取、编辑、编译工程模型
  → 不作为业务能力执行入口
```

## 四、分层职责

```text
项目适配层
  → 项目配置、权限、路径、版本、密钥引用

模块库
  → 组合多个公开能力，形成领域流程

支持库
  → 提供单一原子能力、参数校验和结果转换

Provider / 第三方适配层
  → 封装外部服务、驱动和系统工具

运行核心
  → 装配、调用、权限、句柄、租约、超时、取消、回收、证据

平台控制面
  → 能力发现、编译、验证、发布、回滚
```

## 五、失败与资源回收流程

```text
请求进入
   │
   ▼
参数 / 凭证 / 身份 / 权限 / 并发检查
   │
   ├─ 失败 → 返回明确错误码，不执行、不静默降级
   │
   ▼
受管执行单元开始工作
   │
   ├─ 正常完成
   ├─ 执行失败
   ├─ 超时
   ├─ 用户取消
   ├─ Provider崩溃
   └─ 宿主停止
   │
   ▼
发送结束请求
   │
   ▼
有界等待进程、线程、连接和管道结束
   │
   ├─ 仍未结束
   │    → 返回“结束请求已发出但未收敛”
   │    → 保留资源账本、标识和重试入口
   │    → 不失效句柄、不启动替代资源
   │
   └─ 已结束
        → 关闭连接和管道
        → 清理端口和临时文件
        → 核对无资源残留
        → 写入回收证据
        → 失效句柄
        → 返回“已结束并已释放”
```
