## 〇、单链路树形传参（每个节点固定什么 —— 从外到内，超细粒度）

> 每个节点给出：固定职责 / 入参具体字段 / 校验具体规则 / 失败时返回什么(错误码+HTTP状态码)。
> 看到某个错误码，就能定位是哪一层返回的、该修哪里。

```text
【外部调用方】(业务项目 / Agent / CLI / 其他进程 / 网页 / Hermes)
  │  固定职责：知道 能力id + 参数 + 凭证(纯ASCII) + 网关地址 http://127.0.0.1:40007
  │  入参字段：
  │    headers: Content-Type: application/json
  │             X-System-Credential: <纯ASCII凭证>   或  Authorization: Bearer <凭证>
  │    body:    {"操作":"调用能力", "能力id":"包.能力名", "参数":{...}}
  │             可选: "超时秒", "请求id"(幂等), "项目id", "用户id", "会话id"
  │  禁止：直连 Provider/实现目录/注册表；把 id 当一次传参；中文凭证；GET 执行
  ▼
【HTTP 边界】(本地网关服务器 = 有界线程HTTP服务器, 运行核心/统一网关/本地网关.py)
  │  固定职责：唯一端口 40007（全机一个实例，launchd 托管）；只认 /网关/调用 与 /健康
  │  校验顺序：路径白名单 → 大小上限 → Content-Length → 凭证 → CORS → chunked拒绝
  │    ├─ 路径不在白名单        → 404 未知路径
  │    ├─ 凭证缺失/错误          → 401 权限不足「访问凭证缺失或无效」
  │    ├─ CORS 来源未授权        → 403 权限不足「跨域来源未授权」
  │    ├─ 预检未声明凭证头       → 403 权限不足「预检未声明受支持的凭证请求头」
  │    ├─ 方法不支持             → 405 方法不允许（执行只支持 POST /网关/调用）
  │    ├─ chunked 传输           → 400 拒绝（防污染持久连接）
  │    └─ 请求体超 64MB          → 413 拒绝
  │  出参：HTTP 信封 {"请求id","操作","成功","值","错误码","错误说明","句柄","耗时毫秒"}
  │  传入：通过校验的请求 → 网关核心
  ▼
【网关核心 · 协议层】(运行核心/统一网关/网关核心.py)
  │  固定职责：协议转换 + 权限 + 限流 + 脱敏错误 + 安全审计
  │  限流口径：**进程内固定窗口**（每实例一份计数，不跨重启/不跨实例；多实例需外部共享限流，
  │            本平台当前不提供）→ 权威边界见 运行核心/统一网关/说明/限流边界说明.md
  │  允许操作表（操作→权限档：查询/调用/任务）：
  │    健康检查/能力目录/能力搜索/包详情/能力详情/版本查询/激活版本查询/诊断查询 → 查询
  │    调用能力/资源续租/资源关闭 → 调用
  │    任务提交/任务查询/任务取消 → 任务
  │  校验顺序：操作在允许表 → 能力id非空 → _能力参数错误(对照契约) → 句柄状态 → 限流 → 幂等
  │  失败错误码（全部有中文错误说明，来自 公开错误说明表）：
  │    请求结构错误(400)  契约不存在(404)  契约版本不兼容(409)  能力不存在(404)
  │    参数不合法(400)    句柄无效(400)    句柄已过期(400)      权限不足(403)
  │    限流(429)          幂等键冲突(409)  版本冲突(409)        内部错误(500)
  │  传入：合法请求 → 后端核心.调用(能力id, 参数, 上下文, 超时秒)
  ▼
【唯一能力调用服务】(运行核心/能力调用/唯一能力调用.py = 全仓唯一执行权威)
  │  固定职责：唯一执行权威；只接受 能力注册表；禁止第二通道/旁路/直连实现
  │  校验：能力id 已注册 → 参数类型/必填对照契约 → 版本锁定 → 提供者可用 → 超时/取消
  │  类型铁律：双精度参数必须传 30.0 不能传 30；字典参数必须是对象；
  │            逻辑型必须真 bool；缺参/多余参数/类型漂移 → 立即拒绝，不兜底不降级
  │  失败返回：统一结果 {成功:false, 错误码:中文稳定码, 错误说明, 可重试}
  │  传入：能力id+参数 → 注册表解析 owner → 提供者路由
  ▼
【唯一能力注册表】(公共契约/能力契约/契约.py)
  │  固定职责：一个能力id → 一个公开owner → 一个正式实现（重复注册拒绝）
  │  解析：能力id → 支持库.xxx 或 模块库.xxx → 查表得 实现函数
  │  失败返回：能力不存在（未注册）/ 能力重复（注册期 ValueError）
  │  传入：路由结果 → 模块库 或 支持库 包级公开入口
  ▼
【模块库】(组合层, 如 模块库.直播逐字稿)  ←→  【支持库】(原子层, 如 转写支持库.转写)
  │  模块固定：只存能力id+契约版本；调用底层 = 获取能力调用器().调用能力(能力id,参数)
  │            (旧模块如媒体转写用 HTTP连接器 注入 _调用支持库)；
  │            禁止 import 支持库/Provider/实现目录；公开参数可跨宿主序列化
  │  支持库固定：单一原子能力；实现放 实现/ 子目录不对外；参数校验→调Provider→结果转换
  │  模块组合支持库：仍走 调用能力 同一入口，禁止直连
  │  失败返回：统一结果（错误码透传底层，来源=本包标识）
  │  传入：参数 → Provider 适配层
  ▼
【Provider / 第三方适配层】(支持库/适配层/, 如 MLXWhisper提供者)
  │  固定职责：封装外部服务/系统工具/驱动/第三方库的唯一边界；
  │            包声明 类型 一律写「支持库」；不作为公开owner；不对外第二门面
  │  校验：配置有效性（如 模型路径存在/模型名非空）、资源可用性
  │  执行：受管执行单元（子进程/连接/线程），独立进程组、超时、取消、输出上限
  │  失败返回（以 MLXWhisper 为例）：未配置模型 / 模型缺失 / 提供者不可用(可重试)
  │            / 超时(可重试) / 进程崩溃(可重试) / 超出限制 / 文件不存在
  │  传入：执行请求 → 受管执行单元
  ▼
【受管执行单元】(进程 / 连接 / 线程 / 临时文件 / 端口)
  │  固定职责：独立进程组(start_new_session)、有界输出(如16MB)、超时killpg、临时文件零残留
  │  崩溃隔离：子进程 os._exit 退出，不影响主进程/测试器
  │  返回：原始结果（JSON 行协议）
  ▼
【句柄状态机与资源治理】(公共契约/句柄体系.py)
  │  固定职责：创建→有效→使用→超时/取消/释放→确认回收→已失效
  │  治理对象：租约/权限/进程/连接/线程/管道/端口/临时文件
  │  回收三态：已结束并已释放 / 结束请求已发出但未收敛(保留账本+重试入口)
  │            / 未找到且已幂等；未收敛不失效句柄、不启动替代资源、不伪装成功
  │  句柄超时：模块在 包声明.json 申报 句柄超时秒；不申报默认 1800s；持续使用重置
  ▼
【统一结果】(公共契约/基础类型/结果类型.py = 结果 类)
  │  固定结构：成功(bool) / 值(数据) / 错误码(中文) / 错误说明 / 来源 / 可重试 / 详细信息
  │  铁律：成功不能携带失败状态；失败不能伪装成功；异常必须转稳定错误码；
  │        失败不返回空列表/0/空文本/假句柄
  │  网关层再包 HTTP 信封：请求id / 操作 / 句柄 / 耗时毫秒
  ▼
【返回调用方】HTTP 响应（200 或对应错误状态码）
  │  body: {"请求id","操作","成功","值","错误码","错误说明","句柄","耗时毫秒"}
  │  成功例：{"成功":true,"值":{...业务数据},"错误码":"","错误说明":""}
  │  失败例：{"成功":false,"值":null,"错误码":"未配置模型","错误说明":"...","句柄":null}
```

### 传参铁律（每个节点都遵守）

- **一次传参必须用句柄**（指向能力进程/实例），id 只作句柄内的资源定位二次传参；禁止裸传 id 绕过能力进程。
- 调用方只允许 `调用能力(能力id, 参数)` 一个接口；进程内连接器 vs HTTP连接器只在装配层区分，调用方不感知。
- 类型漂移、缺参、多余参数、返回结构不符 → 在网关/连接器边界立即拒绝，禁止默认值兜底/静默降级/伪造成功。
- 错误码中文；失败不返回空列表/0/空文本/假句柄伪装成功。
- 能力发现和契约查询是只读接口（现役经 stdio 薄壳 `capability_search`），不属于执行入口；执行永远走 40007 POST /网关/调用。原能力发现网关 8866（`MCP工具箱/能力网关.py`）已随整目录删除、40006 只读网关当前未启用（均无监听）。

## 二、新增能力（模块/支持库）的完整开发流程 —— 每个节点固定什么

```text
【1. 需求与决策】
  ├─ 能力搜索：python3.14 开发工具/能力搜索/能力搜索器.py --能力 <词>
  │   → 确认是否已有同能力（能力id全局唯一硬约束；重复=编译期拒绝）
  ├─ 复用决策：若底层能力已存在（如 转写支持库.转写.转写音频文件），
  │   → 新建模块只组合它，不复制实现；决策写入 复用决策.json
  ├─ 判断分层：原子能力+单一第三方边界 → 支持库(适配层/后端/)
  │            组合多个公开能力成流程 → 模块库/
  └─ 落盘开发文档 开发文档/临时文档/NN_*.md（先文档后代码；含开工流程/验证口径）

【2. 包声明.json —— 固定格式（错一处全平台装配崩）】
  ├─ "类型"：只写 模块 / 基础模块 / 功能模块 / 支持库
  │   ✗ 写 "Provider" → 发现器崩 ValueError: 包类型不合法
  │   （适配层 *提供者 包的类型也是 "支持库"）
  ├─ "依赖"：对象数组 [{"能力":"支持库.后端.转写支持库.转写.转写音频文件","版本":">=1.0.0"}]
  │   ✗ 写字符串数组 ["包id"] → 依赖解析崩 AttributeError: 'str' object has no attribute 'get'
  ├─ "能力"：数组，每项 {能力id, 名称, 参数:[{名称,类型}], 返回, 说明}
  │   ✗ 半成品条目(只有id/名称无参数) → 破坏能力注册
  └─ 参照真实样板：模块库/媒体转写/包声明.json、支持库/后端/转写支持库/转写/包声明.json

【3. 能力契约/能力契约/参数契约.json —— 类型口径冻结】
  ├─ 参数类型只能写正式名（迁移解析器才认旧名，新契约禁写）：
  │   文本型 / 整型 / 长整数型 / 单精度数型 / 双精度数型 / 字典型
  │   / 列表型 / 逻辑型 / 字节集型 / 日期时间型 / 句柄型 / 资源引用型
  │   ✗ 禁止写 文本/整数/字典/浮点数/布尔（旧名）
  ├─ 每个参数：{名称, 类型, 必填(true/false), 默认值, 说明}
  ├─ 返回：{类型:"结果型", 值结构:{字段名:类型,...}}   ← 不是 "结果"
  ├─ 错误码：声明实现真实会返回的全部中文错误码（实现有失败路径却没声明 → 合规门禁阻断）
  ├─ 调用示例：{能力id, 参数:{...带默认值示例}}
  └─ 行为/提供者 段落齐全（修改输入/幂等/副作用/线程安全等）

【4. 配套文件（参照 模块库/媒体转写 完整复制结构后改）】
  ├─ 依赖契约/依赖契约.json        ← 与 包声明.依赖 完全一致
  ├─ 权限契约/权限契约.json        ← {能力id: {允许用户:["*"]}}

### 典型报错 → 原因速查（新增包时最常见）

| 报错 | 原因 |
|---|---|
| `ValueError: 包类型不合法: Provider` | 包声明 类型 写了 Provider，应写 支持库 |
| `AttributeError: 'str' object has no attribute 'get'` | 依赖写成了字符串数组，应写对象数组 |
| `后端核心启动失败: xxx 但无提供者` | 依赖的能力没有可注册的实现（半成品包/未注册） |
| `能力id重复` / `能力重复` | 已存在同 id 能力，全局唯一硬约束 |
| `参数不合法：能力 X 的参数 超时秒 必须是 双精度数型` | HTTP 传了 30 而不是 30.0（网关严格类型校验） |
| `能力搜索数据 参数不一致` | 能力数据/能力搜索数据.json 参数名与契约不同 |
| `No module named '公共契约'` | 没加系统根到 sys.path 或 PYTHONPATH 被污染 |
| HTTP 一律 401 | 凭证含中文（必须纯 ASCII）或凭证头名不对 |

  ├─ 源文件存在且可读                  → 否则 文件不存在
  ├─ 源扩展名在支持清单                → mp4/mov/mkv/flv/ts/avi · m4a/mp3/wav/aac/flac
  │                                    → 否则 不支持的媒体格式
  ├─ 导出路径的父目录可创建            → 否则 写入失败
  ├─ 缓存目录的父目录可创建            → 否则 写入失败
  ├─ 导出路径 ≠ 源文件路径             → 否则 参数不合法（防覆盖原始素材）
  ├─ 导出路径不在缓存目录内            → 否则 参数不合法（防交付物混进缓存）
  ├─ 模式号存在于模式注册表            → 否则 未知模式
  └─ 磁盘可用空间 ≥ 源文件大小×1.5     → 否则 磁盘空间不足
  ▼
【阶段1 · 模式路由】（读 模式注册表.json，不加载实现）
  └─ 取：排版模板 + 裁决提示词 + 质检附加规则 + 是否保留时间戳
     ├─ 模式1/7：保留全部有效发言（1 保留话术、7 连噪音也留）
     ├─ 模式2/3：允许重排为议题结构，关键数字必须 100% 保留
     ├─ 模式4/5/8：需要二次结构化（分章 / 问答配对 / 去重）
     ├─ 模式9：先用模式1精校，再对干净文本做总结（禁止直接总结原始ASR）
     └─ 模式6：输出短句要点稿
  ▼
【阶段2 · 媒体探测】（媒体处理.探测媒体 / ffprobe）
  ├─ 判定 视频 还是 音频（用户不需要自己分）
  ├─ 取 时长 / 音轨存在性 / 采样率 / 声道
  └─ 无音轨 → 无音轨（明确失败，不生成空稿）
  ▼
【阶段3 · 音频归一化】（缓存/01_音频/归一化.wav）
  └─ 视频：抽音轨；统一 16kHz 单声道 wav（后续所有节点只认这一个音频源）
  ▼
【阶段4 · 分片】（缓存/02_分片/分片_0001.wav …）
  ├─ 默认 300 秒一片，可用参数覆盖
  ├─ 优先在静音边界切开（避免句子被切断）
  └─ 分片数写进 00_元数据/任务指纹.json
  ▼
【阶段5 · 分片 ASR】（媒体转写 / MLX Whisper large-v3 + 业务术语表）
  ├─ 每片独立进程、独立超时，失败只重跑该片
  └─ 产物：缓存/03_分片转写/分片_0001.json
     字段：文本 / 起止时间 / avg_logprob / compression_ratio / no_speech_prob
  ▼
【阶段6 · 疑难标记】（缓存/04_疑难清单.json）
  ├─ 低置信度（avg_logprob 偏低）        → 进疑难
  ├─ 高压缩比（compression_ratio 异常）  → 进疑难
  ├─ 无语音概率高（no_speech_prob 高）   → 进疑难
  ├─ 数字/专名可疑（含业务词表命中）      → 进疑难
  └─ 死循环段：同一文本连续≥15次 或 短语重复≥10次
       → 标「死循环区间」，**不进复核、不写正文**（直播间音乐/无声导致）
  ▼
【阶段7 · 疑难聚类 + 3 轮独立复核】（只对疑难做复核，这是降本关键）
  ├─ 相邻疑难段间隔≤60秒 合并成一个复核区间
  ├─ 每个区间跑 3 轮独立 ASR（不同上下文条件，可并行）
  └─ 产物：缓存/05_复核区间.json + 缓存/06_复核/复核_0001.json
  ▼
【阶段8 · 证据包】（缓存/07_证据包/证据包.md）
  └─ 汇总：原始底稿 + 该区间 3 轮结果 + 术语表（供裁决按段取用，不整包塞模型）
  ▼
【阶段9 · LLM 逐段精校裁决】（大语言模型支持库 + 该模式裁决提示词）
  ├─ 无疑难段：直接用底稿精校（不浪费复核）
  ├─ 疑难段：必须先看 3 轮证据再裁决
  ├─ 禁止：概括、拔高、补全、替发言者完善逻辑
  ├─ 不确定：写【听不清】/【待确认】，宁缺不错
  └─ 产物：缓存/08_裁决/窗口_0001.md（逐段落盘，中断可续）
  ▼
【阶段10 · 排版合成（模式分叉点）】（缓存/09_合成/全文.md）
  ├─ 模式1 直播：章节标题 + 【主讲】连贯段落，保留循环话术
  ├─ 模式2 方案：议题聚合 → 结论 → 数字 → 待办，弱化口语
  ├─ 模式3 会议：议题 + 发言人 + 决议/责任人/时限
  ├─ 模式4 课程：分章 + 分钟时长表
  ├─ 模式5 访谈：问 → 答 成对
  ├─ 模式6 手卡：要点短句
  ├─ 模式7 还原：严格原文顺序，零删减
  ├─ 模式8 问答库：同类问题归并 + 保留回答差异
  ├─ 模式9 总结：干净文本去重总结，分节按调用方要求或内容自然分节
  └─ 通用收尾：数字形式统一（中文数字→阿拉伯）、口头禅清理、死循环段标时间段
  ▼
【阶段11 · 质检硬门禁】（缓存/10_质检/质检报告.json）
  ├─ 通用：长度比 ≥0.70 · 数字保留率 ≥0.85 · 异常残句 =0
  ├─ 模式1：有效发言保留率 ≥0.70（话术不许被当重复删掉）
  ├─ 模式2：金额/比例/门店数等关键数字 100% 保留
  ├─ 模式7：不允许任何内容删减
  └─ 不过 → 质检不通过（保留缓存可续跑，**导出路径不落半成品**）
  ▼
【阶段12 · 导出（原子写）】
  ├─ 先写临时文件 → 校验字节数与结尾完整 → rename 到导出路径
  ├─ 导出格式：.md（必出）；.docx 按导出路径扩展名或参数决定
  └─ 缓存目录按策略保留（可续跑/可追溯）或清理
  ▼
【阶段13 · 资源与生命周期】
  ├─ 句柄：创建→使用→续租→释放→确认回收（超时默认 1800s，长任务申报）
  ├─ 子进程：独立进程组、超时 killpg、临时文件零残留
  └─ 幂等：同一 源文件+模式+参数 重复调用 → 命中任务指纹，直接返回已有精校稿
```

### 9.4 缓存目录结构（断点续跑的唯一依据）

```text
<缓存目录>/
├── 00_元数据/任务指纹.json      # 源文件sha256 + 模式 + 分片秒 + 模型名 → 命中即复用
├── 01_音频/归一化.wav
├── 02_分片/分片_0001.wav …
├── 03_分片转写/分片_0001.json
├── 04_疑难清单.json
├── 05_复核区间.json
├── 06_复核/复核_0001.json
├── 07_证据包/证据包.md
├── 08_裁决/窗口_0001.md
├── 09_合成/全文.md
└── 10_质检/质检报告.json
```

续跑规则：**任一阶段产物存在且任务指纹一致 → 跳过该阶段**；指纹不一致（换了源文件/改了模式/换了模型）→ 只重算受影响的下游，不整条重跑。

### 9.5 错误码（用户能看懂，且知道下一步）

| 错误码 | 触发点 | 用户可做的下一步 |
|---|---|---|
| 参数不合法 | 非绝对路径 / 导出与源同路径 / 导出在缓存内 | 改参数重发 |
| 文件不存在 | 源文件缺失或不可读 | 核对绝对路径 |
| 不支持的媒体格式 | 扩展名不在清单 | 转成 mp4/m4a/wav |
| 无音轨 | 视频里没有音轨 | 换带声音的源文件 |
| 媒体探测失败 | ffprobe 失败/文件损坏 | 重新导出源文件 |
| 磁盘空间不足 | 缓存所在盘空间不够 | 换盘或清理 |
| 未配置模型 / 模型缺失 | 转写模型未就绪 | 配好模型再跑 |
| 转写失败 | ASR 失败或返回空文本 | 看缓存目录内该分片日志 |
| 复核失败 | 复核片段 ASR 异常 | 用缓存目录续跑 |
| 裁决失败 | LLM 不可用或返回不合规 | 换模型/重试，缓存续跑 |
| 质检不通过 | 长度比/数字保留率不达标 | 看质检报告，调模式或补术语 |
| 写入失败 | 导出路径不可写 | 改导出路径 |
| 未知模式 | 模式号不在注册表 | 查模式表重选 |
