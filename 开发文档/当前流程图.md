## 〇、单链路树形传参（每个节点固定什么 —— 从外到内）

```text
【外部调用方】(业务项目 / V3 / Agent / CLI / 其他进程 / 网页)
  │  固定：知道 能力id + 参数 + 凭证(纯ASCII) + 网关地址 http://127.0.0.1:40007
  │  传入：HTTP 请求（POST /网关/调用）
  │        headers: Content-Type: application/json
  │                 X-System-Credential: <凭证>   或  Authorization: Bearer <凭证>
  │        body:    {"操作":"调用能力","能力id":"xx.能力名","参数":{...},"超时秒":可选}
  │  禁止：直连 Provider/实现目录/注册表；不传句柄当一次传参；中文凭证
  ▼
【HTTP 边界】(本地网关服务器 / 有界线程HTTP服务器)
  │  固定：唯一端口 40007（全机一个实例）；路径必须 /网关/调用（或 /健康）
  │  校验：① 请求大小上限(64MB) ② Content-Length 有界 ③ 路径白名单
  │        ④ 凭证(纯ASCII, hmac比对) ⑤ CORS(浏览器来源) ⑥ 不接收 chunked
  │  失败返回：403/401 {"错误码":"权限不足|未知路径","错误说明":"..."}
  │  传入：通过校验的请求 → 网关核心
  ▼
【网关核心 · 协议层】(运行核心/统一网关/网关核心.py)
  │  固定：允许操作表（健康检查/能力目录/能力搜索/包详情/能力详情/调用能力/
  │        资源状态/资源续租/资源关闭/任务提交/任务查询/任务取消/版本查询/诊断查询）
  │  操作权限表：查询/调用/任务 三档
  │  校验：① 操作在允许表 ② 能力id非空 ③ 参数先过 _能力参数错误(对照能力契约)
  │        ④ 有句柄则校验句柄状态(有效/过期/归属能力id) ⑤ 限流(五维) ⑥ 幂等键
  │  失败返回：{"错误码":"能力不存在|参数不合法|句柄无效|句柄已过期|限流|权限不足",...}
  │  传入：合法请求 → 后端核心.调用(能力id, 参数, 上下文, 超时秒)
  ▼
【唯一能力调用服务】(运行核心/能力调用/唯一能力调用.py = 唯一执行权威)
  │  固定：只接受 能力注册表；全仓唯一执行权威，禁止第二通道
  │  校验：① 能力id 已注册 ② 参数类型/必填对照契约(类型漂移立即拒绝)
  │        ③ 版本锁定 ④ 提供者可用性 ⑤ 超时/取消判断
  │  失败返回：统一结果(成功=false, 错误码=中文稳定码, 错误说明, 可重试)
  │  传入：能力id+参数 → 注册表解析 owner → 提供者路由
  ▼
【唯一能力注册表】(公共契约/能力契约/契约.py)
  │  固定：一个能力id → 一个公开owner → 一个正式实现（重复注册拒绝）
  │  解析：能力id → 支持库.xxx 或 模块库.xxx → 其注册的 实现函数
  │  失败返回：能力不存在 / 能力重复(注册期)
  │  传入：路由结果 → 模块库 或 支持库 包级公开入口
  ▼
【模块库】(组合层, 如 模块库.直播逐字稿)  ←→  【支持库】(原子层, 如 转写支持库.转写)
  │  模块固定：只存能力id+契约版本；用 获取能力调用器().调用能力(能力id,参数)
  │            (旧模块用 HTTP连接器 注入)；禁止 import 支持库/Provider/实现目录
  │  支持库固定：单一原子能力；参数校验→调用 Provider→结果转换
  │  模块组合支持库：仍走 调用能力 同一入口，不直连
  │  失败返回：统一结果(错误码透传底层, 来源=本包)
  │  传入：参数 → Provider 适配层
  ▼
【Provider / 第三方适配层】(支持库/适配层/, 如 MLXWhisper提供者)
  │  固定：封装外部服务/系统工具/第三方库的唯一边界；不作为公开owner
  │  校验：配置有效性(模型路径/名称)、资源是否可用
  │  执行：受管执行单元（子进程/连接/线程），超时/取消/进程组回收
  │  失败返回：未配置模型/模型缺失/提供者不可用/超时/进程崩溃/超出限制
  │  传入：执行请求 → 受管执行单元
  ▼
【受管执行单元】(进程 / 连接 / 线程 / 临时文件 / 端口)
  │  固定：独立进程组、有界输出、超时取消、临时文件零残留
  │  返回：原始结果
  ▼
【句柄状态机与资源治理】(公共契约/句柄体系.py)
  │  固定：创建→有效→使用→超时/取消/释放→确认回收→已失效
  │  治理：租约/权限/进程/连接/线程/管道/端口/临时文件
  │  资源回收三态：已结束并已释放 / 结束请求已发出但未收敛 / 未找到且已幂等
  ▼
【统一结果】(公共契约/基础类型/结果类型.py = 结果 类)
  │  固定结构：成功(bool) / 值(数据) / 错误码(中文) / 错误说明 / 来源 / 可重试 / 详细信息
  │  铁律：成功不能带失败状态；失败不能伪装成功；异常必须转稳定错误码
  │  网关层再包一层HTTP信封：请求id / 操作 / 句柄 / 耗时毫秒
  ▼
【返回调用方】HTTP 响应 {"请求id","操作","成功","值","错误码","错误说明","句柄","耗时毫秒"}
```

### 传参铁律（每个节点都遵守）

- **一次传参必须用句柄**（指向能力进程/实例），id 只作句柄内的资源定位二次传参；禁止裸传 id 绕过能力进程。
- 调用方只允许 `调用能力(能力id, 参数)` 一个接口；进程内连接器 vs HTTP连接器只在装配层区分，调用方不感知。
- 类型漂移、缺参、多余参数、返回结构不符 → 在网关/连接器边界立即拒绝，禁止默认值兜底/静默降级/伪造成功。
- 错误码中文；失败不返回空列表/0/空文本/假句柄伪装成功。

## 二、新增能力（模块/支持库）的完整开发流程 —— 每个节点固定什么

```text
【1. 需求与决策】
  ├─ 能力搜索：python3.14 开发工具/能力搜索/能力搜索器.py --能力 <词>
  │   → 确认是否已有同能力(能力id全局唯一硬约束)；复用决策落 复用决策.json
  ├─ 判断分层：原子能力→支持库；组合流程→模块库
  └─ 落盘开发文档 开发文档/临时文档/NN_*.md（先文档后代码）

【2. 包声明.json —— 固定格式】
  ├─ 类型：只写 模块/基础模块/功能模块/支持库（写 Provider → 发现器崩）
  ├─ 依赖：对象数组 [{"能力":"包.能力","版本":">=1.0.0"}]
  │        （写字符串数组 → 依赖解析崩）
  └─ 能力：每个能力带完整参数(名称+类型)与说明，禁止半成品条目

【3. 能力契约/参数契约.json —— 固定类型口径】
  ├─ 参数类型：文本型/整型/双精度数型/字典型/列表型/逻辑型（禁止 文本/整数/字典 旧名）
  ├─ 返回：结果型 + 值结构(字段名→类型)
  ├─ 错误码：声明实现真实会返回的全部中文错误码
  └─ 调用示例/行为/提供者 齐全

【4. 配套文件（参照 模块库/媒体转写 复制结构）】
  ├─ 依赖契约/依赖契约.json        （与包声明.依赖 一致）
  ├─ 权限契约/权限契约.json        （能力id → 允许用户）
  ├─ 配置契约/配置契约.json        （默认参数）
  ├─ 能力数据/能力搜索数据.json     （参数名必须与契约一致，有对称门禁）
  ├─ 能力数据/Agent查询数据.json
  ├─ 能力定义.json                 （从契约+声明提炼，勿手写漂移）
  ├─ 验证场景/正向HTTP场景.json    （验证器输入）
  ├─ 验证场景引用.json
  ├─ 说明/使用说明.md + 目录树与命令.md
  └─ 实现/<包名>.py                （组合逻辑；调用底层用 获取能力调用器().调用能力）
      __init__.py                  （包级入口 + 注册能力，参数类型从契约读）

【5. 完整性摘要 —— 用官方工具生成，不手写】
  python3.14 -c "from 开发工具.组件规范.组件规范 import 生成完整性摘要; 生成完整性摘要(Path('包目录'))"

【6. 测试 测试中心/模块库/测试_<包>.py】
  ├─ unittest；中文文件名用 python3.14 -m unittest 测试中心.模块库.测试_<包>
  ├─ 手动装配(避开并发线半成品)：能力注册表 + 注册能力调用器(唯一能力调用服务(注册表))
  │   只注册本包依赖的底层包
  └─ 断言统一结果(成功/错误码/值)，不抛异常

【7. 验证】
  ├─ 语法：python3.14 -m py_compile <文件>
  ├─ 定向测试：python3.14 -m unittest 测试中心.模块库.测试_<包>
  ├─ 能力搜索确认注册：python3.14 开发工具/能力搜索/能力搜索器.py --能力 <包>
  ├─ 正式索引：构建索引/能力所有者表 查 owner 唯一、无冲突
  └─ 真实HTTP：起 40007 网关 → curl POST /网关/调用 传真实参数

【8. 文档收口】
  ├─ 更新 开发文档/项目说明.md（能做什么表 + 调用示例）
  ├─ 临时文档标已解决；债务挂 未完成事项.md
  └─ git 提交（先 git status 看工作树有无他人未提交内容）
```

## 三、代码开发到发布流程

```text
修改模块 / 组件 / 能力
        │
        ▼
统一编译器（只编译本次小单元，禁跑全量）
        ├─ 检查能力是否登记
        ├─ 检查参数和返回契约
        ├─ 检查依赖是否闭合
        ├─ 检查模块边界是否越界
        └─ 生成独立编译制品
        │
        ▼
HTML黑盒验证器（对编译产物发真实GET/POST，可并发全量）
        ├─ 检查HTTP状态码
        ├─ 检查成功/值/错误码/错误说明
        ├─ 检查请求id和耗时
        └─ 检查进程、端口、线程、临时文件是否残留
        │
        ▼
发布门禁（发布唯一判定，约5.5s）
        ├─ 制品完整性检查
        ├─ 真实HTTP验证检查
        ├─ Provider和资源检查
        ├─ 发布事务检查
        └─ 证据与当前版本指纹检查
        │
        ├─ 通过 → 发布
        └─ 失败 → 回到对应环节修复
```

## 四、各入口的实际分工

```text
能力发现网关 8866
  → 搜索能力、读取契约
  → 只读，不执行业务能力

业务执行网关 40007
  → POST /网关/调用
  → 普通业务能力唯一执行入口

流式服务
  → POST /网关/流式
  → 统一调用器负责执行
  → 流式HTTP只负责事件传输

MCP（MCP工具箱/项目服务.py, 8766）
  → Agent工具适配层
  → 转发到统一能力入口
  → 不复制能力注册和执行逻辑

浏览器宿主
  → 提供静态页面
  → 转发请求
  → 不直接执行业务能力

轻代码IDE
  → POST /内部/工程请求
  → 读取、编辑、编译工程模型
  → 不作为业务能力执行入口
```

## 五、分层职责（每层固定什么）

```text
项目适配层
  → 项目声明、配置、权限、路径、版本、密钥引用
  → 不得调用支持库/提供者/实现源码

模块库
  → 组合多个公开能力成领域流程
  → 只存能力id+契约版本；经 调用能力 组合
  → 禁止 import 支持库/Provider/实现目录

支持库
  → 提供单一原子能力、参数校验和结果转换
  → 实现放 实现/ 目录，不对外暴露

Provider / 第三方适配层
  → 封装外部服务、驱动、系统工具、第三方库
  → 包声明 类型=支持库；不作为公开owner
  → 不对外提供第二套业务门面

运行核心
  → 装配、调用、权限、句柄、租约、超时、取消、回收、证据

平台控制面
  → 能力发现、编译、验证、发布、回滚
```

## 六、失败与资源回收流程

```text
请求进入
   │
   ▼
参数 / 凭证 / 身份 / 权限 / 并发检查
   │
   ├─ 失败 → 返回明确错误码，不执行、不静默降级
   │
   ▼
受管执行单元开始工作
   │
   ├─ 正常完成
   ├─ 执行失败
   ├─ 超时
   ├─ 用户取消
   ├─ Provider崩溃
   └─ 宿主停止
   │
   ▼
发送结束请求
   │
   ▼
有界等待进程、线程、连接和管道结束
   │
   ├─ 仍未结束
   │    → 返回“结束请求已发出但未收敛”
   │    → 保留资源账本、标识和重试入口
   │    → 不失效句柄、不启动替代资源
   │
   └─ 已结束
        → 关闭连接和管道
        → 清理端口和临时文件
        → 核对无资源残留
        → 写入回收证据
        → 失效句柄
        → 返回“已结束并已释放”
```
