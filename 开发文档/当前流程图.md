## 二、调用主链

```text
业务项目 / V3 / Agent / CLI / IDE / MCP
  → 能力搜索与契约查询（需要时）
  → 调用能力(能力id, 参数)
  → 唯一能力调用服务
  → 唯一能力注册表
  → 支持库 / 模块库
  → 唯一 Provider
  → 受管执行单元
  → 句柄、租约、超时、取消、回收
  → 统一结果
```

## 三、入口分工

| 入口 | 作用 | 是否执行业务能力 |
|---|---|---:|
| `GET /能力/搜索` | 搜索能力目录 | 否，只读 |
| `GET /能力/契约/{能力id}` | 查看能力契约 | 否，只读 |
| `POST /网关/调用` | 普通能力执行 | 是，唯一业务执行入口 |
| `POST /网关/流式` | 流式事件传输 | 经统一调用器执行，不复制执行语义 |
| `POST /内部/工程请求` | IDE工程模型读取、编辑、编译 | 否，工程控制面 |
| MCP | Agent工具适配 | 转发到统一入口 |
| 浏览器宿主 | 静态页面和请求转发 | 不直接执行业务能力 |

## 四、代码开发与发布链

```text
修改模块 / 组件 / 能力
  → 统一编译器只编译本次小单元
  → 检查能力登记、契约、依赖、边界
  → 生成独立编译制品
  → HTML黑盒验证器发真实HTTP请求
  → 检查状态码、成功、值、错误码、错误说明、请求id、耗时
  → 资源残留检查
  → 发布门禁
  → 发布或回滚
```

## 五、分层职责

```text
项目适配层
  负责项目配置、权限、路径、版本和密钥引用

模块库
  负责组合多个公开能力形成完整流程

支持库
  负责单一原子能力和结果转换

Provider / 第三方适配层
  负责封装外部服务、驱动和系统工具

运行核心
  负责装配、调用、权限、句柄、租约、超时、取消、回收和证据

平台控制面
  负责能力发现、编译、验证、发布和回滚
```

## 六、失败与资源回收

```text
请求进入
  → 参数/权限/凭证/并发检查失败
      → 返回明确错误码
      → 不执行、不静默降级

执行中
  → 正常完成 / 失败 / 超时 / 取消 / Provider崩溃
      → 停止受管执行单元
      → 有界等待
      → 确认进程、线程、连接、管道、端口和临时文件收敛
      → 成功才失效句柄并写最终回收证据
      → 未收敛则保留账本和重试入口
```
