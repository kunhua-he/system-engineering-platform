# S0 契约冻结：第二十九阶段 模块体系权威收口（唯一标准）

> 主协调冻结，任何并行工作包不得自行选择格式。基线提交 `08298d7`。

## 一、唯一能力契约格式（S0.1）

统一聚合契约文件：`能力契约/参数契约.json`，顶层固定：

```json
{
  "契约版本": "1.0.0",
  "能力契约": [
    {
      "能力id": "模块名.能力名",
      "版本": "1.0.0",
      "说明": "一句话能力说明",
      "参数": [{"名称": "参数名", "类型": "文本|整数|浮点数|布尔|字典|列表|资源引用|空", "必填": true, "默认值": null, "说明": "参数含义"}],
      "返回": {"类型": "结果", "值结构": {}},
      "错误码": ["参数不合法"],
      "调用示例": {"能力id": "模块名.能力名", "参数": {}}
    }
  ]
}
```

规则：
- 禁止同时保留"单能力顶层对象"与"能力契约数组"两种格式；禁止"任意"类型；
- 所有能力必须有 版本/说明/返回结构/错误码/可执行调用示例；
- 公开契约只允许跨宿主可序列化数据；禁止 callable/线程/连接/Path/文件对象/裸句柄；二进制用资源引用或中文 base64 字段；
- 契约编译器/搜索器/Agent 数据/网关校验/说明书/契约测试 全部复用唯一聚合契约解析函数，禁止各自解析。

## 二、模块类型（S0.2）

正式类型只允许：
- `基础模块`：通用流程或正式薄门面（OCR/图像处理/媒体处理/文件管理/文档读取/简单窗口/网页分析）
- `功能模块`：完整场景流程（媒体转写/文档生成/文档解析/自修复工具）

废弃生产类型 `模块`；加载器/包发现/依赖锁/能力目录/发布门禁统一识别两类为模块类别。

## 三、调用边界（S0.3）

- 模块只持 能力id+契约版本+依赖锁，经 `公共契约.能力契约.调用器.获取能力调用器().调用能力(能力id, 参数)` 调用；
- 模块实现禁止 `from 支持库...` / `import 支持库...` / 提供者 / 实现目录 / 第三方 / 运行核心实现；
- 模块只做参数装配/条件分支/流程状态/结果组合；禁止直接 文件/网络/数据库/进程/临时目录/格式解析 原子操作；
- 公开参数禁止 callable/取消判断 等不可跨宿主对象（改 任务id/取消令牌id/运行上下文 可序列化字段）。

## 四、权威 13 项合规（S0.4）

`开发工具/组件合规/合规测试包.py` 的 13 项强制场景为唯一权威：
结构/契约/依赖/配置/权限/生命周期/资源释放/版本升级/失败语义/说明书/完整性摘要/公共入口/真实返回。
- 契约与权限验证必须遍历聚合契约每个能力（禁整文件当一个能力）；
- 真实返回必须经 公开入口+能力注册表+锁定提供者 调用；
- 缺 配置契约/权限契约/资源预算/复用决策/注册能力/__all__/能力契约/验证证据 一律阻断；
- MCP 校验模块合规、组件合规、发布门禁三者必须同一验证器同一成功判定。

## 五、验收硬指标（S0.5）

- 11/11 模块权威合规 13/13；
- 模块库 实现 中支持库/提供者物理导入 = 0；原子旁路 = 0；类型"模块"残留 = 0；
- 39+ 既有能力及第二十八阶段新增能力全部具完整聚合契约（"任意"/缺必填/缺默认值/缺错误码/缺示例 = 0）；
- 包声明/契约/注册能力/入口导出/__all__ 对称漂移 = 0；
- 常规全量 ≥ 951、发布门禁通过（非旧三目录检查假绿）、新制品冒烟、旧制品可回滚。
