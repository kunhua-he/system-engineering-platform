## 本批问题与修复

| 编号 | 落点 | 修复 |
| --- | --- | --- |
| P1 | `开发工具/轻代码前端编辑器/编译页面.py` | 接入唯一页面模型校验器；未知组件、重复组件/对象 id、父组件缺失或非容器、父图环、无效事件和参数模板全部 fail-closed。 |
| P2 | `开发工具/轻代码前端编辑器/页面模型.py` | 新增组件目录驱动的页面结构校验，兼容目录别名和历史字符串事件并规范化为事件对象。 |
| P3 | `开发工具/项目编译/项目编译器.py` | 项目 JSON 只从声明输入目录读取；Provider 不再作为公开 owner；公开能力重复直接阻断；全部页面生成制品并写路由表；启动.py 不再是假打印入口。 |
| P4 | `运行核心/统一网关/本地网关.py` | `/健康` 改为调用同一网关核心的健康检查，后端失败时返回 503 和结构化失败结果。 |
| P5 | `开发工具/轻代码前端编辑器/启动编辑器.py` | 指定端口监听失败不再静默改绑随机端口；只有显式端口 0 才允许系统分配。页面规范化接入严格校验。 |
| P6 | 前端描述支持库完整性 | 刷新 7 个前端正式包摘要，消除已存在的摘要漂移，恢复逐包 13/13。 |
| P7 | `开发工具/快速编译/运行快速编译.py` | Provider 作为实现集合，不计入公开 owner 冲突；公开支持库/模块仍保持唯一能力 owner。 |
