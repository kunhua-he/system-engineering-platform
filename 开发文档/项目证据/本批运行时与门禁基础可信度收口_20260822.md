# 本批运行时与门禁基础可信度收口（2026-08-22）

## 流程

```text
已知阻断
  -> 运行时/健康/门禁代码定位
  -> 最小修复
  -> 反向测试复现与回归
  -> 资源键串行复验
  -> 证据落盘
```

## 本批范围

- 无依赖锁的标准库 Provider 回退系统解释器；显式空依赖锁仍拒绝装配。
- 健康证据缺失/损坏字段按失败保护；保留旧格式仅对存在且为逻辑值的“健康”字段作成功默认。
- 提供者缓存证据增加跨进程文件锁、强制刷盘和进程/线程唯一临时文件，避免 JSONL 断裂。
- 工作区残留进程匹配保留路径与启动时间边界，并容忍 `ps etime` 整秒舍入误差 2 秒。
- HTTP/能力网关端口入口继续复用端口策略；启动脚本变量改为 ASCII，避免 shell 变量歧义。
