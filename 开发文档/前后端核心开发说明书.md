# 前后端核心开发说明书

> 系统级支持库 · 第七阶段
> 版本：1.0.0 ｜ 覆盖：前端核心/后端核心/网关/异步任务/流式/窗口页面/提供者/跨核心/错误/升级回滚

## 一、前端核心说明

- 位置：`前端核心/前端核心.py`
- 职责：平台无关的前端描述与调度（窗口/页面/组件/状态/事件/资源/路由/调用/渲染）
- 不绑定 Vue、React、原生桌面或任何 CSS 框架
- 用法：

```python
前端 = 前端核心(渲染提供者=测试渲染提供者())
前端.注册窗口(窗口定义(...))
前端.设置状态("结果区", "等待调用")
前端.绑定事件("点击", 处理函数)
前端.调用后端能力("能力id", {"参数": 值})
前端.渲染("窗口id")
```

## 二、后端核心说明

- 位置：`后端核心/后端核心.py`
- 职责：通用运行宿主（发现/装配/注册/调用/任务/生命周期/权限/超时取消/统一错误/停止卸载）
- 不实现具体业务；公开入口只能是能力契约和统一结果
- 用法：

```python
后端 = 后端核心()
后端.启动()          # 装配支持库+模块（64+ 能力）
后端.注册能力("示例.加法", 函数, 参数=[...])
后端.调用("示例.加法", {"甲": 1, "乙": 2}, 上下文=运行上下文(用户id="管理员"))
后端.优雅关闭() / 后端.强制关闭()
```

## 三、网关调用说明

- 位置：`网关/网关核心.py`（协议层）+ `网关/本地网关.py`（HTTP 层）
- 网关是所有外部客户端调用后端的唯一入口
- 本地 HTTP 调用：

```bash
curl -X POST http://127.0.0.1:端口/网关/调用 \
  -H 'Content-Type: application/json' \
  -d '{"操作": "调用能力", "能力id": "示例.加法", "参数": {"甲": 1, "乙": 2}, "用户id": "管理员"}'
```

- 支持操作：健康检查/能力搜索/能力详情/调用能力/任务提交/任务查询/任务取消/版本查询/激活版本查询/诊断查询
- 统一响应：`{"请求id", "操作", "成功", "值", "错误码", "错误说明", "耗时毫秒"}`
- 网关地址/端口来自项目配置（`项目配置/默认配置.json` 的 `网关地址`/`网关端口`），不硬编码

## 四、异步任务说明

- 位置：`异步任务/任务系统.py`
- 提交 → 任务id → 查询状态/进度/结果 → 取消 → 诊断
- 任务状态：等待中/运行中/成功/失败/取消中/已取消/超时/崩溃
- 用法：

```python
系统 = 任务系统(存储目录)
系统.注册执行函数("能力id", lambda 参数, 取消事件: 结果)
任务 = 系统.提交(能力id="能力id", 参数={...}, 请求id="...")
系统.查询状态(任务.任务id)   # 轮询
系统.查询(任务.任务id).结果
系统.取消(任务.任务id)       # 幂等
系统.查询诊断(任务.任务id)   # 失败诊断
```

## 五、流式调用说明

- 位置：`网关/流式语义.py`
- 返回类型：普通返回/流式返回/事件返回/任务句柄返回/资源句柄返回
- 流式事件：首个事件/中间事件/完成事件/失败事件/取消事件
- 用法：

```python
管理器 = 流式管理器()
调用 = 管理器.开始("能力id", 事件生成函数, 最大事件数=10000)
调用.全部事件()          # 事件序列
管理器.取消(调用.调用id)  # 取消
管理器.断开(调用.调用id)  # 客户端断开 → 释放任务和资源
```

## 六、窗口开发说明

- 窗口 = 窗口定义（窗口id/标题/页面列表/资源需求/后端能力依赖）
- 页面 = 页面定义（页面id/路由/标题/组件列表）
- 组件 = 组件定义（组件id/类型/属性/事件），类型：文本/输入框/按钮/列表/状态区
- 生命周期：已创建 → 已打开 → 已关闭

```python
窗口 = 窗口定义("示例窗口", "标题", [
    页面定义("主页", "/", "标题", [
        组件定义("输入", "输入框", {"默认值": "你好"}, ["输入"]),
        组件定义("按钮", "按钮", {"文本": "调用"}, ["点击"]),
        组件定义("结果", "状态区", {}, []),
    ]),
], 后端能力依赖=["示例.分割文本"])
```

## 七、页面开发说明

- 路由切换：页面定义的路由字段；前端核心按路由选择页面
- 状态驱动渲染：组件值 = 状态表[组件id]（设置状态 → 触发 状态变化 事件 → 渲染）
- 空状态/加载状态/错误状态/权限不足/网络断开/重试状态：用 状态区 组件承载，状态表键约定：`加载状态`/`错误区`/`空状态`/`重试状态`

## 八、提供者开发说明

- 渲染提供者：实现 `渲染(渲染请求) -> {"成功", "宿主", "渲染方式", "文本|html"}`
  - 测试渲染提供者（`前端核心/渲染提供者.py`）：纯文本验证
  - HTML渲染提供者：标准库生成 HTML+JS（业务语义经中文能力契约传递）
- 外部提供者：经 `提供者隔离/独立进程.py` 真实 subprocess 运行，中文 JSON 行协议
- 新渲染宿主（桌面/原生）：实现 渲染 接口并注册，不修改前端核心

## 九、跨核心调用说明

```text
前端窗口 → 前端核心 → 网关 → 后端核心 → 模块公开能力 → 支持库公开能力
→ 提供者 → 统一结果 → 网关 → 前端状态 → 页面显示
```

前端设置调用入口（网关客户端）：`前端.设置调用入口(lambda 能力id, 参数: 网关响应.转字典())`
示例：`示例项目/前后端核心示例/运行示例.py`

## 十、错误处理说明

- 统一错误结构：错误码/错误说明/来源/可重试/详细信息
- 网关错误码：能力不存在/参数不合法/权限不足/未知路径/未知操作/内部错误/外部不可访问/限流/超时
- 前端失败状态显示：`错误区` 状态组件显示 `错误码: 错误说明`（实测：能力不存在/参数错误 明确显示，非空白页）
- 敏感错误信息前端只显示脱敏后的内容

## 十一、升级和回滚说明

- 升级路径：真实热切换（`版本系统/热切换.py` 真实热切换）：启动新提供者 → 健康检查 → 最小调用 → 影子调用 → 灰度路由 → 切换 → 排空 → 停止旧
- 回滚：自动恢复旧路由 + 保留回滚记录；旧提供者继续可调用
- 有状态升级：先排空（`有状态排空/排空管理.py`：活动请求/任务/连接/句柄归零）
- 发布事务：`发布事务/发布事务.py` 统一操作记录 + 一致性校验

## 十二、Agent 搜索问答

| 问题 | 答案来源 |
|------|----------|
| 这个能力由谁提供 | 能力搜索器：`提供方` 字段（包id） |
| 需要哪个核心 | 后端核心（`后端核心/后端核心.py`）；前端能力经前端核心调用 |
| 需要哪些模块 | 包声明.json 的 `依赖` + 能力搜索器 `依赖能力` |
| 输入是什么/返回什么 | 能力搜索器 `参数列表`/`返回`；说明书生成器 每能力章节 |
| 是否异步 | 能力契约返回类型：任务句柄返回 = 异步（异步任务/任务系统.py） |
| 是否流式 | 能力契约返回类型：流式返回/事件返回（网关/流式语义.py） |
| 是否有状态 | 状态切换 `判断有无状态`（有状态 = 数据库/队列/长连接/窗口/进程/事务/会话/缓存/句柄） |
| 是否支持热切换 | 版本系统/热切换.py（真实热切换） |
| 失败如何处理 | 统一错误结构 + 诊断中心（归类/验证场景/复现） |
| 如何验证 | 测试中心/运行测试.py + 发布门禁/运行发布门禁.py |
| 如何回滚 | 热切换 自动回滚 + 发布事务 回滚记录 |
