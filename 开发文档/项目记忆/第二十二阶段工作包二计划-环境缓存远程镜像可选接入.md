# 任务计划

## 说明
工作包二（第二十二阶段升级池第2项）：环境缓存远程镜像评估与可选接入。本机无 pip 网络时从镜像拉取已构建环境制品，作为可选加速；默认关闭，未启用时现有本地缓存路径零变化。

## 落点
- 新建 运行核心/运行环境管理器/远程镜像.py：镜像契约（远程镜像配置 dataclass：启用/镜像地址/信任指纹）、制品摘要（计算制品摘要=环境目录稳定摘要，排除 __pycache__/.pyc/构建中）、远程镜像校验器（制品摘要+依赖锁+Python版本+系统版本+架构+信任指纹全部匹配才允许命中）、获取镜像清单/下载镜像制品（标准库 urllib，file:// 支持便于本地隔离验证，tar 安全解压防路径穿越）
- 运行核心/运行环境管理器/环境管理器.py：确保环境 新增可选参数 远程镜像（默认 None→读 工程缓存/远程镜像配置.json，默认关闭）；本地校验失败后 _尝试镜像命中（清单→校验器→下载→制品摘要防篡改→校验环境复校验→原子落盘），失败回退本地构建；证据类型 镜像命中（成功）与 失败（错误码 镜像不可用/镜像摘要不匹配/镜像下载失败），不伪装命中
- 测试中心/运行核心/测试_环境镜像.py：契约/校验器/伪造攻击（摘要/锁/版本不符→拒绝）/未启用零变化/端到端 file:// 临时镜像

## 技术方案
错误码三枚：镜像不可用（清单获取网络失败）/镜像摘要不匹配（元数据任一不符或制品摘要与声明不符）/镜像下载失败（下载/解压/复校验失败）。匹配条件=制品摘要+依赖锁+Python版本+系统版本+架构全部一致。回退语义：镜像任一失败→记录失败证据→明确回退本地构建。真实镜像服务当前无法安全提供（4780 仅代理无镜像站）→如实标记未启用，只完成契约/校验器/本地伪造攻击测试。
