# 调用方式

新会话连接 `system_engineering_toolkit` 后，先调用：

`project_context(task="任务摘要", history_limit=3)`

需要理解结构时调用 `codegraph_explore`，不得先全仓逐文件阅读。

# 固定边界

- 正式代码只调用模块；项目适配层只绑定模块版本、配置、权限和项目别名。
- 模块只经运行核心注入的唯一能力调用服务按能力 id 调用支持库。
- 一个第三方发行包对应一个独立支持库、一个提供者、一个依赖锁和一个受管环境。
- 支持库负责原子能力；模块负责流程组合；运行核心负责装载、调用、资源和生命周期；平台控制面负责目录、策略、制品、发布和证据。
- 回滚切换不可变旧制品，不恢复源码旧分支，不翻转废弃标记。
- 代码地图、项目记忆和验证证据均为系统工程平台仓库独有，不与 V3 共用。

# 证据规则

“证据可信度”不是 Agent 主观判断。它由项目规则、代码地图可用性、当前 Git/工作区指纹与最近成功验证是否匹配计算。代码指纹不匹配时，只复验受影响范围；正式发布仍执行完整门禁。
