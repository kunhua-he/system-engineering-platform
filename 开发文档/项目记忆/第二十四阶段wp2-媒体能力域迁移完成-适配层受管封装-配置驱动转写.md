第二十四阶段工作包二（媒体能力域迁移）已完成并提交（worktree 分支 迁移/媒体能力，提交 734ca80，开工id=2710c2c9237e4c9e，37 项测试通过）。

调用方式：媒体转写/媒体智能 功能模块经 `from 项目适配层.媒体能力 import ...` 调用：
- 探测媒体(路径, 要求音频/要求视频, 超时秒, 最大媒体时长秒) → 严格校验，中文错误码（损坏媒体/无音轨/超长媒体/超时/取消/进程崩溃/提供者不可用）
- 从视频提取音频(源路径, 输出目录, 采样率, 音频格式) → 受管 ffmpeg（配置 V3媒体ffmpeg命令）
- 转写音频文件(音频路径, 模型, 语言, 探测超时秒, 转写超时秒) → 配置驱动（V3转写模型地址 远端 / V3转写模型仓库 本地 / V3转写工作命令 伪提供者并标记"未启用真实模型"）
- 媒体临时目录() → 上下文管理器自动清理，清理失败抛 媒体能力错误（临时清理失败）+ 证据
- 运行受管进程/同步运行受管进程 → start_new_session+killpg、超时、取消回收、输出上限截断
- 查询平台媒体能力缺口() → ffprobe/ffmpeg/转写 均无平台公开能力，已登记

关键决策：ffprobe/ffmpeg/转写平台暂无公开能力 → 受管封装自包含于适配层，平台入口不绑定平台客户端（worktree 中激活指针缺失无法 import，主工作区正常）；服务层把 损坏媒体/无音轨/超长媒体 转 验证错误(400)，其余保持 媒体能力错误(500)；取消语义传播 asyncio.CancelledError 且进程组在 finally 回收。
