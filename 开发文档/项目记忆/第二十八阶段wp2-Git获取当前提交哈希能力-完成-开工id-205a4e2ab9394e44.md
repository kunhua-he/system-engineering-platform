## 调用方式
Git操作.获取当前提交哈希 经 `支持库.适配层.Git提供者.获取当前提交哈希(仓库路径, 超时秒=60)` 调用，返回 `{提交哈希, 分支}`；detached HEAD 时分支=HEAD；非仓库/目录不存在 → 命令失败；git 缺失 → 提供者不可用；超时 → 超时；参数空路径/超时秒非法 → 参数不合法。错误码契约：参数不合法/命令失败/提供者不可用/超时/取消（无 仓库不存在/超出限制）。

## 关键决策
1. 实现走 `git rev-parse HEAD` + `git rev-parse --abbrev-ref HEAD` 两条受管命令（_顺序执行），复用 受管执行.py 参数白名单+进程组回收，禁 shell。
2. S0 契约要求"非仓库 → 命令失败"：受管执行层对非仓库返回"仓库不存在"，获取当前提交哈希 内将该错误码映射为"命令失败"（契约错误码列表不含 仓库不存在）。
3. 派生文件（参数契约.json/包声明.json/能力搜索数据.json/Agent查询数据.json/验证场景引用.json/完整性摘要.json）由 能力定义编译器 从 能力定义.json 重生成（包声明/参数契约格式转为编译器展开格式，语义等价）；__init__.py 手写入口（含 注册能力）被编译器保留，手工加新函数；完整性摘要用 组件规范 唯一生成器重算为纯文件清单格式。
4. 测试新增 6 项：正常分支与真实 git rev-parse HEAD 一致、detached HEAD 分支=HEAD、非仓库→命令失败、Popen OSError 注入→提供者不可用、伪进程 communicate 抛 TimeoutExpired→超时、参数注入拒绝（空路径/超时 0/-1/"60"）。
