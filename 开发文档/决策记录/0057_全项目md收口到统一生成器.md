# 0057 全项目 md 收口到统一生成器（一个入口，传参选类型）

## 背景

华哥 2026-09-20 定方向：「**1 个统一的生成器**，专门维护去整个项目的 md 文档。
你可以**传参**到时候选择是什么类型的文档生成和修改等」；并补足了格式分工：

> 「你把**包级说明，决策记录，方案，权威文档，规范**；这多种类型，**每一种规范一个格式**；
>   然后后面**传参就好了。后面就不能直接写文档了**。」
> 「一定要后面**全部收口好**，这个项目，**全部的编辑，全部归类到项目开发工具**，
>   类似于 **SDK 开发包**的那种一样……全部东西都**单一腿**。」

当时的现场问题有两条：

1. **md 没有统一生产者**：账目块靠手写，两次与正文实数对不上（`71 vs 52`、`合计 52 vs 分区和 49`）；
   权威文档的「最后更新」日期靠人记得改，落后于文件末次提交日（实拍 7 份里 6 份落后）。
2. **格式两套并存**：仅决策记录一个目录就同时存在模板派
   `## 背景 / ## 决策 / …`（各 16–19 份）与序号派 `## 一、背景 / ## 一、决策 / …`（各 3–5 份）。

## 决策

**全项目 Markdown 的编辑收口到唯一入口 `开发工具.MD文档生成`（SDK 式单一腿）**：

```bash
python3.14 -m 开发工具.MD文档生成 --列出                        # 有哪些类型
python3.14 -m 开发工具.MD文档生成 --类型 <类型名> --校验          # 门禁形态（漂移退出 1）
python3.14 -m 开发工具.MD文档生成 --类型 <类型名> --写盘          # 生成器形态（只换生成区）
python3.14 -m 开发工具.MD文档生成 --类型 决策记录 --新建 --标题 <标题>   # 出骨架
```

配套三条硬约定：

1. **一类文档一个格式，格式是数据不是代码**：全部登记在 `开发文档/规范/文档类型判据.json`，
   取自 `--列出` 实测；**新增一类文档 = 改该判据文件一处**，不加代码文件、不加第二套骨架。
2. **生成区 / 人工区分治**：生成区只有生成器能写（人改了 `--校验` 判红、`--写盘` 刷掉）；
   人工区逐行保留并做**零丢失自检**（丢一行即拒绝写盘）。边界切不出即 **fail-closed 报错**，
   绝不猜、绝不整文件重写（防「一次杀完」）。
3. **格式从权威模板派生，不在代码里抄第二份**：决策记录骨架由
   `开发文档/决策记录/模板.md` 派生（改模板即改格式），避免又造出「两边没归一」。

**元信息头日期从 git 派生**（不按「生成当天」）：内容没变 ⇒ 日期 = 该文件末次提交日；
有未提交改动才取当天。否则「内容没变日期天天变」且 `--校验` **隔夜必假红**。

## 考虑过的其他做法

- **只加事后体检**（写一个「债务账目体检」工具去查账目对不对）：被否决。华哥原话
  「底子有问题，你修统一的，也估计修不好呀。**你要两边都归一才行**」——源头仍手写，
  下一个人照样写错。体检只保留为生成器的一个 `--校验` 形态，不另立工具
  （自建的 `债务账目体检.py` 已于同日删除）。
- **一类文档一个生成器脚本**（债务清单一个、权威文档一个……）：被否决。华哥要的是
  「**1 个**统一的生成器……**传参**选择是什么类型」；一类一个脚本等于 N 条腿。
- **按「生成当天」打日期**：被否决。会造成每天假红（隔着一天再跑 `--校验` 必与现行不符），
  属于本平台反复收口的「假绿/假红」病。
- **骨文章节写死在生成器代码里**：先做完再自我否决 —— 代码里一份、模板里一份就是第二套格式。
  改为从模板文件派生。

## 后果

- 好处：md 的格式与生成区有了唯一生产者，「改文档忘刷生成区」会被编译口「债务清单」阻断项当场判红；
  重复实现按哲学 1.2 归并（原 `开发工具/债务清单生成.py` 已删，功能整体进统一入口）。
- 代价与限制：
  - **日期不再是「我改过」的标记，而是「最后一次提交」的事实** —— 内容没动的文档，
    写盘不会改它的日期（这是刻意设计，避免假新鲜与假红）。
  - 目前**只有债务清单与元信息头两类生成区可自动刷新**；方案 / 分析 / 交付记录 / 包级说明
    的正文仍全属人工区（包级说明另有血统生成器 `开发工具.说明书生成.合并重生成`）。

## 验证方式

```bash
# ① 全类型清单（一个入口看全部格式）
python3.14 -m 开发工具.MD文档生成 --列出

# ② 门禁形态：生成区与正文实数一致
python3.14 -m 开发工具.MD文档生成 --类型 债务清单 --校验    # 期望退出 0

# ③ 编译口复跑（含「债务清单」阻断项）
python3.14 -m 开发工具.开发编译口.编译口 --变更              # 期望退出 0

# ④ 反向验证四拍（弄坏必红 / 还原必绿 / sha 一致 / 账目从正文派生）
python3.14 -B /Users/hekunhua/.hermes/cache/scratch/统一生成器反向验证.py
```

实测（2026-09-20）：`--校验` 退出 0；编译口退出 0（无阻断红项）；反向验证四拍全过
（`[拍0] 0`、`[拍1a] 1`、`[拍1b] 1`、`[拍2] 0`、`[拍3] sha 一致=True`、`[拍4] 1`）。
