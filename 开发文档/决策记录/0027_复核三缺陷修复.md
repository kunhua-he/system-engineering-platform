## 病象：一个 0.3 秒的碎片，废掉一整场 31 分钟的稿子

全量精校首场即失败，报告只给一行：

```
复核未完成（状态「部分失败」，6/7 个区间完成，区间5: ）
```

冒号后面是**空的** —— 既无法定位原因，重跑多少次也完全一样。

现场取证（`精校缓存/俏小喵轻简护肤_2026-07-28_19-38-56/06_复核/复核_0005.json`）：

| 项 | 实测值 |
| --- | --- |
| 区间5 时间跨度 | 596.32 → 596.62 秒（**0.3 秒**，音频 5.7 KB） |
| 第1轮 | 成功，文本 `asthma asthma` |
| 第2轮 | 成功，文本 `Or a` |
| 第3轮 | **失败：转写未返回文本** |

即：疑难标记在 0.3 秒处落点 → 区间音频过短 → ASR 三轮里有一轮返回空 → 区间判「部分失败」
→ 整场质检门禁拦下 → HTTP 500 → 整场 30 分钟的稿子交付失败。

## 三个缺陷与修法

### ① 过短区间丢可识别性 → 扩窗到最小复核时长

**修**：新增 `最小复核时长 = 2.0` 与 `_保证最小时长()`，截取前把短于下限的区间**向两侧扩到 2 秒**
（不早于 0 秒），疑难点的时间归属不变，只是把窗口扩到 ASR 能稳定识别的长度。

**实测对照（同一区间同一场）**：

| | 修复前 | 修复后 |
| --- | --- | --- |
| 区间音频 | 5.7 KB（0.3 秒） | 32.9 KB（≈2 秒） |
| 第1轮 | `asthma asthma` | `在设计后的价格的时候,诶,他突然杀手了。` |
| 第2轮 | `Or a` | `在背后的价格的时候,诶,他突然杀手。` |
| 第3轮 | **空（失败）** | `在背后的价格的时候,诶,他突然杀手。` |

### ② 失败缓存被当成果复用 → 区间永久卡死

**病根**：`_读已有复核` 只看「区间 id 一致、轮次非空」，不完整缓存也照原样复用。
失败多因瞬时（那一轮模型未返回文本），可复用就等于把偶发失败**固化成永久失败**。

**修**：新增 `_区间可用()`；不完整的缓存**返回 None**（调用方重跑该区间），配合 ① 自愈。

### ③ 复用路径吞掉失败原因 → 不可诊断

**病根**：复用分支的返回值写死 `"错误码": ""`、`"错误说明": ""`，
于是上层只能拼出 `区间5: ` 这种**空原因**，把「可修复的偶发失败」伪装成「原因不明的顽疾」。

**修**：不完整不再走复用；新跑路径统一由 `_区间可用()` 产出原因（逐轮列明第几轮、什么错）。

## 唯一放宽的口径（明确登记，不静默降级）

新增一种**记账为「完成」但带标注**的情形，仅当同时满足：

1. 各轮**全部**无文本；
2. 区间原始时长 < 最小复核时长（即 0.3 秒这类不可识别碎片）。

此时判「无可用内容」并在结果里带 `标注`（`区间过短（0.30 秒）且各轮均无文本，按无可用内容记账`）。
其余任何一轮失败仍如实判失败，**质检门禁的通过标准（长度比 / 数字保留率 / 异常残句）完全未动**。

## 被否决的做法

- **放宽质检门禁**（让「复核部分失败」不再拦稿）：否决。那会把 0.3 秒碎片升级成
  「整场稿子带未知缺口交付」，属于静默降级；正确方向是让短区间**变得可识别**。
- **直接丢弃过短区间**：否决。疑难点会凭空消失，证据链断裂。
- **把「三轮里有两轮成功」当通过**：否决。三轮交叉核对是复核的立身之本，
  放宽轮次要求等于把复核降级成单轮。
