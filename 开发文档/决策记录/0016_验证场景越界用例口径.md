# 0016 验证场景越界用例的写法口径

## 背景

2026-09-17 统一验收时 HTML 黑盒验证器**阻断**：`阻断: 无任何有效验证场景（禁止零验证成功）`。
逐层深挖出三类场景格式缺陷（全部位于源码侧）：

1. **4 处内联场景缺「清理步骤」键** —— `场景加载.py::_解析多步骤场景` 要求键集**严格等于**
   `{场景id, 前置步骤, 目标步骤, 清理步骤}`，缺一即判「旧格式」。
2. **1 处负向断言缺顶层「错误码」** —— `单步场景.py::_解析断言` 要求「预期成功=false」的步骤
   必须在 `返回断言` **顶层**声明 `错误码`（写进 `关键值.错误码` 不算）。
3. **1 处场景入参含 `..`** —— `启动监督器/健康监督` 与 `平台控制面/能力目录` 其中一个的场景
   `能力目录.文件租约互斥与越界拦截`，其负向步骤「越界路径必须硬失败」把 `../平台控制面/能力目录/服务.py`
   当作 `修改路径` 传入，被 `路径安全.py::_校验动态声明` 拦下：
   「场景 … 禁止静态绝对路径或路径逃逸」。

第 3 条是**两个正当意图打架**：守卫要禁止场景依赖作者本机的真实路径、防止场景真的越界写；
而该步骤的**全部意义**就是「传一个越界路径，断言底座硬失败」。

查证后确认：**守卫是有意设计，且口径早已写明**（`模块库/组件生成/说明/设计说明.md`）：

> 验证器**禁止**场景入参出现静态绝对路径或 `..` 路径逃逸字符串，因此场景文件里的越界用例用
> 「模块名含路径分隔符」触发；`..` 跳转型越界由定向 unittest 与真实网关调用取证。

因此错的是**场景**（它违反了已写明的口径），不是守卫。

## 决策

**守卫保持不变；越界用例改用「非 `..`、非绝对路径」的越界写法触发。**

- 本场景的具体落法：`修改路径` 由 `../平台控制面/能力目录/服务.py` 改为 `~/平台控制面/能力目录/服务.py`，
  断言改为 `返回断言.包含 = "家目录写法"`。
  依据：`平台控制面/能力目录/租约路径.py::校验相对路径` 的第 ③ 条判据明确拒绝 `~` 家目录写法，
  与 `..` **落到同一个 `路径越界` 硬失败分支**、同一个 400 状态码；
  而 `~` 开头的字符串既不是绝对路径、也不含 `..` 段，不触发守卫。
- 口径推广到全平台：**验证场景里的越界用例，用「写法上越界但字面不含 `..`/非绝对路径」的方式触发**
  （`~` 家目录、含路径分隔符的名字等）。`..` 跳转型越界由**定向 unittest + 真实网关调用**取证，
  不进 HTML 黑盒矩阵。

## 考虑过的其他做法

1. **放宽守卫：负向步骤（预期成功=false）允许 `..` 与绝对路径** —— **否决**。
   守卫防的是两件事：场景依赖作者本机真实路径、场景真的越界写。负向步骤同样可能真的落到越界写
   （被测能力若真有这个 bug，正是该用例想抓的场景）；且口径已经写明并生效，为一条用例放宽判据
   等于让既有口径失效、并引入第二套判据（违反第 1 条统一口径）。
2. **把 `..` 塞进 `$动态` 的「相对路径」字段** —— **否决**。
   守卫只检查非字典字符串，`$动态.相对路径` 里写 `..` 恰好能钻过去。但那正是**守卫的漏洞**，
   靠漏洞通过等于把真缺口留在原地、还留下一个「看起来合法」的坏样板。
3. **直接删掉「越界路径必须硬失败」这个步骤** —— **否决**。
   `路径越界` 硬失败是本仓**被记录过的旧缺陷的补丁**（旧 `MCP工具箱/文件租约.py` 只归一化、
   不做项目根边界校验），删掉会丢掉真实安全覆盖，且黑盒矩阵再也测不到这条边界。
4. **改用绝对路径（如 `/etc/passwd`）触发** —— **否决**。
   守卫同样禁止静态绝对路径；且绝对路径比 `~` 更依赖运行平台，可移植性更差。

## 后果

- 好处：口径唯一（守卫一份判据），场景仍完整覆盖「越界写法必须硬失败」；`..` 跳转型由 unittest
  与真实网关调用覆盖，两层各司其职、互不冒充。
- 代价与限制：**场景层只能覆盖「非 `..`」的越界写法**；`..` 路径的端到端（HTTP）覆盖依赖
  `测试中心/平台控制面/测试_文件租约.py` 的定向 unittest + 真实网关调用，不在 HTML 黑盒矩阵内。
  后续新增越界用例时必须按本口径选触发方式，否则会在验证器解析期直接阻断（不是运行期失败）。

## 验证方式

```bash
# 1) 场景格式体检：判据直连验证器自己的解析链，应 0 不合格
python3.14 开发工具/验证场景体检.py

# 2) HTML 黑盒：不应再出现「无任何有效验证场景」或「禁止静态绝对路径或路径逃逸」
python3.14 -m 开发工具.HTML验证.验证器 --制品 <待发布制品目录> --并发 32

# 3) `..` 跳转型越界仍被取证（定向 unittest）
python3.14 -m unittest 测试中心.平台控制面.测试_文件租约
```
