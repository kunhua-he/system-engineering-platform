# 交付收尾

工作包收口的多步工作流（原 MCP 工具 `delivery_closeout` 的语义落点）：
先校验入参，再读协作状态，**反馈门禁 → 验证证据指纹校验** 两道门禁都通过后**才**写终态，
最后释放该开工id 持有的全部占用租约（文件 + 能力）。全程 fail-closed：未反馈、证据指纹不匹配、
未登记一律阻断，**不写终态、不释放资源**。

## 参数

- `开工id`（文本型，必填）：16 位十六进制开工id（协作状态主键 `work_id`）
- `五件套路径`（文本型，必填）：交付证据/五件套路径，原样写入收口记录
- `结论`（文本型，必填）：收口结论，原样写入收口记录
- `项目根目录`（文本型，选填）：底座项目根目录；默认当前工作目录（受控执行的工作目录）
- `运行库路径`（文本型，选填）：底座运行库路径；默认 `<项目根>/工程缓存/运行数据/底座运行.db`
- `控制面库路径`（文本型，选填）：平台控制面权威状态库路径；默认 `<项目根>/工程缓存/平台控制面/权威状态.db`
- `反馈文件`（文本型，选填）：MCP 反馈 JSONL 路径；默认 `<项目根>/开发文档/项目证据/MCP使用反馈.jsonl`
- `验证历史文件`（文本型，选填）：验证证据 JSONL 路径；默认 `<项目根>/开发文档/项目证据/验证历史.jsonl`
- `释放资源`（逻辑型，选填）：是否在写终态后释放占用租约，默认 `true`

相对路径按 `项目根目录`（缺省为当前工作目录）解析。**生产调用请传绝对路径**，
四份默认落点的相对路径是给「工作目录 = 项目根」的场景用的。

## 用法

调用 `技能库.受控执行.运行技能包`，`技能根目录` 传本技能所在根目录（`技能库/技能`），
`能力标识` 传 `技能.交付收尾`，参数放在 `参数` 里。典型生产参数：

```json
{"技能根目录": "<项目根>/技能库/技能", "能力标识": "技能.交付收尾",
 "参数": {"开工id": "e41a3a15531c467e", "五件套路径": "<项目根>/开发文档/交付记录/<批次>",
         "结论": "<一句话收口结论>", "项目根目录": "<项目根>"}}
```

返回（脚本 stdout，经沙箱后位于 `值.值`；沙箱外层 `成功` 恒为 true，**看 `值.值.成功`**）：

```json
{"成功": true, "值": {"技能标识": "技能.交付收尾", "开工id": "...", "生命周期": "完成",
  "五件套路径": "...", "收口结论": "...", "代码指纹": "16 位摘要", "反馈门禁": "通过",
  "证据指纹": "匹配", "证据条数": 1, "收口时间": 1789469459.17,
  "资源释放": {"文件租约": {"成功": true, "释放数量": 1, "租约id": ["..."], "失败": []},
              "能力占用": {"成功": true, "释放数量": 1, "租约id": ["..."], "失败": []}}}}
```

阻断/失败回执：脚本 stdout 为 `{"成功": false, "错误码": "...", "错误说明": "...", "阻断标记": [...]}`。

**受控执行（`运行技能包`）把脚本回执摊平后放进 `值`，且强制把外层 `成功` 置为 `true`**（实测 2026-09-15）：

```json
{"错误码": "未反馈阻断", "错误说明": "未提交 MCP 反馈，阻断收口",
 "开工id": "b2c10de000000002", "阻断标记": ["未反馈"], "耗时秒": 0.035}
```

即：**成功看 `值.值.成功`；失败看 `值.错误码`（此时 `值` 里没有 `值` 键）**。
调用方判定口径：`值` 里出现 `错误码` → 阻断，按 `阻断标记` 处理；否则读 `值.值`。

## 工作流（顺序不可换）

1. **校验入参**：`开工id` 必须 16 位十六进制，`五件套路径`/`结论` 非空 → 否则 `参数不合法` / `开工id无效`
2. **读协作状态**：从底座运行库 `协作状态` 域按主键 `work_id` 取记录（`载荷` JSON 还原清单字段）→ 未登记 `任务不存在`
3. **反馈门禁**：`MCP使用反馈.jsonl` 必须存在该开工id 记录 → 未反馈 `未反馈阻断`（不写终态）
4. **证据指纹校验**：取 `验证历史.jsonl` 该开工id 最后一条的 `指纹`（缺则回退 `工作区指纹`），与记录 `worktree路径` 的目录内容摘要比对 → 不一致 `证据不匹配`
5. **写终态**：`生命周期=完成` + `五件套路径` + `收口结论` + `收口时间`，同步回写 `协作状态` 表列与 `载荷` JSON → 失败 `登记失败`
6. **释放资源**：释放 `占用租约` 表里 `领域=文件`（所有者=开工id）与 `领域=能力`（任务=开工id）的全部活跃租约，并同步底座运行库 `能力占用` 账本终态
7. **回执**：stdout 打印 JSON 收口回执

顺序为什么不能换：门禁不通过就不写终态（否则「完成」是假的）；终态没落账就不释放资源
（否则租约放了、任务还挂在「创建」，无法追责）。

## 边界与落点（与原 `MCP工具箱/协作状态.py 收口登记` 链路对齐）

| 项 | 口径 |
| --- | --- |
| 终态落点 | 底座运行库 `工程缓存/运行数据/底座运行.db` 的 `协作状态` 域（主键 `id` = `work_id`） |
| 释放落点 | 平台控制面 `工程缓存/平台控制面/权威状态.db` 的 `占用租约` 表（`状态='已释放'` + `释放证据`） |
| 账本联动 | 能力占用释放后同步底座运行库 `能力占用` 域（按能力id 一条账本行；账本写失败只进 `资源释放.同步错误`，不改判定） |
| 指纹算法 | 目录内容 sha256 前 16 位，排除 `__pycache__`/`工程缓存`/`测试中心缓存`/`.git`/`完整性摘要.json`/`项目证据`/`临时文件` 路径段（与 `计算代码指纹` 同口径） |
| 依赖 | **只依赖标准库**（`json/sys/re/hashlib/sqlite3/time/pathlib/datetime`）：受控执行的 AST 审计只放行标准库 |
| 不释放的情形 | `释放资源=false`；或控制面库不存在（回执里 `资源释放.跳过` 如实说明，不静默） |

## 验证用例

参数里的夹具路径**相对技能根目录**（受控执行把工作目录设为技能根目录）；
夹具在 `验证夹具/`（表结构取自真实库 DDL，只装夹具行）。

- 正向：已登记 + 已反馈 + 证据指纹匹配 → 生命周期置完成，文件租约与能力占用各释放 1 条（b2c10de000000001）
- 未反馈 → `未反馈阻断`，不写终态（b2c10de000000002）
- 证据指纹不匹配 → `证据不匹配`，不写终态（b2c10de000000003）
- 未登记 → `任务不存在`（b2c10de000000004）
- `释放资源=false` → 写终态但不释放（b2c10de000000005）
- 非法开工id → `开工id无效`

夹具说明：正向用例只动属于本开工id 的租约，**另一个所有者（a1a1a1a1a1a1a1a1）的活跃租约与他人的能力租约
必须保持「活跃」**（这是释放口径的反向断言）。正向用例跑过后租约已释放，重跑仍通过
（终态幂等，`资源释放.释放数量` 变 0）；如需还原夹具的原始态，按同一布局重建两份夹具库
（DDL 从真实库 `sqlite_master` 取）与两份 JSONL 即可，指纹源固定为 `验证夹具/工作区/已通过/交付物.md`。
