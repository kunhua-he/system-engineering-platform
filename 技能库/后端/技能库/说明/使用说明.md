# 技能库（技能库.后端.技能库）

- 类型：支持库
- 版本：1.0.1
- 说明：技能库
- 入口：__init__.py
- 权威分工：**调用口径以本文为准**（能力/参数/返回/错误码/调用示例，由能力契约生成）；
  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。

## 能力
### 校验技能包（`技能库.技能包.校验技能包`）
- 版本：1.0.0
- 一句话说明：校验技能包六件套结构（SKILL.md/契约.json/工作流.json/依赖.json/验证声明.json/scripts）是否齐全，返回 {通过, 技能目录, 来源, 缺失}
- 所属支持库或模块：技能库.后端.技能库
- 参数列表：技能根目录:文本型, 技能标识或路径:文本型
- 必填参数：技能根目录, 技能标识或路径
- 可选参数：无
- 返回结构：结果型（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 目录不存在, 技能未找到
- 调用示例：技能库.技能包.校验技能包()
- 依赖能力：无
### 运行技能包（`技能库.受控执行.运行技能包`）
- 版本：1.0.0
- 一句话说明：受控执行技能包：结构校验→定位入口→AST 导入审计→沙箱运行（进程组回收/超时/输出上限/环境白名单/资源预算），返回技能脚本结果
- 所属支持库或模块：技能库.后端.技能库
- 参数列表：技能根目录:文本型, 能力标识:文本型, 参数:字典型, 超时秒:整数型, 输出上限:整数型, 环境变量:字典型, 禁止导入前缀:列表型, 项目根目录:文本型
- 必填参数：技能根目录, 能力标识
- 可选参数：参数, 超时秒, 输出上限, 环境变量, 禁止导入前缀, 项目根目录
- 返回结构：结果型（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 目录不存在, 技能未找到, 结构不完整, 工作流无效, 缺少入口脚本, 脚本路径逃逸, 脚本读取失败, 脚本审计未通过, 非法环境变量, 启动失败, 超时, 输出超限, 脚本非零退出, 输出格式错误, 脚本执行失败
- 调用示例：技能库.受控执行.运行技能包(超时秒=30, 输出上限=1048576)
- 依赖能力：无
### 扫描技能包（`技能库.技能索引.扫描技能包`）
- 版本：1.0.0
- 一句话说明：扫描技能索引登记的技能包，返回 {数量, 技能列表}，逐项标注结构是否完整
- 所属支持库或模块：技能库.后端.技能库
- 参数列表：技能根目录:文本型
- 必填参数：技能根目录
- 可选参数：无
- 返回结构：结果型（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 目录不存在
- 调用示例：技能库.技能索引.扫描技能包()
- 依赖能力：无
### 生成索引（`技能库.技能索引.生成索引`）
- 版本：1.0.0
- 一句话说明：扫描技能根目录下全部技能包，从各自 契约.json 派生索引条目，并可选写回 索引.json（参数事实唯一源仍是契约）
- 所属支持库或模块：技能库.后端.技能库
- 参数列表：技能根目录:文本型, 写回索引:逻辑型
- 必填参数：技能根目录
- 可选参数：写回索引
- 返回结构：结果型（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 目录不存在
- 调用示例：技能库.技能索引.生成索引(写回索引=True)
- 依赖能力：无
