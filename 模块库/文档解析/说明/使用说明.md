# 文档解析模块使用说明

## 定位

按格式选择支持库提供者，组合 PDF/文字/表格/演示文稿 解析能力，返回平台通用文档。
本模块是 V3 项目适配层解析路由的唯一平台入口，不直接连接任何第三方库。

## 调用示例

```python
from 模块库.文档解析 import 解析文档

结果 = 解析文档("/tmp/报告.docx", "docx")
if 结果.成功:
    文档 = 结果.值   # 通用文档（块列表/资源列表/保真级别/提供者版本）
else:
    错误码 = 结果.错误码   # 提供者不可用 / 文件损坏 / 超出限制 ...
```

## 支持格式

| 格式 | 提供者 |
|---|---|
| doc / docx | 文字文档（python-docx + LibreOffice doc 转换） |
| xls / xlsx | 表格文档（openpyxl + LibreOffice xls 转换） |
| ppt / pptx | 演示文稿（python-pptx + LibreOffice ppt 转换） |
| pdf | PDF文档（pdfplumber + fitz） |

## 错误码

统一来自底层支持库：参数不合法 / 文件不存在 / 提供者不可用 / 文件损坏 /
文件加密 / 超出限制 / 转换失败 / 超时。
