# 媒体转写模块（功能模块）

组合 MLX Whisper 支持库公开能力，统一中文契约；不导入支持库/提供者/第三方/
运行核心实现，公开参数全部可跨宿主序列化（取消令牌id 为文本，禁止 callable）。

## 公开能力

- 检查可用性（超时秒，配置）：MLX Whisper 转写可用性；模型未配置如实返回
  未配置模型。
- 获取模型版本（超时秒，配置）：模型与库版本；未配置 → 未配置模型。
- 转写音频文件（文件路径，超时秒，取消令牌id，配置）：音频文件转写为文本
  （MLX Whisper 受管子进程）。
- 转写视频文件（文件路径，转写超时秒，取消令牌id，配置）：视频直接经
  转写.转写音频文件 转写（mlx_whisper 内部经 ffmpeg 解码音轨）；
  临时媒体/音频由支持库层管理；未配置模型如实返回 未配置模型，绝不伪造转写成功。

## 调用方式

调用方先装配能力调用器（唯一能力调用服务），再经本模块公开入口调用；
调用器未装配时如实返回 提供者不可用。

## 配置

模型路径/模型名来自配置对象（`{"模型路径": ..., "模型名": ...}`）或环境变量
（`MLXWhisper提供者_模型路径` / `MLXWhisper提供者_模型名`）。

## 错误

失败返回统一错误结构，错误码与支持库一致透传（未配置模型 / 模型缺失 / 超时 /
取消 / 进程崩溃 / 提供者不可用 / 参数不合法 / 文件不存在 等）。
