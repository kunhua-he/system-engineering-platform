# 媒体转写模块

组合 FFmpeg 与 MLX Whisper 支持库公开入口，统一中文契约。

## 能力

- 转写视频文件：自动提取音频（FFmpeg媒体.提取音频）后转写（转写.转写音频文件）。
- 转写音频文件：经 MLX Whisper 受管子进程转写（转写.转写音频文件）。
- 检查可用性 / 获取模型版本：经 转写.检查可用性 / 转写.获取模型版本。

## 配置

模型路径/模型名来自配置对象（`{"模型路径": ..., "模型名": ...}`）或环境变量
（`MLXWhisper提供者_模型路径` / `MLXWhisper提供者_模型名`）。未配置模型如实
返回 未配置模型，不伪造转写成功。

## 错误

失败返回统一错误结构，错误码与支持库一致透传（未配置模型 / 模型缺失 / 超时 /
取消 / 进程崩溃 / 提供者不可用 / 无音轨 / 损坏媒体 / 参数不合法 等）。
