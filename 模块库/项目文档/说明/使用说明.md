## 项目文档.登记项目（登记项目）

**说明**：登记一个项目：先校验项目根与文档根真实存在、判据文件就位，再写入登记表（同项目名覆盖更新，幂等）；项目根不存在返回 目录不存在。支持库的存储能力不校验目录存在性，边界校验在模块层做。返回登记档案与文档根绝对路径、判据文件及其就位状态。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 项目名 | 文本型 | 是 | None | 项目名（登记表主键） |
| 项目根目录 | 文本型 | 是 | None | 项目绝对路径 |
| 文档根相对路径 | 文本型 | 否 | 开发文档 | 相对项目根的文档根 |
| 规范文件 | 文本型 | 否 |  | 规范文件相对项目根的路径（留空按约定推导判据文件） |
| 库文件 | 文本型 | 否 | None | 库文件绝对路径；留空取默认 |

**返回结构**：{'类型': '结果型', '值结构': {'项目名': '文本型', '项目根目录': '文本型', '文档根相对路径': '文本型', '规范文件': '文本型', '是否新增': '逻辑型', '文档根绝对路径': '文本型', '判据文件': '文本型', '判据文件就位': '逻辑型'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 目录不存在 |
| 项目未登记 |
| 索引库不可用 |
| 提供者不可用 |

**调用示例**：

```python
项目文档.登记项目(项目名=值, 项目根目录=值, 文档根相对路径=值, 规范文件=值, 库文件=值)
```

## 项目文档.写文档（写文档）

**说明**：按规范判据校验正文，合规才落盘成 md，并在后台线程（非守护、单次、30 秒硬超时）入库；不合规不落盘，单独返回违规范清单（判据id/严重级/行号）。判据文件缺失返回 判据文件不存在，不假装通过；目标已存在且未声明覆盖返回 已存在；路径越出文档根返回 路径越界。入库失败不回滚已落盘文件（文件是权威、索引是派生）。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 项目名 | 文本型 | 是 | None | 已登记的项目名 |
| 文档相对路径 | 文本型 | 是 | None | 相对项目文档根的路径，须落在文档根内 |
| 正文 | 文本型 | 是 | None | 文档正文文本 |
| 判据文件 | 文本型 | 否 |  | 规范判据 JSON 绝对路径；留空按约定推导 |
| 是否权威文档 | 逻辑型 | 否 | False | 真=按权威文档口径校验（含元信息头要求） |
| 覆盖 | 逻辑型 | 否 | False | 真=允许覆盖已存在文件 |
| 库文件 | 文本型 | 否 | None | 库文件绝对路径；留空取默认 |
| 等待入库完成 | 逻辑型 | 否 | False | 真=同步入库（诊断与验证用）；假=后台线程入库 |

**返回结构**：{'类型': '结果型', '值结构': {'项目名': '文本型', '文档相对路径': '文本型', '文档绝对路径': '文本型', '判据文件': '文本型', '入库': '字典型（已受理/是否完成/说明）'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 目录不存在 |
| 路径越界 |
| 已存在 |
| 判据文件不存在 |
| 项目未登记 |
| 索引库不可用 |
| 提供者不可用 |
| 内部错误 |

**调用示例**：

```python
项目文档.写文档(项目名=值, 文档相对路径=值, 正文=值, 判据文件=值, 是否权威文档=值, 覆盖=值, 库文件=值, 等待入库完成=值)
```
> 示例为骨架需验证：能力搜索数据无现成示例，按参数自动生成。

**验证状态**：已纳入验证场景：验证场景/正向写查链场景.json（未登记场景id）、验证场景/拒收与越界场景.json（未登记场景id）
