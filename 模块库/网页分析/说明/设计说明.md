## 网页分析.提取网页信息（提取网页信息）

**说明**：组合提取网页标题与正文：经 网络通信支持库.网页解析.提取网页标题/提取网页正文 能力调用，返回 结果(值={标题, 正文})；正文剔除 script/style、空白归一化、截断到 最大长度。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 网页内容 | 文本型 | 是 | None | HTML 网页内容字符串 |
| 最大长度 | 整数型 | 否 | 20000 | 正文最大长度（默认 20000） |

**返回结构**：{'类型': '结果型', '值结构': {'值': {'标题': '文本型', '正文': '文本型'}, '成功': '逻辑型', '错误': '错误结构'}}（统一结果：成功/值/错误）

**错误码表**：

| 错误码 |
| --- |
| 参数不合法 |
| 提供者不可用 |

**调用示例**：

```python
网页分析.提取网页信息(网页内容=值, 最大长度=值)
```
