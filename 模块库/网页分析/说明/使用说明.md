# 网页分析模块使用说明

## 定位

组合 `网页解析.提取网页标题`、`网页解析.提取网页正文` 支持库公开能力的
统一入口（基础模块）。一次调用返回 标题+正文；模块内部一律经
`获取能力调用器().调用能力` 调用支持库，不接触支持库实现。

## 公开能力

| 能力id | 函数 | 说明 |
|---|---|---|
| 网页分析.提取网页信息 | 提取网页信息(网页内容, 最大长度=20000) | 提取标题与正文，返回 结果(值={标题, 正文}) |

## 调用示例

```python
from 模块库.网页分析 import 提取网页信息

网页内容 = "<html><head><title>示例标题</title></head><body><p>示例正文</p></body></html>"
结果 = 提取网页信息(网页内容)
if 结果.成功:
    标题 = 结果.值["标题"]
    正文 = 结果.值["正文"]

# 限定正文最大长度
结果 = 提取网页信息(网页内容, 最大长度=100)
```

## 行为说明

- 正文剔除 script/style 标签内容，空白归一化，截断到 最大长度；
- 网页内容必须为字符串，否则返回 参数不合法；
- 最大长度必须为整数，否则返回 参数不合法。

## 错误码

| 错误码 | 含义 |
|---|---|
| 参数不合法 | 网页内容非字符串 / 最大长度非整数 |
| 提供者不可用 | 能力调用器未装配（平台不可用） |

错误码语义与支持库保持一致（透传），来源标记为本模块或支持库。

## 调用边界

- 只允许经 `获取能力调用器().调用能力("网页解析.*" 能力id, 参数)` 调用；
- 禁止 import 支持库/提供者/第三方/运行核心实现。
