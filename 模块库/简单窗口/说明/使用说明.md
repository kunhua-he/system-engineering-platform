# 简单窗口基础模块

类型：基础模块。只组合支持库公开入口，不做真实浏览器渲染。

## 能力

- 创建窗口(窗口id, 标题, 宽度, 高度)：创建窗口定义并初始化为关闭状态
- 打开窗口(窗口id)：将窗口状态流转为打开
- 关闭窗口(窗口id)：将窗口状态流转为关闭
- 传递参数(窗口id, 参数)：向窗口传递参数并返回新状态
- 获取窗口描述(窗口id)：获取窗口定义与当前状态、参数描述

## 调用边界

模块只持能力 id 与契约版本，经 获取能力调用器().调用能力 调用
窗口描述/状态描述 支持库能力；禁止直接导入支持库实现。

## 错误码

- 参数不合法：参数非法（支持库透传）
- 窗口不存在：目标窗口未创建
- 状态流转不合法：非法状态流转（如 关闭 后直接再 关闭）
- 内部错误：调用服务异常

失败统一返回 结果.失败（成功=false，错误码+错误说明），不抛异常。
