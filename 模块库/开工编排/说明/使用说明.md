## 开工编排.开工准备（开工准备）

**说明**：开发统一开工入口：逐条做修改路径的项目根边界校验（越界即‘路径越界’失败），再取 Git 提交/分支/工作区状态、证据账本成功记录与代码地图可用性，返回开工上下文与缺失原子能力清单。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 任务 | 文本型 | 是 | None | 本次开工的任务说明 |
| 项目根 | 文本型 | 是 | None | 项目根目录绝对路径，同时是修改路径边界校验的根 |
| 修改路径 | 列表型 | 否 | [] | 本次拟修改的仓库相对路径清单，逐条做项目根边界校验 |
| 历史数量 | 整数型 | 否 | 3 | 返回最近 N 条成功验证证据（1-3） |
| 验证级别 | 文本型 | 否 | 工作包 | 工作包 / 合并波次 / 阶段收口 / 正式发布 |
