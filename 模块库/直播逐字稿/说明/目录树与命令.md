# 直播逐字稿 目录树与命令

> 包id：`模块库.直播逐字稿`；版本：`1.2.0`；类型：`功能模块`

## 目录树

```text
模块库/直播逐字稿/
├── __init__.py                # 包级中文入口 + 注册能力
├── 包声明.json                # 包声明（依赖正式公开能力id）
├── 复用决策.json              # 复用决策记录
├── 能力契约/参数契约.json      # 能力参数/返回/错误码契约
├── 配置契约/配置契约.json      # 默认参数

├── 权限契约/权限契约.json      # 权限
├── 能力数据/                  # 能力搜索数据
├── 说明/                      # 使用说明
├── 验证场景/正向HTTP场景.json  # HTTP 验证场景
├── 验证场景引用.json
└── 实现/直播逐字稿.py          # 组合编排实现（只经调用器调网关）
```
