- 类型：功能模块

## 定位与边界

- 本模块只**组合** 媒体处理（ffmpeg 探测）与 媒体转写（MLX Whisper）公开能力，不复制原子实现。
- 调用方统一经 `获取能力调用器().调用能力(能力id, 参数)`（或网关 `POST /网关/调用`）调用。
- 一次调用 = 传媒体绝对路径 + 输出目录 → 返回逐字稿落盘路径与进度信息。
- 分片/断点/疑难清单/术语纠错等直播领域增强由上层（外部编排或后续版本）在输出目录上继续加工。

## 使用示例

```python
from 模块库.直播逐字稿 import 转写媒体文件

结果 = 转写媒体文件(
    文件路径="/绝对路径/录制/主播_2026-09-05_08-00.mp4",
    输出目录="/绝对路径/逐字稿项目/主播_2026-09-05_08-00",
)
if 结果.成功:
    print(结果.值["原始逐字稿路径"])
else:
    print(结果.错误码, 结果.错误说明)
```

## 错误码

| 错误码 | 场景 |
| --- | --- |
| 参数不合法 | 参数缺失/类型错误 |
| 文件不存在 | 媒体文件不存在 |
| 未配置模型 | 转写模型未配置（模型路径与模型名均为空） |
| 模型缺失 | 模型目录不存在 |
| 媒体探测失败 | ffprobe 探测媒体失败 |
| 转写失败 | MLX Whisper 转写失败或返回空文本 |
| 写入失败 | 无法写原始逐字稿/项目状态 |
| 提供者不可用 | 能力调用器未装配或底层提供者不可用 |
