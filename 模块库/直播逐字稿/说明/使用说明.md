# 直播逐字稿 使用说明

- 包id：模块库.直播逐字稿
- 类型：功能模块
- 版本：1.0.0

## 能力清单

| 能力id | 名称 | 版本 | 返回 | 说明 |
| --- | --- | --- | --- | --- |
| 直播逐字稿.转写媒体文件 | 转写媒体文件 | 1.0.0 | 结果型 | 转写直播媒体文件为原始逐字稿：探测媒体→按类型走 媒体转写 公开能力→产出 02_转录底稿/03_原始逐字稿.txt；未配置模型如实返回 未配置模型 |
| 直播逐字稿.检查可用性 | 检查可用性 | 1.0.0 | 结果型 | 检查直播逐字稿链路可用性：媒体处理(ffmpeg)与转写模型是否就绪 |
| 直播逐字稿.读取项目状态 | 读取项目状态 | 1.0.0 | 结果型 | 读取输出目录下 00_元数据/项目状态.json（断点续跑/进度查询） |
| 直播逐字稿.全自动精校 | 全自动精校 | 1.3.0 | 结果型 | 全自动精校（唯一对外能力）：传 源文件绝对路径 + 导出路径 + 缓存目录 + 模式号，一次调用完成 探测→转写→疑难标记→复核区间→逐窗裁决→按模式排版→质检门禁→原子导出 |

## 定位与边界

- 本模块只**组合** 媒体处理（ffmpeg 探测）与 媒体转写（MLX Whisper）公开能力，不复制原子实现。
- 调用方统一经 `获取能力调用器().调用能力(能力id, 参数)`（或网关 `POST /网关/调用`）调用。
- 一次调用 = 传媒体绝对路径 + 输出目录 → 返回逐字稿落盘路径与进度信息。
- 分片/断点/疑难清单/术语纠错等直播领域增强由上层（外部编排或后续版本）在输出目录上继续加工。

## 使用示例

```python
from 模块库.直播逐字稿 import 转写媒体文件

结果 = 转写媒体文件(
    文件路径="~/直播录制/主播_2026-09-05_08-00.mp4",
    输出目录="~/逐字稿项目/主播_2026-09-05_08-00",
)
if 结果.成功:
    print(结果.值["原始逐字稿路径"])
else:
    print(结果.错误码, 结果.错误说明)
```

## 错误码

| 错误码 | 场景 |
| --- | --- |
| 参数不合法 | 参数缺失/类型错误 |
| 文件不存在 | 媒体文件不存在 |
| 未配置模型 | 转写模型未配置（模型路径与模型名均为空） |
| 模型缺失 | 模型目录不存在 |
| 媒体探测失败 | ffprobe 探测媒体失败 |
| 转写失败 | MLX Whisper 转写失败或返回空文本 |
| 写入失败 | 无法写原始逐字稿/项目状态 |
| 提供者不可用 | 能力调用器未装配或底层提供者不可用 |

## 输出目录结构

```text
<输出目录>/
├── 00_元数据/项目状态.json     # 状态账本（读取项目状态 能力读取）
└── 02_转录底稿/03_原始逐字稿.txt  # [开始-结束] 文本 逐行时间戳原始稿
```

## 直播逐字稿.全自动精校（全自动精校）

**说明**：全自动精校（唯一对外能力）：传 源文件绝对路径 + 导出路径 + 缓存目录 + 模式号，一次调用完成 探测→转写→疑难标记→复核区间→逐窗裁决→按模式排版→质检门禁→原子导出；用户只看到导出的一份逐字稿。行业细节（分节结构、易错词校正）由消费者通过 输出结构 / 附加要求 / 附加术语 传参，底座不写死任何行业内容。失败不落半成品，返回中文错误码与缓存目录。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 源文件路径 | 文本型 | 是 | None | 视频或音频绝对路径（自动判别，无需用户分类） |
| 导出路径 | 文本型 | 是 | None | 精校逐字稿输出绝对路径（用户唯一要看的文件） |
| 缓存目录 | 文本型 | 是 | None | 中间产物绝对路径（分片/疑难/复核/裁决/质检），可断点续跑 |
| 模式 | 整型 | 是 | None | 模式号（1=直播逐字稿 2=方案逐字稿 3=会议 4=课程培训 5=访谈问答 6=手卡口播 7=1:1还原 8=知识问答库 9=总结稿） |
| 分片秒数 | 整型 | 否 | 300 | 分片时长秒数 |
| 附加术语 | 文本型 | 否 |  | 业务术语表（传给转写与裁决，提升品牌词/专名识别） |
| 模型配置 | 字典型 | 否 | None | 转写模型配置（模型路径/模型名）；缺省读环境变量 |
| 裁决模型配置 | 字典型 | 否 | None | 精校裁决用的 LLM 配置（模型/部署形态/url/api_key/协议/上下文长度）；缺省读环境变量 LLM裁决_* |
| 超时秒 | 双精度数型 | 否 | 3600.0 | 转写子进程超时秒 |
| 输出结构 | 文本型 | 否 |  | 消费者指定的分节结构，覆盖模式默认值 |
| 附加要求 | 文本型 | 否 |  | 消费者补充的业务规则（易错词校正、行业口径、禁用写法等），会追加进裁决提示词 |
| 裁决模型句柄 | 整数型 | 否 | None | 消费者先调 大语言模型支持库.模型连接器.连接LLM 得到的句柄；传了它就不必再传 裁决模型配置。底座只借用、不释放（谁连接谁释放），网关重启后需重新连接 |

**返回结构**：结果型（统一结果：成功/值/错误）。成功值结构：{精校稿路径, 模式, 模式名称, 字数, 时长秒, 质检, 缓存目录, 复核, 状态}。

**错误码表**：

| 错误码 |
| --- |

| 模型缺失 |
| 转写失败 |
| 复核失败 |
| 裁决失败 |
| 质检不通过 |

| 未知模式 |

| 超出限制 |

**调用示例**：

