## 图像处理.分析图像文件（分析图像文件）

**说明**：在受控根目录内读取图像文件并一次返回解码+像素统计：{格式, 宽度, 高度, 模式, 像素数, 平均颜色{红,绿,蓝}}；读取/解码/统计错误码透传支持库层

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 受控根目录 | 文本型 | 是 | None | 文件读取的受控根目录（目录不存在 → 目录不存在） |
| 相对路径 | 文本型 | 是 | None | 根目录内相对路径（越出根目录 → 路径越界；不存在 → 文件不存在） |
| 最大字节数 | 整数型 | 否 | 0 | 读取字节上限，0 表示不限制（超限 → 文件超限） |

**返回结构**：{'类型': '结果型', '值结构': {'格式': '文本型', '宽度': '整数型', '高度': '整数型', '模式': '文本型', '像素数': '整数型', '平均颜色': {'红': '整数型', '绿': '整数型', '蓝': '整数型'}}}（统一结果：成功/值/错误）

| --- |

| 文件不存在 |
| 文件超限 |

| 超大 |
| 格式未知 |
| 文件损坏 |
| 超时 |
| 提供者崩溃 |
| 提供者不可用 |

**调用示例**：
