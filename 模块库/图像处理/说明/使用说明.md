# 图像处理模块

基础模块：只经能力调用器按能力id组合支持库公开能力（图像解码/文件系统），
不深入支持库实现目录，不直接读写文件。

## 能力清单

| 能力 | 功能 | 成功值 |
|---|---|---|
| 图像处理.分析图像文件 | 受控根目录内读取图像并一次返回解码+像素统计 | {格式, 宽度, 高度, 模式, 像素数, 平均颜色{红,绿,蓝}} |
| 图像处理.生成占位图 | 生成纯色/渐变/文本占位图 PNG | {图像b64, 格式, 宽度, 高度} |
| 图像处理.识别图像格式 | 按内容识别格式（伪装检测） | {格式, 宽度, 高度, 模式} |
| 图像处理.生成缩略图 | 按最大边长等比例缩略（只缩不放大） | {图像b64, 格式, 宽度, 高度} |
| 图像处理.图像EXIF转置 | 按 EXIF orientation 转置方向（无方向原样返回） | {图像b64, 格式, 宽度, 高度} |
| 图像处理.透明背景合成 | 透明图像与背景色合成（输出 RGB PNG） | {图像b64, 格式, 宽度, 高度} |
| 图像处理.计算感知哈希 | 计算 aHash/dHash/pHash 感知哈希 | {哈希, 哈希类型} |
| 图像处理.缩放图像 | 按指定宽高精确缩放（宽高可空） | {图像b64, 格式, 宽度, 高度} |
| 图像处理.重编码图像 | 按格式与质量重编码（JPEG/PNG/WebP） | {图像b64, 格式, 宽度, 高度} |

## 调用边界

- 字节类参数传 `bytes` 对象（跨宿主场景由调用方编码传输，模块侧保持字节语义）。
- 分析图像文件 的读取在受控根目录内进行（路径越界/超限拒绝），文件读取经
  文件系统支持库能力完成。

## 错误码

失败时错误码原样透传支持库层：参数不合法/目录不存在/路径越界/文件不存在/
文件超限/文件读取失败/超大/格式未知/文件损坏/超时/提供者崩溃/提供者不可用。
