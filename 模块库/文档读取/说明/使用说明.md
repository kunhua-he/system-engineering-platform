# 文档读取（模块库.文档读取）

- 类型：基础模块
- 版本：1.0.2
- 说明：组合文件系统、文本处理与数据交换支持库公开能力：读取正文、提取标题、统计段落数，返回结构化结果与统一错误结构。
- 入口：__init__.py
- 权威分工：**调用口径以本文为准**（能力/参数/返回/错误码/调用示例，由能力契约生成）；
  该库的设计哲学与边界见同目录 `设计说明.md`（设计权威）。

## 依赖能力
- 能力 `文件系统支持库.文件操作.读取文件` 版本约束 `>=1.0.0`
- 能力 `数据操作支持库.文本处理.按行分割` 版本约束 `>=1.0.0`
- 能力 `数据操作支持库.文本处理.去空白` 版本约束 `>=1.0.0`
- 能力 `数据操作支持库.数据交换.序列化JSON` 版本约束 `>=1.0.0`

## 能力
### 读取正文（`文档读取.读取正文`）
- 版本：1.0.0
- 一句话说明：读取文档正文文本：经 文件系统支持库.文件操作.读取文件 能力读取，返回 结果(值=文本)；文件路径非法返回 参数不合法，文件不存在等错误透传支持库。
- 所属支持库或模块：模块库.文档读取
- 参数列表：文件路径:文本型
- 必填参数：文件路径
- 可选参数：无
- 返回结构：{'类型': '结果型', '值结构': {'值': '文本型', '成功': '逻辑型', '错误': '错误结构'}}（统一结果：成功/值/错误码/错误说明）
- 错误码：参数不合法, 文件不存在, 提供者不可用
- 调用示例：文档读取.读取正文()
- 依赖能力：文件系统支持库.文件操作.读取文件, 数据操作支持库.文本处理.按行分割, 数据操作支持库.文本处理.去空白, 数据操作支持库.数据交换.序列化JSON
