# 文档读取模块使用说明

## 定位

组合 `文件系统.读取文件`、`文本处理.按行分割/去空白`、`数据交换.序列化JSON`
支持库公开能力的统一入口（基础模块）。调用方只传 文件路径，拿到统一 `结果`
结构；模块内部一律经 `获取能力调用器().调用能力` 调用支持库，不接触支持库实现。

## 公开能力

| 能力id | 函数 | 说明 |
|---|---|---|
| 文档读取.读取正文 | 读取正文(文件路径) | 读取文档正文文本，返回 结果(值=文本) |
| 文档读取.提取标题 | 提取标题(文件路径) | 首个非空行作为标题；无标题返回空字符串 |
| 文档读取.计算段落数 | 计算段落数(文件路径) | 非空行计数，返回 结果(值=整数) |
| 文档读取.结构化读取 | 结构化读取(文件路径) | 正文/标题/段落数 + JSON 序列化文本 一次返回 |

## 调用示例

```python
from 模块库.文档读取 import 结构化读取, 读取正文

结果 = 结构化读取("说明/使用说明.md")
if 结果.成功:
    结构 = 结果.值
    正文 = 结构["正文"]        # 全文文本
    标题 = 结构["标题"]        # 首个非空行
    段落数 = 结构["段落数"]    # 非空行数量
    序列化文本 = 结构["序列化文本"]  # JSON 文本

正文结果 = 读取正文("说明/使用说明.md")
if 正文结果.成功:
    文本 = 正文结果.值
```

## 错误码

| 错误码 | 含义 |
|---|---|
| 参数不合法 | 文件路径为空/非文本 |
| 文件不存在 | 目标文件不存在（透传支持库） |
| 序列化失败 | 结构化结果 JSON 序列化失败 |
| 提供者不可用 | 能力调用器未装配（平台不可用） |

错误码语义与支持库保持一致（透传），来源标记为本模块或支持库。

## 调用边界

- 只允许经 `获取能力调用器().调用能力("文档解析.*" 能力id, 参数)` 调用；
- 禁止 import 支持库/提供者/第三方/运行核心实现。
