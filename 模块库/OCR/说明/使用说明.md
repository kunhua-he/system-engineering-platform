# OCR 模块（基础模块）

只经 获取能力调用器().调用能力 组合 Tesseract 支持库公开能力，失败返回统一
错误结构（错误码/说明/来源）。取消事件 参数按 S0 冻结契约改为 取消令牌id
（文本语义：空字符串表示不取消；模块只透传令牌id，支持库侧不传 callable）。

## 公开能力

- 识别图片文字：图片路径与图片字节二选一，返回 {文本} 或 词级数据 {词列表}。
- 识别图片文件：按图片文件路径识别文字，返回 {文本} 或 词级数据 {词列表}。
- 可用性检查：探测 tesseract 版本与语言包，返回 版本/满足最低版本/语言列表/
  数据目录/语言数量。

## 调用方式

```python
from 模块库.OCR import 可用性检查, 识别图片文件, 识别图片文字

结果 = 识别图片文字(图片路径="示例图片.png", 取消令牌id="")
if 结果.成功:
    文本 = 结果.值["文本"]

结果 = 识别图片文件(图片路径="示例图片.png", 词级数据=True)
if 结果.成功:
    词列表 = 结果.值["词列表"]

结果 = 可用性检查()
if 结果.成功:
    版本 = 结果.值["版本"]
```

## 错误码

错误码由支持库统一结构透传：参数不合法/文件不存在/工具缺失/语言包缺失/
识别失败/进程崩溃/超时/取消/超出限制/命令失败/版本不兼容/提供者不可用。

## 边界

- 实现只经 公共契约.能力契约.调用器.获取能力调用器 调用支持库能力；
  禁止 import 支持库/提供者/第三方/运行核心。
- 调用器未装配时返回 提供者不可用，不绕过边界。
