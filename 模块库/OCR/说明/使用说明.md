# OCR 模块

组合 Tesseract 支持库公开入口（OCR识别.*），统一中文契约与错误码透传。

## 能力

| 能力id | 功能 | 成功值 |
|---|---|---|
| OCR.识别图片文字 | 图片路径/图片字节 二选一识别文字 | {文本} 或 {词列表}（词级数据） |
| OCR.识别图片文件 | 按图片文件路径识别文字 | {文本} 或 {词列表}（词级数据） |
| OCR.可用性检查 | 真实探测 tesseract 版本与语言包 | {tesseract, 版本, 满足最低版本, 语言列表, 数据目录, 语言数量} |

## 约束

- 只 import 支持库公开入口，禁止 import 实现目录与第三方。
- 错误码原样透传：参数不合法/文件不存在/工具缺失/语言包缺失/识别失败/
  进程崩溃/超时/取消/超出限制/提供者不可用；失败不伪装成功。
- 工具缺失时如实返回 工具缺失（可重试）；本机未配置 tesseract 时测试如实跳过。
