## OCR.识别图片文字（识别图片文字）

**说明**：识别图片文字：图片路径与图片字节二选一，返回 {文本} 或 词级数据 {词列表}

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 图片路径 | 文本型 | 否 | None | 图片路径（与图片字节二选一，必须且只能提供一个） |
| 图片字节 | 字节集型 | 否 | None | 图片字节（与图片路径二选一，必须且只能提供一个） |
| 语言 | 文本型 | 否 | eng | tesseract 语言包（如 eng/chi_sim），默认 eng |
| 词级数据 | 逻辑型 | 否 | False | 是否返回词级数据 {词列表}（默认仅返回 {文本}） |
| 超时秒 | 双精度数型 | 否 | 60.0 | 识别超时秒数 |
| 取消令牌id | 文本型 | 否 |  | 取消令牌id（空字符串表示不取消；平台按令牌id取消运行，支持库侧不传 callable） |
| 输出上限字节 | 整数型 | 否 | None | 识别输出上限字节（超出返回 超出限制） |
| 命令路径 | 文本型 | 否 |  | tesseract 命令路径（显式优先，默认探测） |

**返回结构**：{'类型': '结果型', '值结构': {'文本': '识别出的文本（词级数据为 false 时）', '词列表': '词级数据列表（词级数据为 true 时，每项含 文本/置信度/坐标）'}}（统一结果：成功/值/错误）
