# 自修复开发工具模块

组合 Git 支持库、文件系统（补丁/临时资源）、资源管理（内容摘要）与本地进程适配器（受管验证命令）。

## 创建修复工作区(仓库路径, 补丁列表, 验证命令, 提交消息, 期望摘要="", 检查文件="", 分支名="", 超时秒=60)

Git worktree + 精确补丁应用 + 定向验证 + 可回滚提交组合流程：

1. 检查 git 提供者可用；
2. 创建独立 worktree（系统临时目录唯一宿主，登记临时资源）；
3. 工作区内精确应用补丁（旧内容必须恰好匹配 1 次，多重匹配/未匹配拒绝，路径逃逸拒绝）；
4. 定向验证：受管进程运行验证命令 + 可选内容摘要比对；
5. 提交（add+commit 最小原子提交）；
6. 关闭 worktree；未提交修改等关闭失败时登记临时资源兜底清理。

返回：{路径, 分支, 提交, 摘要, 工作区清理}。

## 验证修复(仓库路径, 验证命令, 期望摘要="", 检查文件="", 超时秒=60)

运行验证命令（参数列表受管执行，禁 shell）并检查内容摘要；失败返回 验证失败。

## 回滚修复(仓库路径, 提交哈希, 操作="回滚", 超时秒=60)

操作=回滚 → git revert；操作=挑拣合入 → git cherry-pick。仓库存在未提交修改时拒绝（未提交修改），冲突自动中止（冲突）。

统一错误码：参数不合法 / 提供者不可用 / 路径逃逸 / 补丁多重匹配 / 验证失败 / 回滚失败 / 未提交修改 / 冲突。
