## 能力目录.搜索能力（搜索能力）

**说明**：按关键词只读检索支持库与模块库公开能力：整条记录大小写不敏感子串匹配，命中按 能力id 稳定升序排列，支持 游标 分页与三档 细节级别。默认档＝「名称」：每条只回 能力id/名称/中文名称/包id/一句话说明 五个精简字段，把 参数/行为/返回/资源预算 这类重字段挡在默认返回之外，保住 Agent 的 prompt 前缀缓存（依据 P-9 第 6 条「精简字段默认返回」与第 2 条「返回指针而不是全文」）；需要重字段必须显式传 细节级别=完整契约，该档与「读取能力」逐字段一致。旧调用（只传 关键词/限制）照常可用，只是返回项由 21 字段变精简。游标不透明、基于排序键（能力id）而非偏移，翻页不漏不重。不加载实现，不暴露适配层与内部层包。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 关键词 | 文本型 | 否 |  | 搜索关键词；空字符串表示不过滤（按 限制 返回候选） |
| 限制 | 整数型 | 否 | 5 | 每页最多返回条数；1~100，超出按边界收敛，非整数一律拒绝（语义为「每页大小」，不再是「总量硬上限」——总量由 游标 翻页取全） |
| 游标 | 文本型 | 否 |  | 翻页游标：空 = 从第一页取；此后原样传回上一次返回的 下一条游标。不透明，调用方不得解析或自行构造；同一轮翻页必须与首次调用传相同的 关键词（不同即拒绝，避免漏项/重项） |
| 细节级别 | 文本型 | 否 | 名称 | 返回明细档位，三档：名称（默认，仅 能力id/名称/中文名称/包id/一句话说明）／名称+说明（追加 说明/包名称/提供方/类型/版本/包版本）／完整契约（全部字段，与 读取能力 一致）。不传取默认档「名称」；传其它值一律拒绝 |
