# 文档生成模块使用说明

## 定位

组合支持库适配层四个生成提供者能力（文字文档.生成文字文档/表格文档.
生成表格文档/演示文稿.生成演示文稿/PDF生成.生成PDF）的统一入口。
调用方只传 格式 + 内容参数，拿到统一 `生成产物`（字节/媒体类型/摘要/诊断），
不接触任何第三方库。

## 调用示例

```python
from 模块库.文档生成 import 生成文档

结果 = 生成文档("docx", {"内容块列表": [{"类型": "段落", "文本": "你好"}]})
if 结果.成功:
    产物 = 结果.值
    字节 = 产物.字节
    媒体类型 = 产物.媒体类型
    摘要 = 产物.摘要          # sha256 hex
    诊断 = 产物.诊断          # 含生成耗时与签名校验结论

# 格式归一化：大小写与点前缀均可
生成文档(".XLSX", {"工作表列表": [{"表名": "表", "列": ["列甲"], "行": [["值"]]}]})
```

## 格式支持

- 可生成：docx / xlsx / pptx / pdf
- 不可生成（归一化后合法但不在生成范围）：doc / xls / ppt → `参数不合法`
- 非法格式（如 txt / 空值）→ `参数不合法`

## 错误码

| 错误码 | 含义 |
|---|---|
| 参数不合法 | 格式非法、格式不可生成、内容参数非字典 |
| 提供者不可用 | 对应生成库未安装（透传支持库） |
| 生成失败 | 支持库生成失败或生成字节为空 |

## 内容参数结构

| 格式 | 内容参数 |
|---|---|
| docx | `{"内容块列表": [{类型, 文本, 级别, 加粗, 对齐, 表头, 行}]}` |
| xlsx | `{"工作表列表": [{表名, 列, 行}]}` |
| pptx | `{"幻灯片列表": [{标题, 要点, 备注}]}` |
| pdf | `{"内容块列表": [{类型, 文本, 级别, 对齐, 表头, 行}]}` |
