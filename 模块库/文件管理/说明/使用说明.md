# 文件管理模块

只组合支持库公开入口，失败返回统一错误结构。

## 公开能力

- 读取文件：读取文本文件内容。
- 写入文件：写入文本文件（自动建父目录）。
- 复制文件 / 移动文件 / 删除文件：文件基本操作。
- 列出文件：列出目录下条目名称。
- 读取二进制文件：受控根目录内按相对路径读取二进制文件；相对路径越出受控根目录时返回「路径越界」，超过最大字节数时返回「文件超限」，文件缺失返回「文件不存在」。
- 读取文件头部字节：只读文件头部 N 字节，不加载全文件；错误码透传「路径越界」「文件不存在」「文件读取失败」。
- 流式创建摘要：大文件分块流式创建 sha256 内容摘要（经资源管理.创建内容摘要），文件缺失返回「文件不存在」，读取异常返回「摘要失败」。

错误码（路径越界 / 文件不存在 / 文件超限 / 文件读取失败 / 摘要失败）由支持库统一结构透传，来源标记为支持库或本模块。
