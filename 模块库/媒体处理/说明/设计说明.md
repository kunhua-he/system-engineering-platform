**说明**：ffmpeg 转码（mp4/mkv/webm/mov/avi）：返回 {格式, 字节数, 输出路径}（可选 字节b64）；编码选项白名单：分辨率/视频码率/音频码率/帧率/视频编码器/音频编码器/码率上限/缓冲/视频标签/预设；Apple Silicon 推荐 h264_videotoolbox/hevc_videotoolbox 硬编

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 文件路径 | 文本型 | 是 | None | 媒体文件绝对路径 |
| 输出格式 | 文本型 | 否 | mp4 | mp4/mkv/webm/mov/avi |
| 编码选项 | 字典型 | 否 | None | 白名单键值：分辨率/视频码率/音频码率/帧率/视频编码器/音频编码器/码率上限/缓冲/视频标签/预设；硬编压缩推荐组合：视频编码器=hevc_videotoolbox、视频码率=900k、码率上限=1100k、缓冲=2200k、帧率=15、视频标签=hvc1、音频编码器=copy |

| 超时秒 | 双精度数型 | 否 | 60 | 转码超时 |
| 最大输出字节 | 整数型 | 否 | 209715200 | 输出大小上限 |
