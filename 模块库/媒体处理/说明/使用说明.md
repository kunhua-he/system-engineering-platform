# 媒体处理模块

只组合 FFmpeg 支持库公开入口（检查提供者/探测媒体/提取音频/转码/抽取帧），
不深入支持库实现目录，不直接调用 ffmpeg/ffprobe 命令。

能力与错误码透传：

- 检查提供者：ffmpeg/ffprobe 可用性与版本；缺失 → 提供者不可用
- 探测媒体：{时长秒, 流, 格式, 大小字节, 比特率}；损坏 → 损坏媒体
- 提取音频：首个音频轨（wav/mp3/aac/m4a/ogg/flac），字节经 b64 返回；
  无音轨 → 无音轨；超长 → 超长媒体
- 转码：mp4/mkv/webm/mov/avi，编码选项白名单（分辨率/视频码率/音频码率/帧率）
- 抽取帧：jpg/png，时间点秒；返回 {字节b64, 格式, 宽度, 高度}

统一错误码：损坏媒体/无音轨/超长媒体/超时/取消/进程崩溃/提供者不可用/
参数不合法/文件不存在/超出限制。
