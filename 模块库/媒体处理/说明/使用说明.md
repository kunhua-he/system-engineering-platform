# 媒体处理模块（基础模块）

只经 获取能力调用器().调用能力 组合 FFmpeg 支持库公开能力，不导入支持库/
提供者/第三方/运行核心实现，不直接调用 ffmpeg/ffprobe 命令；临时媒体由
FFmpeg 支持库自管（自建自清零残留）。

## 公开能力

- 检查提供者（超时秒）：ffmpeg/ffprobe 可用性与版本；缺失 → 提供者不可用。
  超时秒 为版本探针超时预留参数。
- 探测媒体（文件路径，超时秒）：{时长秒, 流, 格式, 大小字节, 比特率}；
  损坏 → 损坏媒体。
- 提取音频（文件路径，输出格式，输出路径，超时秒，最大输出字节，最大时长秒）：
  首个音频轨（wav/mp3/aac/m4a/ogg/flac），字节经 b64 返回；
  无音轨 → 无音轨；超长 → 超长媒体。
- 转码（文件路径，输出格式，编码选项，输出路径，超时秒，最大输出字节，最大时长秒）：
  mp4/mkv/webm/mov/avi，编码选项白名单（分辨率/视频码率/音频码率/帧率）。
- 抽取帧（文件路径，时间点秒，输出格式，输出路径，超时秒，最大输出字节，最大时长秒）：
  jpg/png；返回 {字节b64, 格式, 宽度, 高度}。

## 调用方式

调用方先装配能力调用器（唯一能力调用服务），再经本模块公开入口调用；
调用器未装配时如实返回 提供者不可用，不伪造成功。

## 错误

统一错误码：损坏媒体/无音轨/超长媒体/超时/取消/进程崩溃/提供者不可用/
参数不合法/文件不存在/超出限制。
