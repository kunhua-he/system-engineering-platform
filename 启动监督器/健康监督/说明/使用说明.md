启动监督器健康监督面：把 `启动监督器/容量基线.py` 的只读/判定语义（声明基线 → 实测采样 → 对比超限）切成可经网关调用的原子能力。资源判定的唯一实现在 `启动监督器/容量基线.py`，本包只做边界校验与结果归一；周期探针（`启动监督器/健康监督.py`）与超限处理链属执行类与写类动作，不在本轮能力面。

## 启动监督器.健康监督.执行健康监督（执行健康监督）

**说明**：真跑一次健康监督：按调用方声明的容量基线做一次真实采样并比对，返回健康结论、超限项与采样快照（只读判定，不写证据、不触发超限处理链）。

**参数表**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 基线 | 字典型 | 是 | None | 容量基线声明；必需字段与取值口径见 `启动监督器/容量基线.py` 的 必需基线字段（线程上限/进程上限/内存上限MB/队列长度上限/文件句柄上限/临时空间上限MB/单次调用超时秒/每分钟重启上限），任一字段缺失或非正数判 参数不合法。本包不替调用方编造阈值。 |
| 临时目录 | 文本型 | 否 |  | 临时空间采样目录；留空取系统临时目录 |

**返回结构**：结果型（统一结果：成功/值/错误码/错误说明/可重试/详细信息）

| 值字段 | 说明 |
| --- | --- |
| 健康 | 逻辑型，true=全部基线项都在限内且采样无失败 |
| 超限项 | 列表型，超限或采样失败的项（字段/声明值/实测值，采样失败项带 采样失败=true 与 错误说明） |
| 采样 | 字典型，本次真实采样快照（线程数/进程数/内存MB/文件句柄数/队列深度/临时空间MB 等） |
| 结论 | 文本型，本次健康判定结论原文 |
| 检查项数 | 整数型，本次比对的基线字段条数 |

**实测真实返回**（2026-09-17 真实调用：`后端核心.启动()` 装配 660 能力 + 加载器单包装配本包后经唯一入口 `后端.调用`）：
