# 文件系统支持库（后端纯标准库原子能力）

原子文件系统能力：读取/写入/判断存在/列出目录/删除/复制/移动/获取大小/
获取修改时间/创建目录/受控二进制读取/头部读取/临时资源登记清理。
只依赖 Python 标准库，无第三方依赖。文件读取一律显式关闭句柄。

## 公开能力

- 文本：读取文件 / 写入文件（自动创建父目录）。
- 查询：判断存在（平台既有契约：直接返回布尔，非法参数视为不存在）/
  列出目录 / 获取大小 / 获取修改时间。
- 变更：删除文件（不存在幂等成功）/ 复制文件 / 移动文件 / 创建目录。
- 受控读取：读取二进制文件 / 读取文件头部字节（受控根 + 相对路径双重
  边界校验，防路径逃逸，只读头部不加载全文件）。
- 临时资源：登记临时资源 / 清理全部临时资源（路径前缀非空时只清理匹配项，
  无匹配返回 资源不存在）。

## 调用方式

```python
from 支持库.后端.文件系统 import 读取文件, 写入文件, 判断存在

结果 = 写入文件("/tmp/示例.txt", "内容")
if 结果.成功:
    已写入 = 结果.值

结果 = 读取文件("/tmp/示例.txt", 编码="utf-8")
if 结果.成功:
    内容 = 结果.值

存在 = 判断存在("/tmp/示例.txt")   # 平台既有契约：直接布尔
```

## 错误码

参数不合法 / 文件不存在 / 目录不存在 / 路径越界 / 文件超限 / 文件读取失败 /
文件不可写 / 文件删除失败 / 文件复制失败 / 文件移动失败 / 文件大小读取失败 /
修改时间读取失败 / 目录创建失败 / 目录读取失败 / 资源不存在 / 清理失败。

## 边界

- 参数缺失或类型非法返回 参数不合法；文件系统异常转换为稳定错误码，
  不吞异常、不以成功形状伪装失败。
- 读取二进制文件/读取文件头部字节 的受控根目录 + 相对路径组合阻止
  路径逃逸；实现只经包级中文入口（__init__.py）暴露。
