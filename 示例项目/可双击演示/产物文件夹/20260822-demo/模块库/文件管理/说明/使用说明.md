# 文件管理模块

基础模块：组合文件系统与资源管理支持库公开能力，经
`公共契约.能力契约.调用器.获取能力调用器().调用能力(能力id, 参数)` 调用，
不直接导入支持库/提供者实现。失败返回统一错误结构。

## 公开能力

- 读取文件内容：读取文本文件内容（默认 utf-8），返回 结果[文本]。
- 写入文件并创建目录：写入文本文件（默认 utf-8，自动建父目录）。
- 复制文件并创建目录 / 移动文件并创建目录 / 幂等删除文件：文件基本操作。
- 列出文件：列出目录下条目名称（排序），返回 结果[名称列表]。
- 受控读取二进制内容：受控根目录内按相对路径读取二进制文件；相对路径越出受控根目录时返回「路径越界」，超过最大字节数时返回「文件超限」，文件缺失返回「文件不存在」。
- 受控读取文件头部：只读文件头部 N 字节，不加载全文件；错误码透传「路径越界」「文件不存在」「文件读取失败」。
- 流式创建摘要：大文件分块流式创建 sha256 内容摘要（经 资源管理.创建内容摘要），文件缺失返回「文件不存在」，读取异常返回「摘要失败」。

错误码（路径越界 / 文件不存在 / 文件超限 / 文件读取失败 / 摘要失败）由支持库
统一结构透传，来源标记为支持库或本模块；调用器未装配或支持库不可用时返回
「提供者不可用」，不向调用方抛异常。

## 调用方式

```python
from 公共契约.能力契约.调用器 import 获取能力调用器

调用器 = 获取能力调用器()
结果 = 调用器.调用能力("文件管理.读取文件", {"文件路径": "示例/文件.txt"})
```
